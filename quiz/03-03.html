1. 若 lim(x→0) f(x) = 2，关于 f(0) 能得出什么？

  1. f(0) > 1
  2. f(0) > 0
  3. 什么也得不出——f(0) 可取任意值，甚至无定义

答案： C. 局部保号性只管去心邻域，从不涉及 x₀ 本身。

2. 若 lim(x→x₀) f(x) = A > 0，好用形式保证在某去心邻域内：

  1. f(x) > A
  2. f(x) > A/2
  3. f(x) = A

答案： B. x₀ 附近 f(x) > A/2——符号强度减半，但留有可用的余量。

3. f → A，g → B，要得 lim f/g = A/B，需要：

  1. A ≠ 0
  2. B ≠ 0
  3. A ≠ 0 且 B ≠ 0

答案： B. 只要求分母极限非零；A = 0 没问题。

4. x → 0 时 f → 0，g → 0，则 lim f/g：

  1. 等于 1
  2. 等于 0
  3. 无法由商的法则决定

答案： C. 门关了：x²/x → 0，x/x → 1，x/x² 无有限极限。

5. 为什么函数的有界性只是局部的？

  1. 因为极限不一定唯一
  2. 没有“前面有限项”可吸收；f 在远离 x₀ 处可能无界
  3. 因为 f 必须连续

答案： B. 例如 1/x 在 x₀ = 1 处极限为 1，但在 0 附近无界。

6. 数列的尾部 n > N 翻译成：

  1. f 的整个定义域
  2. 去心邻域 0 < |x − x₀| < δ
  3. 单点 x₀

答案： B. 机制不变，地址改变：尾部变成去心邻域。

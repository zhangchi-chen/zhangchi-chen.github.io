三重积分

1. 1. 被积函数只依赖 z，且 V 的每个水平截面都是圆盘。哪种方法能立刻化成一元积分？
  1. A先一后二：先沿每根竖柱对 z 积分
  2. B先二后一：每个截面上的积分等于 f(z) 乘截面面积
  3. C两者都不行，必须先换球面坐标
    4. 正确答案：B. 截面积分等于 f(z) 乘 Dz 的面积，只剩对 z 的一元积分。
2. 2. V 在球面 x² + y² + z² = 4 之内、锥面 z = √(x² + y²) 之上，它的球面坐标范围是：
  1. A0 ≤ r ≤ 2, 0 ≤ φ ≤ π/4, 0 ≤ θ ≤ 2π
  2. B0 ≤ r ≤ 2, π/4 ≤ φ ≤ π/2, 0 ≤ θ ≤ 2π
  3. C0 ≤ r ≤ 4, 0 ≤ φ ≤ π/4, 0 ≤ θ ≤ 2π
    4. 正确答案：A. 锥面化为 φ = π/4，锥面之上就是更靠近 z 轴；球面是 r = 2。
3. 在球面坐标的小格子里，r² sin φ 的两部分各从哪里来？
  1. A一个 r 来自 φ 方向的边 r dφ；r sin φ 来自 θ 方向的边，即半径 r sin φ 的纬线圈上的弧
  2. Br² 来自径向的边 dr；sin φ 来自锥面
  3. C两个 r 来自两个球面；sin φ 用来修正厚度
    4. 正确答案：A. 三条棱是 dr、r dφ、r sin φ dθ，相乘得 r² sin φ dr dφ dθ。
4. 4. V 由抛物面 2(x² + y²) = z 与平面 z = 4 围成。∭V (x² + y²) dV 在柱面坐标下应写成：
  1. A∫02π dθ ∫0√2 r³ dr ∫2r²4 dz
  2. B∫02π dθ ∫0√2 r² dr ∫2r²4 dz
  3. C∫02π dθ ∫02 r³ dr ∫2r²4 dz
    4. 正确答案：A. 被积函数 r² 乘雅可比 r 得 r³；2r² = 4 给出 r = √2；结果是 8π/3。
5. 一位同学用 r² cos φ dr dφ dθ、0 ≤ φ ≤ π 在半径 R 的球上积分 1，他得到：
  1. A(4/3)πR³
  2. B0
  3. C2πR³/3
    4. 正确答案：B. ∫0π cos φ dφ = 0，球的体积竟成了零，因子应是 sin φ。
6. 6. 用垂直于 x 轴的平面在 x 处（|x| < a）截椭球 x²/a² + y²/b² + z²/c² ≤ 1，截面面积是：
  1. Aπbc(1 − x²/a²)
  2. Bπbc√(1 − x²/a²)
  3. Cπab(1 − x²/a²)
    4. 正确答案：A. 截面是半轴为 b√(1 − x²/a²) 与 c√(1 − x²/a²) 的椭圆，面积是 π 乘两半轴。

介值定理

点击选项下方按钮查看答案与解析。

1. 哪个条件让零点存在定理成为介值定理中 μ = 0 的情形？

A.f(a)·f(b) > 0B.f(a)·f(b) < 0C.f(a) = f(b)
答案: B. f(a)·f(b) < 0 说明两端异号，所以 0 严格介于 f(a) 与 f(b) 之间，取 μ = 0 即可。

2. 证明中（设 f(a) < μ < f(b)），点 x₀ 的定义是：

A.sup E，其中 E = {x ∈ [a, b] : f(x) < μ}B.第一个满足 f(x) = μ 的 xC.中点 (a + b)/2
答案: A. E 含有 a，且以 b 为上界，所以 x₀ = sup E 存在；连续性迫使 f(x₀) = μ。

3. 若 x₀ = sup E 且 f(x₀) < μ，为什么矛盾？

A.函数在 x₀ 处会间断B.E 会是空集C.x₀ 右侧附近的点也属于 E，x₀ 就不再是上界
答案: C. 由连续性，x₀ 附近一整段都满足 f < μ（且因 f(b) > μ 有 x₀ < b），所以 E 越过了 x₀。

4. 对 p(x) = x³ − 2x + 2，零点存在定理保证哪个区间内有根？

A.(−1, 0)B.(0, 1)C.(−2, −1)
答案: C. p(−2) = −2 < 0，p(−1) = 3 > 0。另外两个区间的端点值同号。

5. 对此 p 在 [−2, −1] 上二分：p(−1.5) = 1.625 > 0。应保留哪一半？

A.两半都行B.[−2, −1.5]C.[−1.5, −1]
答案: B. p(−2) < 0 < p(−1.5)，变号——也就是根——被关在 [−2, −1.5] 里。

6. 设 f 连续且 f([a, b]) ⊆ [a, b]。用哪个辅助函数证明存在不动点？

A.F(x) = f(x) − xB.F(x) = f(x) + xC.F(x) = x·f(x)
答案: A. F(a) = f(a) − a ≥ 0，F(b) = f(b) − b ≤ 0；要么端点就是不动点，要么由零点存在定理得到 x₀，使 f(x₀) = x₀。

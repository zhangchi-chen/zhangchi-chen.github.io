Improper integrals with a parameter: uniform convergence returns

← Notes · Index
1. 1. What separates uniform from pointwise convergence of ∫c+∞ f(x, y)dy on I?
  1. AUniform means the tails shrink faster than 1/M.
  2. BThe cutoff N may depend on ε but not on x.
  3. CUniform means the limit Φ(x) is continuous.
    4. Correct: B. Definition 1 asks for one N serving all x ∈ I; no rate is required, and continuity of Φ is a consequence (Theorem 19.10, with f continuous), not the definition.
2. 2. Which argument proves that ∫1+∞ sin(xy)/y² dy converges uniformly on (−∞, +∞)?
  1. A|sin(xy)/y²| ≤ 1/y² and ∫1+∞ dy/y² = 1: M-test.
  2. B|sin(xy)/y²| ≤ 1/y and ∫1+∞ dy/y converges: M-test.
  3. CNone: sin(xy) oscillates faster as |x| grows.
    4. Correct: A. the bound 1/y² holds for every real x and is integrable on [1, +∞); in B the dominating integral ∫ dy/y diverges, and C ignores that the bound needs no x.
3. 3. Why is ∫0+∞ sin(xy)/y dy not uniformly convergent on (0, +∞)?
  1. AFor some x > 0 the integral diverges.
  2. BIts value (π/2)sgn x is discontinuous on (0, +∞).
  3. CFor every M, at x̄ = 1/M the window [πM/3, 2πM/3] beyond M carries an integral ≥ (ln 2)/2.
    4. Correct: C. the Cauchy criterion fails with ε₀ = (ln 2)/2; A is false (it converges to π/2 for every x > 0), and B is false (Φ ≡ π/2 there).
4. 4. In Theorem 19.11, which integral must converge uniformly on I?
  1. A∫f dy, and ∫fx dy needs only to converge.
  2. B∫fx dy, while ∫f dy needs only to converge.
  3. CNeither; convergence of both is enough.
    4. Correct: B. the two-column table: ∫f dy in the “converges” column, ∫fx dy in the “converges uniformly” column.
5. 5. A student checks that ∫0+∞ sin(xy)/y dy converges uniformly on [1, 2] and writes Φ′(x) = ∫0+∞ cos(xy) dy. What is wrong?
  1. AThe hypothesis concerns ∫fx dy, and ∫0+∞ cos(xy) dy diverges; in fact Φ′ = 0.
  2. BNothing; uniform convergence of ∫f dy is the hypothesis.
  3. CThe convergence on [1, 2] is not uniform.
    4. Correct: A. ∫0A cos(xy) dy = sin(Ax)/x has no limit as A → +∞; Φ ≡ π/2 on [1, 2], so Φ′ = 0. C is false: [1, 2] ⊂ [δ, +∞).

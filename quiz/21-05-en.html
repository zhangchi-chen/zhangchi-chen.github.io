Green's formula: one lap around the boundary sees the whole interior

← Notes · Index
1. 1. D is the region between an outer circle L₁ and an inner circle L₂. For the boundary of D to be taken in the positive direction, how must L₂ run?
  1. Acounterclockwise
  2. Bclockwise
  3. Ceither way, since the cut cancels
    4. Correct: B. walking clockwise around the hole is what keeps D on your left.
2. 2. L₁ is a simple closed curve around the origin, L₂ a simple closed curve that does not enclose it, both positively oriented. The values of the integral below on L₁ and on L₂ are: ∮ (x dy − y dx)/(x² + y²)
  1. A0, 0
  2. B2π, 2π
  3. C2π, 0
    4. Correct: C. off the origin ∂Q/∂x = ∂P/∂y, so a loop that leaves the origin outside gives 0; cutting out a small circle shows every positive simple loop around the origin gives 2π.
3. 3. Use S = ½∮(x dy − y dx) for the region bounded by the astroid x = a cos³t, y = a sin³t, 0 ≤ t ≤ 2π.
  1. A3πa²/8
  2. B3πa²/4
  3. Cπa²
    4. Correct: A. x dy − y dx = 3a² sin²t cos²t dt, whose integral over a full turn is 3πa²/4; half of that is 3πa²/8 (B forgets the ½).
4. 4. In the proof, D = {ψ₁(y) ≤ x ≤ ψ₂(y), c ≤ y ≤ d}. For fixed y, the inner integral below equals: ∫ from ψ₁(y) to ψ₂(y) of ∂Q/∂x dx
  1. A∂Q/∂x(ψ₂(y), y) − ∂Q/∂x(ψ₁(y), y)
  2. BQ(ψ₂(y), y) − Q(ψ₁(y), y)
  3. CQ(ψ₁(y), y) − Q(ψ₂(y), y)
    4. Correct: B. Q is an antiderivative of ∂Q/∂x in x, so Newton–Leibniz gives right end minus left end.
5. 5. Take P = −y/(x² + y²), Q = x/(x² + y²) and L the unit circle, counterclockwise. A student writes “∂Q/∂x − ∂P/∂y = 0, so by Green’s formula ∮_L P dx + Q dy = ∬ 0 dσ = 0 over the unit disk.” Which is right?
  1. AThe student is right: the value is 0.
  2. BThe value is −2π, because of the orientation.
  3. CGreen’s formula does not apply here; the value is 2π.
    4. Correct: C. P and Q are undefined at the origin, which lies inside the disk, so the hypothesis fails; on the circle the integrand is dt and the integral is 2π.

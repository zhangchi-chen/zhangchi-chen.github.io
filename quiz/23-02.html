反函数定理与隐函数定理全貌

1. 1. 反函数定理在点x₀处要求什么？
  1. Af′(x₀) = I
  2. Bdet f′(x₀) ≠ 0
  3. Cf在整个D上是一一映射
    4. 正确答案：B. 条件(ii)只要求x₀处雅可比行列式不为零；一一映射是结论，且只在U上成立。
2. 2. m个方程、n + m个未知数时，哪个行列式在(x₀, y₀)处必须不为零？
  1. Adet F_x
  2. Bdet F_y
  3. Cdet F′
    4. 正确答案：B. F_y是m×m方阵；F_x是m×n，F′是m×(n+m)，一般不是方阵。
3. 3. 用链式法则在x₀处对f⁻¹(f(x)) = x求导，得到：
  1. A(f⁻¹)′(f(x₀)) · f′(x₀) = I
  2. B(f⁻¹)′(x₀) = 1/f′(x₀)，逐个元素取倒数
  3. C(f⁻¹)′(f(x₀)) + f′(x₀) = I
    4. 正确答案：A. 链式法则把导数矩阵相乘，恒等映射的导数是单位矩阵I。
4. 4. 当m = n = 1时，公式f′ = −(F_y)⁻¹F_x变成：
  1. A−F_y/F_x
  2. B−F_x/F_y
  3. CF_x · F_y
    4. 正确答案：B. 1×1矩阵的逆就是倒数：−(1/F_y)·F_x = −F_x/F_y，即第18章的公式。
5. 球坐标变换在哪里有det f′ = 0？
  1. A平面z = 0上
  2. Bz轴上
  3. C球面r = 1上
    4. 正确答案：B. det f′ = r² sin θ恰在r = 0或sin θ = 0时为0，即x = y = 0；在z = 0上θ = π/2，det = r²。
6. 6. ⚠️ “det f′在R²上处处不为零，所以f在整个R²上是一一映射。”
  1. A对，由反函数定理
  2. B错：(eˣcos y, eˣsin y)的det为e²ˣ > 0，但f(x, y + 2π) = f(x, y)
  3. C对，只要f′连续
    4. 正确答案：B. 定理只管局部：每点附近一一映射，整个平面却被绕了圈。

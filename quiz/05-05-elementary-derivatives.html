1. 1. 从 (eu)′ = eu 出发，哪条路线能推出 (ax)′？

  1. A. A. ax = ex ln a, chain rule → ax ln a
  2. B. B. inverse rule on ex → ax/ln a
  3. C. C. power rule with exponent x → x·ax−1
A — 内层 u = x ln a 的导数是 ln a，外层照抄 ex ln a = ax。

2. 2. 把 x = tan y（|y| < π/2）反过来，反函数法则给出 (arctan x)′ = ？

  1. A. A. 1/(1 + x²)
  2. B. B. cos²x
  3. C. C. 1/√(1 − x²)
A — dy/dx = 1/sec²y = 1/(1 + tan²y) = 1/(1 + x²)；B 其实是 cos²y，变量写错了。

3. 3. (cos(x³))′ = ？

  1. A. A. −sin(x³)
  2. B. B. −3x² sin(x³)
  3. C. C. 3x² cos(x³)
B — 外层 cos u 给出 −sin u，内层 u = x³ 贡献 3x²。

4. 4. (√(1 − 2x))′ = ？（x < 1/2）

  1. A. A. 1/(2√(1 − 2x))
  2. B. B. −1/√(1 − 2x)
  3. C. C. −2√(1 − 2x)
B — 幂公式取 α = 1/2 得 (1/2)(1 − 2x)−1/2，再乘内层导数 −2。

5. 5. f(x) = ex（x ≤ 0），ax + b（x > 0）。哪组取值使 f 在 0 处可导？

  1. A. A. a = 1, b = 0
  2. B. B. a = 1, b = 1
  3. C. C. a = 0, b = 1
B — 连续要求 b = e⁰ = 1；左侧 (eʰ − 1)/h → 1，右侧 → a，所以 a = 1。

6. 6. 判断：x²（x ≤ 1）与 ax + b（x > 1）在 x = 1 处衔接，只需两段分别求导并在 1 处相等。

  1. A. A. True: this gives a = 2 and finishes the job
  2. B. B. False: continuity forces a + b = 1, then one-sided quotients give a = 2, b = −1
  3. C. C. True, as long as a = b
B — 捷径只定出 a = 2，b 仍任意；取 b = 0 时 f 在 1 处跳跃，不可导。

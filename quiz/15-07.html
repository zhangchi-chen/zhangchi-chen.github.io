1. 1. 2π周期的波g是奇函数，且g(x + π) = −g(x)。它的傅里叶级数里可能有哪些项？
  1. A各种频率的余弦
  2. B只有奇次正弦：sin x, sin 3x, sin 5x, …
  3. C只有偶次正弦
    4. 正确答案：B. 奇函数让余弦全为零；半周期翻转让偶次谐波全为零。
2. 2. 2π周期的波h是偶函数，且h(x + π) = −h(x)。它的级数含有：
  1. A只有cos x, cos 3x, cos 5x, …
  2. B只有sin x, sin 3x, sin 5x, …
  3. C常数项加cos 2x, cos 4x, …
    4. 正确答案：A. 偶函数让正弦全为零；翻转让偶数项全为零，常数项a₀也不例外。
3. 3. 在跳跃点x = 0附近，N增大时，部分和S_N的最高峰会怎样？
  1. A降到波高π/4。
  2. B离跳跃点越来越远。
  3. C向跳跃点挤近，但高度停在0.93左右，高于π/4 ≈ 0.785。
    4. 正确答案：C. 峰值位于x = π/(2m) → 0，高度趋于Si(π)/2 ≈ 0.926：吉布斯现象。
4. 4. 只保留矩形波的b₁、b₃、b₅，其余丢掉。保留的三个系数会怎样？
  1. A不变：仍是1、1/3、1/5。
  2. B必须重新计算来弥补损失。
  3. C全部翻倍。
    4. 正确答案：A. 正弦两两正交：每个bₙ单独计算，截断本身就是均方意义下的最佳逼近。
5. 5. 定理15.1能证明矩形波的级数收敛吗？
  1. A能：系数趋于0。
  2. B能：级数处处收敛。
  3. C不能：1 + 1/3 + 1/5 + ⋯ 发散；逐点收敛靠的是狄利克雷判别法。
    4. 正确答案：C. 条件Σ(|aₙ| + |bₙ|)收敛不成立；何况极限有跳跃，一致收敛本就不可能。
6. 6. 判断：保留足够多的谐波，就能精确还原有间断的波。
  1. A对，N到49就行。
  2. B错：每个部分和都连续，跳跃旁始终有约0.14的过冲。
  3. C对，只有跳跃点本身例外。
    4. 正确答案：B. 收敛是逐点的而非一致的：尖角从来不是免费的。

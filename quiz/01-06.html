1. arctan(tan π) = ？

A. πB. 0C. 无定义

B — tan π = 0，arctan 0 = 0；π 不在 (−π/2, π/2) 内，所以返回它的代表 0。

2. arcsin(sin 2π/3) = ？

A. 2π/3B. −π/3C. π/3

C — sin 2π/3 = √3/2，[−π/2, π/2] 中满足 sin x = √3/2 的唯一 x 是 π/3。

3. arccos(cos 7π/6) = ？

A. 7π/6B. 5π/6C. π/6

B — cos 7π/6 = −√3/2，[0, π] 中满足 cos x = −√3/2 的唯一 x 是 5π/6。

4. arctan(tan x) = x 恰在何时成立？

A. x ∈ ℝB. x ∈ [−π/2, π/2]C. x ∈ (−π/2, π/2)

C — tan 在 ±π/2 无定义，所以等式恰在开的主值区间 (−π/2, π/2) 上成立。

5. 为什么反正切函数的主值区间是开的，而反正弦函数的是闭的？

A. 这只是个人喜好B. tan 在 ±π/2 无定义，而 sin 在 ±π/2 取到 ±1C. 因为 ℝ 是开集

B — 开或闭由原函数决定：sin 取得到端点值，而 ±π/2 根本不在 tan 的定义域内。

6. sin(arcsin x) = x 对哪些 x 成立？

A. 每个 x ∈ ℝB. 每个 x ∈ [−1, 1]C. 每个 x ∈ [−π/2, π/2]

B — 反正弦函数只在 [−1, 1] 上有定义；区间外这个复合根本不存在。

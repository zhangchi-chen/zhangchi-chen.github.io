In the ε–δ definition of lim(x→x₀) f(x) = A, what role does the value f(x₀) play?

A. It must equal A.B. It must at least be defined.C. It plays no role at all.

C. The condition 0 < |x − x₀| < δ excludes x = x₀, so f(x₀) is never checked.

Why does the ε–N definition never need the “0 <” clause?

A. Because sequences are always monotone.B. Because ∞ is not an index: no term sits at the destination.C. Because N is an integer.

B. The tail n > N never contains “n = ∞” — naturally punctured; but x can equal x₀.

Suppose lim(x→2) f(x) = 5 and only f(2) is changed from 5 to 9. The limit…

A. becomes 9B. stays 5C. no longer exists

B. Changing the value at x₀ alone never changes the limit: the punctured neighborhood never looks at x₀.

Which part of the ε–δ definition corresponds to “n > N” in ε–N?

A. for every ε > 0B. 0 < |x − x₀| < δC. |f(x) − A| < ε

B. Both specify where the inspector checks: sequences check the tail, functions check the punctured neighborhood.

For lim(x→1) (2x + 1) = 3 with ε = 0.1, which δ certainly works?

A. δ = 0.05B. δ = 0.1C. δ = 0.2

A. One needs 2|x − 1| < 0.1, i.e. |x − 1| < 0.05; δ = ε/2 = 0.05 works (anything smaller also works), while δ = 0.1 fails, e.g. at x = 1.08.

If δ = 0.3 works for a given ε, then δ = 0.1…

A. also worksB. may failC. works only if 0.3 is the largest workable δ

A. A narrower window only admits fewer points, and those already satisfy |f(x) − A| < ε.

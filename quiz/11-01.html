无穷积分

← 讲稿 · 目录
1. 1. 设f在每个[a, u]上可积，∫a+∞ f(x) dx 是怎样定义的？
  1. A求原函数F，再算F(+∞) − F(a)。
  2. B定义为 limu→+∞ ∫au f(x) dx（极限存在时）。
  3. C取一个很大的u（如10⁶）时∫au f(x) dx的值。
    4. 正确答案：B. 先算到u的定积分，再令u→+∞取极限；无穷不能代入，一个很大的u也不是极限。
2. 2. 下列哪个积分收敛？
  1. A∫1+∞ dx/x
  2. B∫1+∞ dx/√x
  3. C∫1+∞ dx/x3/2
    4. 正确答案：C. p = 3/2 > 1，值为1/(3/2 − 1) = 2；p = 1得ln u → +∞，p = 1/2得2(√u − 1) → +∞。
3. 3. ∫2+∞ dx/(x ln x) 的情况如何？
  1. A发散。
  2. B收敛，值为ln 2。
  3. C收敛，值为1/ln 2。
    4. 正确答案：A. 令t = ln x，化为∫ln 2+∞ dt/t，即p = 1的情形：ln U − ln(ln 2) → +∞。
4. 4. 研究∫−∞+∞ f(x) dx时，可以在哪里把实数轴切开？
  1. A只能在a = 0处。
  2. B任意实数a处；收敛性与积分值都与a无关。
  3. C只能在f(a) = 0的点处。
    4. 正确答案：B. 切点从a移到b，只是把有限的∫ab从一半挪到另一半。
5. 5. 判断：“只要limu→+∞ ∫−uu f(x) dx存在，∫−∞+∞ f(x) dx就收敛。”
  1. A正确：这就是定义。
  2. B正确，但只对奇函数成立。
  3. C错误：两半必须各自收敛。
    4. 正确答案：C. 两个发散的半边可能互相抵消，使对称极限存在；定义要求两半分别收敛。
6. 6. 当f ≥ 0时，“∫1+∞ f(x) dx发散”是什么意思？
  1. A图像下方的无尽区域面积为+∞。
  2. B计算还没有做完。
  3. C面积可能是负数。
    4. 正确答案：A. f ≥ 0时累计积分只增不减，没有有限极限就趋于+∞，这本身就是完整的答案。

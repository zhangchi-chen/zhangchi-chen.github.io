Formula self-check: let the circle and the sphere catch your mistakes

1. 1. Rotate y = √(r² − x²), −r ≤ x ≤ r, about the x-axis. What do 2π∫y√(1+y′²)dx and 2π∫y dx give?
  1. A4πr², π²r²
  2. B4πr², 2πr²
  3. Cπ²r², 4πr²
    4. Correct: A. y√(1+y′²) = r, so the first is 2π·r·2r = 4πr²; the second is 2π times the half-disk area πr²/2, i.e. π²r².
2. 2. Which pair of computations both return πr² for a disk of radius r?
  1. A½∫02π r²dθ and |∫02π r sin t·(−r sin t)dt|
  2. B∫02π r²dθ and |∫02π r sin t·(−r sin t)dt|
  3. C½∫02π r²dθ and ∫02π r dt
    4. Correct: A. ½·r²·2π = πr² and r²∫₀^2π sin²t dt = r²·π = πr²; B’s first integral is 2πr², and C’s second is the circumference 2πr.
3. 3. Rotate y = (r/h)x, 0 ≤ x ≤ h, about the x-axis. What does S = 2π∫y√(1+y′²)dx give?
  1. Aπrh
  2. Bπrl, l = √(r² + h²)
  3. Cπr²h/3
    4. Correct: B. √(1+y′²) = l/h, so S = 2π(r/h)(l/h)·h²/2 = πrl; πrh is what the cylinder element would give.
4. 4. A student writes the arc length as ∫ₐᵇ √(1 + y²) dx. What does the dimension check say?
  1. AFine: the result is a length.
  2. BIllegal: 1 + y² adds a pure number to a squared length.
  3. CDimensions fine, only the coefficient is off.
    4. Correct: B. y carries length, so y² is L² while 1 is a pure number; the correct factor is √(1 + y′²), with y′ dimensionless.
5. 5. Half-remembering the volume of a solid of revolution, which candidate passes both the dimension check and the sphere test 4πr³/3?
  1. A2π∫y dx
  2. Bπ∫y² dx
  3. C2π∫y² dx
    4. Correct: B. A is only L²; C is L³ but gives 2π·4r³/3 = 8πr³/3 for the sphere; B gives π·4r³/3 = 4πr³/3.
6. 6. True or false: dimensional analysis would catch 2π∫y dx as a formula for the surface area of the sphere.
  1. ATrue: its dimension is wrong.
  2. BFalse: it is L², like the correct formula; only 4πr² exposes it.
  3. CTrue: it gives a volume.
    4. Correct: B. √(1+y′²) is a pure number, so 2π∫y dx and 2π∫y√(1+y′²)dx are both L²; only the values π²r² versus 4πr² tell them apart.

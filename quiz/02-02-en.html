If aₙ → a and aₙ → b, then necessarily ( )

A. a = bB. a ≠ bC. a and b may differ

A. Take ε₀ = |b−a|/2: the two ε₀-bands around a and b are disjoint, yet for large n the term aₙ would have to lie in both — contradiction.

Which sequence below is bounded but not convergent?

A. aₙ = nB. aₙ = (−1)ⁿC. aₙ = 1/n

B. |(−1)ⁿ| ≤ 1 is bounded, but it oscillates between −1 and 1, so by uniqueness it cannot converge. A is unbounded; C converges to 0 — boundedness is only a necessary condition.

If lim aₙ = 2 and a′ = 1, then there is N such that for all n > N, ( )

A. aₙ > 2B. aₙ > 1C. aₙ > 0 but not necessarily > 1

B. Sign preservation: for any a′ ∈ (0, 2), eventually aₙ > a′. It guarantees exceeding every number between 0 and 2 — but not 2 itself.

In the classic proof that a convergent sequence is bounded, the standard choice is ( )

A. ε = 1B. ε₀ = |b−a|/2C. ε = a − a′

A. Each proof has its own key: boundedness uses ε = 1 (the tail lands in (a−1, a+1)); uniqueness uses ε₀ = |b−a|/2; sign preservation uses ε = a − a′ (often a′ = a/2).

If aₙ ≤ bₙ for all large n and both sequences converge, then ( )

A. lim aₙ < lim bₙB. lim aₙ ≤ lim bₙC. necessarily lim aₙ = lim bₙ

B. A strict inequality may degenerate to equality in the limit: 1/n > 0 for every n, yet lim 1/n = 0.

In the corollary's proof with ε = (b−a)/2, the intermediate cutoff is ( )

A. (b−a)/2B. (a+b)/2C. b − a

B. For large n: aₙ < a + ε = (a+b)/2 = b − ε < bₙ — the two bands meet exactly at the midpoint.

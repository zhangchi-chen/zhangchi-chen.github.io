拉格朗日中值定理

← 讲稿 · 目录
1. 1. 哪个辅助函数能让罗尔定理完成证明？
  1. AF(x) = f(x) − f(a) − f′(a)(x − a)
  2. BF(x) = f(x) − f(a) − [(f(b) − f(a))/(b − a)](x − a)
  3. CF(x) = f(x) − [(b − a)/(f(b) − f(a))](x − a)
    4. 正确答案：B. F(a) = 0，F(b) = f(b) − f(a) − (f(b) − f(a)) = 0，罗尔定理可用；A 减的是 a 处的切线，C 用了倒数斜率，两端的值一般不相等。
2. 2. 记 h = b − a，哪一种写法与 f(b) − f(a) = f′(ξ)(b − a)，a < ξ < b 等价？
  1. Af(a + h) − f(a) = f′(θh)h，0 < θ < 1
  2. Bf(a + h) − f(a) = f′(a + θh)h，θ > 1
  3. Cf(a + h) − f(a) = f′(a + θh)h，0 < θ < 1
    4. 正确答案：C. θ = (ξ − a)/(b − a) 严格介于 0 与 1 之间，所以 ξ = a + θh；A 丢了起点 a，B 让 ξ 跑出了区间。
3. 3. f 在 (−1, 1) 内可导，对其中每个 x 有 f′(x) = 0，且 f(0) = 3。f(1/2) 等于多少？
  1. A3
  2. B3/2
  3. C无法确定。
    4. 正确答案：A. (−1, 1) 是区间，由推论 1，f 是常量函数：f(1/2) = f(0) = 3。
4. 4. 对一切实数 x 有 f′(x) = g′(x)，且 f(0) = 5，g(0) = 2。f(x) − g(x) 等于什么？
  1. A对每个 x 都等于 7
  2. B对每个 x 都等于 3
  3. C随 x 而变。
    4. 正确答案：B. 由推论 2，f − g 是常数，在 x = 0 处等于 5 − 2 = 3。
5. 5. 当 x ≤ 1 时 f(x) = x²，当 x > 1 时 f(x) = 2x − 1。f′(1) 等于多少？
  1. A1
  2. B不存在，因为 f 是分段函数。
  3. C2
    4. 正确答案：C. f 在 1 处连续（两边都得 1），两侧导数都趋于 2（左边 2x → 2，右边恒为 2），由导数极限定理得 f′(1) = 2。
6. 6. f 在区间 I 上可导，除某一点处 f′ = 0 外，处处有 f′(x) > 0。判断：“所以 f 在 I 上不是递增的。”
  1. A对：f′ 的一个零点就破坏了递增。
  2. B错：f 仍然递增，就像 x³ 一样。
  3. C没有 f 的表达式就无法判断。
    4. 正确答案：B. 对 x₁ < x₂，拉格朗日中值定理给出 f(x₂) − f(x₁) = f′(ξ)(x₂ − x₁) ≥ 0，所以 f 递增；x³ 在 0 处导数为零就是例子，推论 1 要求 f′ 在整个区间上为零，而不是在一个点上。

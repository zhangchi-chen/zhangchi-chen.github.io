1. 1. Which inner function satisfies the third hypothesis of Theorem 3.8 at x₀ = 0, with u₀ = 0?

  1. A. A. x sin(1/x)
  2. B. B. x²
  3. C. C. the constant f(x) ≡ 0
B — x² > 0 for every x ≠ 0, so it avoids 0 on every hollow neighbourhood of 0; the other two take the value 0 arbitrarily close to 0.

2. 2. Classify lim cos(x sin(1/x)) as x → 0 in the 2×2 safety table.

  1. A. A. inner avoids 0; outer not continuous at 0
  2. B. B. inner keeps hitting 0; outer continuous at 0: safe, limit 1
  3. C. C. neither patch: no limit
B — x sin(1/x) is 0 at every 1/(nπ), so Patch A fails; but cos is continuous at 0, so Patch B gives cos 0 = 1.

3. 3. Which sequence xₙ → 0 shows that f(x) = x sin(1/x) keeps hitting 0?

  1. A. A. xₙ = 1/n
  2. B. B. xₙ = 1/(nπ)
  3. C. C. xₙ = 2/((2n+1)π)
B — f(1/(nπ)) = sin(nπ)/(nπ) = 0. For A, sin n ≠ 0 because π is irrational; for C, sin((2n+1)π/2) = ±1.

4. 4. Let f(x) ≡ 0, g(u) = 1 for u ≠ 0 and g(0) = 2. What is lim g(f(x)) as x → 0?

  1. A. A. 1
  2. B. B. 2
  3. C. C. it does not exist
B — g(f(x)) = g(0) = 2 for every x, a constant; the limit of g at 0 (which is 1) never enters.

5. 5. True or false: lim g(f(x)) always equals g(lim f(x)).

  1. A. A. true
  2. B. B. true as soon as the inner function avoids its limit value
  3. C. C. false in general; it is guaranteed when g is continuous at lim f(x)
C — take f(x) = x, g(u) = 1 for u ≠ 0, g(0) = 2: f avoids 0, yet the limit is 1 while g(lim f(x)) = g(0) = 2. Patch A gives the limit of g, not g(u₀).

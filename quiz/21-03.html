极坐标与变量变换

1. 对极坐标变换 x = r cos θ, y = r sin θ ，函数行列式 J(r, θ) 等于：
  1. A1
  2. Br
  3. Cr²
    4. 正确答案：B. 行列式展开为 r cos²θ + r sin²θ = r。
2. 2. 区域 x² + y² ≤ 2x （原点在边界上）的极坐标上下限是：
  1. A−π/2 ≤ θ ≤ π/2, 0 ≤ r ≤ 2 cos θ
  2. B0 ≤ θ ≤ 2π, 0 ≤ r ≤ 2 cos θ
  3. C−π/2 ≤ θ ≤ π/2, 0 ≤ r ≤ 1
    4. 正确答案：A. 由 r² ≤ 2r cos θ 得 r ≤ 2 cos θ，这要求 cos θ ≥ 0。
3. 3. 令 u = x − y, v = x + y ，在三角形 x ≥ 0, y ≥ 0, x + y ≤ 1 上，积分 ∬ e(x−y)/(x+y) dx dy 等于：
  1. A∫01 dv ∫−vv eu/v du
  2. B∫01 dv ∫0v eu/v du
  3. C½ ∫01 dv ∫−vv eu/v du
    4. 正确答案：C. J = ½，三角形变为 −v ≤ u ≤ v，0 ≤ v ≤ 1，结果为 (e − e⁻¹)/4。
4. 4. 同学把半径为 3 的圆盘面积写成 ∫02π∫03 dr dθ 。结果是什么？
  1. A6π, 这就是面积
  2. B6π, 那是周长，面积是 9π
  3. C9π, 因为 f = 1 时可以不乘 r
    4. 正确答案：B. 漏掉 r 得 2π · 3 = 6π，是周长；乘上 r 才得 π · 3² = 9π。
5. 5. 对交换变换 x = v, y = u 有 J = ∂(x, y)/∂(u, v) = −1 。在 ∬D f dx dy = ∬Δ f(v, u) · k du dv 中，因子 k 是：
  1. A1
  2. B−1
  3. C0
    4. 正确答案：A. 公式里用的是 |J| = 1；取 f = 1 时必须得到正的面积。
6. 6. 夹在 r, r + dr 与 θ, θ + dθ 之间的极坐标小格，两边长约为：
  1. Adr 和 dθ
  2. Br dr 和 r dθ
  3. Cdr 和 r dθ
    4. 正确答案：C. 直边长 dr，弧边长 r dθ，所以面积约为 r dr dθ。

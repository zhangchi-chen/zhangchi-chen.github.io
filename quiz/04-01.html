1. f 在 x₀ 处连续，要求哪些量相等？

A.左极限、右极限与 f(x₀)B.只需左极限与右极限C.f(x₀) 与 f(x₀ + 1)
答案: A. 连续就是三方握手：两个单侧极限都存在，并且都等于 f(x₀)。

2. x < 1 时 f(x) = x + 1，x ≥ 1 时 f(x) = 4 − x。x = 1 是……

A.可去间断点B.跳跃间断点，且右连续C.第二类间断点
答案: B. f(1⁻) = 2，f(1⁺) = 3，都存在但两样；f(1) = 3 与右极限一致。

3. x·sin(1/x) 在 0 处无定义，0 是它的……

A.可去间断点B.跳跃间断点C.第二类间断点
答案: A. |x·sin(1/x)| ≤ |x| → 0，极限 0 存在；补定义函数值为 0 即可修好。

4. f(x) = 3x + 1，x₀ = 2，ε = 0.3。哪个 δ 可行？

A.δ = 0.1B.δ = 0.2C.δ = 0.3
答案: A. |f(x) − 7| = 3|x − 2| < 3δ，需要 3δ ≤ 0.3；若 δ = 0.2，取 x = 2.15 得 0.45 > 0.3。

5. 下列哪个是第一类间断点？

A.sin(1/x) 的 0 点B.1/x² 的 0 点C.sgn x 的 0 点
答案: C. sgn x 的左右极限为 −1 和 1，都存在但两样，是跳跃间断点，属于第一类。

6. g 与 f 在 (x₀ − 0.01, x₀ + 0.01) 上相同，f 在 x₀ 处连续。g 在 x₀ 处……

A.连续B.可能间断C.一定间断
答案: A. 连续是局部性质：只与 x₀ 附近（含 x₀）的值有关，而那里 g 与 f 完全一样。

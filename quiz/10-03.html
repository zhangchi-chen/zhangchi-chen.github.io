闭合参数曲线的面积

← 讲稿 · 目录
1. 对 x = 2cos t，y = 2sin t，t 从 0 到 2π（逆时针），∫₀^{2π} x(t)y′(t) dt 等于多少？
  1. A4π
  2. B−4π
  3. C2π
    4. 正确答案：A. x y′ = 4cos²t，且 ∫₀^{2π} cos²t dt = π，所以积分为 4π；逆时针时这种读法为正。
2. 椭圆 x = 4cos t，y = 3sin t（t 从 0 到 2π）所围面积是多少？
  1. A7π
  2. B24π
  3. C12π
    4. 正确答案：C. |∫ 3sin t·(−4sin t) dt| = 12∫₀^{2π} sin²t dt = 12π，即 a = 4、b = 3 时的 πab。
3. 3. 把闭曲线平移 (h, k)，½∮(x dy − y dx) 多出什么？
  1. Ah² + k²
  2. B½(h∮dy − k∮dx), 它等于 0
  3. Chk
    4. 正确答案：B. (x + h)dy − (y + k)dx 多出 h dy − k dx，而闭合一圈 ∮dy = ∮dx = 0，所以结果不变。
4. 4. 课本由公式 (1) 和 (3) 推出公式 (4)。这个推导在什么情况下直接成立？
  1. A曲线按顺时针方向走时
  2. B曲线经过原点时
  3. C最左点和最右点把曲线切成上下两条图像时
    4. 正确答案：C. 公式 (1) 用上图像减下图像，因此每条竖线与曲线最多交两次；C 形曲线不在这个证明的范围内。
5. 5. 同学按顺时针参数化一个区域，算得 ∫ x y′ dt = −5，于是报告面积为 −5。对吗？
  1. A不对：面积是 |−5| = 5
  2. B对：顺时针的区域面积为负
  3. C不对：面积是 10
    4. 正确答案：A. 符号反映的是行进方向，与区域无关；公式 (4) 取绝对值，所以面积是 5。
6. 6. 面积为 A 的简单闭曲线按逆时针方向走一圈，∮ y x′ dt 等于什么？
  1. A+A
  2. B−A
  3. C0
    4. 正确答案：B. 逆时针时上半段从右往左走，所以 y dx 这种读法得 −A（x dy 读法得 +A）。

周期不必最小

← 讲稿 · 目录
1. 把 sin²x 当作 2π 周期函数来算，哪个系数非零？
  1. Aa₁
  2. Ba₂
  3. Cb₂
    4. 正确答案：B. sin²x = 1/2 − (1/2)cos 2x 的周期是 π，奇数号系数全为零；a₂ = −1/2，b₂ = 0。
2. 在 T/2 处切开 ∫₀ᵀ，后半段代换 x = u + T/2。因子 cos(2nπx/T) 变成：
  1. A−cos(2nπu/T) ，对每个 n
  2. Bcos(2nπu/T) ，对每个 n
  3. C(−1)ⁿ cos(2nπu/T)
    4. 正确答案：C. cos(2nπu/T + nπ) = (−1)ⁿ cos(2nπu/T)：n 为奇数时两半抵消，为偶数时相加。
3. 把 |sin x| 按周期 2π 计算，哪些傅里叶系数为零？
  1. A每个奇数 n
  2. B每个偶数 n
  3. C只有 n = 0
    4. 正确答案：A. |sin x| 的周期是 π，减半原理使每个奇数 n 的系数为零（a₁ = 0 单独验算）；偶数 n 得 −4/(π(n²−1))，所有 bₙ = 0。
4. 把 cos x 当作周期 6π 来算，cos(3·x/3) = cos x 的系数是：
  1. A1/3
  2. B1
  3. C3
    4. 正确答案：B. l = 3π 时，a₃ = (1/3π)·∫ cos²x dx（[−3π, 3π] 上）= (1/3π)·3π = 1：放大周期不改变答案。
5. 5. 判断：“一个 2π 周期函数，只要接受多出的零，就可以按周期 π 来算。”
  1. A对
  2. B只对偶函数成立
  3. C错
    4. 正确答案：C. 缩小周期就换了被计算的函数：周期 π 的公式只读一段长 π 的窗口，算出它的 π 周期复制（cos x 取 [−π/2, π/2] 得到 |cos x|，常数项 2/π 而非 0）。只有放大才安全。
6. 6. f 分段光滑、周期为 2π，奇数号系数全为零。哪一步需要收敛定理？
  1. A奇数项为零 ⇒ 级数周期为 π
  2. B级数周期为 π ⇒ f 周期为 π
  3. C计算 a₀
    4. 正确答案：B. 剩下的 cos 2mx、sin 2mx 周期都是 π，和也是，这一步不需要定理；只有收敛定理保证和就是 f（跳跃点取左右极限的平均）。

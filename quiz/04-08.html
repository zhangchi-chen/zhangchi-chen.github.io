1. 1. 在 x₀ = 0、u₀ = 0 时，哪个内函数满足定理 3.8 的第三条假设？
  1. Ax sin(1/x)
  2. Bx²
  3. C常函数 f(x) ≡ 0
    4. 正确答案：B. x ≠ 0 时 x² > 0，在 0 的空心邻域内避开 0；另外两个在 0 的任意近处都取到 0。
2. 用 2×2 安全表给 x → 0 时的 lim cos(x sin(1/x)) 归类。
  1. A内函数避开 0；外函数在 0 处不连续
  2. B内函数反复取 0；外函数在 0 处连续：安全，极限 1
  3. C两个补丁都没有：无极限
    4. 正确答案：B. x sin(1/x) 在每个 1/(nπ) 处为 0，补丁A失效；但 cos 在 0 处连续，补丁B给出 cos 0 = 1。
3. 哪个数列 xₙ → 0 能说明 f(x) = x sin(1/x) 反复取到 0？
  1. Axₙ = 1/n
  2. Bxₙ = 1/(nπ)
  3. Cxₙ = 2/((2n+1)π)
    4. 正确答案：B. f(1/(nπ)) = sin(nπ)/(nπ) = 0。A 中 sin n ≠ 0（π 是无理数）；C 中 sin((2n+1)π/2) = ±1。
4. 设 f(x) ≡ 0，u ≠ 0 时 g(u) = 1，g(0) = 2。x → 0 时 lim g(f(x)) 等于多少？
  1. A1
  2. B2
  3. C不存在
    4. 正确答案：B. 对每个 x 都有 g(f(x)) = g(0) = 2，是常数；g 在 0 处的极限 1 根本用不上。
5. 5. 判断：lim g(f(x)) 总等于 g(lim f(x))。
  1. A正确
  2. B只要内函数避开其极限值就正确
  3. C一般不对；g 在 lim f(x) 处连续时才有保证
    4. 正确答案：C. 取 f(x) = x，u ≠ 0 时 g(u) = 1，g(0) = 2：f 避开 0，极限却是 1，而 g(lim f(x)) = g(0) = 2。补丁A给出的是 g 的极限，不是 g(u₀)。

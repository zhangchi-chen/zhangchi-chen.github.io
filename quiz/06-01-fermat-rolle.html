Fermat and Rolle: self-test费马引理与罗尔定理：自测

Six questions. Pick an option, or show the answer. 共六题：点选一项，或直接显示答案。

  1. In the proof of Rolle’s theorem, which condition guarantees that f attains a maximum M and a minimum m on [a, b]?

    罗尔定理的证明里，哪个条件保证 f 在 [a, b] 上取到最大值 M 和最小值 m？

    A. The extreme value theorem (04-03) needs a continuous function on a closed interval. Condition (iii) then pushes an extremum inside, and (ii) lets Fermat’s lemma act there.

    A。最值定理（04-03）要求闭区间上连续。随后条件三把最值推到内部，条件二让费马引理在那里起作用。

  2. Which function satisfies (i) and (iii) on its interval, yet has no point with f′(ξ) = 0, showing that (ii) cannot be dropped?

    哪个函数满足条件一和条件三，却找不到 f′(ξ) = 0 的点，说明条件二不能去掉？

    B. |x| is continuous with f(−1) = f(1) = 1; its derivative is −1 or 1 away from 0 and does not exist at the corner 0. Option A breaks (iii) instead; option C satisfies all three conditions and has f′(0) = 0.

    B。|x| 连续且两端都等于 1；离开 0 时导数为 −1 或 1，尖角 0 处导数不存在。A 破坏的是条件三；C 三个条件全满足，且 f′(0) = 0。

  3. Rolle’s proof, case m < M with f(a) = f(b). Why is M or m attained strictly inside (a, b)?

    罗尔定理证明的情形 m < M，且 f(a) = f(b)。为什么 M 或 m 一定在开区间内部取到？

    C. If f(a) = f(b) = M, then m < M is taken at an interior point, and vice versa. Differentiability at the endpoints is never assumed, and the midpoint claim is simply false.

    C。若两端都等于 M，m 只能在内部取到；反之亦然。端点可导从未被假设，"中点最大"也不成立。

  4. How many real roots does x⁵ + x − 1 = 0 have?

    方程 x⁵ + x − 1 = 0 有几个实根？

    A. f′(x) = 5x⁴ + 1 ≥ 1 is never 0, so by the Rolle pattern there is at most one root. f(0) = −1 < 0 < 1 = f(1) gives at least one, in (0, 1).

    A。f′(x) = 5x⁴ + 1 ≥ 1 处处非零，按罗尔的套路至多一个根；又 f(0) = −1 < 0 < 1 = f(1)，在 (0, 1) 内至少一个。

  5. True or false: an interior point with f′(ξ) = 0 can exist only when f(a) = f(b).

    判断：只有当 f(a) = f(b) 时，内部才可能有 f′(ξ) = 0 的点。

    A. f(−1) = 1, f(2) = 4, yet f′(0) = 0: Rolle’s conditions are sufficient, not necessary. Option C names a real example with the wrong role — f(x) = x shows that without (iii) the guarantee can fail, which does not refute the statement.

    A。f(−1) = 1，f(2) = 4，仍有 f′(0) = 0：罗尔的条件是充分的，并非必要。C 的例子用错了地方：f(x) = x 说明缺了条件三保证会失效，驳不倒这句话。

  6. For f(x) = x³, the point x = 0 is …

    对 f(x) = x³，点 x = 0 是……

    B. f′(0) = 0, so 0 is stationary; but x³ < 0 just left of 0 and x³ > 0 just right, so it is neither a local max nor a local min.

    B。f′(0) = 0，所以是稳定点；但 0 左侧 x³ < 0，右侧 x³ > 0，既非极大也非极小。

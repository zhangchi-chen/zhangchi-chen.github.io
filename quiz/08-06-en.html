1. 1. With t = tan(x/2), which expression equals cos x?
  1. A2t/(1 + t²)
  2. B(1 + t²)/(1 − t²)
  3. C(1 − t²)/(1 + t²)
    4. Correct: C. cos²(x/2) − sin²(x/2) over cos²(x/2) + sin²(x/2), then divide top and bottom by cos²(x/2).
2. 2. Under t = tan(x/2), what does ∫ dx/(2 + cos x) become?
  1. A∫ 2/(1 + 3t²) dt
  2. B∫ 1/(3 + t²) dt
  3. C∫ 2/(3 + t²) dt
    4. Correct: C. 2 + cos x = (3 + t²)/(1 + t²); multiplying its reciprocal by 2/(1 + t²) leaves 2/(3 + t²).
3. 3. For which integrand is t = tan x the cheaper choice?
  1. A1/(1 + sin²x)
  2. B1/(1 + sin x)
  3. Ccos x/(1 + sin²x)
    4. Correct: A. it stays the same when sin x and cos x both change sign, and becomes ∫ dt/(1 + 2t²).
4. 4. With t = √(x + 1), what does ∫ dx/(1 + √(x + 1)) become?
  1. A∫ 2/(1 + t) dt
  2. B∫ 2t/(1 + t) dt
  3. C∫ t/(1 + t) dt
    4. Correct: B. x = t² − 1 gives dx = 2t dt, so the integrand is 2t/(1 + t).
5. 5. Which move turns 2 sin(x/2)cos(x/2) / (sin²(x/2) + cos²(x/2)) into 2t/(1 + t²)?
  1. Adivide top and bottom by cos²(x/2)
  2. Bmultiply top and bottom by sin(x/2)
  3. Cdifferentiate top and bottom
    4. Correct: A. each sin(x/2)/cos(x/2) becomes t, and cos²(x/2)/cos²(x/2) becomes 1.
6. 6. True or false: the half-angle substitution is always the most economical route.
  1. ATrue
  2. BFalse
  3. CNeither: it fails for some trigonometric rational functions
    4. Correct: B. the course text: always effective, by no means the simplest choice in every situation (compare ∫ dx/(a² sin²x + b² cos²x)).

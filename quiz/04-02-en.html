1. lim(x→π) cos(x/3) = ?

A.1/2B.−1/2C.√3/2
Answer: A. Answer: A cos and x/3 are continuous, so substitute: cos(π/3) = 1/2.

2. lim(x→∞) √(2 − sin x/x) = ?

A.1B.√2C.does not exist
Answer: B. Answer: B |sin x/x| ≤ 1/|x|, so sin x/x → 0; the square root is continuous at 2, giving √(2 − 0) = √2.

3. lim(x→∞) ((2x + 1)/(x + 5))^(3x/(x + 1)) = ?

A.6B.8C.1
Answer: B. Answer: B Power limit rule: the base → 2 > 0 and the exponent → 3, so the limit is 2³ = 8.

4. Why is arcsin continuous on [−1, 1]?

A.Because sin is periodic.B.Because sin is bounded on ℝ.C.Because sin is strictly increasing and continuous on [−π/2, π/2]; apply the inverse-function rule.
Answer: C. Answer: C The inverse rule needs a strictly monotone continuous function on a closed interval: sin on [−π/2, π/2] maps onto [−1, 1].

5. On which set is h(x) = √(4 − x²)/(x − 1) continuous?

A.[−2, 2]B.[−2, 1) ∪ (1, 2]C.ℝ ∖ {1}
Answer: B. Answer: B h is elementary, so it is continuous on its domain: 4 − x² ≥ 0 gives |x| ≤ 2, and the denominator forces x ≠ 1.

6. What does substituting x = 0 into sin x/x tell you?

A.It gives 0, so the limit is 0.B.It gives 1, so the limit is 1 by substitution.C.It gives 0/0: the license is void because the denominator vanishes.
Answer: C. Answer: C 0 is outside the domain of sin x/x. The limit does equal 1, but that needs the chapter-3 argument, not substitution.

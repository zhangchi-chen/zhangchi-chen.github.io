参数方程的导数

← 讲稿 · 目录
1. 曲线 x = t² + 2t，y = t³ + 4t²。t = 1 处 dy/dx 等于多少？
  1. A11/4
  2. B4/11
  3. C7
    4. 正确答案：A. dx/dt = 4，dy/dt = 11，所以 dy/dx = 11/4。B 把比倒过来了；C 是二阶导数之比，不是斜率。
2. 摆线 x = t − sin t，y = 1 − cos t（a = 1）。t = π/2 处的切线是哪一条？
  1. Ay = x + 2 − π/2
  2. By = x + 1 − π/2
  3. Cy = 1
    4. 正确答案：A. 切点 (π/2 − 1, 1)，斜率 cot(π/4) = 1。B 把切点横坐标算错了；C 的斜率 0 属于 t = π（拱顶）。
3. 下面哪一个才是 dy/dx = (dy/dt)/(dx/dt) 的真正理由？
  1. Adt 分子分母把 dt 约掉。
  2. B对 y = ψ(φ⁻¹(x)) 用链式法则，再用反函数求导法则（要求 φ′(t) ≠ 0）。
  3. C先消去 t；只有能把 y 写成 x 的式子时公式才成立。
    4. 正确答案：B. 每一步都是第五章第四集的定理；dt 单独还不是一个数，约分只是记法。C 不对：公式的价值正在于不必消去 t。
4. 对 x = t³ − 3t，y = t²，公式 dy/dx = ψ′(t)/φ′(t) 在哪里用不了？
  1. At = ±1
  2. Bt = 0
  3. Ct = ±√3
    4. 正确答案：A. t = ±1 时 φ′ = 0，但 ψ′ ≠ 0，切线竖直。t = 0 时斜率为 0；t = ±√3 时曲线两次经过 (0, 3)，公式照常可用。
5. 判断：d²y/dx² = ψ″(t)/φ″(t)。
  1. A对：一阶的规律往上推一阶。
  2. B错：摆线（a = 1）在 t = π/2 处，猜想得 0，老实算得 −1。
  3. C只要 φ″(t) ≠ 0 就对。
    4. 正确答案：B. 猜想得 0，老实计算得 −1，同一点两个答案，所以猜想靠不住；而此处 φ″ = 1 ≠ 0，C 也被推翻。原因留给第五章第九集。
6. 哪条曲线在 [−1, 1] 上不是光滑曲线？
  1. Ax = t³, y = |t|³
  2. Bx = t + eᵗ, y = sin t
  3. Cx = 2 cos t, y = sin t
    4. 正确答案：A. A 的两个导数在 t = 0 同时为 0，轨迹是 y = |x|，原点处是拐角，没有切线。B、C 的两个导数从不同时为 0。

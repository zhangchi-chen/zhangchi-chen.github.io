The Intermediate Value Theorem

Click the button under each item to reveal the answer.

1. Which hypothesis turns the root theorem into the IVT case μ = 0?

A.f(a)·f(b) > 0B.f(a)·f(b) < 0C.f(a) = f(b)
Answer: B. f(a)·f(b) < 0 means f(a), f(b) have opposite signs, so 0 lies strictly between them: take μ = 0.

2. In the proof (case f(a) < μ < f(b)), the point x₀ is defined as…

A.sup E, where E = {x ∈ [a, b] : f(x) < μ}B.the first x with f(x) = μC.the midpoint (a + b)/2
Answer: A. E contains a and is bounded above by b, so x₀ = sup E exists; continuity forces f(x₀) = μ.

3. If f(x₀) < μ with x₀ = sup E, why is that absurd?

A.f would be discontinuous at x₀B.E would be emptyC.Points just right of x₀ also lie in E, so x₀ is not an upper bound
Answer: C. Continuity keeps f < μ on a neighborhood of x₀ (and x₀ < b since f(b) > μ), so E reaches past x₀.

4. For p(x) = x³ − 2x + 2, which interval does the root theorem guarantee contains a root?

A.(−1, 0)B.(0, 1)C.(−2, −1)
Answer: C. p(−2) = −2 < 0 and p(−1) = 3 > 0. On (−1, 0) and (0, 1) the endpoint values have the same sign.

5. Bisection on [−2, −1] for this p: p(−1.5) = 1.625 > 0. Which half is kept?

A.Either half worksB.[−2, −1.5]C.[−1.5, −1]
Answer: B. p(−2) < 0 < p(−1.5), so the sign change — and a root — is caged in [−2, −1.5].

6. f is continuous with f([a, b]) ⊆ [a, b]. Which auxiliary function proves a fixed point exists?

A.F(x) = f(x) − xB.F(x) = f(x) + xC.F(x) = x·f(x)
Answer: A. F(a) = f(a) − a ≥ 0 and F(b) = f(b) − b ≤ 0; an endpoint is fixed or the root theorem gives x₀ with f(x₀) = x₀.

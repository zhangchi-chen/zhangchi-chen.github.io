  1. 下面哪条链是正确的增长阶梯（k ≥ 1 固定，a > 1）？
    A. n! ≪ aⁿ ≪ nᵏ ≪ nⁿB. ln n ≪ n ≪ nᵏ ≪ aⁿ ≪ n! ≪ nⁿC. ln n ≪ aⁿ ≪ nᵏ ≪ n! ≪ nⁿ
    答案 B.对数、幂、指数、阶乘、nⁿ 依次排列，相邻两项之比都趋于 0。
  2. 证明 ln n ≪ n 时，为 ln 的每次增量“付账”的是哪个不等式？
    A. ln(1 + x) ≤ xB. 二项式定理C. 均值不等式
    答案 A.ln(1 + 1/k) ≤ 1/k ≤ 1，所以 ln(n+1) = Σ ln(1 + 1/k) ≤ n；再把同一工具用到 √n 上得 ln n ≤ 2√n。
  3. 为什么二项展开中只留一项就能击倒 nᵏ？
    A. 因为 C(n, k+1) = 2ⁿB. 因为 (1+b)ⁿ 各项都为正，而 C(n, k+1)bᵏ⁺¹ 的增长是常数乘以 nᵏ⁺¹C. 因为必须有 b > 1
    答案 B.丢掉正项只会让和变小，而保留的那一项 ≥ c·nᵏ⁺¹，比 nᵏ 多出一个 n 的因子。
  4. 在 aⁿ/n! = (a/1)(a/2)⋯(a/n) 中，从哪里开始每个新因子都小于 ½？
    A. 从 n = 1 开始B. n > a 之后C. n > 2a 之后
    答案 C.a/n < ½ 当且仅当 n > 2a；此后乘积每步至少减半，趋于 0。
  5. 1.01ⁿ 与 n¹⁰⁰ 比较，哪种说法正确？
    A. 1.01 太接近 1，n¹⁰⁰ 永远更大B. 从 n = 100 起 1.01ⁿ 就更大C. 1.01ⁿ 终将胜出，但要到 n ≈ 10⁵ 之后
    答案 C.a = 1.01 > 1 且 k = 100 固定，所以指数最终获胜；交叉点约在 n ≈ 1.17×10⁵，那时两边都有 507 位数字。
  6. 下面哪种取法会破坏 nᵏ ≪ aⁿ 这一级？
    A. a = 1.0001B. k = 50C. a = 1
    答案 C.a = 1 时“指数”是常数 1；任何 a > 1，哪怕再接近 1，对固定的 k 都终将胜出。

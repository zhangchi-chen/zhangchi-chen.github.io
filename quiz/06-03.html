单调性与不等式

← 讲稿 · 目录
1. 1. f(x) = x³ − 3x 在哪个区间上递减？
  1. A[−1, 1]
  2. B[1, +∞)
  3. C[−3, 3]
    4. 正确答案：A. f′(x) = 3(x − 1)(x + 1) 恰在 [−1, 1] 上 ≤ 0；在 [1, +∞) 上 f′ ≥ 0；f(−3) = −18 < f(−1) = 2，排除 C。
2. 2. f 在 (0, 3) 内可导，f′ ≥ 0，且 f′ 恰在 [1, 2] 上为零。f 在 (0, 3) 内：
  1. A严格递增
  2. B递增，但非严格
  3. C既不递增也不递减
    4. 正确答案：B. 定理 6.3 给出递增；定理 6.4 的条件 (ii) 在 [1, 2] 上失效，f 在那里是常数，f(1) = f(2)。
3. 3. 用 F(x) = x − ln(1 + x)（在 0 处连续）证明 x > 0 时 ln(1 + x) < x，哪组事实足以收尾？
  1. AF(0) = 0，且 x > 0 时 F′(x) = x/(1 + x) > 0
  2. BF(0) = 0，且 F′(x) = 1/(1 + x) > 0
  3. CF(1) > 0，且 F 连续
    4. 正确答案：A. F 在 (0, +∞) 上严格递增，加上 0 处连续，延伸到 [0, +∞)，所以 F(x) > F(0) = 0。B 的导数算错；C 只查了一个点。
4. 4. f(x) = 1/x 对每个 x ≠ 0 有 f′(x) = −1/x² < 0。哪个说法正确？
  1. Af 在 (−∞, 0) ∪ (0, +∞) 上严格递减
  2. Bf 分别在 (−∞, 0) 与 (0, +∞) 上严格递减
  3. Cf 在某个区间上递增
    4. 正确答案：B. 推论在每个区间上分别成立；A 错，因为 f(−1) = −1 < 1 = f(1)；C 错，因为处处 f′ < 0。
5. 5. < 时，哪一步能证明 sin b − sin a ≤ b − a？
  1. A，其中 cos ξ ≤ 1
  2. B，其中 sin ξ ≤ 1
  3. C对一切实数 x，sin x ≤ x
    4. 正确答案：A. 目标里有 f(b) − f(a)，用中值定理那份菜谱：f′(ξ) = cos ξ ≤ 1，b − a > 0。B 的导数错了；C 在 x < 0 时为假（sin(−1) ≈ −0.84 > −1）。
6. 6. f 在区间 I 上可导。“在 I 上 f′(x) > 0”是 f 在 I 上严格递增的必要条件吗？
  1. A是：推论这么说
  2. B不是：x³ 在实数集上严格递增，而 f′(0) = 0
  3. C不是：严格递增的可导函数必在某处 f′ < 0
    4. 正确答案：B. 推论给的是充分条件，并非必要；定理 6.4 允许 f′ 有孤立零点。C 错：eˣ 处处 f′ > 0。

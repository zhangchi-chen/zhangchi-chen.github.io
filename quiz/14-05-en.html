Binomial endpoints: guess from the function, then prove with Raabe

← Notes · Index
1. 1. Take α = −2/3. Before running any test, what does the function predict at x = −1?
  1. AConverges, with sum 0
  2. BConverges conditionally
  3. CDiverges: (1+x)^α → +∞ there
    4. Correct: C. 0^α blows up for α < 0; by Theorem 14.6(ii) a convergent series would have to have this infinite limit as its sum (Raabe agrees: r = 1/3 < 1, same-signed terms).
2. 2. With bₙ = |C(α,n)|, what is lim n(1 − bₙ₊₁/bₙ)?
  1. A1 + α
  2. Bα
  3. C1 − α
    4. Correct: A. bₙ₊₁/bₙ = (n − α)/(n + 1), so 1 − bₙ₊₁/bₙ = (1 + α)/(n + 1), and n(1 + α)/(n + 1) → 1 + α.
3. 3. α = 1/2, i.e. √(1+x). What is the convergence domain of its binomial series?
  1. A(−1, 1)
  2. B[−1, 1]
  3. C(−1, 1]
    4. Correct: B. r = 3/2 > 1 gives absolute convergence at both endpoints; the sum at x = −1 is 0 = √0, as the function predicted.
4. 4. α = −1/2 at x = 1: what happens to 1 − 1/2 + 3/8 − 5/16 + ⋯?
  1. AConverges absolutely
  2. BDiverges
  3. CConverges conditionally, with sum 1/√2
    4. Correct: C. Raabe gives r = 1/2 < 1, so not absolutely; the signs alternate and the sizes decrease to 0, so the Leibniz test gives convergence; Theorem 14.6(ii) gives the sum 2^(−1/2) = 1/√2.
5. 5. “At x = 1 the binomial series converges iff α > −1, because the function value 2^α is finite.” Judge this sentence.
  1. ACorrect, and the reason is complete
  2. BThe conclusion is right, the reason is not
  3. CThe conclusion is wrong
    4. Correct: B. 2^α is finite for every α, so it only removes an obstruction: α = −1 gives 1/2, yet 1 − 1 + 1 − ⋯ diverges. The proof needs the term test (α > −1), then Raabe (α > 0) or Leibniz (−1 < α < 0).

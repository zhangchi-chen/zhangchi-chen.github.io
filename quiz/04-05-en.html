Uniform Continuity

Click the button under each item to reveal the answer.

1. Which statement is the definition of “f is uniformly continuous on I”?

A.∀ε > 0 ∃δ > 0 ∀x′, x″ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εB.∀ε > 0 ∀x″ ∈ I ∃δ > 0 ∀x′ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εC.∃δ > 0 ∀ε > 0 ∀x′, x″ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < ε
Answer: A. In A, δ is chosen before the points, so δ = δ(ε) serves all of I: one ruler for the whole road. B lets δ depend on the point x″ — that is ordinary continuity. C puts δ before ε, so f(x′) = f(x″) whenever |x′ − x″| < δ, which forces f to be constant on I.

2. For f(x) = x² on [0, +∞), the pointwise recipe δ = ε/(2x + 1) works for 0 < ε ≤ 1. What is δ at x = 100?

A.ε/201B.ε/101C.ε/200
Answer: A. 2·100 + 1 = 201. As x grows, δ shrinks: ε/3 at x = 1, ε/201 at x = 100, ε/2000001 at x = 10⁶. No single δ > 0 works for every x.

3. Which statement says that f is NOT uniformly continuous on I?

A.∃ε₀ > 0 ∀δ > 0 ∃x′, x″ ∈ I: |x′ − x″| < δ and |f(x′) − f(x″)| ≥ ε₀B.∀ε > 0 ∃δ > 0 ∃x′, x″ ∈ I: |x′ − x″| < δ and |f(x′) − f(x″)| ≥ εC.∃ε₀ > 0 ∃δ > 0 ∀x′, x″ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| ≥ ε₀
Answer: A. Negate one quantifier at a time: ∀ε becomes ∃ε₀, ∃δ becomes ∀δ, and “every pair behaves” becomes “some pair misbehaves”. The hostile king can defeat every δ with a devil pair.

4. Which pair of sequences in (0, 1) shows, by the sequence criterion, that sin(1/x) is not uniformly continuous there?

A.x′ₙ = 1/(2nπ), x″ₙ = 1/(2nπ + π/2)B.x′ₙ = 1/(2nπ), x″ₙ = 1/(2nπ + 2π)C.x′ₙ = 1/n, x″ₙ = 1/(n + 1)
Answer: A. In A, x′ₙ − x″ₙ → 0 while sin(2nπ) = 0 and sin(2nπ + π/2) = 1, so the value gap stays 1. In B both values are 0, so the gap is 0 and proves nothing. In C the values sin n and sin(n + 1) are never shown to stay apart.

5. When the hostile king is fed δ = 1, 1/2, 1/3, …, what does the negation hand back?

A.Pairs with |x′ₙ − x″ₙ| < 1/n and |f(x′ₙ) − f(x″ₙ)| ≥ ε₀B.Pairs with |x′ₙ − x″ₙ| ≥ 1/n and |f(x′ₙ) − f(x″ₙ)| < ε₀C.One fixed pair that works for every δ
Answer: A. Each δ = 1/n gets its own devil pair, so x′ₙ − x″ₙ → 0 while f(x′ₙ) − f(x″ₙ) does not tend to 0. That is the sufficiency half of the sequence criterion: the pairs are extracted from the negation, not guessed.

6. Is f(x) = √x uniformly continuous on [0, +∞)?

A.Yes: |√x′ − √x″| ≤ √|x′ − x″|, so δ = ε² worksB.No: its graph is vertical at 0C.No: it is unbounded on [0, +∞)
Answer: A. Steepness and unboundedness are not the enemy. A δ that is the same everywhere exists: if |x′ − x″| < ε², then |√x′ − √x″| < ε. (Compare ax + b, where δ = ε/(|a| + 1) works.)

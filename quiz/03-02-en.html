lim(x→0⁺) e^(1/x) = ?

A. 0B. 1C. +∞

C. As x → 0⁺, 1/x → +∞, so e^(1/x) → +∞.

lim(x→0⁻) arctan(1/x) = ?

A. π/2B. −π/2C. 0

B. As x → 0⁻, 1/x → −∞ and arctan sinks to the lower end of its principal interval (−π/2, π/2).

lim(x→0⁻) |x|/x = ?

A. 1B. −1C. does not exist

B. For x < 0, |x| = −x, so |x|/x is identically −1.

lim(x→0) 1/x² = +∞ shows that this limit…

A. exists and equals +∞B. does not exist: f diverges to +∞C. exists, because both sides agree

B. The definition demands a real number A; +∞ is not one — this is divergence with a title.

x → ∞ (without a sign) fills which blank?

A. x > MB. |x| > MC. 0 < |x − x₀| < δ

B. The bare ∞ has no direction, so both rays are required: |x| > M.

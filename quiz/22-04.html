1. 1. 家族表中，立体V的边界是什么？
  1. A一条闭曲线
  2. B一张闭曲面
  3. C两个端点
    4. 正确答案：B. 立体是三维的，边界低一维：一张闭曲面，正如高斯公式。
2. 2. 斯托克斯公式在曲面S上积分的是哪种导数？
  1. A（散度）
  2. B（梯度）
  3. C（旋度）
    4. 正确答案：C. 定理22.6的三个括号正是rot A的分量；散度属于高斯公式。
3. 3. 上半单位球面，A = (−y, x, 0)。同学取下侧，L却取从上往下看的逆时针方向，算得曲面积分为−2π、曲线积分为2π。错在哪里？
  1. A侧与方向错配：取下侧时，L应为从上往下看顺时针。
  2. B曲面积分算错了。
  3. C斯托克斯公式对半球面不成立。
    4. 正确答案：A. 按右手法则，下侧配顺时针的L，两边都是−2π。
4. 4. L是平面x + y + z = 1被三个坐标面截出的三角形，从向量(1, 1, 1)所指一侧看为逆时针。用平的三角形面片计算 ∮L z dx + x dy + y dz，结果为
  1. A1/2
  2. B√3
  3. C3/2
    4. 正确答案：C. rot A = (1, 1, 1)，n = (1, 1, 1)/√3，rot A · n = √3；边长√2的正三角形面积为√3/2；乘积为3/2。
5. 是单位法向为n = (cos α, cos β, cos γ)的平面上的闭曲线，方向按右手法则，所围面积为S。行列式 |dx dy dz; cos α cos β cos γ; x y z| 沿L的积分等于
  1. AS
  2. B2S
  3. C0
    4. 正确答案：B. 场n × r的旋度是2n，由斯托克斯公式得∬ 2n · n dS = 2S。

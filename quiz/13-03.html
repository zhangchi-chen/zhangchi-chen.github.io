1. 1. 用哪个Mₙ可以证明Σ sin(nx)/(n√n)在实轴上一致收敛？
  1. A1/n
  2. B1/(n√n)
  3. C1/√n
    4. 正确答案：B. |sin(nx)| ≤ 1，故|uₙ(x)| ≤ 1/(n√n)，而p = 3/2 > 1的p级数收敛；A、C虽是上界，但对应级数发散。
2. 2. 在[−1/2, 1/2]上，Σ n xⁿ 该用哪道围栏？
  1. AMₙ = n/2ⁿ
  2. BMₙ = 1/2ⁿ
  3. CMₙ = n
    4. 正确答案：A. 区间上|n xⁿ| ≤ n/2ⁿ，由比式判别法（比值→1/2）Σ n/2ⁿ收敛；B在n ≥ 2时不是上界（取x = 1/2），C的级数发散。
3. 3. M判别法的两行证明里，三角不等式起什么作用？
  1. A证明ΣMₙ收敛。
  2. B在每个x处把|uₙ₊₁(x) + ⋯ + uₙ₊ₚ(x)|放大为Mₙ₊₁ + ⋯ + Mₙ₊ₚ。
  3. C求出和函数。
    4. 正确答案：B. 第一行由ΣMₙ的柯西准则取出N；第二行用三角不等式和|uₖ(x)| ≤ Mₖ把这个N交给每个x，于是定理13.3适用。
4. 依次判断：Σxⁿ在[−1/2, 1/2]上；Σxⁿ在(−1, 1)上；Σ sin(nx)/n²在实轴上。
  1. A一致收敛；不一致收敛；一致收敛
  2. B一致收敛；一致收敛；不一致收敛
  3. C不一致收敛；不一致收敛；一致收敛
    4. 正确答案：A. [−1/2, 1/2]上用围栏(1/2)ⁿ；(−1, 1)上各项通不过推论（sup|xⁿ| = 1）；实轴上用围栏1/n²。
5. 5. 驳倒Σxⁿ在(0, 1)上一致收敛，最快的正确理由是？
  1. A对每个n，xⁿ在(0, 1)上的上确界都是1，各项并非一致趋于0。
  2. B级数在x = 1/2处发散。
  3. C每一项xⁿ在(0, 1)上连续。
    4. 正确答案：A. 这正是推论的检查没通过；B是错的（x = 1/2处级数收敛于2），C虽对却什么也证明不了。
6. 6. 判断：因为Σxⁿ在每个[−a, a]（0 < a < 1）上一致收敛，所以它在(−1, 1)上一致收敛。
  1. A对：(−1, 1)是这些[−a, a]的并。
  2. B错：内闭一致收敛不能升级为整个开区间上的一致收敛。
  3. C对：取Mₙ = aⁿ的M判别法覆盖了(−1, 1)。
    4. 正确答案：B. 围栏总和1/(1 − a)在a → 1时爆掉，且(−1, 1)上sup|xⁿ| = 1，所以级数只是内闭一致收敛。

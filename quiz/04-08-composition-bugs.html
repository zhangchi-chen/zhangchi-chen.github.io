1. 1. 在 x₀ = 0、u₀ = 0 时，哪个内函数满足定理 3.8 的第三条假设？

  1. A. A. x sin(1/x)
  2. B. B. x²
  3. C. C. the constant f(x) ≡ 0
B — x ≠ 0 时 x² > 0，在 0 的空心邻域内避开 0；另外两个在 0 的任意近处都取到 0。

2. 2. 用 2×2 安全表给 x → 0 时的 lim cos(x sin(1/x)) 归类。

  1. A. A. inner avoids 0; outer not continuous at 0
  2. B. B. inner keeps hitting 0; outer continuous at 0: safe, limit 1
  3. C. C. neither patch: no limit
B — x sin(1/x) 在每个 1/(nπ) 处为 0，补丁A失效；但 cos 在 0 处连续，补丁B给出 cos 0 = 1。

3. 3. 哪个数列 xₙ → 0 能说明 f(x) = x sin(1/x) 反复取到 0？

  1. A. A. xₙ = 1/n
  2. B. B. xₙ = 1/(nπ)
  3. C. C. xₙ = 2/((2n+1)π)
B — f(1/(nπ)) = sin(nπ)/(nπ) = 0。A 中 sin n ≠ 0（π 是无理数）；C 中 sin((2n+1)π/2) = ±1。

4. 4. 设 f(x) ≡ 0，u ≠ 0 时 g(u) = 1，g(0) = 2。x → 0 时 lim g(f(x)) 等于多少？

  1. A. A. 1
  2. B. B. 2
  3. C. C. it does not exist
B — 对每个 x 都有 g(f(x)) = g(0) = 2，是常数；g 在 0 处的极限 1 根本用不上。

5. 5. 判断：lim g(f(x)) 总等于 g(lim f(x))。

  1. A. A. true
  2. B. B. true as soon as the inner function avoids its limit value
  3. C. C. false in general; it is guaranteed when g is continuous at lim f(x)
C — 取 f(x) = x，u ≠ 0 时 g(u) = 1，g(0) = 2：f 避开 0，极限却是 1，而 g(lim f(x)) = g(0) = 2。补丁A给出的是 g 的极限，不是 g(u₀)。

1. 1. For x² + xy + y² = 3, what is y′?
  1. A−(2x + y)/(x + 2y)
  2. B−(x + 2y)/(2x + y)
  3. C(2x + y)/(x + 2y)
    4. Correct: A. F_x = 2x + y and F_y = x + 2y, so y′ = −F_x/F_y.
2. 2. On the ellipse x² + 4y² = 4, where does y′ = −F_x/F_y break down?
  1. A(0, ±1)
  2. B(±2, 0)
  3. Cnowhere
    4. Correct: B. F_y = 8y vanishes only where y = 0, i.e. at (±2, 0), where the tangent is vertical.
3. 3. On x² + y² = 25, compute y″ at (3, 4) by differentiating the identity.
  1. A−25/64
  2. B−1/4
  3. C25/64
    4. Correct: A. 2 + 2y′² + 2y·y″ = 0 with y′ = −3/4 gives y″ = −(1 + 9/16)/4 = −25/64; −1/4 is the frozen-y slip.
4. 4. For x² − xy + y² = 3, the point (1, 2) is a stationary point of the implicit function. It is:
  1. Aa maximum, y″ = −2/3
  2. Ba minimum, y″ = 2/3
  3. Cneither, y″ = 0
    4. Correct: A. there F_x = 2x − y = 0, F_y = 2y − x = 3 and F_xx = 2, so y″ = −F_xx/F_y = −2/3 < 0.
5. 5. On x² + y² = 1 a student differentiates y′ = −x/y holding y constant and writes y″ = −1/y. Verdict?
  1. Acorrect: y′ is already known
  2. Bwrong: y depends on x, so the y′ terms are missing
  3. Ccorrect: partial derivatives always freeze y
    4. Correct: B. the true value is −1/y³ (check with y = √(1 − x²)); y moves with x.
6. 6. Applying d to xy + eʸ = 1 gives y dx + x dy + eʸ dy = 0. So dy/dx =
  1. A−y/(x + eʸ)
  2. B−(x + eʸ)/y
  3. Cy/(x + eʸ)
    4. Correct: A. collect: (x + eʸ) dy = −y dx; this matches −F_x/F_y with F_x = y, F_y = x + eʸ.

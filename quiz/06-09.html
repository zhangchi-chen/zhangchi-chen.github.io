极值与最值

← 讲稿 · 目录
1. 1. f(x) = ∛(x²)，在 x = 0 处是什么情况？
  1. A稳定点，由第二充分条件得极小值
  2. B不可导点，由第一充分条件得极小值
  3. C该点导数不存在，所以没有极值
    4. 正确答案：B. x < 0 时 f′(x) = 2/(3∛x) < 0，x > 0 时 f′(x) > 0，且 f 在 0 处连续。
2. 2. f(x) = x³ − 3x，在 x = −1 处是什么情况？
  1. A极大值 2
  2. B极小值 −2
  3. C第二充分条件失效
    4. 正确答案：A. f′(−1) = 3 − 3 = 0，f″(−1) = −6 < 0，f(−1) = −1 + 3 = 2。
3. 3. f(x) = (x − 1)⁴ + 2，在 x = 1 处能得出什么？
  1. A第二充分条件给出极小值
  2. B第二充分条件失效，第一充分条件给出极小值
  3. C因为 f″(1) = 0，所以没有极值
    4. 正确答案：B. f′(1) = f″(1) = 0，但 f′(x) = 4(x − 1)³ 在 1 处由负变正（另：f⁽⁴⁾(1) = 24 > 0，为偶数阶）。
4. 4. f(x) = |x² − 4x| 在 [−1, 5] 上的最大值与最小值？
  1. A最大值 4，最小值 0
  2. B最大值 5，最小值 0
  3. C最大值 5，最小值 −4
    4. 正确答案：B. 稳定点 x = 2 处值为 4；不可导点 x = 0、x = 4 处值为 0；端点 x = −1、x = 5 处值为 5。
5. 5. 矩形周长为 20 cm，求面积最大。哪个一元函数设定正确？
  1. AA(x) = x(20 − x), 0 ≤ x ≤ 20
  2. BA(x) = x(10 − x), 0 ≤ x ≤ 10
  3. CA(x) = x(10 − 2x), 0 ≤ x ≤ 5
    4. 正确答案：B. 设两边为 x、y，2x + 2y = 20，所以 y = 10 − x。
6. 6. “稳定点都是极值点，极值点都是稳定点。”
  1. A两句都对
  2. B只有后一句对
  3. C两句都错
    4. 正确答案：C. x³ 在 0 处是稳定点却无极值；|x| 在 0 处取极小值却不可导。

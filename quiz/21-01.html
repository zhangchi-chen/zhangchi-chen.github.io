二重积分

← 讲稿 · 目录
1. 1. 定积分里分割的条件是 λ → 0。二重积分里，谁扮演这个角色？
  1. An → ∞ （小块个数趋于无穷）
  2. B‖T‖ → 0 （细度，即最大小块直径）
  3. CS_D → 0 （D 的面积趋于零）
    4. 正确答案：B. 只增加块数不够：把正方形切成 n 条细长条，无论 n 多大，直径始终大于 2。
2. 2. 为什么定义二重积分之前，D 的面积必须先确定？
  1. A因为 f 在 D 上必须非负。
  2. B因为每个积分和都要乘小块面积 Δσᵢ，面积必须有意义。
  3. C因为 D 必须是矩形。
    4. 正确答案：B. 积分和 Σ f(ξᵢ, ηᵢ)Δσᵢ 由面积搭成；既不要求非负，也不要求矩形。
3. 3. 在单位正方形上，曲线 y = x² 及其下方 f = 1，上方 f = 2。f 可积吗？
  1. A不可积：它沿整条曲线不连续。
  2. B可积：f 有界，不连续点落在连续函数的图像上，是零面积集。
  3. C只有把曲线换成直线才可积。
    4. 正确答案：B. 定理21.7：有界，且不连续点集为零面积集（n 个小矩形盖住曲线，总面积 1/n）。
4. 4. D 是单位圆盘 x² + y² ≤ 1，面积为 π。估值不等式给出的范围是？ I = ∬_D e^(x²+y²) dσ
  1. A1 ≤ I ≤ e
  2. Bπ ≤ I ≤ eπ
  3. C0 ≤ I ≤ π
    4. 正确答案：B. 在 D 上 0 ≤ x² + y² ≤ 1，所以 1 ≤ e^(x²+y²) ≤ e，再乘面积 π。选项 A 忘了乘面积。
5. 5. 判断：在 D 上有界的函数，在 D 上一定可积。
  1. A对，由定理21.6。
  2. B对，由定理21.7。
  3. C错：在单位正方形的有理点取 1、其余取 0，有界却不可积。
    4. 正确答案：C. 每个小块里两类点兼有，任意细度下积分和可为 1 也可为 0；它的不连续点占满整个正方形。
6. 6. f 在区域 D 上连续，D 的面积为 3，∬_D f dσ = 12。下面哪一条一定成立？
  1. Af 在 D 上处处等于 4。
  2. BD 中某点 (ξ, η) 处 f(ξ, η) = 4。
  3. Cf 在 D 上处处不超过 4。
    4. 正确答案：B. 二重积分中值定理：12 = f(ξ, η)·3。若 f 不是常数，A 和 C 都不成立。

Self-test · 自测：Chain rule and inverse functions · 链式法则与反函数

Episode 05-04. Pick an answer, then reveal. · 先选答案，再点“显示答案”。

1. Annotate the layers and differentiate y = ecos(2x).

逐层标注，求 y = ecos(2x) 的导数。

Answer A · 答案 A

Layers: y = eu, u = cos v, v = 2x. Rates: eu, −sin v, 2. Multiply: ecos 2x·(−sin 2x)·2. B drops the innermost factor 2; C uses 2x, which is the rate of x², not of 2x.

三层：外层指数、中层余弦、内层 2x；三个因子相乘。B 漏了最里层的 2；C 把 2x 的导数错写成 2x。

2. A classmate writes (sin x³)′ = cos x³. What is missing?

同学写 (sin x³)′ = cos x³，漏了什么？

Answer A · 答案 A

Two layers, two factors: (sin x³)′ = cos(x³) · 3x². Stopping at cos x³ is the forgotten inner factor.

两层套娃就有两个因子：cos(x³)·3x²。停在 cos x³ 就是丢了内层因子。

3. Which "cancellation" is a correct use of the chain rule?

下面哪个“约分”是链式法则的正确用法？

Answer B · 答案 B

Only matching middle letters link up: B is Theorem 5.8 in Leibniz notation. In A and C the middles do not match, so nothing cancels; the "fraction" is a memory aid, not arithmetic.

只有中间字母相同才扣得上：B 就是定理 5.8。A、C 字母对不上，不能约；约分只是帮助记忆，不是算术。

4. y = arctan x is the inverse of x = tan y on (−π/2, π/2). Use the inverse rule: (arctan x)′ = ?

用反函数求导法则求 (arctan x)′。

Answer C · 答案 C

dx/dy = sec²y = 1 + tan²y = 1 + x² ≥ 1, never zero, so dy/dx = 1/(1 + x²). A forgets to take the reciprocal; B is a sign slip.

dx/dy = 1 + x² 恒大于零，取倒数得 1/(1 + x²)。A 忘了取倒数，B 符号错了。

5. x = φ(y) = y³ is continuous and strictly increasing; its inverse is y = ∛x. Why does the inverse rule give no derivative at x₀ = 0?

x = y³ 连续且严格递增，反函数是 ∛x。为什么在 x₀ = 0 处反函数法则给不出导数？

Answer A · 答案 A

φ′(y) = 3y², so φ′(0) = 0 and the hypothesis φ′(y₀) ≠ 0 fails. Indeed (∛h − 0)/h = h−2/3 → +∞: a vertical tangent. φ is monotone and ∛x is continuous, so B and C are false.

条件 φ′(y₀) ≠ 0 不成立：差商 h−2/3 趋于正无穷，切线竖直。B、C 的说法都不对。

6. True or false: "The chain rule is proved by writing Δy/Δx = (Δy/Δu)(Δu/Δx) and cancelling Δu."

判断：“链式法则的证明，就是把差商拆成两段再约掉 Δu。”

Answer B · 答案 B

The split divides by Δu, which is identically 0 for a constant inner function (and 0 infinitely often near 0 for x² sin(1/x)). The theorem still holds, 0 = f′(u₀)·0; the honest proof multiplies patched quotients instead of dividing.

拆分要除以 Δu，而常数内层让它恒为零。定理仍成立（0 = f′(u₀)·0），正确证法用“补洞的差商”相乘，不做除法。

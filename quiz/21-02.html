交换积分次序

← 讲稿 · 目录
1. 1. 交换积分次序： ∫02 dx ∫x/21 f(x,y) dy
  1. A∫01 dy ∫02y f(x,y) dx
  2. B∫01 dy ∫2y2 f(x,y) dx
  3. C∫01 dy ∫0y/2 f(x,y) dx
    4. 正确答案：A. 区域是顶点为 (0,0)、(0,1)、(2,1) 的三角形，对 [0, 1] 中的每个 y，x 从 0 走到 2y。
2. 2. 某同学把第一个积分换成了第二个。错在哪里？ ∫01 dx ∫x1 f dy → ∫01 dy ∫y1 f dx
  1. A没有错，换得对。
  2. B新的里层上下限描述的是另一块三角形，里层应为 ∫₀ʸ f dx。
  3. C外层上下限应从 0 到 y。
    4. 正确答案：B. 原区域是 0 ≤ x ≤ y ≤ 1，x 应从 0 走到 y，而 y ≤ x ≤ 1 是对角线下方的那块三角形。
3. 3. D 是由 x = 0、y = 1、y = x 围成的三角形。哪个次序能算出这个积分？ I = ∬D x²e−y² dσ
  1. A∫01 dy ∫0y x²e−y² dx
  2. B∫01 dx ∫x1 x²e−y² dy
  3. C哪个次序都不行，这个积分没有精确值。
    4. 正确答案：A. y 在外层时 e^(−y²) 对里层是常数，里层得 (y³/3)e^(−y²)，再令 t = y² 得 I = 1/6 − 1/(3e)；B 需要 e^(−y²) 的原函数，而它不是初等函数。
4. 4. 由 y = 2x、y = x/2、x + y = 3 围成的三角形：每个上下限只用一个公式时，两种次序各要分几块？面积是多少？
  1. A竖切两块，横切一块；面积 3/2。
  2. B两种次序都只要一块；面积 3。
  3. C两种次序都要两块；面积 3/2。
    4. 正确答案：C. 竖切时顶边在 (1,2) 换公式，横切时右边在 (2,1) 换公式；三角形关于 y = x 对称，两条路都得 3/4 + 3/4 = 3/2。
5. 5. 下面哪一个不是合法的累次积分？
  1. A∫01 dy ∫0√y f(x,y) dx
  2. B∫x²1 dy ∫01 f(x,y) dx
  3. C∫02 dx ∫x/21 f(x,y) dy
    4. 正确答案：B. 外层的界 x² 含有已被里层积掉的变量，而外层上下限必须是常数。
6. 6. 判断：对单位正方形上任意有界函数 f，两个累次积分都存在并且相等。
  1. A对，这就是定理 21.8。
  2. B只要二重积分存在就对。
  3. C错；缺了定理的条件，它们可能不存在，教材习题里有例子。
    4. 正确答案：C. 定理 21.8 还要求每个里层积分存在；教材习题给出了二重积分存在而两个累次积分不存在的函数，也给出了反过来的例子。

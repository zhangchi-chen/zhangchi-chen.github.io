The inverse and implicit function theorems in full: a nonvanishing determinant

← Notes · Index
1. 1. Which condition does the inverse function theorem put at the point x₀?
  1. Af′(x₀) = I
  2. Bdet f′(x₀) ≠ 0
  3. Cf is one-to-one on all of D
    4. Correct: B. Clause (ii) asks only for a nonzero Jacobian determinant at x₀; one-to-one is a conclusion, and only on U.
2. 2. For m equations F(x, y) = 0 in n + m unknowns, which determinant must be nonzero at (x₀, y₀)?
  1. Adet F_x
  2. Bdet F_y
  3. Cdet F′
    4. Correct: B. F_y is the square m×m block; F_x is m×n and F′ is m×(n+m), not square in general.
3. 3. Differentiating f⁻¹(f(x)) = x at x₀ with the chain rule gives:
  1. A(f⁻¹)′(f(x₀)) · f′(x₀) = I
  2. B(f⁻¹)′(x₀) = 1/f′(x₀), entry by entry
  3. C(f⁻¹)′(f(x₀)) + f′(x₀) = I
    4. Correct: A. The chain rule multiplies derivative matrices, and the derivative of the identity map is I.
4. 4. With m = n = 1, the formula f′ = −(F_y)⁻¹F_x becomes:
  1. A−F_y/F_x
  2. B−F_x/F_y
  3. CF_x · F_y
    4. Correct: B. A 1×1 inverse is a reciprocal: −(1/F_y)·F_x = −F_x/F_y, the formula of chapter 18.
5. 5. Where does the spherical-coordinate map have det f′ = 0?
  1. AOn the plane z = 0
  2. BOn the z axis
  3. COn the sphere r = 1
    4. Correct: B. det f′ = r² sin θ is 0 exactly when r = 0 or sin θ = 0, i.e. x = y = 0; on z = 0, θ = π/2 and det = r².
6. 6. ⚠️ “det f′ ≠ 0 at every point of R², so f is one-to-one on all of R².”
  1. ATrue, by the inverse function theorem
  2. BFalse: (eˣcos y, eˣsin y) has det e²ˣ > 0, yet f(x, y + 2π) = f(x, y)
  3. CTrue, provided f′ is continuous
    4. Correct: B. The theorem is local: each point has a neighbourhood where f is one-to-one, but the plane as a whole is wrapped around.

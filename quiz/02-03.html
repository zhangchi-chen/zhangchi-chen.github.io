极限的四则运算

1. 写 aₙ = a + αₙ、bₙ = b + βₙ（αₙ, βₙ → 0），乘积展开后的"二阶噪声"项是（　）

A. aβₙ　　B. bαₙ　　C. αₙβₙ

C。噪声 × 噪声是更高阶的小量，衰减得比 αₙ、βₙ 都快——这正是"常数 + 无穷小"机制能穿透乘法的原因。

2. 当分母极限 b = 0 时，商 aₙ/bₙ 的极限（　）

A. 一定不存在　　B. 一定存在　　C. 三种结局都可能

C。(1/n)/(1/n²) = n → ∞；(1/n²)/(1/n) → 0；((−1)ⁿ/n)/(1/n) 发散——什么都可能发生，所以商法则无法挽救。

3. 护城河论证：b ≠ 0 时，最终必有 |bₙ| ≥（　）

A. |b|　　B. |b|/2　　C. 2|b|

B。从某项起 bₙ 落在 b 的 |b|/2 带内，离 0 只会更远——1/bₙ 因此有界，除法安全。

4. (−1)ⁿ 与 (−1)ⁿ⁺¹ 都发散，其和恒为 0。这说明（　）

A. 发散 + 发散必发散　　B. 法则是单向的　　C. 法则有错

B。收敛 + 收敛 ⇒ 收敛成立，但反向不成立。法则是计算的凭证，不是判断收敛的工具。

5. 误差预算 |aₙbₙ − ab| ≤ |a||βₙ| + |b||αₙ| + |αₙ||βₙ| 中按 ε/3 分配，是为了（　）

A. 每个误差源各自领额度　　B. 让 N 更小　　C. 消掉交叉项

A。三个误差源各分一份 ε，各自找到自己的 N，最后取最大——证明靠的是小技巧，不是魔法。

1. 1. With σₖ = v₁ + ⋯ + vₖ, the sum Σᵢ₌₁ⁿ εᵢvᵢ equals:
  1. AΣᵢ₌₁ⁿ⁻¹ (εᵢ − εᵢ₊₁)σᵢ + εₙσₙ
  2. BΣᵢ₌₁ⁿ⁻¹ (εᵢ₊₁ − εᵢ)σᵢ + εₙσₙ
  3. CΣᵢ₌₁ⁿ⁻¹ (εᵢ − εᵢ₊₁)σᵢ + ε₁σ₁
    4. Correct: A. write vᵢ = σᵢ − σᵢ₋₁ (σ₀ = 0) and collect by σᵢ. Check with ε = (5, 4, 3, 2, 1), v = (1, −1, 1, −1, 1): the direct sum is 3, A gives 3, B gives −1, C gives 7.
2. 2. {aₙ} is monotone and bounded but does not tend to 0; Σbₙ diverges, but its partial sums are bounded. Then:
  1. AAbel's test gives convergence of Σaₙbₙ
  2. BDirichlet's test gives convergence of Σaₙbₙ
  3. Cneither test applies; Σaₙbₙ may diverge
    4. Correct: C. Abel's test needs Σbₙ to converge and Dirichlet's test needs aₙ → 0; aₙ = 1, bₙ = (−1)ⁿ⁺¹ gives the divergent series Σ(−1)ⁿ⁺¹.
3. 3. For 0 < x < 2π, the series Σ sin(nx)/√n:
  1. Aconverges by Dirichlet's test
  2. Bconverges absolutely, since |sin nx|/√n ≤ 1/√n
  3. Cdiverges, because 1/√n tends to 0 too slowly
    4. Correct: A. 1/√n decreases to 0 and |Σₖ₌₁ⁿ sin kx| ≤ 1/sin(x/2). B fails: Σ1/√n diverges, so that bound proves nothing. C fails: Dirichlet's test asks only for a monotone decrease to 0, not for a speed.
4. 4. Multiplying 1/2 + Σₖ₌₁ⁿ cos kx by 2 sin(x/2) gives:
  1. Asin((n+½)x)
  2. Bsin((n+½)x) − sin(x/2)
  3. Ccos(x/2) − cos((n+½)x)
    4. Correct: A. each 2 sin(x/2) cos kx = sin((k+½)x) − sin((k−½)x); the sum telescopes to sin((n+½)x) − sin(x/2), and the ½ term contributes the sin(x/2) that cancels it. B forgets the ½; C is the numerator of the sine twin.
5. 5. “Σ sin nx/n converges for every x in (0, 2π), so it converges absolutely there.” This statement is:
  1. Atrue — Dirichlet's test gives absolute convergence
  2. Bfalse — at x = π/2 the absolute series is 1 + 1/3 + 1/5 + ⋯, which diverges
  3. Ctrue — |sin nx|/n ≤ 1/n
    4. Correct: B. Dirichlet's test gives convergence only. At x = π/2 the absolute series keeps exactly the odd reciprocals, and 1/(2k+1) ≥ ½·1/(k+1) makes it diverge, so the convergence there is conditional. C fails because Σ1/n diverges.

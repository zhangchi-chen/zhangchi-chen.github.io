一致连续

点击选项下方按钮查看答案与解析。

1. 下面哪一条是“f 在 I 上一致连续”的定义？

A.∀ε > 0 ∃δ > 0 ∀x′, x″ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εB.∀ε > 0 ∀x″ ∈ I ∃δ > 0 ∀x′ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εC.∃δ > 0 ∀ε > 0 ∀x′, x″ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < ε
答案: A. A 中 δ 在选点之前确定，δ = δ(ε) 对整个 I 都管用：一把尺量全程。B 中 δ 可以依赖点 x″，这只是连续。C 把 δ 放到 ε 前面，于是只要 |x′ − x″| < δ 就有 f(x′) = f(x″)，f 在 I 上只能是常数。

2. f(x) = x² 在 [0, +∞) 上，当 0 < ε ≤ 1 时逐点配方 δ = ε/(2x + 1) 可行。x = 100 时 δ 是多少？

A.ε/201B.ε/101C.ε/200
答案: A. 2·100 + 1 = 201。x 越大，δ 越小：x = 1 时为 ε/3，x = 100 时为 ε/201，x = 10⁶ 时为 ε/2000001。找不到对所有 x 都管用的 δ > 0。

3. 下面哪一条表示 f 在 I 上“一致连续失败”？

A.∃ε₀ > 0 ∀δ > 0 ∃x′, x″ ∈ I: |x′ − x″| < δ 且 |f(x′) − f(x″)| ≥ ε₀B.∀ε > 0 ∃δ > 0 ∃x′, x″ ∈ I: |x′ − x″| < δ 且 |f(x′) − f(x″)| ≥ εC.∃ε₀ > 0 ∃δ > 0 ∀x′, x″ ∈ I: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| ≥ ε₀
答案: A. 逐个量词取否定：∀ε 变 ∃ε₀，∃δ 变 ∀δ，“所有点对都好”变成“有一对捣乱”。敌对的国王对每个 δ 都能找来一对恶魔点。

4. 用数列判别法说明 sin(1/x) 在 (0, 1) 上一致连续失败，应取哪一对数列？

A.x′ₙ = 1/(2nπ)，x″ₙ = 1/(2nπ + π/2)B.x′ₙ = 1/(2nπ)，x″ₙ = 1/(2nπ + 2π)C.x′ₙ = 1/n，x″ₙ = 1/(n + 1)
答案: A. A 中 x′ₙ − x″ₙ → 0，而 sin(2nπ) = 0，sin(2nπ + π/2) = 1，函数值差始终是 1。B 中两个函数值都是 0，差为 0，什么也证明不了。C 中 sin n 与 sin(n + 1) 的差，无法保证始终分开。

5. 依次喂给敌对的国王 δ = 1, 1/2, 1/3, …，否定命题交出的是什么？

A.点对满足 |x′ₙ − x″ₙ| < 1/n 且 |f(x′ₙ) − f(x″ₙ)| ≥ ε₀B.点对满足 |x′ₙ − x″ₙ| ≥ 1/n 且 |f(x′ₙ) − f(x″ₙ)| < ε₀C.一对对所有 δ 都管用的固定点
答案: A. 每个 δ = 1/n 各得一对恶魔点，于是 x′ₙ − x″ₙ → 0，而 f(x′ₙ) − f(x″ₙ) 趋于 0 失败。这正是数列判别法的充分性：点对是从否定中机械抽出来的，靠的是推理而非灵感。

6. f(x) = √x 在 [0, +∞) 上一致连续吗？

A.是：|√x′ − √x″| ≤ √|x′ − x″|，取 δ = ε² 即可B.否：它的图像在 0 处竖直C.否：它在 [0, +∞) 上无界
答案: A. 陡峭和无界都算不上敌人。处处相同的 δ 存在：只要 |x′ − x″| < ε²，就有 |√x′ − √x″| < ε。（对照 ax + b：取 δ = ε/(|a| + 1)。）

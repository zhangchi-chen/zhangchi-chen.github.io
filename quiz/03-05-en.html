Find lim(x→∞) (1 + 3/x)²ˣ.

A. e^(3/2)B. e⁶C. e⁵

B. Rewrite as [(1 + 3/x)ˣ]²: the bracket is the k = 3 costume, tending to e³, so the limit is (e³)² = e⁶.

Find lim(x→0) (cos x)^(1/x²).

A. 1B. e^(−1/2)C. e⁻²

B. A 1^∞ form with α = cos x − 1 = −2sin²(x/2): αg = −½·(sin(x/2)/(x/2))² → −½, so the limit is e^(−1/2).

lim(x→∞) (1 − 1/x)ˣ is a family member in disguise; its value is:

A. eB. e⁻¹C. 1

B. It is (1 + k/x)ˣ with k = −1, tending to e⁻¹; for k < 0 one uses the ancestor's x → −∞ version.

Why does the proof that sin x / x → 1 compare areas rather than lengths?

A. Areas are larger, so the inequality is easier to see.B. Comparing arc with chord would require a theory of arc length first — circular reasoning.C. Lengths cannot satisfy strict inequalities.

B. Arc length itself is built from this very limit; areas need only elementary geometry — one figure containing another.

Setting u = 1/x, (1 + u)^(1/u) → e (two-sided u → 0) needs which ancestor processes?

A. only x → +∞B. both x → +∞ and x → −∞C. only x → 0

B. x → +∞ corresponds to u → 0⁺ and x → −∞ to u → 0⁻; forgetting one process loses half the answer.

lim(x→∞) sin x / x = ?

A. 1B. 0C. does not exist

B. |sin x / x| ≤ 1/|x| → 0: the first ruler only rules near 0; far away the graph oscillates while decaying.

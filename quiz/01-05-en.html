For S = {q ∈ ℚ : q² < 3} with m = 1, the first step yields a₁ = ?

A. 1.7B. 1.8C. 1.73

A. 1.7² = 2.89 < 3, so 1.7 is not an upper bound; 1.8² = 3.24 ≥ 3, so 1.8 is; hence a₁ = 1.7 and the target lies in [1.7, 1.8].

For S = [−2.5, −0.3), the largest integer that is NOT an upper bound is:

A. −1B. 0C. −3

A. −1 is exceeded by −0.5 ∈ S while 0 is an upper bound, so m = −1 and the target lies in [−1, 0].

For S = [0, 0.42), why does the recurring-9 convention matter?

A. The search spells 0.42000…; the convention is irrelevantB. The search spells 0.41999…, equal to sup S = 0.42 only by conventionC. The search never ends, so α does not exist

B. 0.42 is always an upper bound and never gets chosen, so the digits are 0.41999…; the convention recognizes this decimal as 0.42.

In point (i), which constructed fact leads to the contradiction?

A. aₙ is not an upper boundB. aₙ + 10⁻ⁿ is an upper boundC. α ∈ S

B. From s > α, for all large n we get s > aₙ + 10⁻ⁿ, so aₙ + 10⁻ⁿ fails to be an upper bound.

Which inequality holds for every n?

A. aₙ < α < aₙ + 10⁻ⁿB. aₙ ≤ α ≤ aₙ + 10⁻ⁿC. α ≤ aₙ

B. aₙ is the truncation of α to n digits; the remaining digits contribute between 0 and 10⁻ⁿ (equality can occur, e.g. 0.41999… = 0.42).

Where exactly is completeness used in the proof?

A. When choosing the integer mB. When admitting that the infinite decimal α is a real numberC. In the contradiction of point (i)

B. Every other step is a finite check; only “the infinite decimal α is a number of ℝ” invokes completeness.

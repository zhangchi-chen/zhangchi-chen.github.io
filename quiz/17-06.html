无条件极值

← 讲稿 · 目录
1. 1. 求 f = x² + y² − 2x + 4y 的稳定点并判别类型。
  1. A(1, −2)，极小值
  2. B(−1, 2)，极小值
  3. C(1, −2)，无极值
    4. 正确答案：A. f_x = 2x − 2 = 0，f_y = 2y + 4 = 0 得 (1, −2)；A = 2，B = 0，C = 2，AC − B² = 4 > 0 且 A > 0：极小值 f(1, −2) = −5。
2. 2. f = x³ − 3x + y² 的稳定点是 (1, 0) 与 (−1, 0)。哪种判别正确？
  1. A两点都是极小值点
  2. B(1, 0) 极小；(−1, 0) 无极值
  3. C(1, 0) 无极值；(−1, 0) 极大
    4. 正确答案：B. A = 6x，B = 0，C = 2：在 (1, 0) 处 AC − B² = 12 > 0 且 A = 6 > 0；在 (−1, 0) 处 AC − B² = −12 < 0。
3. 3. 某稳定点处 A = −3，B = 1，C = −2。落在判别表的哪一格？
  1. A负定：极大值
  2. B正定：极小值
  3. C不定：无极值
    4. 正确答案：A. AC − B² = 6 − 1 = 5 > 0，且 A = −3 < 0。
4. 4. 对 f = (y − x²)(y − 2x²) 在原点，哪句话正确？
  1. AAC − B² < 0，所以无极值
  2. BAC − B² = 0，原点附近 f 有正有负：无极值
  3. C极小值，因为过原点每条直线上都是极小
    4. 正确答案：B. A = B = 0，C = 2；f(t, 1.5t²) = −t⁴/4 < 0，f(0, t) = t² > 0，而 f(0, 0) = 0。逐条直线看是极小，说明不了问题。
5. 5. f = √(x² + y²) 在原点：
  1. A偏导不存在，所以算不上候选
  2. B是极小值点，尽管偏导不存在
  3. C是稳定点
    4. 正确答案：B. f ≥ 0 = f(0, 0)；f(x, 0) = |x| 在 0 处导数不存在，这类候选点靠 grad f = 0 找不到。
6. 6. 陷阱题：某稳定点处 AC − B² = 0。能得出什么？
  1. A一定无极值
  2. B一定有极值
  3. C判别表给不出结论
    4. 正确答案：C. x² + y⁴ 满足 AC − B² = 0 却有极小值（否定 A）；(y − x²)(y − 2x²) 满足 AC − B² = 0 却无极值（否定 B）。

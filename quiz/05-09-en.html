2. 2y = eˣ with x = t². What is d²y with respect to t? <button
  1. AA4t² et² dt²
  2. BB(4t² + 2) et² dt²
  3. CC2 et² dt²
    4. Correct: B.
3. 3x = t², y = t³ (t > 0). What is d²y/dx²? <button
  1. AA32t
  2. BB34t
  3. CC32
    4. Correct: B.
4. 4f(x) = x³ − 3x at x = 1. What do dy and d²y say? <button
  1. AAdy = 0, d²y = 6dx² > 0: local minimum
  2. BBdy = 0, d²y = 6dx² > 0: local maximum
  3. CCdy ≠ 0 there, so the sign of d²y decides nothing
    4. Correct: A.
5. 5When is reading d²y ÷ dx² as f″(x) guaranteed to be right? <button
  1. AAAlways: d²y/dx² is just a fraction
  2. BBWhen x is the independent variable (a linear substitution x = at + b, a ≠ 0, is also fine)
  3. CCOnly when f″(x) ≠ 0
    4. Correct: B.
6. 6Which statement about d(x²) and dx² is correct? <button
  1. AAd(x²) = dx²: they look alike because they are the same
  2. BBd(x²) = 2x dx, while dx² = (dx)²d(x²) = 2x dx
  3. CCd(x²) = 2x dx + (dx)²d(x²) 包含角上的小正方形
    4. Correct: B.

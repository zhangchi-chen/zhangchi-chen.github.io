1. Which expression equals f′(x0) = limx→x0 f(x) − f(x0)x − x0 ? <button type="button"
  1. AAlimΔx→0 f(x0 + Δx) − f(x0)Δx
  2. BBlimΔx→0 f(x0 + Δx) − f(x0)x0
  3. CCf(x0 + Δx) − f(x0)Δx for one small fixed Δx
    4. Correct: A. A Put x = x0 + Δx: then x − x0 = Δx, and x → x0 exactly when Δx → 0. B divides by the wrong quantity; C is one difference quotient, not its limit.
2. From the definition, f(x) = 3x² − x has f′(2) = <button type="button"
  1. AA10
  2. BB11
  3. CC12
    4. Correct: B. B f(2 + Δx) − f(2)Δx = 11Δx + 3Δx²Δx = 11 + 3Δx → 11. (10 is f(2) itself, a value, not a rate.)
3. The tangent line to y = x² at (−1, 1) is <button type="button"
  1. AAy = 2x + 3
  2. BBy = −2x + 1
  3. CCy = −2x − 1
    4. Correct: C. C (−1 + Δx)² − 1Δx = −2 + Δx → −2, so y − 1 = −2(x + 1). A has the wrong sign of slope; B has the right slope but misses (−1, 1).
4. A ball falls s(t) = 5t² metres. Its instantaneous velocity at t = 2 s is <button type="button"
  1. AA10 m/s
  2. BB20 m/s
  3. CC40 m/s
    4. Correct: B. B 5(2 + Δt)² − 20Δt = 20 + 5Δt → 20. The 10 m/s option is the average over the first two seconds.
5. Where is f(x) = x²·D(x) differentiable (D the Dirichlet function)? <button type="button"
  1. AAonly at x = 0
  2. BBat every rational x
  3. CCnowhere
    4. Correct: A. A At 0 the quotient is x·D(x), squeezed by ±|x| → 0, so f′(0) = 0. At any x0 ≠ 0 the top stays about x0² on a dense set of points while the bottom → 0: the quotient is unbounded.
6. For f(x) = |x|, limh→0 f(h) − f(−h)2h = 0. Therefore <button type="button"
  1. AAf′(0) = 0
  2. BBf′(0) = 1
  3. CCnothing about f′(0); in fact it does not exist
    4. Correct: C. C The symmetric quotient never looks at f(0). The true quotient |x|/x is 1 on the right and −1 on the left, so it has no limit.

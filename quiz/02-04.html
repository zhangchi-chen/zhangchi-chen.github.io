1. 不等式 0 ≤ cₙ ≤ 1 + 3/n 成立，能推出 cₙ 的什么？

A. cₙ → 1B. 推不出极限C. cₙ → 0
B — 两界分别趋于 0 和 1，极限不同，迫敛法推不出任何结论。

2. 配合下界 1 − 1/n² ≤ cₙ，上界 1 + 3/n 够用吗？

A. 够用：两界都趋于 1B. 不够：它比下界粗糙得多C. 须把 3/n 换成 3/n²
A — 两个界的精度可以不同，只要求它们的极限相同。

3. 为什么乘积法则不能给出 (−1)ⁿ · n/(n²+1) → 0？

A. n/(n²+1) 没有极限B. 乘积无界C. (−1)ⁿ 没有极限
C — 乘积法则要求两个因子都收敛；(−1)ⁿ 振荡，所以改用 |cₙ| ≤ 1/n 迫敛。

4. 用哪两个界来迫敛 xₙ = Σᵢ₌₁ⁿ 1/√(n²+i)？

A. n/√(n²+n) 与 n/√(n²+1)B. 1/√(n²+n) 与 1/√(n²+1)C. 0 与 1
A — 把 n 项全换成最小项、再全换成最大项，两界都趋于 1。

5. 推出 [nα]/n → α 的关键不等式是？

A. [nα] ≥ nαB. nα − 1 < [nα] ≤ nαC. [nα] ≤ nα − 1
B — 将 nα − 1 < [nα] ≤ nα 同除以 n，得到两个都趋于 α 的界。

6. 下列哪个极限真正需要迫敛法？

A. (2n+1)/(n+3)B. (n+1)/nC. sin n / n
C — sin n 没有极限，四则运算失效；由 |sin n / n| ≤ 1/n 迫敛到 0。

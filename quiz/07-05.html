1. 在对照词典中，增量 Δan = an+1 − an 对应的是……
答案: B. 一步增量是离散的导数，累加增量是离散的积分。
2. 对 bn = 2 − 1/n，an = 3 − 1/n，清单中哪一项不成立？
答案: B. bn 递增但始终小于 2，开头冲不掉，于是 anbn → 3/2 而不是 1。
3. 证明中，初始存量 aₘ, bₘ 为什么最终无关紧要？
答案: A. 头部以 (am − (L ± ε)bm)/bn 的形式出现，因 bn → +∞ 而趋于 0。
4. 对每个固定的 ε，夹逼直接得到什么？
答案: B. 上极限与下极限都被困在 L 的 ε 邻域内；ε 任意，二者只能在 L 相遇。
5. lim (1 + 2 + … + n)/n² 等于多少？
答案: B. 增量分别为 n + 1 与 2n + 1，其比趋于 1/2，且 n² 严格递增趋于 +∞。
6. an = (−1)n，bn = n 这个例子说明……
答案: A. anbn → 0，但增量之比 2(−1)n+1 没有极限：定理是单向的。

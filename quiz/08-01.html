原函数与不定积分

← 讲稿 · 目录
1. 1. 下列哪个函数是 f(x) = x eˣ 在 ℝ 上的原函数？
  1. Ax eˣ + eˣ
  2. Bx eˣ − eˣ
  3. C½x² eˣ
    4. 正确答案：B. 求导验证：eˣ + x eˣ − eˣ = x eˣ；A 得 (x + 2)eˣ，C 得 x eˣ + ½x² eˣ。
2. 在 x ≠ 0 上，F(x) = arctan x 与 G(x) = −arctan(1/x) 的导数都是 1/(1 + x²)。下列哪个说法正确？
  1. AF − G 在所有 x ≠ 0 上是同一个常数。
  2. BF − G 在 (0, +∞) 上不是常数。
  3. CF − G 在 (−∞, 0) 和 (0, +∞) 上各自是常数，但两个常数不同。
    4. 正确答案：C. 在每个区间上用拉格朗日中值定理的推论：x > 0 时 F − G = π/2，x < 0 时 F − G = −π/2。
3. 等式 ∫ cos x dx = sin x + C 说的是什么？
  1. A在 ℝ 上的全体原函数是 sin x + C，C 为任意常数。
  2. B它只指一个特定的原函数，即 C = 0 的那个。
  3. C只有知道了 C，cos x 的原函数才存在。
    4. 正确答案：A. 按定义2，不定积分是全体原函数；定理8.2保证每一个都形如 sin x + C。
4. 4. f(x) = 3x² 的某个原函数 F 满足 F(1) = 5，求 F(2)。
  1. A8
  2. B12
  3. C13
    4. 正确答案：B. F(x) = x³ + C，由 1 + C = 5 得 C = 4，所以 F(2) = 8 + 4 = 12。
5. 5. 判断：“有间断点的函数一定没有原函数。”
  1. A正确，由定理8.1可得。
  2. B正确，因为导函数总是连续的。
  3. C错误：取 F(x) = x² sin(1/x)，F(0) = 0，导函数 f = F′ 在 0 点间断，却有原函数 F。
    4. 正确答案：C. F′(0) = 0，x ≠ 0 时 F′(x) = 2x sin(1/x) − cos(1/x)，在 0 点无极限；定理8.1只给出单向结论。

归结原则

1. 要证明 limx→0 sin(1/x) 不存在，哪一对路线可行？
  1. Axn = 1/(2nπ + π/2) 与 xn = 1/(2nπ)
  2. Bxn = 1/n 与 xn = 2/n
  3. Cxn = 1/(2nπ) 与 xn = 1/(4nπ)
正确答案： A. 前者使 sin(1/xn) = 1 → 1，后者给出 0 → 0：两份报告不同，故极限不存在。
2. 对狄利克雷函数，在任一点 x₀ 处，哪组路线能否决极限断言？
  1. A两个趋于 x₀ 的无理数列
  2. B一个有理数列和一个无理数列，都趋于 x₀
  3. C常数列 xn = x₀
正确答案： B. 有理路线报告 1，无理路线报告 0；常数列不合要求，因为必须 xn ≠ x₀。
3. f(x) = 1（x > 0），f(x) = −1（x < 0）。哪对路线说明它在 0 处无极限？
  1. Axn = 1/n 与 xn = 1/n²
  2. Bxn = −1/n 与 xn = −1/n²
  3. Cxn = 1/n 与 xn = −1/n
正确答案： C. 右侧路线报告 1，左侧路线报告 −1；极限不同即无极限。
4. 你只检查了一个数列 xn → x₀，发现 f(xn) → A。能得出什么？
  1. Alimx→x₀ f(x) = A
  2. B还不能断言极限为 A：别的数列可能给出不同报告
  3. C极限存在，但可能不等于 A
正确答案： B. 证明极限需要每一个数列；狄利克雷函数通过了所有无理路线，却仍无极限。
5. 探针 xn = n 给出 en → +∞，它对 limx→+∞ ex 有什么作用？
  1. A排除了所有有限极限；完整结论需要所有探针（由单调性保证）
  2. B单独就能证明完整结论
  3. C说明极限为 0
正确答案： A. 一份无界的报告就能否决所有有限候选值，但确认 +∞ 仍需每一个趋于 +∞ 的数列。

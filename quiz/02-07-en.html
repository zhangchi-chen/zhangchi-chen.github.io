What does the Cauchy criterion compare?

A. each term aₙ with a candidate limit AB. pairs of tail terms aₙ, aₘ (m, n > N)C. each term aₙ with 0

B. The criterion is an internal check: no target value needed, only pairwise distances within the tail.

For sₙ = 1 + 1/2 + … + 1/2ⁿ and n > m, the tail |sₙ − sₘ| equals

A. 1/2ᵐ − 1/2ⁿB. 1/2ⁿ − 1/2ᵐC. 1/2ᵐ⁺¹

A. Each block 1/2ᵏ = 1/2ᵏ⁻¹ − 1/2ᵏ telescopes from k = m+1 to n, leaving 1/2ᵐ − 1/2ⁿ.

Suppose |aₙ₊₁ − aₙ| → 0. Which statement is correct?

A. {aₙ} must be CauchyB. {aₙ} must convergeC. neither follows — take the harmonic partial sums

C. For the harmonic series each step is 1/n → 0, yet |s₂ₙ − sₙ| ≥ 1/2: adjacent terms controlled, but not all tail pairs.

Which formula says “{aₙ} is NOT Cauchy”?

A. ∀ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀C. ∃ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀

B. Negation swaps the quantifiers one by one: there is one bad ε₀, and for every N some far-out pair still differs by at least ε₀.

A Cauchy sequence has a subsequence converging to L. Then

A. the whole sequence may still divergeB. the whole sequence converges to LC. only that subsequence converges

B. Triangle inequality: for large n, |aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε.

With ε₀ = 1/2, which pair proves the harmonic partial sums diverge?

A. sₙ and sₙ₊₁B. sₙ and s₂ₙC. s₁ and sₙ

B. Between sₙ and s₂ₙ lie n terms, each ≥ 1/(2n), so the gap is at least 1/2 for every n.

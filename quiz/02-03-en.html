Write aₙ = a + αₙ and bₙ = b + βₙ (αₙ, βₙ → 0). In the product expansion, the “second-order noise” term is ( )

A. aβₙB. bαₙC. αₙβₙ

C. Noise × noise is a higher-order small quantity, decaying faster than both αₙ and βₙ — this is exactly why the “constant + infinitesimal” mechanism survives multiplication.

When the denominator limit is b = 0, the limit of aₙ/bₙ ( )

C. (1/n)/(1/n²) = n → ∞; (1/n²)/(1/n) → 0; ((−1)ⁿ/n)/(1/n) diverges — anything can happen, so the quotient rule cannot be rescued.

B. From some term on, bₙ stays inside the |b|/2-band around b — only farther from 0 — so 1/bₙ is bounded and division is safe.

(−1)ⁿ and (−1)ⁿ⁺¹ both diverge, yet their sum is identically 0. This shows ( )

B. Convergent + convergent ⇒ convergent holds, but not the converse. The rule is a license to compute, not a test for convergence.

A. Each of the three error sources gets its share of ε and finds its own N, taking the maximum at the end — a small trick, not magic.

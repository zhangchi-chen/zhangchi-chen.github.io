By convention, 0.999… is…

A. slightly smaller than 1B. exactly 1C. not a real number

B. No decimal lies strictly between 0.999… and 1.000…: both name the same point, 0.999… = 1.

By convention, 0.24999… equals…

A. 0.24B. 0.25C. a number between 0.249 and 0.25 other than 0.25

B. An expansion ending in recurring 9s denotes the finite decimal after carrying — here 0.25.

Take x = π, n = 3. The truncation bound aₙ ≤ x < aₙ + 10⁻ⁿ reads…

A. 3.141 ≤ π < 3.142B. 3.14 ≤ π < 3.15C. 3.141 < π ≤ 3.142

A. a₃ = 3.141 is π truncated to three decimals, and a₃ + 10⁻³ = 3.142.

Why is the right-hand inequality in aₙ ≤ x < aₙ + 10⁻ⁿ strict?

A. Equality would force recurring 9s, which the convention excludesB. Because x is always irrationalC. Because truncation rounds up

A. x = aₙ + 10⁻ⁿ would force every digit after position n to be 9; the convention rewrites such x in carried form.

f continuous on [a, b] with f(a) < 0 < f(b): the intermediate value property guarantees…

A. a rational zero existsB. some c ∈ [a, b] with f(c) = 0 existsC. bisection stops after finitely many steps

B. The zero exists as a real number, possibly irrational: the zero of x² − 2 on [1, 2] is √2.

For x = 0.1428… and y = 0.1432…, which is correct?

A. x < yB. x > yC. Undecidable without knowing all digits

A. The first differing digit is the third: 2 < 3, hence x < 0.143 ≤ y.

1. 1. f(x) = x² 在 [0, 2] 上的平均值是多少？中值点在哪？
  1. A平均值 4/3，ξ = 2/√3
  2. B平均值 8/3，ξ = √(8/3)
  3. C平均值 2，ξ = √2
    4. 正确答案：A. ∫₀² x² dx = 8/3，除以区间长度 2 得 4/3；由 ξ² = 4/3 得 ξ = 2/√3 ≈ 1.15，在 (0, 2) 内。
2. 对 [0, 2π] 上的 f(x) = cos x，关于中值点哪个说法正确？
  1. A只有 ξ = 0 可以。
  2. Bξ = π/2 或 3π/2，都在 (0, 2π) 内。
  3. C不存在，因为积分等于 0。
    4. 正确答案：B. 平均值为 0，cos ξ = 0 的解 π/2 与 3π/2 都在区间内部，与课本的注一致。
3. 3. 定理9.7的三步证明中，工具的顺序哪个正确？
  1. A介值定理 → 最大最小值定理 → 积分的单调性
  2. B积分的单调性 → 介值定理 → 最大最小值定理
  3. C最大最小值定理 → 积分的单调性 → 介值定理
    4. 正确答案：C. 先得到 m 和 M，再对 m ≤ f ≤ M 积分，最后用介值定理取到平均值。
4. 4. 在 [0, 1] 上取 f(x) = x，权 g(x) = x。哪个 ξ 满足定理9.8？
  1. Aξ = 1/2
  2. Bξ = 2/3
  3. Cξ = 1/√3
    4. 正确答案：B. ∫₀¹ x·x dx = 1/3，∫₀¹ x dx = 1/2，所以 ξ = (1/3)/(1/2) = 2/3；1/2 忽略了权。
5. 5. 用 m(b − a) ≤ ∫ₐᵇ f ≤ M(b − a)，∫₀¹ e^(−x²) dx 满足哪个估计？
  1. A1/e ≤ ∫ ≤ 1
  2. B0 ≤ ∫ ≤ 1/e
  3. C1 ≤ ∫ ≤ e
    4. 正确答案：A. e^(−x²) 在长度为 1 的区间上从 1 降到 1/e；真值约 0.747，在两界之间。
6. 6. 在 [−1, 1] 上取 f(x) = x，g(x) = x。定理9.8的结论成立吗？
  1. A成立，ξ = 0 即可。
  2. B成立，因为 ∫g = 0，任意 ξ 都行。
  3. C不成立：左边是 2/3，右边对任何 ξ 都是 0。
    4. 正确答案：C. g 变号：∫₋₁¹ x² dx = 2/3，而 f(ξ)∫₋₁¹ x dx = 0；不变号的条件去不掉。

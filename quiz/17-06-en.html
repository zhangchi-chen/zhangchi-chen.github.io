Unconditional extrema: the quadratic form behind AC − B²

1. 1. Find and classify the stationary point of f = x² + y² − 2x + 4y.
  1. A(1, −2), local minimum
  2. B(−1, 2), local minimum
  3. C(1, −2), no extremum
    4. Correct: A. f_x = 2x − 2 = 0, f_y = 2y + 4 = 0 give (1, −2); A = 2, B = 0, C = 2, AC − B² = 4 > 0, A > 0: minimum, f(1, −2) = −5.
2. 2. f = x³ − 3x + y² has stationary points (1, 0) and (−1, 0). Which classification is right?
  1. Aboth are local minima
  2. B(1, 0) local minimum; (−1, 0) no extremum
  3. C(1, 0) no extremum; (−1, 0) local maximum
    4. Correct: B. A = 6x, B = 0, C = 2: at (1, 0), AC − B² = 12 > 0 with A = 6 > 0; at (−1, 0), AC − B² = −12 < 0.
3. 3. At a stationary point A = −3, B = 1, C = −2. Which cell of the 2×2 grid applies?
  1. Anegative definite: local maximum
  2. Bpositive definite: local minimum
  3. Cindefinite: no extremum
    4. Correct: A. AC − B² = 6 − 1 = 5 > 0 and A = −3 < 0.
4. 4. For f = (y − x²)(y − 2x²) at the origin, which statement is true?
  1. AAC − B² < 0, so no extremum
  2. BAC − B² = 0, and f takes both signs near the origin: no extremum
  3. Clocal minimum, since every line through the origin sees one
    4. Correct: B. A = B = 0, C = 2; f(t, 1.5t²) = −t⁴/4 < 0 and f(0, t) = t² > 0, while f(0, 0) = 0. Line-by-line minima prove nothing.
5. 5. f = √(x² + y²) at the origin:
  1. Anot a candidate, because f_x(0, 0) does not exist
  2. Ba local minimum, although f_x(0, 0) does not exist
  3. Ca stationary point
    4. Correct: B. f ≥ 0 = f(0, 0); f(x, 0) = |x| has no derivative at 0, so the origin is a candidate that grad f = 0 cannot find.
6. 6. Trap: at a stationary point AC − B² = 0. What follows?
  1. Athere is no extremum
  2. Bthere is an extremum
  3. Cthe table gives no conclusion
    4. Correct: C. x² + y⁴ has AC − B² = 0 and a minimum (refutes A); (y − x²)(y − 2x²) has AC − B² = 0 and no extremum (refutes B).

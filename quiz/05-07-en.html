Parametric curves: dy/dx is a ratio of two rates

← Notes · Index
1. A curve is given by x = t² + 2t, y = t³ + 4t². What is dy/dx at t = 1?
  1. A11/4
  2. B4/11
  3. C7
    4. Correct: A. dx/dt = 2t + 2 = 4, dy/dt = 3t² + 8t = 11, so dy/dx = 11/4. B flips the ratio; C is ψ″/φ″ = (6t + 8)/2, which is not the slope.
2. Cycloid x = t − sin t, y = 1 − cos t (a = 1). Which line is the tangent at t = π/2?
  1. Ay = x + 2 − π/2
  2. By = x + 1 − π/2
  3. Cy = 1
    4. Correct: A. The point is (π/2 − 1, 1) and the slope is cot(π/4) = 1, so y − 1 = x − (π/2 − 1). B takes the point as (π/2, 1), forgetting − sin t; C uses slope 0, which belongs to t = π.
3. Which is the honest justification of dy/dx = (dy/dt)/(dx/dt)?
  1. ACancel the dt in numerator and denominator.
  2. BChain rule on y = ψ(φ⁻¹(x)), then the inverse rule dt/dx = 1/(dx/dt), which needs φ′(t) ≠ 0.
  3. CEliminate t first; the formula only works when y can be written in x.
    4. Correct: B. Every step is a theorem from 05-04. In this episode dt alone is not yet a number, so cancelling is only a memory aid. C is wrong: the whole point is that t never has to be eliminated (try x = t + eᵗ).
4. For x = t³ − 3t, y = t², where is the formula dy/dx = ψ′(t)/φ′(t) unavailable?
  1. At = ±1
  2. Bt = 0
  3. Ct = ±√3
    4. Correct: A. φ′(t) = 3t² − 3 = 0 at t = ±1. There ψ′ = 2t = ±2 ≠ 0, so the tangent exists and is vertical. At t = 0, φ′ = −3 and the formula gives slope 0. At t = ±√3, φ′ = 6; the curve passes (0, 3) twice there, and the formula works at each value.
5. True or false: d²y/dx² = ψ″(t)/φ″(t).
  1. ATrue: it is the first-order pattern, one order up.
  2. BFalse: on the cycloid (a = 1) at t = π/2, the guess gives 0 but the honest computation gives −1.
  3. CTrue whenever φ″(t) ≠ 0.
    4. Correct: B. Guess: cos t/sin t = 0 at π/2. Honest: d/dt cot(t/2) = −1 there, divided by dx/dt = 1, gives −1. Since φ″(π/2) = 1 ≠ 0, C fails at the same point. Why the pattern breaks is the business of 05-09.
6. Which curve is not smooth on [−1, 1]?
  1. Ax = t³, y = |t|³
  2. Bx = t + eᵗ, y = sin t
  3. Cx = 2 cos t, y = sin t
    4. Correct: A. x′ = 3t² and y′ = 3t|t| are continuous, but both vanish at t = 0; the curve is y = |x|, with a corner and no tangent at the origin. B: x′ = 1 + eᵗ > 0. C: x′ = −2 sin t and y′ = cos t are never both 0.

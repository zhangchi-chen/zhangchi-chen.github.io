1. 1. (x sin x)⁽⁴⁾ equals:

  1. A. A. x sin x − 4cos x
  2. B. B. x sin x + 4cos x
  3. C. C. x sin x
A — Leibniz with v = x: only k = 0, 1 survive, x·sin x + 4·1·(−cos x).

2. 2. The value of (x² cos x)⁽⁴⁾ at x = 0 is:

  1. A. A. 0
  2. B. B. −12
  3. C. C. 12
B — v = x²: x²cos x + 4·2x·sin x + 6·2·(−cos x); at 0 only −12 remains.

3. 3. In (uv)⁽⁵⁾, the coefficient of u‴v″ is:

5. 5. For f(x) = |x|³, which is true?

  1. A. A. f″(0) does not exist
  2. B. B. f″(0) = 0, but f‴(0) does not exist
  3. C. C. f‴(0) = 6
B — f′ = 3x|x|, f″ = 6|x| with f″(0) = 0 by the definition; then 6|h|/h = ±6 has no limit.

6. 6. Trap: “For f(x) = x|x|, f = x² when x ≥ 0, so f″(0) = 2.”

  1. A. A. Correct
  2. B. B. Wrong: f″(0) does not exist
  3. C. C. Wrong: f″(0) = 0
B — f′ = 2|x|; its quotient at 0 is 2 from the right and −2 from the left.

  1. In the area picture, (u+Δu)(v+Δv) − uv = Δu·v + u·Δv + Δu·Δv. Which piece is o(Δx), and why?面积图中 (u+Δu)(v+Δv) − uv = Δu·v + u·Δv + Δu·Δv。哪一块是 o(Δx)？为什么？

    B — Each strip divided by Δx has a non-zero limit (u′v and uv′). The corner's ratio is (Δu/Δx)·Δv, and Δv → 0 because a differentiable v is continuous (Theorem 5.1, 05-02).每条窄条除以 Δx 都有非零极限（u′v 与 uv′）。角块的比值是 (Δu/Δx)·Δv，而可导的 v 必连续，所以 Δv → 0（定理 5.1，05-02）。

  2. Which route turns the product rule into the quotient rule?哪条路线能由乘积法则推出商法则？

    C — Step 1, the reciprocal: [1/v(x₀+Δx) − 1/v(x₀)]/Δx = −(Δv/Δx)/(v(x₀+Δx)v(x₀)) → −v′/v², using continuity and v(x₀) ≠ 0. Step 2: u′/v + u·(−v′/v²) = (u′v − uv′)/v². The minus sign is the reciprocal's.第一步，倒数：[1/v(x₀+Δx) − 1/v(x₀)]/Δx = −(Δv/Δx)/(v(x₀+Δx)v(x₀)) → −v′/v²，用到连续性和 v(x₀) ≠ 0。第二步：u′/v + u·(−v′/v²) = (u′v − uv′)/v²。减号来自倒数。

  3. What is (x² sin x)′ at x = π?(x² sin x)′ 在 x = π 处等于多少？

    A — (x² sin x)′ = 2x sin x + x² cos x; at π: 0 + π²·(−1) = −π². The value −2π is the mistake u′v′ = 2x cos x.(x² sin x)′ = 2x sin x + x² cos x；在 π 处：0 + π²·(−1) = −π²。−2π 是错误公式 u′v′ = 2x cos x 的结果。

  4. Let f(x) = x/(1 + x²). What is f′(2)?设 f(x) = x/(1 + x²)，f′(2) 是多少？

    B — f′ = [1·(1+x²) − x·2x]/(1+x²)² = (1 − x²)/(1+x²)², so f′(2) = −3/25. 3/25 swaps the order in the numerator; 1/4 is u′/v′ = 1/(2x).f′ = [1·(1+x²) − x·2x]/(1+x²)² = (1 − x²)/(1+x²)²，所以 f′(2) = −3/25。3/25 是把分子两项顺序弄反了；1/4 是 u′/v′ = 1/(2x)。

  5. Let f(x) = (x⁴ + 3x²)/x² for x ≠ 0. What is f′(1)? (Simplify first.)设 f(x) = (x⁴ + 3x²)/x²（x ≠ 0），f′(1) 是多少？（先化简。）

    A — For x ≠ 0, f(x) = x² + 3, so f′(x) = 2x and f′(1) = 2. The quotient rule gives the same, in more lines. 5 is u′/v′ = (4x³ + 6x)/(2x) at 1.x ≠ 0 时 f(x) = x² + 3，所以 f′(x) = 2x，f′(1) = 2。用商法则结果相同，只是多写几行。5 是 u′/v′ = (4x³ + 6x)/(2x) 在 1 处的值。

  6. True or false: (uv)′ = u′v′.判断：(uv)′ = u′v′。

    B — One counterexample is enough: x·x = x² has derivative 2x = 2 at 1, while u′v′ = 1·1 = 1. The missing half is the two strips x·Δx.一个反例就够：x·x = x² 的导数在 1 处是 2x = 2，而 u′v′ = 1·1 = 1。少掉的一半就是两条窄条 x·Δx。

The implicit function theorem: a function hidden inside an equation

1. 1. Take the circle and the point below. Which statement is true? F(x, y) = x² + y² − 1, P₀(0, −1)
  1. AAll four hypotheses hold; near P₀ the implicit function is y = −√(1 − x²)
  2. BHypothesis (iv) fails, since F_y(0, −1) = 0
  3. CHypothesis (ii) fails, since F(0, −1) ≠ 0
    4. Correct: A. the initial condition holds, F_y is nonzero there, and the lower branch is the implicit function. F(0, −1) = 0, F_y = 2y = −2 ≠ 0
2. 2. At which points of the circle below does hypothesis (iv) fail? x² + y² = 1
  1. A(0, 1), (0, −1)
  2. BNowhere on the circle
  3. C(1, 0), (−1, 0)
    4. Correct: C. the partial in y vanishes exactly where y is zero; there the curve stops being a graph of x. F_y = 2y = 0 ⇔ y = 0, x = ±1
3. 3. The rectangle picture gives the sign pattern below. Why does each column hold exactly one zero? F(x, y₀ − β) 0
  1. AContinuity in x alone is enough
  2. BThe intermediate value theorem gives at least one; strict monotonicity in y gives at most one
  3. CBecause F_x(P₀) ≠ 0
    4. Correct: B. the column starts negative and ends positive, and since F only rises along it, it crosses zero once.
4. 4. Claim: when hypothesis (iv) fails at P₀, no implicit function exists near P₀. Test it on the equation below at the origin. y³ − x³ = 0, F_y(0, 0) = 0
  1. ATrue: the theorem forbids an implicit function
  2. BTrue, because F(0, 0) ≠ 0
  3. CFalse: the equation still determines y = x
    4. Correct: C. the conditions are only sufficient; equal cubes force equal numbers, so the solution set is one continuous function. y³ = x³ ⇔ y = x, F(0, 0) = 0
5. 5. For the equation below, what is F_y at the origin? y − x − ½ sin y = 0
  1. A½
  2. B0
  3. C3/2
    4. Correct: A. differentiate in y and put y equal to zero; the cosine there is one. F_y = 1 − ½ cos y, F_y(0, 0) = 1 − ½ = ½
6. 6. For the lemniscate below, which statement about the origin is true? (x² + y²)² − x² + y² = 0
  1. AAll four hypotheses hold
  2. B(iv) fails, and no unique implicit function exists in any neighbourhood
  3. C(ii) fails, since F(0, 0) ≠ 0
    4. Correct: B. the origin lies on the curve but the partial in y vanishes, and every column beside it meets the curve twice. F(0, 0) = 0, F_y = 4y(x² + y²) + 2y, F_y(0, 0) = 0

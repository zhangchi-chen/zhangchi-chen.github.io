Continuity and Discontinuities · Self-test

1. Continuity of f at x₀ requires which values to be equal?

A.left limit, right limit and f(x₀)B.left limit and right limit onlyC.f(x₀) and f(x₀ + 1)
Answer: A. Continuity is the three-way handshake: both one-sided limits must exist and equal f(x₀).

2. f(x) = x + 1 for x < 1 and 4 − x for x ≥ 1. At x = 1 the point is …

A.removableB.a jump, and f is right-continuousC.of the second kind
Answer: B. f(1⁻) = 2 and f(1⁺) = 3 both exist but differ; f(1) = 3 matches the right limit.

3. x·sin(1/x), undefined at 0, has at 0 a discontinuity that is …

A.removableB.a jumpC.of the second kind
Answer: A. |x·sin(1/x)| ≤ |x| → 0, so the limit 0 exists; defining the value 0 repairs it.

4. f(x) = 3x + 1, x₀ = 2, ε = 0.3. Which δ works?

A.δ = 0.1B.δ = 0.2C.δ = 0.3
Answer: A. |f(x) − 7| = 3|x − 2| < 3δ, so we need 3δ ≤ 0.3; with δ = 0.2, x = 2.15 gives 0.45 > 0.3.

5. Which of these is a discontinuity of the first kind?

A.sin(1/x) at 0B.1/x² at 0C.sgn x at 0
Answer: C. sgn x has one-sided limits −1 and 1: both exist and differ, a jump, hence first kind.

6. g equals f on (x₀ − 0.01, x₀ + 0.01) and f is continuous at x₀. Then g at x₀ is …

A.continuousB.possibly discontinuousC.always discontinuous
Answer: A. Continuity is local: only values near x₀ (including x₀) matter, and there g and f coincide.

1. 1. f(x) = x² 在 x₀ = 3 处，微分 dy 把增量 Δx 送到：

  1. A. A. 6·Δx
  2. B. B. 6·Δx + (Δx)²
  3. C. C. 9 + 6·Δx
A —— dy = f′(3)·Δx = 6Δx；B 是整个增量 Δy，C 是切线的高度。

2. 2. 下面哪一句是定理 5.9（一元函数）？

  1. A. A. If f is continuous at x₀, then f is differentiable at x₀.
  2. B. B. f is differentiable at x₀ if and only if f′(x₀) exists, and then A = f′(x₀).
  3. C. C. If f′(x₀) exists, f is differentiable at x₀, but A can differ from f′(x₀).
B —— 两个方向都成立，常数只能是 Δy/Δx 的极限。A 的反例：|x| 在 0 处。

3. 3. y = sin(x³)。令 u = x³，用 dy = f′(u) du：

  1. A. A. dy = cos(x³) dx
  2. B. B. dy = 3x²·cos(x³) dx
  3. C. C. dy = cos(3x²) dx
B —— dy = cos u du，而 du = 3x² dx；A 漏剥了内层。

4. 4. 在圆 x² + y² = 25 上的点 (3, 4) 处：

  1. A. A. dy/dx = −3/4, dx/dy = −4/3
  2. B. B. dy/dx = 3/4, dx/dy = 4/3
  3. C. C. dy/dx = −4/3, dx/dy = −3/4
A —— 由 2x dx + 2y dy = 0 得 dy/dx = −x/y = −3/4，dx/dy = −y/x = −4/3，用不着先选自变量。

5. 5. 曲线 x = t²，y = t³ 在 t = 1 处的斜率 dy/dx 是：

  1. A. A. 3/2
  2. B. B. 2/3
  3. C. C. 3
A —— dx = 2t dt，dy = 3t² dt，所以 dy/dx = 3t/2 = 3/2，真正的微分之商。

6. 6. 陷阱：“dy 就等于 Δy”。用 f(x) = x²，x₀ = 1，Δx = 0.1 检验。

  1. A. A. True: dy = Δy = 0.21
  2. B. B. False: dy = 0.2 but Δy = 0.21
  3. C. C. False: dy = 0.21 but Δy = 0.2
B —— dy = 2·0.1 = 0.2，Δy = 1.1² − 1 = 0.21；差 0.01 正是小角 (Δx)²。只有线性函数两者才相等。

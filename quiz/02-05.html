单调 + 有界 ⇒ 收敛 · 自测

1. 下列哪个数列有界但发散？

A. aₙ = 1/nB. aₙ = (−1)ⁿC. aₙ = 2 − 1/n

答案：B。(−1)ⁿ 始终在 [−1, 1] 内，却永远交替，没有极限；另两个都单调有界。

2. 用三步法处理 aₙ₊₁ = f(aₙ) 时，何时才能确信 L = f(L) 的根就是极限？

A. 一解出 L = f(L) 就可以B. 证明数列单调有界之后C. 算出前三项之后

答案：B。只有单调有界才保证极限存在；之后取极限才说明它满足 L = f(L)。

3. 对 a₁ = √2, aₙ₊₁ = √(2 + aₙ)，归纳步证明的是什么？

A. aₙ < 2 ⇒ aₙ₊₁ < 2B. aₙ > 2 ⇒ aₙ₊₁ > 2C. 对所有 n，aₙ = 2

答案：A。若 aₙ < 2，则 aₙ₊₁ = √(2 + aₙ) < √4 = 2；而 a₁ = √2 < 2 作为起点。

4. a₁ = 1, aₙ₊₁ = 2aₙ。解 L = 2L 得 L = 0。哪项正确？

A. aₙ → 0B. aₙ → ∞，L = 0 并不是极限C. aₙ → 1

答案：B。aₙ = 2ⁿ⁻¹ → ∞；L = f(L) 不涉及极限是否存在，先用它就是循环论证。

5. 对 aₙ₊₁ = aₙ²，取 a₁ = 0.5，数列会……

A. 递减趋于 0B. 收敛到 1C. 递增趋于 ∞

答案：A。起点在 (0, 1) 内，平方使每项变小；递减且以 0 为下界，故趋于 0。

6. 为什么说 lim (1 + 1/n)ⁿ 是 1^∞ 型？

A. 底数趋于 1，而指数趋于 ∞B. 因为极限等于 1C. 因为数列递减

答案：A。底数 → 1 与指数 → ∞ 相互角力，不能用“1 的任何次方都是 1”判断；这里极限是 e。

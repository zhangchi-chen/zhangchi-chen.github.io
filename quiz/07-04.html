上极限与下极限

← 讲稿 · 目录
1. 设 xₙ = (−1)ⁿ + 1/n。尾部上确界 sup{xₖ : k ≥ n} 怎样变化？
  1. A全都等于 1。
  2. B它们不增并趋于 1，所以 limsup xₙ = 1。
  3. C它们趋于 0，所以 limsup xₙ = 0。
    4. 正确答案：B. n 为偶数时尾部上确界是 1 + 1/n，为奇数时是 1 + 1/(n+1)：始终大于 1，不增，趋于 1。
2. 2. 定理 7.7 第 (i) 条：对任意 ε > 0，最终 xₙ < Ā + ε。它对应定理 7.7′ 的哪一句？
  1. A对任意 α > Ā，只有有限项大于 α。
  2. B对任意 β < Ā，有无穷多项大于 β。
  3. C数列没有任何一项大于 Ā。
    4. 正确答案：A. 取 α = Ā + ε；ε 任意，所以「最终低于 Ā 上方的每一条线」与「Ā 上方每一条线之上只有有限项」等价。B 对应的是第 (ii) 条。
3. 依次重复取 −1/2, −1/2, 1。求它的下极限与上极限。
  1. A下极限是 −1，上极限是 1。
  2. B下极限是 −1/2，上极限是 1/2。
  3. C下极限是 −1/2，上极限是 1。
    4. 正确答案：C. 聚点只有反复出现的 −1/2 和 1；用尾部上确界的说法，每一段尾部的上确界都是 1，下确界都是 −1/2。
4. 4. 对一个有界数列，你证明了 limsup xₙ ≤ liminf xₙ，却猜不出极限值。能推出什么？
  1. A还推不出什么：要先知道极限值。
  2. B数列收敛，极限就是两者的公共值。
  3. C数列最终是常数列。
    4. 正确答案：B. 定理 7.5 总有下极限 ≤ 上极限，所以两者相等；再由定理 7.6 得到收敛，无需先写出极限。C 不对：1/n 收敛，但从不是常数。
5. 5. 下列有界数列中，哪一个不可能收敛？
  1. A数列 (−1)ⁿ + 1/n
  2. B数列 (−1)ⁿ/n
  3. C数列 sin(nπ)
    4. 正确答案：A. 它的聚点是 1 和 −1，上极限 1 不等于下极限 −1，由定理 7.6 不收敛。(−1)ⁿ/n → 0，而 sin(nπ) 对每个 n 都等于 0。
6. 6. 判断：有界数列的上极限一定是它的某一项。
  1. A对：它是最大聚点，所以是数列的某个值。
  2. B对，至少在数列有界时成立。
  3. C错：(−1)ⁿ n/(n+1) 的上极限是 1，却没有一项等于 1。
    4. 正确答案：C. 每一项都满足 |xₙ| = n/(n+1) < 1，偶数项却逼近 1，所以上极限 1 取不到。sin(nπ/4) 的上极限恰好是某一项，但一般未必。

Limits at Infinity

1. In route one, how is g defined at the right endpoint π/2?

A.g(π/2) = f(π/2)B.g(π/2) = L₊ = lim(x→+∞) f(x)C.g(π/2) = tan(π/2)
Answer: B. tan x → +∞ as x → π/2⁻, so setting g(π/2) = L₊ is exactly what makes g continuous there.

2. Which theorem turns 'g continuous on [−π/2, π/2]' into 'g uniformly continuous'?

A.The Cantor theoremB.The max-min theoremC.The Bolzano–Weierstrass theorem
Answer: A. Cantor: continuous on a closed interval ⇒ uniformly continuous. Then f = g∘arctan, and |arctan y′ − arctan y″| ≤ |y′ − y″| carries the same δ over to f.

3. Which is the definition of 'f uniformly continuous on ℝ'?

A.∀x′ ∈ ℝ ∀ε > 0 ∃δ > 0 ∀x″: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εB.∀ε > 0 ∃δ > 0 ∀x′, x″ ∈ ℝ: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εC.∃δ > 0 ∀ε > 0 ∀x′, x″ ∈ ℝ: |x′ − x″| < δ ⇒ |f(x′) − f(x″)| < ε
Answer: B. δ depends only on ε, and must serve all pairs of points. The first option lets δ depend on x′ (that is plain continuity); the third forces f to be constant.

4. Contradiction route, exit two: (xₙ) is unbounded. Why does |f(xₙₖ) − f(yₙₖ)| → 0?

A.Because f is bounded on ℝB.Because f is monotone far outC.Because xₙₖ → +∞ and yₙₖ → +∞ (or both → −∞), so both images tend to the same limit L₊ (or L₋)
Answer: C. |xₙ − yₙ| < 1/n drags yₙₖ to the same horizon, and the limit at that horizon is one number, so the gap tends to 0, contradicting ≥ ε₀.

5. For f(x) = 1/(1 + x²), which statement is true?

A.Maximum 1 is attained at 0; the infimum 0 is not attainedB.Both the maximum and the minimum are attainedC.Neither extremum is attained
Answer: A. 1 + x² ≥ 1 gives f ≤ 1 = f(0); f > 0 everywhere but f → 0 at ±∞. On the strip g(x) = cos²x, and its minimum 0 sits only on the capes ±π/2.

6. f(x) = arctan x has limits π/2 and −π/2. What do Results 1 and 2 say about it?

A.Result 2 applies, so arctan attains its maximumB.It is uniformly continuous (Result 1), but Result 2 does not apply and indeed neither extremum is attainedC.It is not uniformly continuous, since its range is bounded
Answer: B. Result 1 needs only that both limits exist. Result 2 needs them equal: here g(x) = x on [−π/2, π/2], whose extrema sit only on the two endpoints.

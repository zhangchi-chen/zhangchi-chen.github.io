无穷远的极限

点击选项下方按钮查看答案与解析。

1. 第一条路中，g 在右端点 π/2 处怎样定义？

A.g(π/2) = f(π/2)B.g(π/2) = L₊ = lim(x→+∞) f(x)C.g(π/2) = tan(π/2)
答案: B. x → π/2⁻ 时 tan x → +∞，所以令 g(π/2) = L₊，g 在该点恰好连续。

2. 哪个定理把“g 在 [−π/2, π/2] 上连续”升级为“g 一致连续”？

A.康托尔定理B.最大值最小值定理C.致密性定理（波尔查诺–魏尔斯特拉斯）
答案: A. 康托尔定理：闭区间上的连续函数一致连续。再由 f = g∘arctan 与 |arctan y′ − arctan y″| ≤ |y′ − y″|，同一个 δ 对 f 也成立。

3. “f 在 ℝ 上一致连续”的定义是哪一个？

A.∀x′ ∈ ℝ ∀ε > 0 ∃δ > 0 ∀x″：|x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εB.∀ε > 0 ∃δ > 0 ∀x′, x″ ∈ ℝ：|x′ − x″| < δ ⇒ |f(x′) − f(x″)| < εC.∃δ > 0 ∀ε > 0 ∀x′, x″ ∈ ℝ：|x′ − x″| < δ ⇒ |f(x′) − f(x″)| < ε
答案: B. δ 只依赖于 ε，并且要对所有点对成立。第一项允许 δ 依赖 x′，那只是连续；第三项会迫使 f 为常数。

4. 反证路线的出口二：(xₙ) 无界。为什么 |f(xₙₖ) − f(yₙₖ)| → 0？

A.因为 f 在 ℝ 上有界B.因为 f 在远处单调C.因为 xₙₖ → +∞ 且 yₙₖ → +∞（或都趋于 −∞），两列像趋于同一个极限 L₊（或 L₋）
答案: C. |xₙ − yₙ| < 1/n 把 yₙₖ 也拖到同一条地平线，那里的极限是同一个数，所以像的差趋于 0，与 ≥ ε₀ 矛盾。

5. 关于 f(x) = 1/(1 + x²)，哪一句正确？

A.在 0 处取到最大值 1；下确界 0 取不到B.最大值与最小值都取到C.两个最值都取不到
答案: A. 由 1 + x² ≥ 1 得 f ≤ 1 = f(0)；处处 f > 0，但在 ±∞ 处 f → 0。条带上 g(x) = cos²x，最小值 0 只在海角 ±π/2 上。

6. f(x) = arctan x 的两端极限是 π/2 与 −π/2。结论一、二怎么说？

A.结论二适用，所以 arctan 取到最大值B.它一致连续（结论一），但结论二不适用，事实上两个最值都取不到C.因为值域有界，它并非一致连续
答案: B. 结论一只要两端极限存在；结论二要两极限相等。这里 g(x) = x，最值只落在两个端点上。

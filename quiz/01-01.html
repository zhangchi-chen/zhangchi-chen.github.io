1. 按约定，0.999… 是……
A比 1 略小的数B恰好等于 1C不是实数
答案: B. 0.999… 与 1.000… 之间没有任何小数，二者表示同一个点：0.999… = 1。
2. 按约定，0.24999… 等于……
A0.24B0.25C介于 0.249 与 0.25 之间但不等于 0.25 的数
答案: B. 以循环 9 结尾的展开表示进位后的有限小数，这里是 0.25。
3. 取 x = π，n = 3，截断界 aₙ ≤ x < aₙ + 10⁻ⁿ 是……
A3.141 ≤ π < 3.142B3.14 ≤ π < 3.15C3.141 < π ≤ 3.142
答案: A. a₃ = 3.141 是 π 截断到 3 位小数，a₃ + 10⁻³ = 3.142。
4. 为什么 aₙ ≤ x < aₙ + 10⁻ⁿ 右边是严格不等号？
A取等需要循环 9，已被约定排除B因为 x 总是无理数C因为截断是向上取整
答案: A. x = aₙ + 10⁻ⁿ 会迫使第 n 位之后全是 9；约定把这样的 x 改写成进位形式。
5. f 在 [a, b] 上连续且 f(a) < 0 < f(b)，介值性保证……
A存在有理零点B存在 c ∈ [a, b] 使 f(c) = 0C二分法有限步内停止
答案: B. 零点作为实数存在，可能是无理数：[1, 2] 上 x² − 2 的零点是 √2。
6. 对 x = 0.1428… 和 y = 0.1432…，哪项正确？
Ax < yBx > yC不知道全部数字就无法判断
答案: A. 第一个不同的数字在第三位：2 < 3，所以 x < 0.143 ≤ y。

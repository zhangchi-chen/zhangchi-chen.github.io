Cantor's Theorem

Click the button under each item to reveal the answer.

1. Why does “collect every local δ(x) on [a, b] and take the smallest” fail as a proof?

A.There are infinitely many δ(x), and their infimum may be 0, so a smallest one need not exist.B.Local δ(x) can be negative, so the minimum is meaningless.C.A closed interval contains only finitely many points, so the argument is unnecessary.
Answer: A. 1, 1/2, 1/3, … are all positive, yet inf = 0. The argument also never uses the walls: word for word it would “prove” that 1/x is uniformly continuous on (0, 1], which is false.

2. In Beat one of the proof, where exactly is closedness of [a, b] used?

A.To make the sequence xₙ bounded.B.To guarantee the limit x₀ of xₙₖ stays in [a, b], since a ≤ xₙₖ ≤ b gives a ≤ x₀ ≤ b.C.To make f continuous.
Answer: B. Boundedness is what Bolzano–Weierstrass needs; closedness keeps x₀ inside the courtyard, so continuity at x₀ is available in Beat three.

3. Run the three beats for f(x) = 1/x on (0, 1] with xₙ = 1/n, yₙ = 1/(n+1). What breaks?

A.Beat two: yₙ no longer follows xₙ.B.Nothing breaks, because 1/x is uniformly continuous on (0, 1].C.Beat three: the limit x₀ = 0 is outside (0, 1], so there is no continuity at x₀ to use.
Answer: C. |xₙ − yₙ| = 1/(n(n+1)) → 0 and both tend to 0, but |f(xₙ) − f(yₙ)| = 1 for every n. The checkpoint escaped through the missing wall.

4. In the gluing lemma, how is a cross-border pair x′ ∈ I₁, x″ ∈ I₂ handled?

A.Route through c: since x′ ≤ c ≤ x″, each point is within δ₃ of c, so each value is within ε/2 of f(c).B.Take δ = δ₁ + δ₂.C.It cannot be handled; the lemma needs one formula for f on both pieces.
Answer: A. |f(x′) − f(x″)| ≤ |f(x′) − f(c)| + |f(c) − f(x″)| < ε/2 + ε/2 = ε, with δ = min{δ₁, δ₂, δ₃}.

5. On [1, ∞), |cos √x′ − cos √x″| ≤ |x′ − x″|/2. Given ε > 0, which δ works?

A.δ = ε/2B.δ = 2εC.δ = ε²
Answer: B. L = 1/2, so δ = ε/L = 2ε: then |cos √x′ − cos √x″| ≤ |x′ − x″|/2 < 2ε/2 = ε.

6. Which statement about √x is true?

A.√x satisfies a Lipschitz condition on [0, ∞).B.√x is uniformly continuous on [0, ∞), yet has no Lipschitz constant on [0, 1].C.√x is not uniformly continuous near 0.
Answer: B. |√t − √0|/|t − 0| = 1/√t → ∞ as t → 0, so no L works on [0, 1]; Cantor covers [0, 1], L = 1/2 covers [1, ∞), and gluing at 1 finishes. Lipschitz is sufficient, not necessary.

  1. Which expression equals f′(x0) = limx→x0 f(x) − f(x0)x − x0 ?下面哪一个等于 f′(x0) = limx→x0 f(x) − f(x0)x − x0？

    A Put x = x0 + Δx: then x − x0 = Δx, and x → x0 exactly when Δx → 0. B divides by the wrong quantity; C is one difference quotient, not its limit.令 x = x0 + Δx，那么 x − x0 = Δx，并且 x → x0 恰好对应 Δx → 0。B 除错了量；C 只是一个差商，没有取极限。

  3. The tangent line to y = x² at (−1, 1) is曲线 y = x² 在点 (−1, 1) 处的切线是

    C (−1 + Δx)² − 1Δx = −2 + Δx → −2, so y − 1 = −2(x + 1). A has the wrong sign of slope; B has the right slope but misses (−1, 1).(−1 + Δx)² − 1Δx = −2 + Δx → −2，所以 y − 1 = −2(x + 1)。A 斜率符号错；B 斜率对，却不过点 (−1, 1)。

  4. A ball falls s(t) = 5t² metres. Its instantaneous velocity at t = 2 s is小球下落的规律是 s(t) = 5t²（米）。t = 2 秒时的瞬时速度是

    B 5(2 + Δt)² − 20Δt = 20 + 5Δt → 20. The 10 m/s option is the average over the first two seconds.5(2 + Δt)² − 20Δt = 20 + 5Δt → 20。10 m/s 是前两秒的平均速度。

  5. Where is f(x) = x²·D(x) differentiable (D the Dirichlet function)?f(x) = x²·D(x)（D 为狄利克雷函数）在哪些点可导？

    A At 0 the quotient is x·D(x), squeezed by ±|x| → 0, so f′(0) = 0. At any x0 ≠ 0 the top stays about x0² on a dense set of points while the bottom → 0: the quotient is unbounded.在 0 处差商为 x·D(x)，被 ±|x| 夹住趋于 0，所以 f′(0) = 0。在任何 x0 ≠ 0 处，分子在稠密的点上保持约 x0² 的大小，分母却趋于 0，差商无界。

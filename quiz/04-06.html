Cantor 定理

点击选项下方按钮查看答案与解析。

1. “把 [a, b] 上每个点的 δ(x) 都收集起来取最小”，为什么算不上证明？

A.δ(x) 有无穷多个，下确界可能是 0，最小值未必存在。B.δ(x) 可能是负数，取最小没有意义。C.闭区间只有有限个点，所以这个论证多余。
答案: A. 1, 1/2, 1/3, … 个个为正，下确界却是 0。而且这个论证根本没用到围墙：照搬到 (0, 1] 上，它会“证明”1/x 一致连续，这是错的。

2. 证明的第一拍里，闭区间的“闭”究竟用在哪里？

A.用来保证数列 xₙ 有界。B.保证子列极限 x₀ 留在 [a, b] 内：由 a ≤ xₙₖ ≤ b 得 a ≤ x₀ ≤ b。C.用来保证 f 连续。
答案: B. 有界性是致密性定理需要的条件；“闭”让 x₀ 留在院内，于是第三拍才能用 x₀ 处的连续性。

3. 对 (0, 1] 上的 f(x) = 1/x，取 xₙ = 1/n，yₙ = 1/(n+1) 走一遍三拍，哪里出了问题？

A.第二拍：yₙ 跟丢了 xₙ。B.哪里都没问题，1/x 在 (0, 1] 上一致连续。C.第三拍：极限 x₀ = 0 落在 (0, 1] 之外，x₀ 处的连续性无从使用。
答案: C. |xₙ − yₙ| = 1/(n(n+1)) → 0，两列都趋于 0，可 |f(xₙ) − f(yₙ)| 恒为 1。检查站从缺失的围墙处逃走了。

4. 拼接引理中，跨境点对 x′ ∈ I₁，x″ ∈ I₂ 怎么处理？

A.绕道边境小镇 c：因为 x′ ≤ c ≤ x″，两点到 c 的距离都小于 δ₃，函数值到 f(c) 的距离都小于 ε/2。B.取 δ = δ₁ + δ₂。C.处理不了，引理要求 f 在两段上是同一个公式。
答案: A. |f(x′) − f(x″)| ≤ |f(x′) − f(c)| + |f(c) − f(x″)| < ε/2 + ε/2 = ε，取 δ = min{δ₁, δ₂, δ₃}。

5. 在 [1, ∞) 上 |cos √x′ − cos √x″| ≤ |x′ − x″|/2。给定 ε > 0，哪个 δ 可用？

A.δ = ε/2B.δ = 2εC.δ = ε²
答案: B. L = 1/2，所以 δ = ε/L = 2ε：此时 |cos √x′ − cos √x″| ≤ |x′ − x″|/2 < 2ε/2 = ε。

6. 关于 √x，哪个说法正确？

A.√x 在 [0, ∞) 上满足利普希茨条件。B.√x 在 [0, ∞) 上一致连续，但在 [0, 1] 上找不到利普希茨常数。C.√x 在 0 附近并非一致连续。
答案: B. t → 0 时 |√t − √0|/|t − 0| = 1/√t → ∞，所以 [0, 1] 上找不到 L；[0, 1] 交给康托尔，[1, ∞) 上 L = 1/2，在 1 处拼接即得。利普希茨只是充分条件，并非必要。

In Stirling's formula, which factor is the main engine of growth?

A) √(2πn)B) (n/e)ⁿC) e^(θₙ/(12n))

B) (n/e)ⁿ — exponential growth with an ever-growing base; √(2πn) is only a polynomial factor, and e^(θₙ/(12n)) lies between 1 and e^(1/(12n)).

In the proof skeleton, what does comparing Σ ln k with ∫ ln x dx give?

A) the exact value √(2π) of the constantB) bₙ = ln n! − (n+½)·ln n + n is monotone and bounded, so n!/(√n·(n/e)ⁿ) lies between two positive constantsC) n! grows faster than nⁿ

B) The first step only pins the shape √n·(n/e)ⁿ up to a constant factor; the value of that constant is still unknown here.

What role does Wallis' formula play in the proof?

A) proving bₙ convergesB) pinning down the constant: the Wallis ratio tends to C²/4, so C²/4 = π/2 and C = √(2π)C) showing the relative error is about 1/(12n)

B) Substitute n! ≈ C√n(n/e)ⁿ into the Wallis ratio: all powers of n and e cancel, leaving C²/4, which must equal π/2.

For n = 10, the relative error of √(2πn)·(n/e)ⁿ is roughly

A) about 8%B) about 0.8%C) about 0.08%

B) The error is about 1/(12n) = 1/120 ≈ 0.83% — already below one percent.

Fix a > 1: aⁿ/n! ≈ (ae/n)ⁿ/√(2πn). What happens once n > a·e?

A) the base ae/n drops below 1 and the ratio plunges to 0B) the ratio settles near √(2πn)C) the ratio keeps growing like (ae)ⁿ

A) Past n = a·e the base is below 1; its n-th power decays faster than any geometric sequence, so aⁿ/n! → 0.

Which expression gives the leading part of ln n!?

A) n ln n − nB) n ln n + nC) ½·ln(2πn)

A) ln n! = n ln n − n + ½·ln(2πn) + θₙ/(12n); the first two terms dominate and ½·ln(2πn) is lower order.

Parametric curves: a ratio of two rates
参数方程求导：两个速率之比

Episode 05-07 self-test, six questions. Pick an option or reveal the answer.
第05-07集自测，共六题：点选项，或直接看答案。

  1. A curve is given by x = t² + 2t, y = t³ + 4t². What is dy/dx at t = 1?

    曲线 x = t² + 2t，y = t³ + 4t²。t = 1 处 dy/dx 等于多少？

    A. dx/dt = 2t + 2 = 4, dy/dt = 3t² + 8t = 11, so dy/dx = 11/4. B flips the ratio; C is ψ″/φ″ = (6t + 8)/2, which is not the slope.

    dx/dt = 4，dy/dt = 11，所以 dy/dx = 11/4。B 把比倒过来了；C 是二阶导数之比，不是斜率。

  2. Cycloid x = t − sin t, y = 1 − cos t (a = 1). Which line is the tangent at t = π/2?

    摆线 x = t − sin t，y = 1 − cos t（a = 1）。t = π/2 处的切线是哪一条？

    A. The point is (π/2 − 1, 1) and the slope is cot(π/4) = 1, so y − 1 = x − (π/2 − 1). B takes the point as (π/2, 1), forgetting − sin t; C uses slope 0, which belongs to t = π.

    切点 (π/2 − 1, 1)，斜率 cot(π/4) = 1。B 把切点横坐标算错了；C 的斜率 0 属于 t = π（拱顶）。

  3. Which is the honest justification of dy/dx = (dy/dt)/(dx/dt)?

    下面哪一个才是 dy/dx = (dy/dt)/(dx/dt) 的真正理由？

    B. Every step is a theorem from 05-04. In this episode dt alone is not yet a number, so cancelling is only a memory aid. C is wrong: the whole point is that t never has to be eliminated (try x = t + eᵗ).

    每一步都是第五章第四集的定理；dt 单独还不是一个数，约分只是记法。C 不对：公式的价值正在于不必消去 t。

  4. For x = t³ − 3t, y = t², where is the formula dy/dx = ψ′(t)/φ′(t) unavailable?

    对 x = t³ − 3t，y = t²，公式 dy/dx = ψ′(t)/φ′(t) 在哪里用不了？

    A. φ′(t) = 3t² − 3 = 0 at t = ±1. There ψ′ = 2t = ±2 ≠ 0, so the tangent exists and is vertical. At t = 0, φ′ = −3 and the formula gives slope 0. At t = ±√3, φ′ = 6; the curve passes (0, 3) twice there, and the formula works at each value.

    t = ±1 时 φ′ = 0，但 ψ′ ≠ 0，切线竖直。t = 0 时斜率为 0；t = ±√3 时曲线两次经过 (0, 3)，公式照常可用。

  5. True or false: d²y/dx² = ψ″(t)/φ″(t).

    判断：d²y/dx² = ψ″(t)/φ″(t)。

    B. Guess: cos t/sin t = 0 at π/2. Honest: d/dt cot(t/2) = −1 there, divided by dx/dt = 1, gives −1. Since φ″(π/2) = 1 ≠ 0, C fails at the same point. Why the pattern breaks is the business of 05-09.

    猜想得 0，老实计算得 −1，同一点两个答案，所以猜想靠不住；而此处 φ″ = 1 ≠ 0，C 也被推翻。原因留给第五章第九集。

  6. Which curve is not smooth on [−1, 1]?

    哪条曲线在 [−1, 1] 上不是光滑曲线？

    A. x′ = 3t² and y′ = 3t|t| are continuous, but both vanish at t = 0; the curve is y = |x|, with a corner and no tangent at the origin. B: x′ = 1 + eᵗ > 0. C: x′ = −2 sin t and y′ = cos t are never both 0.

    A 的两个导数在 t = 0 同时为 0，轨迹是 y = |x|，原点处是拐角，没有切线。B、C 的两个导数从不同时为 0。

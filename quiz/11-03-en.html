Convergence tests: the p-integral as the measuring stick

← Notes · Index
1. 1. Decide ∫₁^{+∞} √x/(x² + 1) dx with the limit form.
  1. Adiverges: p = ½, λ = 1
  2. Bthe limit form cannot decide it
  3. Cconverges: p = 3/2, λ = 1
    4. Correct: C. x^{3/2}·√x/(x² + 1) = x²/(x² + 1) → 1, and 3/2 > 1.
2. 2. Decide ∫₁^{+∞} x¹⁰⁰ e^{−√x} dx.
  1. Aconverges: x²·x¹⁰⁰e^{−√x} → 0, so p = 2, λ = 0
  2. Bdiverges: x¹⁰⁰ grows too fast
  3. Cno conclusion, because λ = 0
    4. Correct: A. with t = √x the product is t²⁰⁴e^{−t} → 0; for p = 2 > 1 the value λ = 0 is allowed.
3. 3. ∫₁^{+∞} sin x/√x dx is …
  1. Aabsolutely convergent
  2. Bconditionally convergent
  3. Cdivergent
    4. Correct: B. Dirichlet (|cos 1 − cos u| ≤ 2, 1/√x decreases to 0) gives convergence; |sin x|/√x ≥ sin²x/x = 1/(2x) − cos 2x/(2x), whose integral diverges.
4. 4. To apply the Dirichlet test to ∫₁^{+∞} cos x/ln(1 + x) dx, which two facts are checked?
  1. A|cos x| ≤ 1 and ∫₁^{+∞} dx/ln(1 + x) converges
  2. Bcos x → 0 and 1/ln(1 + x) is bounded
  3. C|∫₁ᵘ cos x dx| ≤ 2 and 1/ln(1 + x) decreases to 0
    4. Correct: C. F(u) = sin u − sin 1 is bounded by 2 and 1/ln(1 + x) is monotone with limit 0; A fails because 1/ln(1 + x) ≥ 1/x has a divergent integral.
5. 5. ∫₀¹ dx/√(sin x) has the singular point 0. What happens?
  1. Adiverges, because q = ½ ≤ 1
  2. Bconverges: x^{1/2}·f(x) → 1 with q = ½ < 1
  3. Cdiverges, because the integrand is unbounded
    4. Correct: B. near a singular point convergence needs q < 1 (the mirror rule); x^{1/2}/√(sin x) = √(x/sin x) → 1.
6. 6. True or false: if f(x) → 0 as x → +∞, then ∫ₐ^{+∞} f(x) dx converges.
  1. Atrue, by the Cauchy criterion
  2. Btrue whenever f ≥ 0
  3. Cfalse
    4. Correct: C. 1/x → 0 but ∫₁^{+∞} dx/x diverges (even with f ≥ 0). What is true: if the integral converges and lim f exists, that limit is 0; f → 0 is not even necessary (sin(x²)).

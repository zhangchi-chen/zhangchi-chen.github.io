Continuous functions on a closed region: old theorems in a new home

← Notes · Index
1. 1. f(x, y) = x on the open unit square never attains its supremum 1. Which hypothesis of Theorem 16.8 is missing?
  1. Af is continuous
  2. BD is bounded
  3. CD is closed
    4. Correct: C. The square is bounded and f is continuous; the missing edge x = 1 is exactly where the supremum would be attained.
2. 2. In the four-frame proof of boundedness, which frame uses that D is closed?
  1. Athe limit P₀ of the subsequence lies in D
  2. Bchoosing Pₙ with |f(Pₙ)| > n
  3. Cextracting a convergent subsequence
    4. Correct: A. Closedness keeps the limit point in D, so continuity at P₀ can be used; the subsequence itself comes from boundedness (accumulation theorem).
3. 3. D = {xy > 0} and f(x, y) = the sign of x. Which statement is true?
  1. Af is not continuous on D
  2. Bf takes 1 and −1 but never 0, because D is not connected
  3. Cf(0, 0) = 0, so the value 0 is taken
    4. Correct: B. f is constant on each open quadrant, hence continuous; the origin is not in D, and no polygonal line inside D joins the two quadrants.
4. 4. True or false: if f is continuous in each variable separately at a point, then f is continuous at that point.
  1. Atrue
  2. Btrue only on bounded closed regions
  3. Cfalse: f = 0 on the axes, f = 1 elsewhere
    4. Correct: C. Along both axes f is constantly 0, but along y = x it equals 1, while f(0, 0) = 0; 17-01 will meet the same warning for partial derivatives.
5. 5. Suppose f < M everywhere on a bounded closed region D and sup f = M. Then F = 1/(M − f) is …
  1. Acontinuous and unbounded, contradicting the boundedness part of 16.8
  2. Bdiscontinuous where f is close to M
  3. Ccontinuous and bounded, so nothing goes wrong
    4. Correct: A. M − f is continuous and positive, so F is continuous; f comes arbitrarily close to M, so F is unbounded. Part one says it must be bounded: contradiction.
6. 6. f(x, y) = x + y on [0, 1]², ε = 0.1. Which δ works for every pair P, Q?
  1. Aδ = 0.2
  2. Bδ = 0.07
  3. Cδ = 0.1
    4. Correct: B. |f(P) − f(Q)| ≤ |Δx| + |Δy| ≤ √2·ρ(P, Q) < √2·0.07 ≈ 0.099 < 0.1. For δ = 0.1 or 0.2, P = (0, 0), Q = (0.06, 0.06) has ρ ≈ 0.085 but |f(P) − f(Q)| = 0.12.

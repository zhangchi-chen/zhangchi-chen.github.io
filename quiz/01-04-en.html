Verifying M = sup S requires which two points?

A. M ∈ S, and M is an upper bound.B. M is an upper bound, and for every ε > 0 there is s ∈ S with s > M − ε.C. M is the maximum of S, and s < M for all s ∈ S.

B. (i) says M is an upper bound, (ii) says no smaller number is; M need not belong to S.

For S = {1 − 1/n : n ∈ ℕ} and a given ε > 0, which n defeats the probe 1 − ε?

A. any n ∈ ℕ with n > 1/εB. any n ∈ ℕ with n < 1/εC. only n = 1

A. if n > 1/ε then 1/n < ε, hence 1 − 1/n > 1 − ε.

About S = {1 − 1/n : n ≥ 1}, which statement is right?

A. sup S = 1 and 1 ∈ S.B. sup S = 1 and 1 ∉ S.C. S never reaches 1, so no supremum exists.

B. the lid stops at 1, yet no point equals 1: the supremum exists without belonging to the set.

For f(x) = 1 − 1/x on [1, ∞):

A. sup f = 1, attained by f.B. sup f = 1, but f has no maximum.C. sup f does not exist.

B. the graph climbs toward 1 without reaching it, so 1 is the supremum of the value set but not a value.

When can sup(f + g) ≤ sup f + sup g be strict?

A. Never: it is always equality.B. When f and g peak at different places, so both maxima never appear together.C. Only when f or g takes negative values.

B. take f = e^(−(x+1)²), g = e^(−(x−1)²): then sup(f + g) ≈ 1.02 while sup f + sup g = 2.

The infimum version of subadditivity is:

A. inf(f + g) ≤ inf f + inf gB. inf(f + g) ≥ inf f + inf gC. inf(f + g) always equals inf f + inf g

B. it is the mirror image: f(x) ≥ inf f and g(x) ≥ inf g give a lower bound for f + g, so the inequality reverses.

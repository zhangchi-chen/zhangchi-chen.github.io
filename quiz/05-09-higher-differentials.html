1For an independent variable x, which of these is always 0?

当 x 是自变量时，下面哪一个恒为 0？

The step dx of an independent x is the same everywhere, so its own change d²x is 0; dx² = (dx)² and d(x²) = 2x dx are not.

自变量的小步 dx 处处相同，它自身的变化 d²x = 0；而 dx² = (dx)²，d(x²) = 2x dx，一般不为 0。

2y = eˣ with x = t². What is d²y with respect to t?

y = eˣ，x = t²。对 t 的二阶微分 d²y 是多少？

d²y = eˣ dx² + eˣ d²x with dx = 2t dt and d²x = 2 dt²; A drops the extra term eˣ d²x, C keeps only that term.

d²y = eˣdx² + eˣd²x，其中 dx = 2t dt，d²x = 2dt²；A 漏掉了多出的一项，C 只剩下那一项。

3x = t², y = t³ (t > 0). What is d²y/dx²?

x = t²，y = t³（t > 0），求 d²y/dx²。

(y″ₜx′ₜ − y′ₜx″ₜ)/(x′ₜ)³ = 6t²/(8t³) = 3/(4t), as y = x3/2 confirms; A is the guess y″ₜ/(x′ₜ)², C stops one division by x′ₜ short.

(y″ₜx′ₜ − y′ₜx″ₜ)/(x′ₜ)³ = 3/(4t)，与直接对 y = x3/2 求导一致；A 是猜测式 y″ₜ/(x′ₜ)²，C 少除了一次 x′ₜ。

4f(x) = x³ − 3x at x = 1. What do dy and d²y say?

f(x) = x³ − 3x 在 x = 1 处，dy 与 d²y 说明什么？

f′(1) = 3 − 3 = 0 and f″(1) = 6 > 0, so at this flat point d²y > 0: a minimum, with f(1) = −2 below f(0.9) = −1.971 and f(1.1) = −1.969.

f′(1) = 0，f″(1) = 6 > 0，平坦点处 d²y > 0，是极小值：f(1) = −2 低于两侧的 −1.971 与 −1.969。

5When is reading d²y ÷ dx² as f″(x) guaranteed to be right?

什么时候把 d²y ÷ dx² 读作 f″(x) 一定正确？

In general d²y = f″(x) dx² + f′(x) d²x; the quotient is f″(x) once d²x = 0, which holds for an independent x and for x = at + b.

一般 d²y = f″(x)dx² + f′(x)d²x；只要 d²x = 0，商就等于 f″(x)：自变量与线性换元都满足。

6Which statement about d(x²) and dx² is correct?

关于 d(x²) 与 dx²，哪一项正确？

d(x²) is the L-shaped strip 2x dx; dx² squares one small step; 2xΔx + (Δx)² is the full increment Δ(x²), not the differential.

d(x²) 是那条 L 形的边 2x dx；dx² 是一小步的平方；2xΔx + (Δx)² 是完整增量 Δ(x²)，不是微分。

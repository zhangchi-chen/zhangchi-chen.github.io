多元函数的泰勒公式

← 讲稿 · 目录
1. 1. f(x, y) = eˣ ln(1 + y) 在(0, 0)处的二阶泰勒多项式是：
  1. Ay + xy − ½y²
  2. By + 2xy − y²
  3. Cx + y + xy
    4. 正确答案：A. 在(0, 0)处 f = f_x = f_xx = 0，f_y = 1，f_xy = 1，f_yy = −1，所以 P₂ = y + ½(2xy − y²)。
2. 2. 用 xʸ ≈ 1 + 4(x − 1) + 6(x − 1)² + (x − 1)(y − 4) 估计 1.08^3.96。
  1. A1.32
  2. B1.3552
  3. C1.3584
    4. 正确答案：B. 1 + 0.32 + 0.0384 − 0.0032 = 1.3552；1.32只到一阶，1.3584漏掉了hk项 −0.0032。
3. 3. 定理17.8为什么要求D是凸区域？
  1. A为了让f在D上有界
  2. B为了让线段PQ（点(a + θh, b + θk)在其上）全在D内
  3. C为了让f_x、f_y连续
    4. 正确答案：B. 证明对Φ(t) = f(a + th, b + tk)在[0, 1]上用一元定理，所以PQ上每一点都要在D内。
4. 4. 若二阶偏导数连续，(h∂/∂x + k∂/∂y)²f 等于：
  1. Ah²f_xx + 2hk f_xy + k²f_yy
  2. Bh²f_xx + k²f_yy
  3. C(h f_x + k f_y)²
    4. 正确答案：A. 算子作用两次得四项，f_xy = f_yx 使中间两项合并。
5. 5. “泰勒公式的二阶项是 f_xx h² + 2f_xy hk + f_yy k²。”这句话：
  1. A正确
  2. B错误：漏了因子1/2!
  3. C错误：中间系数应为1
    4. 正确答案：B. 二阶项是 (1/2!)(h∂/∂x + k∂/∂y)²f = ½(f_xx h² + 2f_xy hk + f_yy k²)。
6. 6. 设f可微，Φ(t) = f(a + th, b + tk)，那么Φ′(t)等于：
  1. Af_x(a + th, b + tk) + f_y(a + th, b + tk)
  2. Bf_x(a + th, b + tk)h + f_y(a + th, b + tk)k
  3. Cf_x(a, b)h + f_y(a, b)k
    4. 正确答案：B. 链式法则：x = a + th，y = b + tk，dx/dt = h，dy/dt = k；偏导数取在动点处。

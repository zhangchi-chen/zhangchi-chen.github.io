1. 1. Which route regenerates (ax)′ from the card (eu)′ = eu?

  1. A. A. ax = ex ln a, chain rule → ax ln a
  2. B. B. inverse rule on ex → ax/ln a
  3. C. C. power rule with exponent x → x·ax−1
A — the inner u = x ln a has slope ln a, and the outer card copies ex ln a = ax.

2. 2. Inverting x = tan y (|y| < π/2), the inverse rule gives (arctan x)′ = ?

  1. A. A. 1/(1 + x²)
  2. B. B. cos²x
  3. C. C. 1/√(1 − x²)
A — dy/dx = 1/sec²y = 1/(1 + tan²y) = 1/(1 + x²); B is cos²y written in the wrong variable.

3. 3. (cos(x³))′ = ?

  1. A. A. −sin(x³)
  2. B. B. −3x² sin(x³)
  3. C. C. 3x² cos(x³)
B — outer card cos u gives −sin u; the inner u = x³ contributes 3x².

4. 4. (√(1 − 2x))′ = ? (x < 1/2)

  1. A. A. 1/(2√(1 − 2x))
  2. B. B. −1/√(1 − 2x)
  3. C. C. −2√(1 − 2x)
B — power card with α = 1/2 gives (1/2)(1 − 2x)−1/2, times the inner slope −2.

5. 5. f(x) = ex for x ≤ 0 and ax + b for x > 0. Which choice makes f differentiable at 0?

  1. A. A. a = 1, b = 0
  2. B. B. a = 1, b = 1
  3. C. C. a = 0, b = 1
B — continuity forces b = e⁰ = 1; the left quotient (eʰ − 1)/h → 1 and the right one → a, so a = 1.

6. 6. True or false: at the join x = 1 of x² (x ≤ 1) and ax + b (x > 1), it is enough to differentiate both pieces and equate them at 1.

  1. A. A. True: this gives a = 2 and finishes the job
  2. B. B. False: continuity forces a + b = 1, then one-sided quotients give a = 2, b = −1
  3. C. C. True, as long as a = b
B — the shortcut finds a = 2 but leaves b free; b = 0 makes f jump at 1, so f is not differentiable there.

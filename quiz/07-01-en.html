Completeness of the reals: six keys, one door

← Notes · Index
1. 1. You must produce a point with a given property by repeatedly halving an interval. Which theorem is the natural key?
  1. ANested Interval Theorem
  2. BCauchy Convergence Criterion
  3. CSupremum Principle
    4. Correct: A. Repeated halving produces closed intervals, each inside the last, with lengths → 0; the Nested Interval Theorem supplies the one trapped point.
2. 2. Show that xₙ = (cos 1)/3 + (cos 2)/3² + … + (cos n)/3ⁿ converges, without knowing its limit. Natural key?
  1. AFinite Covering Theorem
  2. BCauchy Convergence Criterion
  3. CWeierstrass Cluster Point Theorem
    4. Correct: B. For m > n, |xₘ − xₙ| ≤ 1/3ⁿ⁺¹ + … + 1/3ᵐ < 1/(2·3ⁿ), so the sequence is Cauchy; no limit has to be guessed.
3. 3. Which is the course text's statement of the Supremum Principle (Theorem 1.1)?
  1. AEvery nonempty set of numbers has a supremum and an infimum.
  2. BLet S be a nonempty set of numbers. If S has an upper bound, then S has a least upper bound (supremum); if S has a lower bound, then S has a greatest lower bound (infimum).
  3. CIf S has an upper bound, then S contains a largest element.
    4. Correct: B. A drops the bound hypotheses (the positive integers have no upper bound, hence no supremum); C is false: {1 − 1/n} has supremum 1 but no largest element.
4. 4. Which is the course text's Theorem 2.9 (Monotone Convergence)?
  1. AEvery monotone sequence has a limit.
  2. BIn the real number system, every bounded sequence has a limit.
  3. CIn the real number system, every bounded monotone sequence has a limit.
    4. Correct: C. A fails for aₙ = n (monotone, unbounded); B fails for (−1)ⁿ (bounded, no limit).
5. 5. Working only inside the rationals, which statement is true?
  1. AS = {x ∈ ℚ : x² < 2} has least rational upper bound 1.415.
  2. B1, 1.4, 1.41, 1.414, … is a Cauchy sequence with no rational limit.
  3. C[1, 2] ⊃ [1.4, 1.5] ⊃ [1.41, 1.42] ⊃ … share a rational point.
    4. Correct: B. 0 ≤ aₘ − aₙ < 10⁻ⁿ for m > n, and the only candidate limit √2 is irrational. A: 1.4143 is a smaller rational upper bound (1.4143² = 2.00024449 > 2). C: the only common real point is √2.
6. 6. True or false: “The Finite Covering Theorem holds for any interval.”
  1. ATrue: finitely many intervals always suffice.
  2. BTrue, as long as the interval is bounded.
  3. CFalse: (1/(n+1), 1), n = 1, 2, …, cover (0, 1), but no finite subfamily does.
    4. Correct: C. A finite subfamily with largest index N covers only (1/(N+1), 1) and misses 1/(N+2); (0, 1) is bounded but not closed.

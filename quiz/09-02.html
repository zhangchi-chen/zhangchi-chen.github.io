1. 1. f(x) = x² 在 [0, 1] 上，分割 T = {0, ½, 1}，上和 S(T) 与下和 s(T) 各是多少？
  1. AS(T) = 5/8, s(T) = 1/8
  2. BS(T) = 1/2, s(T) = 1/4
  3. CS(T) = 5/8, s(T) = 0
    4. 正确答案：A. f 递增，上确界取在右端、下确界取在左端：S = (¼ + 1)·½ = 5/8，s = (0 + ¼)·½ = 1/8。
2. 2. 狄利克雷函数 D 在 [0, 1] 上，对任意分割 T，S(T) − s(T) 等于多少？
  1. A取决于 ‖T‖，并趋于 0。
  2. B永远是 1。
  3. C永远是 0。
    4. 正确答案：B. 每一小段里都有有理点和无理点，Mᵢ = 1，mᵢ = 0，于是任何分割下 S(T) = 1，s(T) = 0。
3. 3. 哪一个机制证明了 [a, b] 上的递增函数可积？
  1. A一致连续：细度够小时，每个 ωᵢ 都小。
  2. B把间断点圈进很短的小区间。
  3. C振幅之和恒为 f(b) − f(a)，所以缺口 ≤ ‖T‖·(f(b) − f(a))。
    4. 正确答案：C. 递增时 ωᵢ = f(xᵢ) − f(xᵢ₋₁)，求和逐项抵消；递增函数未必连续，间断点甚至可以有无穷多个。
4. 4. 定理 9.16 说：f 可积，当且仅当对任意正数 ε 与 η，存在分割 T 满足下列哪一条？
  1. A每个小区间上的振幅都小于 ε。
  2. B振幅 ≥ ε 的小区间，总长小于 η。
  3. C振幅 ≥ ε 的小区间，个数少于 η。
    4. 正确答案：B. 大振幅允许出现，只要总长够短；A 对阶梯函数就不成立，可阶梯函数照样可积；C 数的是个数而不是长度。
5. 5. 判断：若 g 与 φ 都可积，则 g∘φ 可积。
  1. A正确，总是成立。
  2. B错误：取 g(u) = 1（u ≠ 0）、g(0) = 0，φ = R，复合在 (0, 1) 上就是狄利克雷函数。
  3. C只要 φ 在每个无理点连续，就成立。
    4. 正确答案：B. g 只有一个间断点，R 可积，可 g∘R 在 (0, 1) 的有理点取 1、无理点取 0；R 在每个无理点连续，所以 C 也不对。

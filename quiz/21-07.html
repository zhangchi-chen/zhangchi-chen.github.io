重积分的应用:重心与转动惯量

← 讲稿 · 目录
1. 1. 在 x̄ 的三步推导中,是什么把有限和公式 Σ ξᵢρ(Pᵢ)ΔVᵢ / Σ ρ(Pᵢ)ΔVᵢ 变成积分公式?
  1. AV 的对称性
  2. B令细度趋于零:分子分母都趋于积分,且分母的总质量为正
  3. C假设密度均匀
    4. 正确答案：B. 两个和都是连续函数的积分和;总质量 m 为正,比值的极限等于极限之比。
2. 2. 密度为 ρ 的均匀圆环 R₁ ≤ r ≤ R₂ 绕中心轴转动,J 是哪个积分?
  1. Aρ · 2π · ∫[R₁,R₂] r² dr
  2. Bρ · 2π · ∫[R₁,R₂] r³ dr
  3. Cρ · 2π · ∫[R₁,R₂] r dr
    4. 正确答案：B. r² 是到轴距离的平方,dσ = r dr dθ 再添一个 r;C 是质量,A 漏了因子 r。
3. 3. 均匀圆盘绕直径的转动惯量为什么恰好是 mR²/4?
  1. A一整圈上 cos²θ 的平均是 ½,所以是绕中心轴 mR²/2 的一半
  2. B每个点到直径的距离都不超过 R/2
  3. C只有四分之一的质量不在轴上
    4. 正确答案：A. ∫₀^2π cos²θ dθ = π,恰是 2π 的一半;B 错(点到直径可达 R),C 错(只有直径本身在轴上)。
4. 4. (X, Y) 在单位圆盘上均匀分布。求 E[√(X² + Y²)] 该用什么坐标?值是多少?
  1. A极坐标;2/3
  2. B直角坐标;1/2
  3. C极坐标;1/2
    4. 正确答案：A. (1/π) · 2π · ∫₀¹ r · r dr = 2 · 1/3 = 2/3;1/2 是 E[X² + Y²],不是所求。
5. 5. ⚠️ 实心圆柱绕自身轴(z 轴)转动,某同学写 J = ∭ (x² + y² + z²) ρ dV。错在哪里?
  1. A没错,完全正确
  2. B用了到原点的距离,圆柱沿轴平移时结果会变
  3. C只在密度不均匀时才错
    4. 正确答案：B. 绕 z 轴应当用 x² + y²;多出的 ∭ z²ρ dV 在底面过原点时等于 mh²/3,圆柱往上推它还会变大。

1求 limx → ∞ (1 + 3x)2x.

  1. A. e3/2
  2. B. e6
  3. C. e5

答案: B. 写成 [(1 + 3/x)x]2：方括号是 k = 3 的戏服，趋于 e3，故极限为 (e3)2 = e6。

2求 limx → 0 (cos x)1/x².

  1. A. 1
  2. B. e−1/2
  3. C. e−2

答案: B. 1∞ 型，α = cos x − 1 = −2sin²(x/2)，αg = −½·(sin(x/2)/(x/2))² → −½，所以极限是 e−1/2。

3limx → ∞ (1 − 1x)x 是家族成员的伪装，其值为：

  1. A. e
  2. B. e−1
  3. C. 1

答案: B. 这是 k = −1 的 (1 + k/x)x，趋于 e−1；k < 0 时 x/k → −∞，用到祖先的 x → −∞ 版本。

4为什么 sin x / x → 1 的证明比较面积而不是长度？

  1. A. 面积更大，不等式更容易看出。
  2. B. 比较弧与弦要先有弧长理论——此刻会陷入循环论证。
  3. C. 长度不能满足严格不等式。

答案: B. 弧长本身要靠这类极限建立；面积只需初等几何——一个图形包含另一个。

5令 u = 1/x，(1 + u)1/u → e（u → 0 双侧）需要祖先的哪些过程？

  1. A. 只要 x → +∞
  2. B. x → +∞ 与 x → −∞ 都要
  3. C. 只要 x → 0

答案: B. x → +∞ 对应 u → 0⁺，x → −∞ 对应 u → 0⁻；忘了过程就丢一半答案。

6limx → ∞ sin xx = ?

  1. A. 1
  2. B. 0
  3. C. 不存在

答案: B. |sin x/x| ≤ 1/|x| → 0：第一把尺只在 x → 0 时管用，远处图像振荡衰减。

If lim(x→0) f(x) = 2, what can be concluded about f(0)?

A. f(0) > 1B. f(0) > 0C. Nothing — f(0) may be anything, or even undefined

C. Local sign preservation governs only a punctured neighborhood and never touches x₀ itself.

If lim(x→x₀) f(x) = A > 0, the handy form guarantees, in some punctured neighborhood:

A. f(x) > AB. f(x) > A/2C. f(x) = A

B. Near x₀, f(x) > A/2 — the sign survives at half strength, leaving usable room.

If f → A and g → B, concluding lim f/g = A/B requires:

A. A ≠ 0B. B ≠ 0C. both A ≠ 0 and B ≠ 0

B. Only the denominator's limit must be nonzero; A = 0 is perfectly fine.

As x → 0, f → 0 and g → 0. Then lim f/g:

A. equals 1B. equals 0C. cannot be decided by the quotient rule

C. The gate is closed: x²/x → 0, x/x → 1, and x/x² has no finite limit.

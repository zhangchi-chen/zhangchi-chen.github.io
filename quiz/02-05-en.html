Which sequence is bounded but divergent?

A. aₙ = 1/nB. aₙ = (−1)ⁿC. aₙ = 2 − 1/n

B. (−1)ⁿ stays inside [−1, 1] yet alternates forever, so it has no limit; the other two are monotone and bounded.

In the three-step method for aₙ₊₁ = f(aₙ), when can you trust that a root of L = f(L) is the limit?

A. as soon as you solve L = f(L)B. only after proving the sequence monotone and boundedC. after computing three terms

B. Only monotone + bounded guarantees the limit exists; taking limits afterwards then shows it satisfies L = f(L).

For a₁ = √2, aₙ₊₁ = √(2 + aₙ), what does the induction step prove?

A. aₙ < 2 ⇒ aₙ₊₁ < 2B. aₙ > 2 ⇒ aₙ₊₁ > 2C. aₙ = 2 for all n

A. If aₙ < 2, then aₙ₊₁ = √(2 + aₙ) < √4 = 2; the starting point a₁ = √2 < 2.

a₁ = 1, aₙ₊₁ = 2aₙ. Solving L = 2L gives L = 0. Which statement is correct?

A. aₙ → 0B. aₙ → ∞; L = 0 is not the limitC. aₙ → 1

B. aₙ = 2ⁿ⁻¹ → ∞; the equation L = f(L) says nothing about existence — using it first would be circular reasoning.

For aₙ₊₁ = aₙ² with a₁ = 0.5, the sequence will…

A. decrease to 0B. converge to 1C. increase to ∞

A. Starting inside (0, 1), squaring shrinks every term; decreasing with lower bound 0, it tends to 0.

Why is lim (1 + 1/n)ⁿ a 1^∞ form?

A. the base tends to 1 while the exponent tends to ∞B. because the limit equals 1C. because the sequence decreases

A. The base → 1 races against the exponent → ∞; “1 to any power is 1” does not apply. The limit here is e.

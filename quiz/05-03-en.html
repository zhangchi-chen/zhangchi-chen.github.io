Sum, product, quotient: the extra little patch of area

← Notes · Index
1. In the area picture, (u+Δu)(v+Δv) − uv = Δu·v + u·Δv + Δu·Δv. Which piece is o(Δx), and why? <button type="button"
  1. AAThe strip Δu·v, because Δu is small.
  2. BBThe corner Δu·Δv: divided by Δx it is (Δu/Δx)·Δv → u′(x₀)·0.
  3. CCNone: all three pieces survive after dividing by Δx.
    4. Correct: B. Each strip divided by Δx has a non-zero limit (u′v and uv′). The corner's ratio is (Δu/Δx)·Δv, and Δv → 0 because a differentiable v is continuous (Theorem 5.1, 05-02).
2. Which route turns the product rule into the quotient rule? <button type="button"
  1. AADifferentiate top and bottom separately: (u/v)′ = u′/v′.
  2. BBMultiply top and bottom by v, then differentiate uv/v² term by term.
  3. CCWrite u/v = u·(1/v); first find (1/v)′ = −v′/v², then use the product rule.
    4. Correct: C. Step 1, the reciprocal: [1/v(x₀+Δx) − 1/v(x₀)]/Δx = −(Δv/Δx)/(v(x₀+Δx)v(x₀)) → −v′/v², using continuity and v(x₀) ≠ 0. Step 2: u′/v + u·(−v′/v²) = (u′v − uv′)/v². The minus sign is the reciprocal's.
3. What is (x² sin x)′ at x = π? <button type="button"
  1. AA−π²
  2. BB−2π
  3. CC0
    4. Correct: A. (x² sin x)′ = 2x sin x + x² cos x; at π: 0 + π²·(−1) = −π². The value −2π is the mistake u′v′ = 2x cos x.
4. Let f(x) = x/(1 + x²). What is f′(2)? <button type="button"
  1. AA3/25
  2. BB−3/25
  3. CC1/4
    4. Correct: B. f′ = [1·(1+x²) − x·2x]/(1+x²)² = (1 − x²)/(1+x²)², so f′(2) = −3/25. 3/25 swaps the order in the numerator; 1/4 is u′/v′ = 1/(2x).
5. Let f(x) = (x⁴ + 3x²)/x² for x ≠ 0. What is f′(1)? (Simplify first.) <button type="button"
  1. AA2
  2. BB5
  3. CC0
    4. Correct: A. For x ≠ 0, f(x) = x² + 3, so f′(x) = 2x and f′(1) = 2. The quotient rule gives the same, in more lines. 5 is u′/v′ = (4x³ + 6x)/(2x) at 1.
6. True or false: (uv)′ = u′v′. <button type="button"
  1. AATrue, at least for polynomials.
  2. BBFalse: with u = v = x at x = 1, (x²)′ = 2 but u′v′ = 1.
  3. CCTrue whenever u′ and v′ exist.
    4. Correct: B. One counterexample is enough: x·x = x² has derivative 2x = 2 at 1, while u′v′ = 1·1 = 1. The missing half is the two strips x·Δx.

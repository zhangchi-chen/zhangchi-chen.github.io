  1. f is differentiable at x₀. Which single line proves that f is continuous at x₀? f 在 x₀ 处可导。下面哪一行能证明 f 在 x₀ 处连续？

    A — both items die: f′(x₀)Δx → 0 and o(Δx) = [o(Δx)/Δx]·Δx → 0·0, so Δy → 0, which is continuity. B mixes up the ratio with the change; C says nothing about values near x₀. A —— 两项都趋于 0：f′(x₀)Δx → 0，o(Δx) = [o(Δx)/Δx]·Δx → 0·0，所以 Δy → 0，这就是连续。B 把比值和增量混为一谈；C 没有谈到 x₀ 附近的函数值。

  2. f(x) = ∛x is continuous at 0 but not differentiable there. Which failure is it? f(x) = ∛x 在 0 处连续但不可导。它属于哪一类失败？

    B — (∛h − 0)/h = h−2/3 → +∞ from both sides, so the secants stand up into the tangent line x = 0. It is continuous because ∛h → 0. B —— (∛h − 0)/h = h−2/3 → +∞，左右两侧都如此：割线竖起来，成为切线 x = 0。它连续，因为 ∛h → 0。

  3. f(x) = x² for x ≥ 0 and f(x) = sin x for x < 0. At 0: 当 x ≥ 0 时 f(x) = x²，当 x < 0 时 f(x) = sin x。在 0 处：

    A — continuity first: f(0) = 0 and sin h → 0. Right: h²/h = h → 0. Left: (sin h − 0)/h → 1. The one-sided derivatives differ, so by Theorem 5.2 f′(0) does not exist. A —— 先查连续：f(0) = 0，且 sin h → 0。右侧：h²/h = h → 0。左侧：(sin h − 0)/h → 1。左右导数不相等，由定理 5.2，f′(0) 不存在。

  4. On [0, +∞), which function has a finite right derivative at the endpoint 0? 在 [0, +∞) 上，哪个函数在端点 0 处有有限的右导数？

    B — h√h/h = √h → 0, so f′+(0) = 0. For √x the quotient is 1/√h → +∞, and for √x + x it is 1/√h + 1 → +∞: vertical tangents, no finite slope. B —— h√h/h = √h → 0，所以 f′+(0) = 0。√x 的差商是 1/√h → +∞，√x + x 的差商是 1/√h + 1 → +∞：都是垂直切线，没有有限的斜率。

  5. Claim: “g is continuous at x₀, therefore g is differentiable at x₀.” 说法：“g 在 x₀ 处连续，所以 g 在 x₀ 处可导。”

    B — Theorem 5.1 runs one way only. Continuity says Δy → 0 and nothing about the rate; |x| is the course text’s own witness. B —— 定理 5.1 只有一个方向。连续只说 Δy → 0，不管消失的速度；|x| 就是课本给的反例。

  6. f(x) = x² for x ≤ 0 and f(x) = 2x + 1 for x > 0. For x > 0, f′(x) = 2, so f′(x) → 2 as x → 0⁺. What is f′+(0)? 当 x ≤ 0 时 f(x) = x²，当 x > 0 时 f(x) = 2x + 1。x > 0 时 f′(x) = 2，所以 x → 0⁺ 时 f′(x) → 2。f′+(0) 等于多少？

    C — the right derivative measures from the point itself: [f(h) − f(0)]/h = (2h + 1)/h = 2 + 1/h → +∞. The jump at 0 (f(0) = 0, right limit 1) breaks continuity, so the limit of f′ tells you nothing here. Episode 06-02’s derivative limit theorem needs continuity first. C —— 右导数从这一点本身出发：[f(h) − f(0)]/h = (2h + 1)/h = 2 + 1/h → +∞。0 处有跳跃（f(0) = 0，右极限为 1），连续性被破坏，导数的右极限在这里说明不了什么。第 06-02 集的导数极限定理，先要求连续。

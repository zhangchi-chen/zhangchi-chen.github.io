最值定理

点击选项下方按钮查看答案与解析。

1. 下面哪种分工是对的？

A.引理：f在[a, b]上有界。定理：f在[a, b]上取到最大值和最小值。B.引理：f在[a, b]上取到最大值。定理：f在[a, b]上有界。C.两者说的是一回事，其中一个多余。
答案: A. 有界是铺垫（天花板存在），取到才是主角（天花板被碰到）。第二步还要用到第一步。

2. 开区间(0, 1)上的f(x) = x，哪句话对？

A.f的最大值是1。B.f有界，但最大值、最小值都取不到。C.f无界。
答案: B. 0 < f(x) < 1，所以有界；上确界是1，下确界是0，可是(0, 1)里找不到x使f(x) = 1或f(x) = 0。函数值从开口处溜走了。

3. 在[0, 1]上，0 < x < 1时f(x) = x，并且f(0) = f(1) = 1/2。哪里出了问题？

A.闭区间这个条件失效，最大值是1。B.连续性失效，上确界1始终碰不到。C.连续性失效，可是端点处取到最大值1/2。
答案: B. 区间是闭的；端点的跳跃破坏了连续性。所有函数值都小于1（内部f(x) = x < 1，端点1/2 < 1），但能任意接近1，所以上确界1碰不到。1/2也算不上最大值：f(0.9) = 0.9 > 1/2。

4. 第一步（有界性）里，闭区间到底用在哪？

A.用来造出满足f(xₙ) > n的点xₙ。B.保证子列的极限c仍在[a, b]里。C.保证M = sup f存在。
答案: B. 由a ≤ yₖ ≤ b和yₖ → c，得到a ≤ c ≤ b，于是f在c处有定义且连续。点xₙ来自“假设无界”；M = sup f属于第二步，靠的是确界原理。

5. 设处处f(x) < M，辅助函数g(x) = 1/(M − f(x))满足g(x) ≤ K，其中K > 0。能推出什么？

A.处处f(x) ≤ M − 1/K。B.处处f(x) ≥ M − 1/K。C.处处f(x) ≤ M − K。
答案: A. 两边都是正数，所以由1/(M − f(x)) ≤ K得M − f(x) ≥ 1/K，也就是f(x) ≤ M − 1/K。这是比M更小的上界，和M = sup f矛盾。

6. [0, 1)上的f(x) = x：M = 1，g(x) = 1/(1 − x)。g(0.99)等于多少？说明了什么？

A.g(0.99) = 100；g无界，而且没有矛盾，因为[0, 1)非闭。B.g(0.99) = 99；g始终有界。C.g(0.99) = 100；这是矛盾，所以f一定取到1。
答案: A. 1 − 0.99 = 0.01，1/0.01 = 100；同样g(0.999) = 1000。g冲向无穷，正如“碰不到”所预言。引理要求闭区间，这里引理管不着，所以没有矛盾，f也确实碰不到1。

积分判别法

← 讲稿 · 目录
1. 1. 设 f ≥ 0 且递减。在一格 [n, n+1] 上，哪个不等式总成立？
  1. A∫ₙⁿ⁺¹ f(x)dx ≤ f(n+1)
  2. Bf(n+1) ≤ ∫ₙⁿ⁺¹ f(x)dx ≤ f(n)
  3. Cf(n) ≤ ∫ₙⁿ⁺¹ f(x)dx
    4. 正确答案：B. 在这一格上递减的图像夹在右端高度 f(n+1) 与左端高度 f(n) 之间，而格宽为 1。
2. 2. 下列级数中哪一个收敛？
  1. AΣn≥2 1/(n ln n)
  2. BΣ 1/√n
  3. CΣn≥2 1/(n(ln n)²)
    4. 正确答案：C. 它是 p = 2 > 1 的对数级数；A 是 p = 1 的情形，B 是 p = 1/2 的 p 级数，二者发散。
3. 3. 对 uₙ = n!/((a+1)(a+2)⋯(a+n))，取 a = 2，拉贝判别法给出什么？
  1. Ar = 2 ，收敛
  2. Br = 1 ，无法判定
  3. Cr = 1/2 ，发散
    4. 正确答案：A. uₙ₊₁/uₙ = (n+1)/(n+3)，于是 n(1 − uₙ₊₁/uₙ) = 2n/(n+3) → 2 > 1。
4. 4. “各项 f(n) 为正且趋于 0，所以可以用积分判别法。”这句话对吗？
  1. A对：为正且趋于 0 就够了。
  2. B不对：递减是前提；格子里的尖峰会破坏夹逼。
  3. C对，但只在 p > 1 时成立。
    4. 正确答案：B. 正函数可以在整数点很小，却在每一格里有高尖峰，于是级数收敛而积分发散。
5. 5. 取 f(x) = 1/x²，在 ∫₁ᵐ f ≤ Σn≤m−1 f(n) ≤ f(1) + ∫₁ᵐ f 中令 m → ∞，S = Σ1/n² 满足哪个估计？
  1. A1 ≤ S ≤ 2
  2. B0 ≤ S ≤ 1
  3. C2 ≤ S ≤ 3
    4. 正确答案：A. 积分 ∫₁^{+∞} dx/x² 等于 1，且 f(1) = 1，所以 1 ≤ S ≤ 2（实际上 S ≈ 1.645）。

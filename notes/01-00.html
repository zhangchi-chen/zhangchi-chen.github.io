什么是数学分析？比较的艺术

数学分析，就是用精确的数学把“比较”不断推广：先比大小，再比距离，再比趋势。

本学期地图

1比大小
2极限
3连续
4导数
5泰勒展开
6完备性

每一站后面都有专门的几集，今天只是路过看看。

0开场问题

0.999… 和 1，哪个更大？无论你说多小的差距，9 足够多时都会更小：1 − 0.99…9 = 10−n。要判定它，得学会和无穷做比较。

1比大小

7 > 3，√2 > 1.4

两个数一比就知道。但数列和函数不是单独一个数——放上天平，天平只会摇摆。“比较”必须重新发明。

2比距离、比趋势 → 极限

|an − 1| = 1/n，an → 1

an = 1 + (−1)n/n 与 bn = 1 的大小关系永远来回翻转。于是改量到目标的距离，并看长远趋势，忽略任何有限的开头。这就是数列的极限，随之而来的是逼近（近似）。

3让极限穿过函数 → 连续

f(lim xn) = lim f(xn)

若 x 只是 x0 的近似，我们希望 f(x) 也近似 f(x0)：2.99² = 8.9401，2.999² = 8.994001。希望极限能穿过函数，这就是连续。跳跃会破坏它。

4比增长速度 → 导数

f′，xn+1 = xn − f(xn)/f′(xn)

f(t) = 100 + t 起点领先，g(t) = t² 增长更快，约在 t ≈ 10.5 处反超。当前大小决定不了胜负，增长速度——导数——才行。切线给出线性近似，牛顿法把它变成快速求根：√2 的正确位数每步约翻倍。

5越拟合越好 → 泰勒展开

sin x ≈ x − x³/6 + x⁵/120

一条切线只在一点附近贴合。更高阶导数带来更好的多项式拟合：泰勒展开，以及需要控制的余项。弯曲还带来凸性与不等式，例如对所有实数 x 有 eˣ ≥ 1 + x。

6脚下的地基 → 完备性

0.999… = 1

每说一次“收敛”，都默认极限存在。1.4, 1.41, 1.414, … 瞄准 √2，而它不是有理数：在 ℚ 里这里有个洞。实数没有洞——这就是完备性，它有许多等价形式，课程后面会证明等价。对不收敛的数列，上极限与下极限仍能描述长远行为：对 (−1)n(1 + 1/n)，它们是 1 与 −1。

7你将学会做什么

  1. 读懂并写出精确的定义（ε–N 语言下几集登场）。
  2. 写证明时，逐条验证定义。
  3. 估计与比较——不等式的日常手艺。
  4. 构造小反例，击破错误的论断。
  5. 先画图，再写公式。

自测

先在心里选定答案，再点开查看。

1. 为什么不能用“比大小”来比较 an = 1 + (−1)n/n 与 bn = 1？
A. an 的每一项都大于 1。B. 逐项比较时，大小关系来回翻转。C. an 没有极限。
正确答案： B. a1 < 1，a2 > 1，a3 < 1……所以改比距离 |an − 1| = 1/n 与长远趋势。
2. “x 靠近 x0，f(x) 就靠近 f(x0)”说的是哪个概念？
A. 连续B. 导数C. 完备性
正确答案： A. 连续就是希望极限能穿过函数：f(lim xn) = lim f(xn)。
3. f(t) = 100 + t 与 g(t) = t²：长远来看谁领先，由什么决定？
A. 它们在 t = 0 处的值。B. 哪个公式更短。C. 它们的增长速度，即导数。
正确答案： C. f′(t) = 1，而 g′(t) = 2t 不断增大，所以 g 约在 t ≈ 10.5 处永久反超。
4. 泰勒展开做的是什么？
A. 在局部用多项式逼近好的函数，并带有余项。B. 证明每个数列都收敛。C. 求函数的最大值。
正确答案： A. 例如在 0 附近 sin x ≈ x − x³/6 + x⁵/120；控制余项才是真功夫。
5. 为什么数列 1.4, 1.41, 1.414, … 需要实数的完备性？
A. 它的每一项都是无理数。B. 它的极限 √2 不是有理数，在 ℚ 中无处落脚。C. 它发散到 ∞。
正确答案： B. 完备性保证这样的极限作为实数一定存在——ℝ 没有洞。
6. 对 an = (−1)n(1 + 1/n)，上极限是多少？
A. 0B. 2C. 1
正确答案： C. 偶数项 1 + 1/n 从上方趋于 1，奇数项趋于 −1，所以上极限为 1，下极限为 −1。

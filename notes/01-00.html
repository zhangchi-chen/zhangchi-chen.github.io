什么是数学分析？比较的艺术

数学分析，就是用精确的数学把“比较”不断推广：先比大小，再比距离，再比趋势。

本学期地图

1比大小
2极限
3连续
4导数
5泰勒展开
6完备性

每一站后面都有专门的几集；今天只是路过——还没有定义，也没有证明。

0开场问题

0.999… 和 1，哪个更大？n 个 9 之后的差距是 1 − 0.99…9 = 10−n；9 足够多时，它比你说的任何正数都小。要判定它，得学会和无穷做比较。

1比大小

7 > 3，√2 = 1.41421… > 1.4

两个数一比就知道：放上天平，较重的 7 那边下沉。但数列和函数不是单独一个数——放上天平，天平只会摇摆。“比较”必须重新发明。

2比距离、比趋势 → 极限

|an − 1| = 1/n

an = 1 + (−1)n/n 与 bn = 1 的大小关系永远来回翻转（a1 = 0 < 1，a2 = 1.5 > 1，……）。于是改量到目标的距离，看长远趋势，忽略任何有限的开头：第 1000 项以后，误差都小于 0.001。这就是数列的极限 an → 1，随之而来的是逼近（近似）。精确的 ε–N 语言下几集登场。

3让极限穿过函数 → 连续

2.9² = 8.41，2.99² = 8.9401，2.999² = 8.994001

输入只是 x0 的近似时，我们希望输出也近似 f(x0)。对 f(x) = x²，逼近 3 的输入给出逼近 9 的输出：极限穿过了函数。要求对任何逼近方式都如此，就是连续；跳跃会破坏它。精确定义留到后面的专集。

4比增长速度 → 导数

y = 6x − 9 在 x = 3 处与 y = x² 相切

f(t) = 100 + t 在 t = 10 时领先（110 比 100），但 g(t) = t² 在 t = 11 时领先（121 比 111）：从 10 到 11，f 涨 1，g 涨 21。决定胜负的是增长速度——导数。切线给出线性近似（3.1² = 9.61，切线给出 6·3.1 − 9 = 9.6），沿切线还能快速求根：求 √10，从 3 出发，得 19/6 ≈ 3.1667、721/228 ≈ 3.162281……正确位数每步约翻倍。

5越拟合越好 → 泰勒展开

1/(1 − x) 在 x = 0.1：1.1，1.11，1.111，…

t² 的涨幅是 21、23、25：增长本身在增长——加速度，即高阶导数。高阶导数带来更好的多项式拟合：x = 0.1 时 1/(1 − x) = 1.1111…，而 1 + x、1 + x + x²、1 + x + x² + x³ 依次给出 1.1、1.11、1.111。这就是泰勒展开；剩下的 0.00111… 是余项。凸性把拟合变成不等式：对所有实数 x 有 x² ≥ 6x − 9，由 (x − 3)² ≥ 0 印证。

6脚下的地基 → 完备性

0.999… = 1

每说一次“收敛”，都默认极限存在。0.999… 与 1 的差距比任何正数都小，只能是 0。但 1.4, 1.41, 1.414, … 瞄准 √2，而它不是有理数：在 ℚ 中无处落脚。实数没有这样的洞——这就是完备性，它的等价形式（确界原理、闭区间套、单调有界数列、柯西收敛准则）课程后面证明等价。对不收敛的数列，例如 (−1)n n/(n + 1)，上极限与下极限仍能描述长远行为：1 与 −1。

7你将学会做什么

  1. 读懂并写出精确的定义（ε–N 语言下几集登场）。
  2. 写证明时，逐条验证定义。
  3. 估计与比较——不等式的日常手艺。
  4. 构造小反例，击破错误的论断。
  5. 先画图，再写公式。

自测

先在心里选定答案，再点开查看。

1. 为什么不能用“比大小”来比较 an = 1 + (−1)n/n 与 bn = 1？
A. an 的每一项都大于 1。B. 逐项比较时，大小关系来回翻转。C. an 没有极限。
正确答案： B. a1 = 0 < 1，a2 = 1.5 > 1，a3 = 2/3 < 1……所以改比距离 |an − 1| = 1/n 与长远趋势。
2. “近似的输入给出近似的输出”说的是哪个概念？
A. 连续B. 导数C. 完备性
正确答案： A. 连续就是希望极限能穿过函数，例如在 x² 下，2.9, 2.99, 2.999 给出 8.41, 8.9401, 8.994001。
3. f(t) = 100 + t 与 g(t) = t²：长远来看谁领先，由什么决定？
A. 它们在 t = 10 处的值。B. 哪个公式更短。C. 它们的增长速度，即导数。
正确答案： C. t = 10 时 f 领先（110 比 100），但从 10 到 11，g 涨 21 而 f 只涨 1，从 t = 11 起 g 领先（121 比 111）。
4. x = 0.1 时，拟合 1 + x + x² 对 1/(1 − x) = 1.1111… 给出什么？
A. 1.11，余项为 0.00111…B. 1.1，没有余项C. 1.111，恰好相等
正确答案： A. 1 + 0.1 + 0.01 = 1.11，而 1.1111… − 1.11 = 0.00111… 就是余项。
5. 为什么数列 1.4, 1.41, 1.414, … 需要实数的完备性？
A. 它的每一项都是无理数。B. 它的极限 √2 不是有理数，在 ℚ 中无处落脚。C. 它发散到 ∞。
正确答案： B. 每一项都是有限小数，因而是有理数，但目标 √2 不是；完备性保证 ℝ 中没有这样的洞。
6. 对 an = (−1)n n/(n + 1)，上极限是多少？
A. 0B. 4/5C. 1
正确答案： C. 偶数项 2/3, 4/5, 6/7, … 趋于 1（且从不超过 1），奇数项趋于 −1，所以上极限为 1，下极限为 −1。

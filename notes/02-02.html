§2.2 · 数学分析（一）

收敛数列的基本性质

唯一性 · 有界性 · 保号性

收敛数列有无穷多项，而极限只是一个数——正是这一个数，控制住了几乎所有的项。

回顾定义

an→A ⇔ ∀ε>0, ∃N, ∀n>N: |an−A|<ε

对任意 ε>0，某个 N 之后的每一项都落在带 (A−ε, A+ε) 内；带外只有有限项。

类比：极限就像总部，几乎所有分部都被锁在总部周围的一条带内。

定理 2.2（唯一性）

定理 2.2（唯一性）
若数列 {an} 收敛，则它的极限是唯一的。
  1. 设 an→a 且 an→b，a≠b。取 ε0=|b−a|2。
  2. n>N1⇒an∈(a−ε0, a+ε0)；  n>N2⇒an∈(b−ε0, b+ε0)。
  3. 当 n>max{N1,N2} 时，an 要同时落在两条带内——而两带不相交。矛盾，故 a=b。

★ 总部的地址只有一个。

定理 2.3（有界性）

定理 2.3（有界性）
若 {an} 收敛，则 {an} 有界，即存在 M>0，使得对一切正整数 n，都有 |an|≤M。
  1. 取 ε=1：存在 N，当 n>N 时 an∈(a−1, a+1)，所以尾部满足 |an|<|a|+1。
  2. 只剩下有限项 a1,…,aN；有限个数总有最大值。
  3. 取 M=max{|a1|,…,|aN|, |a|+1}，则对一切 n，|an|≤M。∎

例题

an=nn+1→1。取 ε=1：对每个 n，|an−1|=1n+1<1， 所以 0<an<2，取 M=2 即可。

必要，但不充分
收敛 ⇒ 有界，但反之不成立：an=(−1)n 满足 |an|≤1，却在 −1 与 1 之间来回跳动，所以发散。

定理 2.4（保号性）

定理 2.4（保号性）
若 liman=a>0（或 <0），则对任意 a′∈(0,a)（或 a′∈(a,0)），存在 N，使得当 n>N 时，有 an>a′（或 an<a′）。实际中常取 a′=a/2。
  1. 取 ε=a−a′>0。当 n>N 时：an>a−ε=a′。
  2. 取 a′=a/2：当 n 充分大时，an>a2>0。
几何意义：极限为正，则整个尾部都为正——总部在正半轴，几乎所有成员也在正半轴。
推论
若 liman=a，limbn=b，且 a<b，则当 n 充分大时，an<bn。
思路：取 ε=b−a2，当 n 充分大时 an<a+b2<bn。

三个证明的共同模式

唯一性ε0=|b−a|2
有界性ε=1
保号性ε=a−a′，常取 a′=a2
选定一个具体的 ε，让定义替你完成证明。

附注 · 定理 2.5（保序性）

定理 2.5（保序性）
若 n 充分大时 an≤bn，且两数列都收敛，则 liman≤limbn。
注意：严格不等号取极限后可能退化为等号：对每个 n，1n>0，但 lim1n=0。

自测 · 检验一下

1. 若 aₙ → a 且 aₙ → b，则一定有（　）

A. a = b　　B. a ≠ b　　C. a、b 可以不相等

A。取 ε₀ = |b−a|/2，以 a、b 为中心的两条 ε₀ 带不相交；n 充分大时 aₙ 要同时落在两条带内，矛盾。

2. 下列数列中有界但不收敛的是（　）

A. aₙ = n　　B. aₙ = (−1)ⁿ　　C. aₙ = 1/n

B。|(−1)ⁿ| ≤ 1 有界，但在 −1 与 1 之间来回跳动，由唯一性不可能收敛。A 无界；C 收敛于 0——有界只是必要条件。

3. 若 lim aₙ = 2，取 a′ = 1，则存在 N，当 n > N 时必有（　）

A. aₙ > 2　　B. aₙ > 1　　C. aₙ > 0 但未必 > 1

B。保号性保证的是：对任意 a′ ∈ (0, 2)，最终 aₙ > a′。它保证超过 0 与 2 之间的任何数，但不保证超过 2 本身。

4. 证明收敛数列有界时，经典取法是（　）

A. ε = 1　　B. ε₀ = |b−a|/2　　C. ε = a − a′

A。三个证明各配一把钥匙：有界性取 ε = 1（尾部落入 (a−1, a+1)）；唯一性取 ε₀ = |b−a|/2；保号性取 ε = a − a′（常取 a′ = a/2）。

5. 若 n 充分大时 aₙ ≤ bₙ 且两数列都收敛，则（　）

A. lim aₙ < lim bₙ　　B. lim aₙ ≤ lim bₙ　　C. 必有 lim aₙ = lim bₙ

B。严格不等号取极限后可能退化为等号：对每个 n 有 1/n > 0，但 lim 1/n = 0。

6. 推论证明中取 ε = (b−a)/2，得到的中间分界数是（　）

A. (b−a)/2　　B. (a+b)/2　　C. b − a

B。n 充分大时 aₙ < a + ε = (a+b)/2 = b − ε < bₙ——两边的带子恰好以中点为界。

第 3.5 集

两个重要极限

两把总尺：一把校准角度（弧对弦），一把校准复利（逃离对追赶）。

第一把尺 · 第一个重要极限

limx → 0 sin xx = 1

内三角形 OQP: ½ sin x cos x   扇形 OAP: ½x   外三角形 OAT: ½ tan x

当 0 < x < π/2：

½ sin x cos x < ½x < ½ tan x

除以 ½x，再移走余弦因子：

cos x < sin xx < 1cos x

两侧都 → 1，由迫敛法（夹逼）函数版（3.4 集）中间 → 1；sin x / x 为偶函数，x → 0⁻ 随之成立。

为何比面积、为何只能 x → 0、以及后代

  • 比面积，不比长度： 弧对弦要先有弧长理论——而弧长本身就靠这类极限建立，会循环论证。面积靠图形包含比较，只需初等几何。
  • 只在 0 附近： 角一大夹层失效；sin x / x 振荡衰减，趋于 0。

后代： tan xx = sin xx·1cos x → 1,   arcsin xx → 1 （令 t = arcsin x；继承自反函数那一集）.

第二把尺 · 第二个重要极限

limx → ∞ (1 + 1x)x = e

对 x → +∞ 与 x → −∞ 都成立。1∞ 是一场赛跑：底数以 1/x 逃离 1，指数追向 ∞。数列一章已证 (1 + 1/n)n 单调递增且有界，极限记作 e；连续复利使 1 元增长到 e 元。

换元家族

翻译过程，不只翻译式子（u = 1/x）：

x 世界u 世界
x → +∞u → 0⁺
x → −∞u → 0⁻
两者合并u → 0 （双侧）
(1 + 1x)x → e
(1 + u)1/u → e
(1 + kx)x → ek
(1 + 1x)kx → ek

(1 + kx)x = [(1 + 1x/k)x/k]k,   (1 + 1x)kx = [(1 + 1x)x]k

陷阱：换元时过程也要一起翻译——x → +∞ 对应 u → 0⁺，不是 u → 0。k < 0 时 x/k → −∞，两个方向都要用。

1∞ 配方

若 f(x) → 1，g(x) → ∞，且 (f(x) − 1)·g(x) → L，则

f(x)g(x) → eL

记账：令 α = f − 1 → 0， fg = [(1 + α)1/α]αg; 方括号是伪装的祖先 → e，外层指数 αg → L。

IOU #1 — 在幂中取极限的完整依据，要等对数的连续性（下一章）。

例： limx → 0 (cos x)1/x²: α = cos x − 1 = −2sin²(x/2) ~ −x²/2,  αg → −½,  故极限为 e−1/2 ≈ 0.60653.

第三个母公式

limx → 0 ln(1 + x)x = 1

它是祖先取对数： ln(1 + x)x = ln[(1 + x)1/x] → ln e = 1.

IOU #2 — 严格证明待对数连续性建立后给出（下一章）。

两把尺加欠条：下一集等价无穷小表的原料。

自测

1求 limx → ∞ (1 + 3x)2x.

  1. A. e3/2
  2. B. e6
  3. C. e5

答案: B. 写成 [(1 + 3/x)x]2：方括号是 k = 3 的戏服，趋于 e3，故极限为 (e3)2 = e6。

2求 limx → 0 (cos x)1/x².

  1. A. 1
  2. B. e−1/2
  3. C. e−2

答案: B. 1∞ 型，α = cos x − 1 = −2sin²(x/2)，αg = −½·(sin(x/2)/(x/2))² → −½，所以极限是 e−1/2。

3limx → ∞ (1 − 1x)x 是家族成员的伪装，其值为：

  1. A. e
  2. B. e−1
  3. C. 1

答案: B. 这是 k = −1 的 (1 + k/x)x，趋于 e−1；k < 0 时 x/k → −∞，用到祖先的 x → −∞ 版本。

4为什么 sin x / x → 1 的证明比较面积而不是长度？

  1. A. 面积更大，不等式更容易看出。
  2. B. 比较弧与弦要先有弧长理论——此刻会陷入循环论证。
  3. C. 长度不能满足严格不等式。

答案: B. 弧长本身要靠这类极限建立；面积只需初等几何——一个图形包含另一个。

5令 u = 1/x，(1 + u)1/u → e（u → 0 双侧）需要祖先的哪些过程？

  1. A. 只要 x → +∞
  2. B. x → +∞ 与 x → −∞ 都要
  3. C. 只要 x → 0

答案: B. x → +∞ 对应 u → 0⁺，x → −∞ 对应 u → 0⁻；忘了过程就丢一半答案。

6limx → ∞ sin xx = ?

  1. A. 1
  2. B. 0
  3. C. 不存在

答案: B. |sin x/x| ≤ 1/|x| → 0：第一把尺只在 x → 0 时管用，远处图像振荡衰减。

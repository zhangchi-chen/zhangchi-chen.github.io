2.9 · Stirling 公式

选修深度

n! 究竟有多大？——用光滑曲线丈量锯齿阶梯

定理（Stirling 公式）

n! = √(2πn) · (n/e)n · eθn/(12n)

其中 0 < θn < 1；特别地，

n! ~ √(2πn) · (n/e)n
√(2πn)温和的多项式因子
(n/e)ⁿ主引擎：指数增长，且底数本身在变大
e^(θₙ/(12n))微小修正，夹在 1 与 e^(1/(12n)) 之间

1 · 为什么精确大小很重要

增长阶梯 ln n ≪ nk ≪ an ≪ n! ≪ nn 只给出排序：它只说谁赢，不说赢多少。感受一下这个差距：100! 写出来有 158 位数字——手算毫无希望——而它的对数只是一个三位数，ln 100! ≈ 363.7。这才是可以估计的大小，它需要 n! 的精确形状，而不只是名次——这正是 Stirling 公式用三个因子给出的。

验算 100!：ln 100! ≈ 100·ln 100 − 100 + ½·ln(200π) ≈ 363.74，真值为 363.739…（100! ≈ 9.33 × 10157）。

2 · 骨架第一步——性质良好的比值

先取对数：ln n! = ln 1 + ln 2 + … + ln n 是一段 n 级阶梯，第 k 级高 ln k。再叠上光滑曲线 ln x，其积分 ∫1n ln x dx = n ln n − n + 1。阶梯与曲线每级约差半格——这就是 n + ½ 的来历。

定义  bn = ln n! − (n + ½)·ln n + n。

下降量 bn − bn+1 = (n + ½)·ln(1 + 1/n) − 1 为正且约为 1/(12n²)：一小薄片。所以 bn 单调递减且有下界，必收敛于某个极限 c。取指数后，n! / (√n·(n/e)ⁿ) = ebn 始终介于两个正常数 A 与 B 之间——形状对了，只差一个常数。

bn − bn+1 ≈ 112n² > 0,    A ≤ n!√n · (n/e)n = ebn ≤ B

3 · 骨架第二步——Wallis 公式钉死常数

Wallis 公式：

π2 = limn→∞ 2·2·4·4·…·(2n)·(2n)1·3·3·5·…·(2n−1)·(2n+1)

把它想成两段交错的阶梯——偶数积与奇数积的部分乘积——从两侧向 π/2 收紧。把乘积改写成阶乘：2·4·…·2n = 2ⁿ·n!，1·3·…·(2n−1) = (2n)!/(2ⁿ·n!)，于是第 n 个 Wallis 比值为 Wn = 24n(n!)4 / (((2n)!)2(2n+1))。代入第一步的 n! ≈ C·√n·(n/e)ⁿ（(2n)! 用同一个 C）：n 与 e 的幂全部约掉，Wn → C²/4。因此 C²/4 = π/2，C = √(2π)，两个界被挤到一起：A = B = √(2π)。

Wn = 24n(n!)4((2n)!)2(2n+1) → C²4 = π2  ⇒  C = √(2π)

5 · 收获——带数字的 aⁿ 与 n! 之争

再取一次对数：ln n! ≈ n ln n − n + ½·ln(2πn)，主项为 n ln n − n。回到 an 与 n! 的较量：

ann! ≈ (ae/n)n√(2πn) → 0  (n → ∞)

一旦 n 超过 a·e，底数 ae/n 就小于 1，n 次幂把比值压向 0——这就是带上数字的增长阶梯。

6 · 花掉这笔钱——应用

第一笔：中心二项系数。 C(2n, n) = (2n)!/(n!)²；代入 Stirling 公式，n 与 e 的幂再次约掉，得到

C(2n, n) = (2n)!(n!)² ≈ √(4πn) · (2n/e)2n2πn · (n/e)2n = 4n√(πn)

于是 n 次抛公平硬币恰好一半正面的概率为 C(n, n/2)/2ⁿ ≈ √(2/(πn))——一个人人都能感受的数：

抛掷次数 n精确值 P(恰好 n/2 次正面)√(2/(πn))相对误差

100 次里恰好 50 次正面只有约 8% 的机会，而估计值的误差已不到 0.3%。

第二笔：ln n! 是一种计数成本。 n 个物件有 n! 种排列，指定其中一种要花 log2 n! ≈ n·log2 n − 1.44·n 比特——这是所有比较排序的下界：排 1000 个元素至少要比较 ⌈log2 1000!⌉ = 8530 次。在统计计数中，N 枚硬币里放 m 个正面共有 W = C(N, m) 种方式，ln W ≈ N·H(m/N)，其中 H(p) = −p ln p − (1−p) ln(1−p) 是熵函数；玻尔兹曼熵 S = k·ln W 正是物理学中的 Stirling 公式。

log2 n! ≈ n·log2 n − 1.44·n,    ln C(N, m) ≈ N·H(m/N),    S = k·ln W

7 · 展望——含阶乘的级数一行搞定

手握 Stirling 公式，含阶乘的级数判别就成了一行字：对 Σ n!/nⁿ，根值判别法给出 (n!/nⁿ)1/n = (n!)1/n/n → 1/e < 1，级数收敛；又因 C(2n, n)1/n → 4，幂级数 Σ C(2n, n)·xⁿ 的收敛半径恰为 1/4。

(n!/nn)1/n → 1/e < 1  ⇒  Σ n!/nn 收敛;    C(2n, n)1/n → 4  ⇒  R = 1/4

一句话证明骨架

积分比较（Σ ln k 对比 ∫ ln x dx）→ bn 单调有界 → Wallis 公式钉死常数 √(2π)。

自测

围绕本讲要点的六道小题。先选答案，再点击揭晓。

1. Stirling 公式中，哪个因子是增长的主引擎？

A)√(2πn)
B)(n/e)ⁿ
C)e^(θₙ/(12n))
正确答案： B) (n/e)ⁿ
(n/e)ⁿ 是底数不断变大的指数增长；√(2πn) 只是多项式因子，e^(θₙ/(12n)) 介于 1 与 e^(1/(12n)) 之间。

2. 在证明骨架中，比较 Σ ln k 与 ∫ ln x dx 得到了什么？

A)常数的精确值 √(2π)
B)bₙ = ln n! − (n+½)·ln n + n 单调有界，从而 n!/(√n·(n/e)ⁿ) 介于两个正常数之间
C)n! 比 nⁿ 增长更快
正确答案： B) bₙ = ln n! − (n+½)·ln n + n 单调有界，从而 n!/(√n·(n/e)ⁿ) 介于两个正常数之间
第一步只把形状 √n·(n/e)ⁿ 确定到相差一个常数因子，常数的值此时还未知。

3. Wallis 公式在证明中起什么作用？

A)证明 bₙ 收敛
B)钉死常数：Wallis 比值趋于 C²/4，于是 C²/4 = π/2，C = √(2π)
C)说明相对误差约为 1/(12n)
正确答案： B) 钉死常数：Wallis 比值趋于 C²/4，于是 C²/4 = π/2，C = √(2π)
把 n! ≈ C√n(n/e)ⁿ 代入 Wallis 比值，n 与 e 的幂全部约掉，只剩 C²/4，它必须等于 π/2。

4. n = 10 时，√(2πn)·(n/e)ⁿ 的相对误差大约是多少？

A)约 8%
B)约 0.8%
C)约 0.08%
正确答案： B) 约 0.8%
误差约为 1/(12n) = 1/120 ≈ 0.83%，已经不足 1%。

5. 固定 a > 1，aⁿ/n! ≈ (ae/n)ⁿ/√(2πn)。当 n > a·e 之后会怎样？

A)底数 ae/n 小于 1，比值迅速趋于 0
B)比值稳定在 √(2πn) 附近
C)比值继续像 (ae)ⁿ 一样增长
正确答案： A) 底数 ae/n 小于 1，比值迅速趋于 0
越过 n = a·e 后底数小于 1，n 次幂的衰减快于任何等比数列，aⁿ/n! → 0。

6. 下列哪个表达式给出 ln n! 的主项？

A)n ln n − n
B)n ln n + n
C)½·ln(2πn)
正确答案： A) n ln n − n
ln n! = n ln n − n + ½·ln(2πn) + θₙ/(12n)；前两项占主导，½·ln(2πn) 是低阶项。

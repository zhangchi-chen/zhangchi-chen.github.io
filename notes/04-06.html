Cantor 定理

本页为旁白讲稿全文；公式与图示请配合视频 04-06.mp4 观看，自测见右上角。

同学们好！今天找一把管全区间的尺子。上集里，x² 的 δ 失控了。一致连续要一个 δ 管所有点对。逐点连续允许 δ 随点而变。把 [a, b] 想成围墙庭院。每个点 x 都有自己的 δ(x)。

诱人的想法：全收集，取最小。有围墙，一切都有限吧？停一下：庭院里有几个点？无穷多个，δ 也有无穷多个。看 1/n 这一串，个个为正。可它们的下确界是 0。无穷多个数，未必有最小值。

而 δ = 0 根本算不上尺子。拿 1/x 到 (0, 1] 试试。同样的论证，一字照搬。可 1/x 在那里并非一致连续。取相邻点 1/n、1/(n+1)。距离趋于 0，函数值差却恒为 1。可见这个直觉根本没用到围墙！

它指向真相，但还算不上证明。严格证明必须让围墙真正出力。康托尔定理：闭区间上连续必一致连续。反证：假设结论失败。存在刁难的 ε₀，任何 δ 都失效。于是得到坏点对 (xₙ, yₙ)。两点越来越近，函数值差却 ≥ ε₀。

三拍好戏，把它逼成矛盾。第一拍：xₙ 是有界数列。致密性定理抽出 xₙₖ → x₀。问一句：x₀ 落在哪里？取极限得 a ≤ x₀ ≤ b。区间是闭的，x₀ 留在院内。围墙在这里合法地发挥作用。

在 (0, 1] 上极限会逃到 0。第二拍：看搭档 yₙₖ。yₙₖ 离 xₙₖ 小于 1/nₖ。三角不等式：yₙₖ 被拖向 x₀。两列点在同一检查站 x₀ 会合。第三拍：f 在 x₀ 处连续。所以 f(xₙₖ) → f(x₀)。

同样 f(yₙₖ) → f(x₀)。两者之差被挤压到 0。可每个差都 ≥ ε₀，矛盾！所以 f 一致连续，证毕。回顾：困住、会合、相撞。闭区间把无穷多个要求压进一个检查站。闭性与连续性，缺一不可。

拼接引理：两段各一致连续，并集也是。两块领地，各有尺子 δ₁、δ₂。它们在边境小镇 c 相接。同侧的两点：δ₁ 或 δ₂ 就够了。危险在于跨境的点对。c 夹在 x′ 与 x″ 之间。c 处连续：取 δ₃ 管住 ε/2。

两侧到 f(c) 都小于 ε/2。相加，差小于 ε。所以取三者最小值作 δ。

注意：c 要同属两块领地。利普希茨条件：伸缩有界，必一致连续。L 是有界的伸缩因子。给定 ε，取 δ = ε/L。距离小于 δ，函数值差就小于 ε。无需极限和子列，一行搞定。试试 x²，先做因式分解。

伸缩因子正是 |x′ + x″|。[0, M] 上取 L = 2M。在 [0, ∞) 上，它无限增大。点距 1/n，值差却超过 2。这正是上集失控的 δ，换了件衣服。

再看 √x，分领地处理。分子有理化。在 [1, ∞) 上分母至少是 2。所以那里 L = 1/2。可在 0 附近，这个因子会爆掉。[0, 1] 上 √x 找不到 L。但康托尔定理照样保它一致连续。

在 1 处拼接，全线一致连续。利普希茨只是充分条件，并非必要。压轴：半直线上的 cos(√x)。领地 [0, 1]：交给康托尔。领地 [1, ∞)：找利普希茨界。先用和差化积。再用 |sin t| ≤ |t|。

得到：余弦的伸缩因子至多 1。接上 √x 的界。所以 L = 1/2，δ = 2ε。在接缝 x = 1 处拼接。于是 cos(√x) 全线一致连续。全程只用不等式，无需导数。闭区间免费送出这次升级。

可整条实轴 ℝ 四面无墙。ℝ 上的函数，何时仍能一致连续？下集：无穷远处的极限，考试常客。今天的灵魂：把无限压缩成有限。下集见！

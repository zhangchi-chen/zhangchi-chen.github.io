用无限小数定义实数

数轴上每个点的“无限邮编”

1 · 数轴上有洞

单位正方形的对角线长度 x 满足 x² = 2，但没有分数 p/q 满足它。在有理数中，落点是一个洞。

问题不止一个方程。若 f 在 [a, b] 上连续且 f(a) < 0 < f(b)，则它必然穿过零（介值性，即介值定理）。二分法只能追踪真实存在的交点：对 [1, 2] 上的 x² − 2，交点不在有理数中。

2 · 承诺

陈述

每个实数都能写成无限小数 ±a₀.a₁a₂a₃…，而每个无限小数都表示一个实数。

有限小数是尾部全为 0 的特例：0.25 = 0.25000…

3 · 约定

约定

以循环 9 结尾的展开，与进位后的有限小数表示同一个数；例如 0.999… = 1。有了这个约定，表示是唯一的。

理由：0.999… 与 1.000… 之间严格地没有任何小数。若它们表示不同的点，数轴上就会有一个没有名字的缺口。同理 0.24999… = 0.25。

0.999… = 1     0.24999… = 0.25

4 · 放大

每多一位数字，包含它的区间就缩为原来的十分之一。目标点挺过每一次放大；数字就是它的放大指令。

[3.1, 3.2] → [3.14, 3.15] → [3.141, 3.142] → …

5 · 下逼近与上逼近

截断界

若 aₙ 是 x 截断到 n 位小数，则

aₙ ≤ x < aₙ + 10⁻ⁿ

aₙ 是下逼近，aₙ + 10⁻ⁿ 是上逼近；两者之差 10⁻ⁿ 趋于 0。把实数写成无限小数，意思就是给出两列有限小数，在每个精度上把它夹住。

当 x 是有限小数时左边取等；右边取等需要循环 9，已被约定排除。

6 · 逐位比较

两个无限小数在第一个不同的数字处比较大小，就像字典排序。截断让比较成为有限次检查。（先把循环 9 改写成进位形式。）

x = 0.1428…，y = 0.1432…：前两位 1、4 相同；第三位 2 < 3，故 x < y。在 3 位精度下：x < 0.142 + 10⁻³ = 0.143 ≤ y。

7 · 回顾与预告

  • 有理数留下了洞，比如 √2。
  • 无限小数填满了每一个洞。
  • 循环 9 一律进位，名字唯一。
  • 每一位数字放大十倍。
  • 下逼近与上逼近把 x 夹住：aₙ ≤ x < aₙ + 10⁻ⁿ。

下集：稠密性——有理数在数轴中排得有多密？

自测

1. 按约定，0.999… 是……
A比 1 略小的数B恰好等于 1C不是实数
答案: B. 0.999… 与 1.000… 之间没有任何小数，二者表示同一个点：0.999… = 1。
2. 按约定，0.24999… 等于……
A0.24B0.25C介于 0.249 与 0.25 之间但不等于 0.25 的数
答案: B. 以循环 9 结尾的展开表示进位后的有限小数，这里是 0.25。
3. 取 x = π，n = 3，截断界 aₙ ≤ x < aₙ + 10⁻ⁿ 是……
A3.141 ≤ π < 3.142B3.14 ≤ π < 3.15C3.141 < π ≤ 3.142
答案: A. a₃ = 3.141 是 π 截断到 3 位小数，a₃ + 10⁻³ = 3.142。
4. 为什么 aₙ ≤ x < aₙ + 10⁻ⁿ 右边是严格不等号？
A取等需要循环 9，已被约定排除B因为 x 总是无理数C因为截断是向上取整
答案: A. x = aₙ + 10⁻ⁿ 会迫使第 n 位之后全是 9；约定把这样的 x 改写成进位形式。
5. f 在 [a, b] 上连续且 f(a) < 0 < f(b)，介值性保证……
A存在有理零点B存在 c ∈ [a, b] 使 f(c) = 0C二分法有限步内停止
答案: B. 零点作为实数存在，可能是无理数：[1, 2] 上 x² − 2 的零点是 √2。
6. 对 x = 0.1428… 和 y = 0.1432…，哪项正确？
Ax < yBx > yC不知道全部数字就无法判断
答案: A. 第一个不同的数字在第三位：2 < 3，所以 x < 0.143 ≤ y。

函数极限：ε–δ 定义

同一个检查员，新的岗位：为什么 x₀ 的邻域要去心。

1检查员换岗

数列沿整数一步步前进，所以“趋近”就是 n > N。函数的自变量连续变化，可以从两侧逼近任意一点 x₀。检查员的关卡从“N 之后”搬到了“x₀ 附近”。

2翻译对照表

ε–N（数列 aₙ → A）ε–δ（函数 f(x) → A，x → x₀）
任给 ε > 0任给 ε > 0
存在 N，使得当存在 δ > 0，使得当
n > N 时（尾部）0 < |x − x₀| < δ 时（去心邻域）
有 |aₙ − A| < ε有 |f(x) − A| < ε

图像从 A 周围的水平 ε 带升级为一个窗口：宽 x₀ ± δ，高 A ± ε。在 x₀ 附近，图像必须待在窗口内。

定义 limx→x₀ f(x) = A 是指：任给 ε > 0，存在 δ > 0，使得当 0 < |x − x₀| < δ 时，有 |f(x) − A| < ε。

3为什么要去心？

极限描述的是逼近，而不是到达。该点本身可以是个洞（如 0 处的 sin x / x），可以取一个不等于 A 的值，也可以根本不在定义域内。

注：函数值 f(x₀)——无论是否有定义——在定义中不起任何作用。

两个推论

  1. f 在 x₀ 处可以无定义，极限照样可以存在。
  2. 只改动 x₀ 处的函数值，永远不会改变极限。

为什么 ε–N 定义从不需要这一条？因为 ∞ 不是下标：没有哪一项会坐在终点上，尾部天然就是去心的。而这里 x 可以恰好落在 x₀ 上，所以排除必须亲手写上——这正是 0 < 的作用。

4δ 是一种选择，不是函数

若对给定的 ε 某个 δ 可行，则任何更小的 δ 也可行：窗口更窄只会放进更少的点。所以 δ 不必最优。它依赖于 ε，也悄悄依赖于点 x₀。

5示范验证

命题：limx→1 (2x + 1) = 3。

草稿：|(2x + 1) − 3| = 2|x − 1|，而 2|x − 1| < ε ⟺ |x − 1| < ε/2。于是试取 δ = ε/2。

验证。任给 ε > 0，取 δ = ε/2 > 0。则对一切满足 0 < |x − 1| < δ 的 x，有 |(2x + 1) − 3| = 2|x − 1| < 2δ = ε，故 limx→1 (2x + 1) = 3。∎

0 < |x − 1| < δ  ⟹  |(2x + 1) − 3| = 2|x − 1| < ε

6小结

  • 同一个检查员，新的岗位：ε 定 A 周围的容差，δ 划 x₀ 的邻域。
  • 门——点 x₀ 本身——始终关着。
  • 邻域发言，那个点保持沉默。

?自测

1. 在 lim(x→x₀) f(x) = A 的 ε–δ 定义中，函数值 f(x₀) 起什么作用？
  1. A. 必须等于 A。
  2. B. 至少必须有定义。
  3. C. 不起任何作用。
答案： C. 条件 0 < |x − x₀| < δ 排除了 x = x₀，所以 f(x₀) 从不被检查。
2. 为什么 ε–N 定义从不需要“0 <”这一条？
  1. A. 因为数列总是单调的。
  2. B. 因为 ∞ 不是下标，没有哪一项会坐在终点上。
  3. C. 因为 N 是整数。
答案： B. 尾部 n > N 里永远没有“n = ∞”，天然去心；而 x 却可以等于 x₀。
3. 设 lim(x→2) f(x) = 5，只把 f(2) 从 5 改成 9，则极限……
  1. A. 变成 9。
  2. B. 仍是 5。
  3. C. 不再存在。
答案： B. 只改动 x₀ 处的值永远不会改变极限：去心邻域从不看 x₀。
4. ε–δ 定义中哪一部分对应 ε–N 中的“n > N”？
  1. A. 任给 ε > 0
  2. B. 0 < |x − x₀| < δ
  3. C. |f(x) − A| < ε
答案： B. 两者都描述检查员在哪里检查：数列看尾部，函数看去心邻域。
5. 对 lim(x→1) (2x + 1) = 3，取 ε = 0.1，下列哪个 δ 一定可行？
  1. A. δ = 0.05
  2. B. δ = 0.1
  3. C. δ = 0.2
答案： A. 需要 2|x − 1| < 0.1，即 |x − 1| < 0.05；δ = ε/2 = 0.05 可行（更小的也行），而 δ = 0.1 不行，例如 x = 1.08。
6. 若对给定的 ε，δ = 0.3 可行，则 δ = 0.1……
  1. A. 也可行。
  2. B. 可能不行。
  3. C. 只有当 0.3 是最大可行 δ 时才行。
答案： A. 窗口更窄只会放进更少的点，而这些点本来就满足 |f(x) − A| < ε。

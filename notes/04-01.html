函数的连续性与间断点

连续是逐点的、局部的约定：在一点 x₀ 处，左极限、右极限、函数值 f(x₀) 这三个数必须一致。

1 · 三方握手

称 f 在 x₀ 处连续，是指

limx→x₀ f(x) = f(x₀)

三个承诺：f(x₀) 有定义、极限存在、二者相等。等价地：

limx→x₀⁻ f(x) = f(x₀) = limx→x₀⁺ f(x)

2 · 三种写法，同一个命题

增量语言Δx → 0 时，Δy = f(x₀ + Δx) − f(x₀) → 0
极限语言limx→x₀ f(x) = f(x₀)
ε–δ 语言任给 ε > 0，存在 δ > 0，当 |x − x₀| < δ 时，|f(x) − f(x₀)| < ε

为何等价：令 x = x₀ + Δx，于是 Δx → 0 恰好对应 x → x₀，而 Δy → 0 就是 f(x) → f(x₀)。把这个极限写成 ε–δ 语言，得到：只要 0 < |Δx| < δ，就有 |Δy| < ε；而 Δx = 0 时 Δy = 0 < ε 自动成立，所以可以去掉条件 0 < |Δx|。和上一章的极限检查员相比，目标值换成了 f(x₀) 本身，x₀ 这一点也要上岗。

小试：f(x) = 3x + 1，x₀ = 2，有 |f(x) − f(2)| = 3|x − 2|，取 δ = ε/3 即可；例如 ε = 0.3 时，δ = 0.1。

3 · 单侧连续

若 limx→x₀⁺ f(x) = f(x₀)，称 f 在 x₀ 处右连续；左连续同理。f 在 x₀ 处连续，当且仅当它在该点既左连续又右连续。在区间端点处，连续是指相应的单侧连续——例如 √x 在 0 处右连续，所以在 [0, +∞) 上连续。

4 · 分类器：两个问题

问题一 · 左右极限都存在（为有限数）吗？
否 → 第二类间断点
问题二 · 二者相等吗？
否 → 跳跃间断点
相等，但函数值缺失或另有其值 → 可去间断点

可去间断点与跳跃间断点合称第一类间断点。

函数与点诊断类型
x + 1（x < 1），4 − x（x ≥ 1），在 1 处左 2，右 3 = f(1)跳跃，右连续
|sgn x| 在 0 处两侧极限为 1，函数值为 0可去
sgn x 在 0 处左 −1，右 1跳跃
x·sin(1/x) 在 0 处（无定义）|x·sin(1/x)| ≤ |x| → 0可去
sin(1/x) 在 0 处在任意靠近 0 处取到 ±1第二类
1/x² 在 0 处两侧趋于 +∞第二类
狄利克雷函数 D(x) 在任一点每个区间里有理数、无理数都有第二类
x·D(x)|x·D(x)| ≤ |x|只在 0 处连续
(1/(n+1), 1/n] 上取 n，在 1/n 处（n ≥ 2）左 n = f(1/n)，右 n − 1跳跃，左连续

5 · 为何先分类

  • 修补可去间断点：sin x / x 在 0 处无定义，极限为 1；补定义函数值为 1，它就连续了。
  • 读懂阶梯函数：快递资费 0 < w ≤ 1 kg 收 8 元、1 < w ≤ 2 kg 收 12 元，在 1 kg 处跳跃且左连续——实心点决定边界价格。
  • 诊断数据：孤立异常值是可去的（用邻近极限替换）；台阶是跳跃（查原因，别抹平）；无休止的振荡提示采样本身可疑。

自测

1. f 在 x₀ 处连续，要求哪些量相等？

A.左极限、右极限与 f(x₀)B.只需左极限与右极限C.f(x₀) 与 f(x₀ + 1)
答案: A. 连续就是三方握手：两个单侧极限都存在，并且都等于 f(x₀)。

2. x < 1 时 f(x) = x + 1，x ≥ 1 时 f(x) = 4 − x。x = 1 是……

A.可去间断点B.跳跃间断点，且右连续C.第二类间断点
答案: B. f(1⁻) = 2，f(1⁺) = 3，都存在但两样；f(1) = 3 与右极限一致。

3. x·sin(1/x) 在 0 处无定义，0 是它的……

A.可去间断点B.跳跃间断点C.第二类间断点
答案: A. |x·sin(1/x)| ≤ |x| → 0，极限 0 存在；补定义函数值为 0 即可修好。

4. f(x) = 3x + 1，x₀ = 2，ε = 0.3。哪个 δ 可行？

A.δ = 0.1B.δ = 0.2C.δ = 0.3
答案: A. |f(x) − 7| = 3|x − 2| < 3δ，需要 3δ ≤ 0.3；若 δ = 0.2，取 x = 2.15 得 0.45 > 0.3。

5. 下列哪个是第一类间断点？

A.sin(1/x) 的 0 点B.1/x² 的 0 点C.sgn x 的 0 点
答案: C. sgn x 的左右极限为 −1 和 1，都存在但两样，是跳跃间断点，属于第一类。

6. g 与 f 在 (x₀ − 0.01, x₀ + 0.01) 上相同，f 在 x₀ 处连续。g 在 x₀ 处……

A.连续B.可能间断C.一定间断
答案: A. 连续是局部性质：只与 x₀ 附近（含 x₀）的值有关，而那里 g 与 f 完全一样。

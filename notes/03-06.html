无穷小的阶

O(f)、o(f) 作为函数类 —— 计算 —— 等价替换

1无穷小的竞速

当 x → x₀，用比值极限比较两个无穷小 u、v——终点记分牌：

比值极限结论
lim u/v = 0u 是比 v 高阶的无穷小：u = o(v)
lim u/v = c ≠ 0同阶无穷小
c = 1等价无穷小：u ~ v
lim u/v = ∞u 是低阶无穷小
lim u/vk = c ≠ 0u 是 k 阶无穷小

这是数列一章无穷大阶梯的镜像：那里比谁长得快，这里比谁消失得快。

2为什么要用函数类

取 u = x·sin(1/x)，v = x（x → 0），比值 sin(1/x) 永远摆动：没有比值极限，也就没有称号。但 |u| ≤ |v|——这是可靠的比较。于是改讲上界与趋势：函数类 O(f) 与 o(f)。

3函数类的语言

函数类是放函数的柜子，函数都生活在过程点 x₀ 附近：

g ∈ O(f) ⟺ 在 x₀ 的某去心邻域内 |g| ≤ C|f|
g ∈ o(f) ⟺ g/f → 0

两个有名字的类：o(1) = 全体无穷小（本章就是给它排座次）；O(1) = 局部有界函数。

坦白（仅此一次）：我们写 o(f) + o(f) = o(f)，但这个等号的意思是 ⊆：左边任一成员都落在右边的类里。只能从左往右读。这种滥用是被许可的——从此，等号算数通行无阻。

4查表计算

先给每个因子归类，再查表计算。

#恒等式图景
1O(f) + O(f) = O(f)受 f 控制 + 受 f 控制
2O(f)·O(g) = O(fg)常数相乘
3o(f) + o(f) = o(f)可忽略 + 可忽略
4o(f)·O(g) = o(fg)小 × 有界 = 小
5c·o(f) = o(f)c 为常数
6x·o(f(x)) = o(x·f(x))x → 0；变量乘子整体缩放
7o(1)·O(f(x)) = o(f(x))主力：趋于 0 × 受 f 控制，被 f 压倒
8f ~ g ⟺ f − g = o(g)等价是关于差的类陈述

算一个例子（x → 0）：x³·o(1)·(2 + sin(1/x))/x。归类：(2 + sin(1/x))/x ∈ O(1/x)。第 7 条：o(1)·O(1/x) = o(1/x)。第 6 条：x³·o(1/x) = o(x²)。结论：o(x²)。

5等价替换：乘除自由

f ~ g 即 f = g·(1 + o(1))。修正因子趋于 1，可随意合并（o(1)·o(1) = o(1)），且不改变极限，所以乘积与商之中等价替换成立。

limx→0 sin 3x·(e2x − 1) / (x·tan 5x) = lim 3x·2x / (x·5x) = 6/5

6陷阱：加减之中

天真做法：tan x ~ x，sin x ~ x，于是 (tan x − sin x)/x³ → (x − x)/x³ = 0。错——真实值是 1/2。

函数类诊断：tan x = x + o(x)，sin x = x + o(x)，所以 tan x − sin x = o(x)：主部抵消，余项说了算，而 o(x)/x³ 无法确定。就像抵消两个数的前几位数字，却指望剩下的尾数也是零。加减之中，等价替换一般不成立。

解药——先因式分解，再替换因子：

tan x − sin x = tan x·(1 − cos x)，  1 − cos x = 2sin²(x/2) ~ x²/2
(tan x − sin x)/x³ = (sin x/x)·(1/cos x)·((1 − cos x)/x²) → 1·1·(1/2) = 1/2

根本的解药——更细的尺度、高阶展开——就是后面的泰勒展开（预告）。

7家族树与桥梁

等价无穷小表是长出来的，不是背出来的。三位母亲：sin x/x → 1（子女 tan x ~ x、arcsin x ~ x、1 − cos x ~ x²/2）；e 家族及其代换（ex − 1 ~ x）；ln(1 + x)/x → 1，仍挂着欠条（ln(1 + x) ~ x）。

至此，极限的语言已经完备。下一问：若 x → x₀，是否 f(x) → f(x₀)？那就是连续性——下一章——它也将兑现那张欠条。

✎自测

1. x → 0 时，o(x²)·O(1/x) 化简为：
  • A. o(x)
  • B. O(x)
  • C. o(x³)
✓ A — 由 o(f)·O(g) = o(fg)，取 f = x²，g = 1/x：o(x²·1/x) = o(x)。
2. x → 0 时，x·o(1/x²) 等于：
  • A. o(x)
  • B. o(1/x)
  • C. O(1/x²)
✓ B — 由 x·o(f(x)) = o(x·f(x))：o(x·1/x²) = o(1/x)。
3. “o(f) + o(f) = o(f)”中的等号表示：
  • A. 两个类双向相等
  • B. 两个 o(f) 是同一个函数
  • C. 包含 ⊆：o(f) 中任两个成员之和仍在 o(f) 中
✓ C — 函数类等式从左往右读，表示属于/包含，而不是对称的相等。
4. 一般而言，等价替换在哪里合法？
  • A. 乘积与商之中
  • B. 和与差之中
  • C. 表达式中任何位置
✓ A — 修正因子 1 + o(1) 可以穿过乘除；而在差中，主部可能互相抵消。
5. 为什么在 (tan x − sin x)/x³ 中直接替换会得到错误的 0？
  • A. tan x 与 x 不等价
  • B. 主部抵消只剩 o(x)，而 o(x)/x³ 无法确定
  • C. 该极限不存在
✓ B — tan x − sin x 只知道属于 o(x)；由余项决定，真实极限是 1/2。
6. 对 u = x·sin(1/x)、v = x（x → 0），哪个结论成立？
  • A. u ~ v
  • B. u ∈ O(v)，尽管 lim u/v 不存在
  • C. u 不是无穷小
✓ B — |u| ≤ |v| 即得 u ∈ O(v)，无需比值极限——这正是函数类更稳健之处。

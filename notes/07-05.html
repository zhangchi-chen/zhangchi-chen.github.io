Stolz 定理

洛必达法则的离散孪生：增量之比决定总量之比。

1对照词典

把点 (bn, an) 连成折线。从原点出发的斜率是总量之比 anbn；最新一段的斜率是增量之比 ΔanΔbn，其中 Δan = an+1 − an。

数列（离散）函数（连续）
Δan⟷f′(x)增量 ↔ 导数
Σk≤n Δak⟷∫ f′求和 ↔ 积分
anbn⟷f(x)g(x)总量之比 ↔ 函数之比
ΔanΔbn⟷f′(x)g′(x)增量之比 ↔ 导数之比
洛必达lim f′(x)g′(x) = L ⟹ lim f(x)g(x) = L
Stolz 定理lim ΔanΔbn = L ⟹ lim anbn = L

2定理表述

∞/∞ 型

{bn} 严格递增，bn → +∞

若 limn→∞ an+1 − anbn+1 − bn = L（L 有限，或 ±∞），则 limn→∞ anbn = L。

0/0 型

an → 0, bn → 0，{bn} 严格递减（从某项起 bn > 0）

若 limn→∞ an+1 − anbn+1 − bn = L，则 limn→∞ anbn = L。

3条件缺一不可

取 bn = 2 − 1/n，an = 3 − 1/n：每个增量之比都等于 1，但 anbn → 3/2。分母有界，新窗口不再打开，开头部分永远冲不掉。

检查清单 —— 先过一遍（标记对应上例）

  • 1. {bn} 严格递增吗？ ✓
  • 2. bn → +∞ 吗？ ✗
  • 3. 增量之比有极限吗？ ✓

4证明骨架：夹逼

固定 ε > 0，取 m 使 m 之后的增量之比都落在 (L − ε, L + ε)。红色头部是初始存量 am, bm；尾部每张选票的单价都在金色带内。

裂项相消an = am + Σk=mn−1 Δak,   bn = bm + Σk=mn−1 Δbk
逐项夹住尾部(L − ε) Δbk < Δak < (L + ε) Δbk,   k ≥ m
同除以 bnam + (L − ε)(bn − bm)bn ≤ anbn ≤ am + (L + ε)(bn − bm)bn

令 n → ∞：头部被 bn → +∞ 除掉而消失；上下界趋于 L ± ε。

上极限limsup anbn ≤ L + ε    下极限liminf anbn ≥ L − ε
ε 任意，故极限存在且等于 L。尾部压倒了头部。

5例题

(i) Cesàro 平均

若 an → a，取 An = a1 + … + an，bn = n（严格递增，→ +∞）。于是

An+1 − Anbn+1 − bn = an+11 → a
⟹ a1 + … + ann → a

(ii) 正方形里的阶梯和

分子增量为 n + 1，分母 n² 的增量为 2n + 1（严格递增，→ +∞）。于是

n + 12n + 1 → 12
⟹ 1 + 2 + … + nn² → 12

6误用与适用范围

✓ 合法使用✗ 违规
方向✓ ΔanΔbn → L ⟹ anbn → L✗ an = (−1)n, bn = n：anbn → 0，但 ΔanΔbn = 2(−1)n+1 来回跳动
∞/∞ 型✓ {bn} 严格递增，bn → +∞✗ bn = 2 − 1/n 有界：增量之比为 1，但 anbn → 3/2
0/0 型✓ an → 0, bn → 0，{bn} 严格递减✗ an = 1 + 1/n ↛ 0，bn = 1/n：增量之比为 1，但 anbn = n + 1 → +∞

?自测

先选一个答案，再点击查看。

1. 在对照词典中，增量 Δan = an+1 − an 对应的是……
答案: B. 一步增量是离散的导数，累加增量是离散的积分。
2. 对 bn = 2 − 1/n，an = 3 − 1/n，清单中哪一项不成立？
答案: B. bn 递增但始终小于 2，开头冲不掉，于是 anbn → 3/2 而不是 1。
3. 证明中，初始存量 aₘ, bₘ 为什么最终无关紧要？
答案: A. 头部以 (am − (L ± ε)bm)/bn 的形式出现，因 bn → +∞ 而趋于 0。
4. 对每个固定的 ε，夹逼直接得到什么？
答案: B. 上极限与下极限都被困在 L 的 ε 邻域内；ε 任意，二者只能在 L 相遇。
5. lim (1 + 2 + … + n)/n² 等于多少？
答案: B. 增量分别为 n + 1 与 2n + 1，其比趋于 1/2，且 n² 严格递增趋于 +∞。
6. an = (−1)n，bn = n 这个例子说明……
答案: A. anbn → 0，但增量之比 2(−1)n+1 没有极限：定理是单向的。

确界原理的证明

逐位搜寻 sup S，看清完备性究竟在哪里登场。

确界原理
若 S ⊆ ℝ 非空且有上界，则 S 在 ℝ 中有上确界 sup S。
构造中用到的两个事实（每一步 n）
✗ aₙ 不是 S 的上界
✓ aₙ + 10⁻ⁿ 是 S 的上界

1要造出什么

一个数 α，身兼两职：(i) α 是 S 的上界；(ii) 任何 b < α 都不是上界。策略：逐位找出它的地址——街道（整数部分）、楼（十分位）、门（百分位）……

2–3构造

整数部分。S 非空，故有整数不是上界；S 有上界，故有整数是上界。设 m 为最大的非上界整数，则 m + 1 是上界，目标在 [m, m + 1] 中。

加细。把当前窗口十等分，令 aₙ 为最大的、不是上界的 n 位小数分点。则 aₙ + 10⁻ⁿ 是上界，目标在长度为 10⁻ⁿ 的嵌套窗口 [aₙ, aₙ + 10⁻ⁿ] 中。

地址。依次读出 a₁, a₂, a₃, … 的数字，得到一个无限小数 α = m + 0.d₁d₂d₃…，它的前 n 位截断正是 aₙ。

例：S = {q ∈ ℚ : q² < 2}

对 c > 0：若 c² < 2，则 S 中有元素超过 c；若 c² ≥ 2，则 c 是上界。   m = 1.

每一位数字都是一个承诺：目标就在这个更小的窗口里。

4验证两点

对每个 n：aₙ ≤ α ≤ aₙ + 10⁻ⁿ（α 与 aₙ 前 n 位相同；其余各位贡献介于 0 与 10⁻ⁿ 之间）。

(i) α 是上界。

假设某个 s ∈ S 满足 s > α。取 n 充分大，使 10⁻ⁿ < s − α。则 aₙ + 10⁻ⁿ ≤ α + 10⁻ⁿ < s，从而 aₙ + 10⁻ⁿ 不是 S 的上界，与构造矛盾。故对一切 s ∈ S，有 s ≤ α。

(ii) 比 α 小的数都不是上界。

设 b < α。取 n 充分大，使 10⁻ⁿ < α − b。则 aₙ ≥ α − 10⁻ⁿ > b。而 aₙ 不是 S 的上界，故存在 s ∈ S，使 s > aₙ > b。所以 b 不是上界。

所以 α = sup S。∎

5约定悄悄救了证明

取 S = [0, 0.42)，则 sup S = 0.42。由于 0.42 是上界，搜寻从不选它：a₁ = 0.4，a₂ = 0.41，a₃ = 0.419，a₄ = 0.4199，……各位数字拼出 α = 0.41999…，而循环 9 约定规定 0.41999… = 0.42。没有这个约定，地址系统会在每个有限小数处出故障。

0.41999… = 0.42

6寓意

完备性只在一处登场：逐位搜寻产出一个无限小数，而 ℝ 接纳每个无限小数为数。若只在 ℚ 中，对 S = {q ∈ ℚ : q² < 2} 的同样搜寻会逼近 1.41421…，它不是有理数。这招嵌套区间日后会成为关于嵌套闭区间的定理——而在这里，它已真正出力。

✓自测

1. S = {q ∈ ℚ : q² < 3} 的 m = 1。做第 1 步：a₁ 是多少？
A1.7B1.8C1.73
正确答案： A. 1.7² = 2.89 < 3，故 1.7 不是上界；1.8² = 3.24 ≥ 3，故 1.8 是上界；所以 a₁ = 1.7，目标在 [1.7, 1.8] 中。
2. 对 S = [−2.5, −0.3)，最大的非上界整数 m 是多少？
A−1B0C−3
正确答案： A. −1 被 −0.5 ∈ S 超过，而 0 是上界，所以 m = −1，目标在 [−1, 0] 中。
3. 对 S = [0, 0.42)，循环 9 约定为何重要？
A搜寻拼出 0.42000…，约定无关紧要B搜寻拼出 0.41999…，它等于 sup S = 0.42 全靠约定C搜寻永不结束，所以 α 不存在
正确答案： B. 0.42 始终是上界、从不被选，所以各位数字是 0.41999…，约定把这个小数认定为 0.42。
4. 第 (i) 点中，被推出矛盾的是哪个构造事实？
Aaₙ 不是上界Baₙ + 10⁻ⁿ 是上界Cα ∈ S
正确答案： B. 由 s > α 可知 n 充分大时 s > aₙ + 10⁻ⁿ，于是 aₙ + 10⁻ⁿ 就不是上界了。
5. 哪个不等式对每个 n 都成立？
Aaₙ < α < aₙ + 10⁻ⁿBaₙ ≤ α ≤ aₙ + 10⁻ⁿCα ≤ aₙ
正确答案： B. aₙ 是 α 的前 n 位截断，其余各位贡献介于 0 与 10⁻ⁿ 之间（可以取等号，如 0.41999… = 0.42）。
6. 完备性究竟在证明的哪一步用到？
A选取整数 m 时B承认无限小数 α 是一个实数时C第 (i) 点的反证中
正确答案： B. 其余各步都是有限的检验；只有“无限小数 α 是 ℝ 中的数”这一步用到完备性。

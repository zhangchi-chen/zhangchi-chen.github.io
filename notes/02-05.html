单调 + 有界 ⇒ 收敛

递推数列、不动点与数 e · 数学分析 2.5

定理（单调有界原理） 单调有界数列必收敛：若 (aₙ) 递增且有上界，或递减且有下界，则 (aₙ) 收敛。

1 · 仅有界还不够

aₙ = (−1)ⁿ 始终在 −1 与 1 之间，却永远来回跳：有界 ✓ 收敛 ✗。缺少的是方向。想象在有屋顶的楼里爬楼梯：只往上走，又穿不过屋顶，高度必定稳定下来——也许停在屋顶之下的 sup aₙ，但一定会稳定。

2 · 递推 aₙ₊₁ = f(aₙ) 的三步法

  1. 估计。若极限 L 存在，则 L = f(L)。这只是猜测。
  2. 证明单调 + 有界，通常用归纳法。此时由定理，极限确实存在。
  3. 取极限：在 aₙ₊₁ = f(aₙ) 两边令 n → ∞，解出 L。

例题: a₁ = √2, aₙ₊₁ = √(2 + aₙ)

① L = √(2 + L) ⇒ L² = 2 + L ⇒ (L − 2)(L + 1) = 0，又 L ≥ 0，猜测 L = 2。

② 有界：a₁ = √2 < 2；若 aₙ < 2，则 aₙ₊₁ = √(2 + aₙ) < √4 = 2。递增：a₂ = √(2 + √2) > √2 = a₁；由于 √(2 + x) 是增函数，aₙ > aₙ₋₁ 推出 aₙ₊₁ > aₙ。

③ 令 n → ∞：L = √(2 + L)，故 L = 2——这是证出来的，而非假设的。

aₙ 与 2 之间的阴影带每一步都在收窄。

3 · 循环论证陷阱

✗ 循环论证

取 a₁ = 1, aₙ₊₁ = 2aₙ。

解 L = 2L ⇒ L = 0。

“所以极限是 0。”

实际上 aₙ = 2ⁿ⁻¹ → ∞：极限根本不存在。

✓ 正确顺序

① 估计：解 L = f(L)（猜测）

② 单调 + 有界 ⇒ 极限存在

③ 取极限，解出 L

L = f(L) 只告诉你极限若存在会在哪里，并不说明极限存在。估计只是向导，定理才是通行证。

4 · 两个不动点，两种命运

aₙ₊₁ = aₙ²：由 L = L² 得不动点 0 与 1。起点在 (0, 1) 内：数列递减趋于 0（0.9 → 0.81 → 0.66 → 0.43 → …）。起点大于 1：数列无界递增（1.1 → 1.21 → 1.46 → 2.14 → …）。同一规则，两种命运——起点决定一切。

5 · 用复利认识 e

存入 1，年利率 100%，每年结算 n 次：年末得到 (1 + 1/n)ⁿ。

结算n(1 + 1/n)ⁿ

每半年22.25
每季42.4414
每月122.6130
每天3652.7146
连续∞e ≈ 2.71828

二项式展开的图景：(1 + 1/n)ⁿ = Σₖ₌₀ⁿ (1/k!)·(1 − 1/n)(1 − 2/n)⋯(1 − (k−1)/n)。每个因子都小于 1 且随 n 增大而变大，n 越大项数越多 ⇒ 递增。又 (1 + 1/n)ⁿ ≤ Σₖ₌₀ⁿ 1/k! < 1 + 1 + 1/2 + 1/4 + ⋯ = 3 ⇒ 有上界。故极限存在：e = lim (1 + 1/n)ⁿ。

1^∞ 型。底数 1 + 1/n → 1，指数 n → ∞。“1 的任何次方都是 1”在这里不适用：极限是 e，而不是 1。这种隐藏的不定式将在后续一集中解决。

自测

1. 下列哪个数列有界但发散？

A. aₙ = 1/nB. aₙ = (−1)ⁿC. aₙ = 2 − 1/n

答案：B。(−1)ⁿ 始终在 [−1, 1] 内，却永远交替，没有极限；另两个都单调有界。

2. 用三步法处理 aₙ₊₁ = f(aₙ) 时，何时才能确信 L = f(L) 的根就是极限？

A. 一解出 L = f(L) 就可以B. 证明数列单调有界之后C. 算出前三项之后

答案：B。只有单调有界才保证极限存在；之后取极限才说明它满足 L = f(L)。

3. 对 a₁ = √2, aₙ₊₁ = √(2 + aₙ)，归纳步证明的是什么？

A. aₙ < 2 ⇒ aₙ₊₁ < 2B. aₙ > 2 ⇒ aₙ₊₁ > 2C. 对所有 n，aₙ = 2

答案：A。若 aₙ < 2，则 aₙ₊₁ = √(2 + aₙ) < √4 = 2；而 a₁ = √2 < 2 作为起点。

4. a₁ = 1, aₙ₊₁ = 2aₙ。解 L = 2L 得 L = 0。哪项正确？

A. aₙ → 0B. aₙ → ∞，L = 0 并不是极限C. aₙ → 1

答案：B。aₙ = 2ⁿ⁻¹ → ∞；L = f(L) 不涉及极限是否存在，先用它就是循环论证。

5. 对 aₙ₊₁ = aₙ²，取 a₁ = 0.5，数列会……

A. 递减趋于 0B. 收敛到 1C. 递增趋于 ∞

答案：A。起点在 (0, 1) 内，平方使每项变小；递减且以 0 为下界，故趋于 0。

6. 为什么说 lim (1 + 1/n)ⁿ 是 1^∞ 型？

A. 底数趋于 1，而指数趋于 ∞B. 因为极限等于 1C. 因为数列递减

答案：A。底数 → 1 与指数 → ∞ 相互角力，不能用“1 的任何次方都是 1”判断；这里极限是 e。

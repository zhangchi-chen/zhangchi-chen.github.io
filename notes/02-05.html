单调 + 有界 ⇒ 收敛

为什么有些数列必定到达——证明，以及它的用处 · 数学分析 2.5

I第一幕 · 动机：计算器之谜

在计算器上输入 √2，反复“加 2 再开方”：1.41421，1.84776，1.96157，1.99037，1.99759，…… 数字似乎锁定在 2。可是满屏的数字只是证据，不是证明：有限多项再多，也说明不了之后的无穷多项。

代数只能有条件地帮忙：如果极限 L 存在，那么 L = √(2 + L)，于是 L = 2。代数定位极限，却保证不了极限存在。存在性是另一个问题——这正是本定理要补的缺口。

II第二幕 · 定理说了什么

定理（单调有界原理） 单调有界数列必收敛：如果 (aₙ) 递增而且有上界，或者递减而且有下界，那么 (aₙ) 收敛。
单调——每一步都朝同一方向。只有单调不够：数列 aₙ = n 一直往上爬。
有界——存在屋顶。只有有界也不够：(−1)ⁿ 始终在屋顶下，却永远来回跳。
结论：到达。在屋顶下向上爬，必定到达某处——可能低于屋顶，就是 sup aₙ。定理保证存在，并不给出极限值。

III第三幕 · 证明与方法

为什么成立：证明

关键反例——有理数。1，1.4，1.414，1.4142，…… 递增，而且以 2 为上界，然而它在有理数中没有极限（唯一的候选是 √2 ∉ ℚ）。更糟的是，在有理数里这些项连最小上界都找不到：每个有理数上界都大于 √2，中间总能再塞进一个更小的有理数。证明需要的正是这个对象，所以在有理数里根本无法起步。在实数里，确界原理（第 1.5 集已证）保证它存在。

设 (aₙ) 递增而且有上界，令 s = sup aₙ（根据确界原理，它存在）。断言：aₙ → s。

任取 ε > 0。因为 s − ε < s，而 s 是最小上界，所以 s − ε 这个数不是上界：存在某一项 aₘ > s − ε。

单调性带着后面每一项一起上升：对所有 n ≥ m，s − ε < aₘ ≤ aₙ ≤ s，也就是 |aₙ − s| < ε。这正是第 2.1 集的 ε–N 定义，取 N = m；ε 是任取的，所以 aₙ → s。

递减情形，由对称得到：如果 (aₙ) 递减而且有下界，那么 (−aₙ) 递增而且有上界，所以 −aₙ → sup(−aₙ) = −inf aₙ，也就是 aₙ → inf aₙ。

递推 aₙ₊₁ = f(aₙ) 的三步法

  1. 估计。如果极限 L 存在，那么 L = f(L)。这只是猜测。
  2. 证明单调 + 有界，通常用归纳法。这时根据定理，极限确实存在。
  3. 取极限：在 aₙ₊₁ = f(aₙ) 两边令 n → ∞，解出 L。

例题: a₁ = √2, aₙ₊₁ = √(2 + aₙ)

① L = √(2 + L) ⇒ L² = 2 + L ⇒ (L − 2)(L + 1) = 0，又因为 L ≥ 0，猜测 L = 2。

② 有界：a₁ = √2 < 2；如果 aₙ < 2，那么 aₙ₊₁ = √(2 + aₙ) < √4 = 2。递增：a₂ = √(2 + √2) > √2 = a₁；因为 √(2 + x) 是增函数，从 aₙ > aₙ₋₁ 得到 aₙ₊₁ > aₙ。

③ 令 n → ∞：L = √(2 + L)，所以 L = 2——这是证出来的，而不是假设的。

aₙ 与 2 之间的阴影带每一步都在收窄。

循环论证陷阱

✗ 循环论证

取 a₁ = 1, aₙ₊₁ = 2aₙ。

解 L = 2L ⇒ L = 0。

“所以极限是 0。”

实际上 aₙ = 2ⁿ⁻¹ → ∞：极限根本不存在。

✓ 正确顺序

① 估计：解 L = f(L)（猜测）

② 单调 + 有界 ⇒ 极限存在

③ 取极限，解出 L

L = f(L) 只告诉你极限如果存在会在哪里，说明不了极限存在。估计只是向导，定理才是通行证。

IV第四幕 · 应用与展望

应用一 · 复利与 e

存入 1，年利率 100%，每年结算 n 次：年末得到 (1 + 1/n)ⁿ。

结算n(1 + 1/n)ⁿ

连续∞e ≈ 2.71828

二项式展开的图景：(1 + 1/n)ⁿ = Σₖ₌₀ⁿ (1/k!)·(1 − 1/n)(1 − 2/n)⋯(1 − (k−1)/n)。每个因子都小于 1，而且随 n 增大而变大；n 越大项数越多 ⇒ 递增。又有 (1 + 1/n)ⁿ ≤ Σₖ₌₀ⁿ 1/k! < 1 + 1 + 1/2 + 1/4 + ⋯ = 3 ⇒ 有上界。单调有界，所以极限存在：e = lim (1 + 1/n)ⁿ ≈ 2.71828。

底数与指数。底数 1 + 1/n → 1，指数 n → ∞，可是极限并不是 1：数列从 2 出发，只升不降，所以极限至少是 2——它就是 e。

应用二 · 不动点迭代（数值方法预告）

计算机用迭代 xₙ₊₁ = (xₙ + 2/xₙ)/2，x₁ = 2 求 √2——这就是解 x² − 2 = 0 的牛顿法。迭代值：2，1.5，1.41666667，1.41421569，1.41421356237（正确位数 1 → 3 → 6 → 12）。

所有 xₙ > 0；根据均值不等式 xₙ₊₁ ≥ √(xₙ · 2/xₙ) = √2——有下界。

xₙ₊₁ − xₙ = (2 − xₙ²)/(2xₙ) ≤ 0，因为 xₙ ≥ √2——递减。

所以收敛，再从 L = (L + 2/L)/2 得到 L² = 2，L = √2。

aₙ₊₁ = aₙ²：从 L = L² 得到不动点 0 和 1。起点在 (0, 1) 内：数列递减趋于 0（0.9 → 0.81 → 0.66 → 0.43 → …）。起点大于 1：数列无界递增（1.1 → 1.21 → 1.46 → 2.14 → …）。同一规则，两种命运——起点决定一切。

应用三 · 部分和

换一种对象：任取 α > 1，令 Sₙ = 1 + 1/2ᵅ + 1/3ᵅ + ⋯ + 1/nᵅ。它显然递增，问题是有没有屋顶。诀窍是自相似——把 S₂ₙ 拆成偶数项和奇数项：

偶数部分：Σₖ₌₁ⁿ 1/(2k)ᵅ = Sₙ/2ᵅ，正是整体的缩小版。

奇数部分：1 + Σₖ₌₁ⁿ⁻¹ 1/(2k+1)ᵅ < 1 + Σₖ₌₁ⁿ⁻¹ 1/(2k)ᵅ ≤ 1 + Sₙ/2ᵅ，因为第一项之外，每个奇数项都小于它前面的偶数项。

相加：S₂ₙ < 1 + 2·Sₙ/2ᵅ = 1 + Sₙ/2ᵅ⁻¹。部分和递增，所以 Sₙ < S₂ₙ < 1 + Sₙ/2ᵅ⁻¹。

因为 1 − 2¹⁻ᵅ > 0，得到 Sₙ < 1/(1 − 2¹⁻ᵅ)。递增而且有界，所以对每个 α > 1，部分和都收敛——存在性一举证明，用不着求出和的公式。（α = 2 时屋顶是 2。）

当 α → 1，2¹⁻ᵅ → 1，屋顶就塌了；α = 1 时是否收敛，两集后用柯西准则解决。

应用四 · 根式瀑布与连分数

√(2 + √(2 + √(2 + ⋯))) 唯一的含义是计算器数列的 lim aₙ，而定理已经确定这个极限是 2。

连分数 1 + 1/(1 + 1/(1 + ⋯)) 是 lim bₙ，其中 b₁ = 1, bₙ₊₁ = 1 + 1/bₙ：1，2，1.5，1.667，1.6，1.625，……——不单调。但奇数项上升、偶数项下降，而且都在 [1, 2] 内，所以各自收敛；两个极限都满足 L = 1 + L/(1 + L)，也就是 L² − L − 1 = 0，所以都等于黄金比 φ = (1 + √5)/2 ≈ 1.618。

自测

1. 在证明中（递增，s = sup aₙ），为什么存在某一项 aₘ > s − ε？

A. s − ε 比最小上界还小，所以它不是上界B. 因为已经知道 aₙ → sC. 因为数列有下界

答案：A。s 是最小上界，而 s − ε < s，所以 s − ε 挡不住某一项，这一项就是 aₘ。

2. 对 1，1.4，1.414，1.4142，……，为什么证明在有理数里根本无法起步？

A. 在有理数里这些项没有最小上界B. 在有理数里这个数列连上界都找不到C. 这些项都不是有理数

答案：A。2 是有理数上界，但每个有理数上界都大于 √2，中间总能塞进更小的有理数，所以找不到最小的——而证明需要的正是 s = sup aₙ。

3. 是什么让 (1 + 1/n)ⁿ 收敛，从而 e 有定义？

A. 它递增（二项式图景），而且以 3 为上界B. 它的底数趋于 1C. 它递减，而且以 2 为下界

答案：A。单调有界：二项式的每一项随 n 增大而变大，项数也在增加；总和始终小于 1 + 1 + 1/2 + 1/4 + ⋯ = 3。

4. 用三步法处理 aₙ₊₁ = f(aₙ) 时，什么时候才能确信 L = f(L) 的根就是极限？

A. 一解出 L = f(L) 就可以B. 证明数列单调有界之后C. 算出前三项之后

答案：B。只有单调有界才保证极限存在；之后取极限，才说明它满足 L = f(L)。

5. a₁ = 1，aₙ₊₁ = 2aₙ。解 L = 2L 得到 L = 0。哪项正确？

A. aₙ → 0B. aₙ → ∞，L = 0 并不是极限C. aₙ → 1

答案：B。aₙ = 2ⁿ⁻¹ → ∞；方程 L = f(L) 本身并不涉及极限是否存在，先用它就是循环论证。

6. 对 aₙ₊₁ = aₙ²，取 a₁ = 0.5，数列会……

A. 递减趋于 0B. 收敛到 1C. 递增趋于 ∞

答案：A。起点在 (0, 1) 内，平方使每一项变小；递减而且以 0 为下界，所以趋于 0。

数列的柯西收敛准则

不说出极限，也能判定收敛：看队形，别看记分牌。

第一幕 · 动机

什么时候可以停？

在计算器上按 cos，然后一次又一次地按。显示屏上的数字来回摆动——1, 0.5403, 0.8576, 0.6543, …——然后稳定下来：0.7390, 0.7391, 0.7391, … 作业要求这个数精确到三位小数。

cos ▸ 0.7391

没有人告诉你极限是多少，它也没有封闭公式。那么：什么时候可以停下来，只凭已经算出的项，保证自己足够接近？

第一反应：第三位小数不再变化就停。这算证明吗？先记住这个问题——第三幕会给出一个恰好骗过这一招的数列。

缺的是一种完全不提极限的收敛判别法。这就是柯西收敛准则。

第二幕 · 定理说了什么

定理（柯西收敛准则）

{aₙ} converges ⇔ for every ε > 0 there exists N such that |aₙ − aₘ| < ε for all m, n > N.

即：{aₙ} 收敛 ⇔ 对每个 ε > 0，存在 N，使得对所有 m, n > N 都有 |aₙ − aₘ| < ε。满足右边条件的数列称为柯西列。在 ℝ 中两边等价，所以柯西收敛准则既能判定收敛，也能判定发散。

逐条配图

① 对每个 ε > 0——任你指定多小的容差。

② 存在 N——过了某个下标，前面的混乱不再重要。

③ 对所有 m, n > N 有 |aₙ − aₘ| < ε——N 之后的所有项都挤在一个宽度为 ε 的团块里：任意两项都是，不只相邻项。团块是围着各项本身画出来的，没有提到任何极限。

内部自查

ε–N 定义

∀ε > 0 ∃N : n > N ⇒ |aₙ − A| < ε

需要先有一个候选极限 A（记分牌上的值），才能开始检验。

柯西收敛准则

∀ε > 0 ∃N : m, n > N ⇒ |aₙ − aₘ| < ε

完全不需要目标值：在 N 之后打开一个尾部窗口，测量窗口内每一对项的距离。若所有距离都小于 ε，这个数列就是柯西列。

看队形，别看记分牌：这是一次内部自查，各项之间互相比对。

为什么在 ℝ 中这就够了

团块未必有中心，所以挤成一团看起来比收敛弱——在 ℚ 中它确实更弱：√2 的小数截断 1, 1.4, 1.41, 1.414, … 构成一个柯西列（第 k 项之后所有距离都小于 10⁻ᵏ），但在 ℚ 中它无处可收敛：有理数轴在 √2 处有一个洞。实数没有洞——每个柯西列都有极限。这就是完备性，也是这条定理的真正内涵。

第三幕 · 证明

方向一：收敛 ⇒ 柯西列

|aₙ − aₘ| ≤ |aₙ − A| + |A − aₘ| < ε/2 + ε/2 = ε

若 aₙ → A，则过了某个 N，每一项与 A 的距离都小于 ε/2。绕道 A：两段距离各不到 ε/2，所以 |aₙ − aₘ| ≤ |aₙ − A| + |A − aₘ| < ε/2 + ε/2 = ε。这个方向用到了极限；另一个方向才是深刻的。

方向二：柯西列 ⇒ 收敛

  1. 第一步——有界。取 ε = 1：整个尾部都离尾部第一项不到 1，前面有限多项也跑不掉。
  2. 第二步——存在收敛子列（上一集：有界数列必有收敛子列，波尔查诺–魏尔斯特拉斯定理）。记其极限为 L。
  3. 第三步——整个数列跟着收敛。对 n > N 取子列下标 nₖ > N：|aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε。
柯西列⇒有界⇒有收敛子列⇒收敛

第二步出大力的是完备性。顺带一提：柯西列的每个子列也是柯西列，因为它的项对本来就是尾部的项对。

热身 · 写出一次柯西列验证

断言：部分和 sₙ = 1 + 1/2 + 1/4 + … + 1/2ⁿ 构成柯西列。

拆开尾部。 n > m:   sₙ − sₘ = nΣk = m+112ᵏ = 12ᵐ⁺¹ + … + 12ⁿ

每一块都是剩余长度的一半，所以各块裂项相消：

12ᵏ = 12ᵏ⁻¹ − 12ᵏ,   (12ᵐ − 12ᵐ⁺¹) + (12ᵐ⁺¹ − 12ᵐ⁺²) + … + (12ⁿ⁻¹ − 12ⁿ) = 12ᵐ − 12ⁿ < 12ᵐ

证明

任给 ε > 0，取 N 使 1/2ᴺ < ε。

对 n > m > N：|sₙ − sₘ| = 1/2ᵐ − 1/2ⁿ < 1/2ᵐ < 1/2ᴺ < ε。

没有提到任何极限值，收敛却已得到证明。∎

裂项相消的尾部（m = 3，n = 7）

阅读策略

柯西列的验证总是同一个套路：把 |aₙ − aₘ| 写成尾部和，用一个只依赖 m 的量（这里是 1/2ᵐ）来控制尾部，再取 N 使这个界小于 ε。

相邻项陷阱

|aₙ₊₁ − aₙ| → 0 能推出 {aₙ} 是柯西列吗？ 不能。

调和级数的部分和 sₙ = 1 + 1/2 + … + 1/n

|s₂ₙ − sₙ| = 1n+1 + … + 12n ≥ n · 12n = 12

每一步 sₙ₊₁ − sₙ = 1/(n+1) → 0，但比较 sₙ 和 s₂ₙ：中间共 n 项，每项至少 1/(2n)，所以永远有 |s₂ₙ − sₙ| ≥ n · 1/(2n) = 1/2。远处的项对从不靠近。

第二个例子：aₙ = √n

相邻差 √(n+1) − √n = 1/(√(n+1) + √n) → 0，但 √n → ∞，数列发散。

教训：要控制尾部所有的项对，而不只是相邻项。

非柯西列 = 发散凭证

准则的否定式是一个量词阶梯：

∃ ε₀ > 0
⇓
∀ N
⇓
∃ m, n > N : |aₙ − aₘ| ≥ ε₀

读法：存在一个 ε₀，使得无论多远，总有一对项相差至少 ε₀。赛跑故事里的检查员现在改为测量尾部窗口内的项对——对每个 N，只需找到一对不合格的就够了。

调和级数部分和的发散凭证

ε₀ = 12,   m = N + 1,   n = 2m  ⇒  |sₙ − sₘ| ≥ 12

取 ε₀ = 1/2。对任意 N，令 m = N + 1，n = 2m，则 |sₙ − sₘ| ≥ 1/2，所以 {sₙ} 不是柯西列，从而发散——全程不必谈论极限值。

第四幕 · 应用与展望

应用一 · 级数的部分和

对级数 Σaₖ，数列是 sₙ = a₁ + … + aₙ，所以 sₙ − sₘ = aₘ₊₁ + … + aₙ 是一段连续的项。准则变成：

Σaₖ 收敛 ⇔ 对每个 ε > 0，存在 N，使得对所有 n > m > N 有 |aₘ₊₁ + … + aₙ| < ε。

取 n = m + 1：收敛级数必有 aₙ → 0——但反之不然（调和级数）。要控制的是整段，而不是单项。

调和级数这个反例

Hₙ = 1 + 1/2 + … + 1/n。它的步长趋于零：Hₙ₊₁ − Hₙ = 1/(n+1) → 0。但 H₂ₙ − Hₙ = 1/(n+1) + … + 1/(2n) 是 n 项之和，每项至少 1/(2n)，所以对每个 n 都有 H₂ₙ − Hₙ ≥ 1/2。取 ε = 1/2，柯西条件失效，Hₙ 发散。步长趋于零并不等于收敛：步子越来越短，也可能永远走不到。

H₂ₙ − Hₙ = 1n+1 + … + 12n ≥ n · 12n = 12

前面证明过：对每个 α > 1，1 + 1/2ᵅ + … + 1/nᵅ 收敛，而在 α = 1 时屋顶论证失效。答案在此：α = 1 时级数发散。

再看一个收敛的例子：Σ 1/k²。当 k ≥ 2 时 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k，于是一段连续项裂项相消：对 n > m，|sₙ − sₘ| = Σₖ₌ₘ₊₁ⁿ 1/k² < 1/m − 1/n < 1/m。算到 m 项后，累计和与级数和相差不到 1/m——不管这个和是多少。机器可用：要保证误差小于 0.0005，取 m = 2000：s₂₀₀₀ = 1.64443…

这个和确有著名的精确值 π²/6——但上面的保证从未用到它：即使存在封闭形式，准则也无需借助它就能保证误差。

应用二 · 算法的停止准则

回到计算器：xₙ₊₁ = cos xₙ，步长 dₙ = |xₙ − xₙ₋₁|。单凭步长小证明不了什么——想想 Hₙ。但这里每一步至多是上一步的 q = sin 1 ≈ 0.84 倍，因为在 [cos 1, 1] 上 |cos u − cos v| ≤ sin 1 · |u − v|（中值定理）。

于是尾部是几何级数：|xₘ − xₙ| ≤ dₙ(q + q² + …) = dₙ · q/(1−q)。这正是柯西条件，所以迭代收敛到某个 x*；令 m → ∞ 得 |x* − xₙ| ≤ q/(1−q) · dₙ < 5.31 dₙ（q/(1−q) = 5.3079…）。

和几何级数的热身是同一套逻辑：衰减率让相邻步长控制住了尾部所有项对。

展望

这条准则不是数列的小技巧——它说的是：实数没有洞。到第七章它加入等价环：确界原理、单调收敛定理、闭区间套定理、波尔查诺–魏尔斯特拉斯定理、柯西收敛准则。其中任何一条都可作为完备性公理，其余随之推出。

这条陈述还能走得更远。在平面上 |aₙ − aₘ| 变成两点间的距离；在 ℝⁿ 和任何度量空间里，同样的聚集条件都有意义：d(aₙ, aₘ) < ε。那里往往没有顺序、没有上确界，所以柯西条件是唯一可用的收敛概念。每个柯西列都收敛的空间叫完备空间——ℝ 是你遇到的第一个。

自测

1. 柯西收敛准则比较的是什么？

A. 每一项 aₙ 与候选极限 AB. 尾部内的项对 aₙ, aₘ（m, n > N）C. 每一项 aₙ 与 0
正确答案： B. 尾部内的项对 aₙ, aₘ（m, n > N） — 准则是一次内部自查：不需要目标值，只需要尾部内的两两距离。

2. 对 sₙ = 1 + 1/4 + … + 1/n² 及 n > m ≥ 1，由 1/k² < 1/(k−1) − 1/k（k ≥ 2）可得哪个尾部估计？

A. |sₙ − sₘ| < 1/mB. |sₙ − sₘ| < 1/m²C. |sₙ − sₘ| < 1/n
正确答案： A. |sₙ − sₘ| < 1/m — 从 k = m+1 到 n 求和，裂项相消得 1/m − 1/n，它小于 1/m；另外两个界在 n 很大时都会失效。

3. 设 |aₙ₊₁ − aₙ| → 0，下列哪个说法正确？

A. {aₙ} 一定是柯西列B. {aₙ} 一定收敛C. 都推不出——例如调和级数的部分和
正确答案： C. 都推不出——例如调和级数的部分和 — 每步 1/n → 0，但 |s₂ₙ − sₙ| ≥ 1/2：只控制了相邻项，没有控制尾部所有项对。

4. 哪个式子表示"{aₙ} 不是柯西列"？

A. ∀ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀C. ∃ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀
正确答案： B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀ — 否定要逐个交换量词：有一个坏的 ε₀，并且对每个 N 都仍有一对远处的项相差至少 ε₀。

5. 柯西列有一个子列收敛到 L，那么

A. 整个数列仍可能发散B. 整个数列收敛到 LC. 只有那个子列收敛
正确答案： B. 整个数列收敛到 L — 三角不等式：当 n 充分大时 |aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε。

6. 对 Hₙ = 1 + 1/2 + … + 1/n，哪个估计对每个 n ≥ 1 都成立？

A. H₂ₙ − Hₙ ≥ 1B. H₂ₙ − Hₙ ≥ 1/2C. H₂ₙ − Hₙ ≤ 1/(2n)
正确答案： B. H₂ₙ − Hₙ ≥ 1/2 — H₂ₙ − Hₙ 是 n 项之和，每项至少 1/(2n)，所以至少为 1/2（n = 1 时取等号，因此“≥ 1”不成立）。

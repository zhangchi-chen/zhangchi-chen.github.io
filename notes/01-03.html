第 1.3 集 · 前情：无限小数、稠密性

实数的完备性初识

本集刻意保持非形式化：只种下图景与术语；后续章节将证明下面列出的各种说法彼此等价。

1 · 有理数的“洞”

在 ℚ 中取下面的集合。它有上界（2 是上界，1.5 也是）。从两侧追捕它的最小上界。

S = {x ∈ ℚ : x² < 2}

从下方（属于 S）

11² = 1 < 2
1.41.4² = 1.96 < 2
1.411.41² = 1.9881 < 2
1.4141.414² = 1.999396 < 2

从上方（都是上界）

22² = 4 > 2
1.51.5² = 2.25 > 2
1.421.42² = 2.0164 > 2
1.4151.415² = 2.002225 > 2

若有理数 q 太小（q² < 2），S 中总有元素在它上方——所以 q 不是上界。

若有理数 q 是 S 的上界（q² > 2），更小的有理数仍是上界——所以 ℚ 中没有最小上界。

两路猎手向 √2 夹紧，而 √2 ∉ ℚ（此处直接采用，不证明）。在 ℚ 里，猎手追的是幽灵：有界却没有有理的上确界——这就是一个“洞”。

2 · 完备性的三句口号

i · 对极限封闭

对“取极限”和“逼近”封闭：收敛的追捕终点必是实数。

ii · 没有洞

数轴是一个连续统。

iii · 包含 ℚ 的最小者

ℝ 是包含 ℚ 且具备这些性质的最小集合：逼近需要什么就补什么，不多也不少。

3 · 种子：无限小数的语言

对 a = 1.41421356…，下截断 aₙ（保留小数点后 n 位）与上截断 aₙ + 10⁻ⁿ 在每个精度下都夹住 a。这些区间层层嵌套，长度 10⁻ⁿ → 0。

an ≤ a ≤ an + 10−n
种子（本课程直接接受）

每个无限小数都是一个实数，每个实数也都是一个无限小数。

这本身已是一条乔装的完备性命题；本课程由它生长出其余一切。

5 · 为什么重要

第一集的承诺（介值定理）：f 在 [a, b] 上连续且 f(a) < 0 < f(b)，则 f 必穿过零。二分法无限次对半；完备性保证这场追捕收敛到一个真实的数。例：f(x) = x² − 2，区间 [1, 2]。

零点 √2 = 1.41421356… 存在于 ℝ 中，它的无限小数正是二分法逐位算出的。没有完备性（在 ℚ 中），算法只是在追幽灵。

6 · 小结

稠密性

每个窗口都会被击中。

完备性

每场正当的追捕都有终点。

下一集：如何给追捕的目标命名——上确界 sup S。

自测

先在心里选定答案，再点击查看。

下列哪个有界有理数集在 ℚ 中没有上确界？
  1. A{x ∈ ℚ : x ≤ 2}
  2. B{x ∈ ℚ : x² < 2}
  3. C{x ∈ ℚ : 0 < x < 1}
答案: B. 它的最小上界本应是 √2，而 √2 不是有理数；另两个的上确界 2 和 1 都在 ℚ 中。
哪一条承诺属于完备性，而不是稠密性？
  1. A每个窗口 (a, b)（a < b）都含有理数。
  2. B长度 → 0 的闭区间套收拢于一个实数。
  3. C两个有理数之间总有另一个有理数。
答案: B. A 与 C 是稠密性的承诺（ℚ 也满足，却仍有洞）；只有 B 说每场正当的追捕都有终点。
若有理数 q > 0 且 q² > 2，对 S = {x ∈ ℚ : x² < 2} 可得什么？
  1. Aq 是 S 的最小上界。
  2. B存在更小的有理数仍是 S 的上界。
  3. Cq 属于 S。
答案: B. 上方猎手总能再缩小一点而仍是上界，所以 ℚ 中没有最小上界。
本课程接受的“种子”是什么？
  1. A每个无限小数都是实数，每个实数也都是无限小数。
  2. B每个实数都是有理数。
  3. C每个有理柯西列都有有理极限。
答案: A. 种子就是用无限小数刻画 ℝ；它本身已是一条乔装的完备性命题。
下列哪一条不在本集列出的五种完备性说法之中？
  1. A单调有界数列必收敛。
  2. B每个有界数列都是单调的。
  3. C柯西列必收敛。
答案: B. 该命题本身就是错的（如 (−1)ⁿ）；五种说法是戴德金分割、闭区间套、单调有界、柯西列与确界原理。
对 f(x) = x² − 2 在 [1, 2] 上二分，完备性保证了什么？
  1. A算法在有限步后停止。
  2. B区间套收拢于一个真实的实数 √2。
  3. C中点的极限是有理数。
答案: B. 追捕永不停止，但终点是 ℝ 中的一个点：零点 √2 存在，二分法逐位算出它的小数。

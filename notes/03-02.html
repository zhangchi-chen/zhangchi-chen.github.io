极限过程与单侧极限

六种极限过程，一副骨架；无穷极限；交界点从两侧判定。

1 · 一张表，六种极限过程

ε–δ 骨架冻结不动，只换一个空格——逼近集合，以及它自带的尺度（δ 或 M）。

limx → ⋯ f(x) = A  ⟺  ∀ε > 0, ∃ δ / M > 0 : 逼近集合 ⇒ |f(x) − A| < ε
极限过程空格：逼近集合尺度图像
x → x₀0 < |x − x₀| < δδ
x → x₀⁺0 < x − x₀ < δδ
x → x₀⁻−δ < x − x₀ < 0δ
x → +∞x > MM
x → −∞x < −MM
x → ∞|x| > MM

第 2、3 行：左极限与右极限（单侧极限）

任何极限过程都不靠背：抄骨架，换空格。

2 · 符号陷阱：x → ∞ 与 x → +∞

不带符号的 ∞ 没有方向：|x| > M 要求两条射线同时成立。

错误： limx → ∞ arctan x = π/2 ✗

右射线 → π/2，左射线 → −π/2：两个答案，所以 x → ∞ 时极限不存在。

正确的单向写法：
limx → +∞ arctan x = π/2 ✓
limx → −∞ arctan x = −π/2 ✓

3 · 无穷极限

同一副骨架，这次换结论的空：|f(x) − A| < ε 换成 f(x) > G。

limx → x₀ f(x) = +∞ 的含义：任给 G > 0，存在 δ > 0，使得
0 < |x − x₀| < δ ⇒ f(x) > G

limx → 0 1/x² = +∞

其他结论空格：

f(x) < −G → −∞  ·  |f(x)| > G → ∞

关键：这不算极限存在。极限的定义要求 A 是实数，而 +∞ ∉ ℝ——极限是数（完备性一集的承诺）。“发散到 +∞”是一种有头衔的发散。

4 · 单侧 = 半个去心邻域

单侧极限：同样的检查，只在半个去心邻域上进行。

5 · 交界点的判定

在交界点（如分段函数的接缝处），两条路各交一份报告。该点的函数值 f(x₀) 从来不问。

左极限 L  ·  右极限 R
两侧都存在且相等（= A）⟺ 极限存在，等于 A
两侧有限但 L ≠ R⇒ 跳跃：无极限
某一侧为无穷⇒ 发散：无极限

limx → x₀ f(x) = A  ⟺  limx → x₀⁻ f(x) = limx → x₀⁺ f(x) = A

6 · 经典三例（考试常客）

一个配方，三位被告：查左，查右，比较。

e1/x

arctan(1/x)

|x|/x

函数（在 0 处）左 x → 0⁻右 x → 0⁺判决
e1/x0+∞无极限——右侧发散到 +∞
arctan(1/x)−π/2π/2无极限——跳跃高度 π（主值区间两端）
|x|/x−11无极限——符号不一致，跳跃 2

7 · 回顾

  1. 六种极限过程，一副骨架：只换空格。
  2. 极限为 ±∞ 或 ∞：有头衔的发散，不算极限存在。
  3. 交界点要从两侧来判。

自测

先选答案，再揭晓。

1. lim(x→0⁺) e1/x = ?
A. 0 B. 1 C. +∞
答案: C. x → 0⁺ 时 1/x → +∞，所以 e1/x → +∞。
2. lim(x→0⁻) arctan(1/x) = ?
A. π/2 B. −π/2 C. 0
答案: B. x → 0⁻ 时 1/x → −∞，arctan 沉向主值区间 (−π/2, π/2) 的下端。
3. lim(x→0⁻) |x|/x = ?
A. 1 B. −1 C. 不存在
答案: B. x < 0 时 |x| = −x，故 |x|/x 恒等于 −1。
4. lim(x→0) 1/x² = +∞ 说明该极限……
A. 存在且等于 +∞ B. 不存在：f 发散到 +∞ C. 存在，因为两侧一致
答案: B. 定义要求 A 是实数，+∞ 不是实数：这是有头衔的发散。
5. x → ∞（不带符号）对应哪个空格？
A. x > M B. |x| > M C. 0 < |x − x₀| < δ
答案: B. 光秃秃的 ∞ 没有方向，两条射线都要：|x| > M。
6. 左极限为 2，右极限为 2，f(x₀) = 5，则 lim(x→x₀) f(x)……
A. 等于 2 B. 等于 5 C. 不存在
答案: A. 两侧极限存在且相等；该点的函数值从来不问。

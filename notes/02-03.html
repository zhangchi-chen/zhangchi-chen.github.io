极限的四则运算

数列极限 · 和、差、积、商
定理若 an→a，bn→b，则 an±bn→a±b，anbn→ab；当 b≠0 时，anbn→ab。

① 一个机制，四条法则

写成 an=a+αn，bn=b+βn，其中 αn,βn→0。一切都是常数 + 无穷小。

  • an±bn=(a±b)+(αn±βn) —— 偏差只是相加。
  • anbn=ab+(aβn+bαn+αnβn) —— αnβn 是噪声乘噪声：二阶小量。
  • 商：先控制 1bn。

② 为什么 b ≠ 0 是真正的墙

护城河（复用保号性）：因 b≠0，最终 |bn|≥|b|2。于是 1bn−1b=b−bnbnb，且 |bnb|≥|b|22。

分母极限为 0 时，什么结果都可能出现（0/0 型预告）：

1/n1/n2=n→∞1/n21/n=1n→0(−1)n/n1/n=(−1)n 发散

③ 法则只指向一个方向

收敛 + 收敛 ⇒ 收敛。反之不成立：(−1)n 与 (−1)n+1 都发散，它们的和却恒为 0。

法则是计算极限的凭证，而不是判断收敛的检验。

④ 把证明读成误差预算

|anbn−ab|≤|a||βn|+|b||αn|+|αn||βn|

每个误差来源分得 ε/3；每个要求在各自的 Ni 之后成立；取 N=max(N1,N2,N3)。|b|+1 之类的常数只为记账整洁：ε2(|b|+1) 是记账，不是魔法。

⑤ 只限有限次运算

对任意多项式 P：P(an)→P(a)。无穷多次运算是另一个世界：1n+1n+⋯+1n=1（共 n 项），而不是 0，尽管每项都 →0。

0/0、∞ − ∞ 需要新工具——夹逼（下集）。

自测 · 检验一下

1. 写 aₙ = a + αₙ、bₙ = b + βₙ（αₙ, βₙ → 0），乘积展开后的"二阶噪声"项是（　）

A. aβₙ　　B. bαₙ　　C. αₙβₙ

C。噪声 × 噪声是更高阶的小量，衰减得比 αₙ、βₙ 都快——这正是"常数 + 无穷小"机制能穿透乘法的原因。

2. 当分母极限 b = 0 时，商 aₙ/bₙ 的极限（　）

A. 一定不存在　　B. 一定存在　　C. 三种结局都可能

C。(1/n)/(1/n²) = n → ∞；(1/n²)/(1/n) → 0；((−1)ⁿ/n)/(1/n) 发散——什么都可能发生，所以商法则无法挽救。

3. 护城河论证：b ≠ 0 时，最终必有 |bₙ| ≥（　）

A. |b|　　B. |b|/2　　C. 2|b|

B。从某项起 bₙ 落在 b 的 |b|/2 带内，离 0 只会更远——1/bₙ 因此有界，除法安全。

4. (−1)ⁿ 与 (−1)ⁿ⁺¹ 都发散，其和恒为 0。这说明（　）

A. 发散 + 发散必发散　　B. 法则是单向的　　C. 法则有错

B。收敛 + 收敛 ⇒ 收敛成立，但反向不成立。法则是计算的凭证，不是判断收敛的工具。

5. 误差预算 |aₙbₙ − ab| ≤ |a||βₙ| + |b||αₙ| + |αₙ||βₙ| 中按 ε/3 分配，是为了（　）

A. 每个误差源各自领额度　　B. 让 N 更小　　C. 消掉交叉项

A。三个误差源各分一份 ε，各自找到自己的 N，最后取最大——证明是记账，不是魔法。

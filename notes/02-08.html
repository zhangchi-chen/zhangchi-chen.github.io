无穷大的比阶：增长阶梯

02-08 · 比较 ln n、n、nᵏ、aⁿ (a > 1)、n!、nⁿ 的无穷大的阶

ln n ≪ n ≪ nk ≪ an ≪ n! ≪ nn

k ≥ 1 固定 · a > 1

?为什么要关心？

课堂之外，为什么有人要关心 n log n、n²、2ⁿ 谁更大？因为它们正是常见算法的步数：给一个列表排序约需 n log n 步，检查所有数对需要 n² 步，枚举所有子集需要 2ⁿ 步。

n = 10 时步数分别是 33、100、1024，看不出差别。n = 100 时，在每秒 10⁹ 步的机器上，排序需 0.7 µs，检查数对需 10 µs，而 2100 ≈ 1.3 × 1030 步需要 4 × 1013 年，约为宇宙年龄的 2900 倍。n = 106 时：0.02 秒、约 17 分钟，以及一个有 301 030 位数字的步数。

同一任务，不同的增长速度：今天就能完成，还是要熬过宇宙的寿命。所以“长得多快”需要一件测量仪器，而不是凭感觉。这件仪器就是下面的阶梯。

六级阶梯

xn ≪ yn 表示 xn/yn → 0：yn 是更高阶的无穷大。从底部读起：对数在爬，幂在走，指数在跑，阶乘在冲刺，而 nn 把它们全甩在身后。

每一级都有小字条款：k ≥ 1 固定，a > 1。图中把六个数列画在对数刻度的“墙”上（k = 2，a = 3）：n = 12 处的高度已经排成一座楼梯。

1第一级 · ln n ≪ n

工具：当 x > −1 时 ln(1 + x) ≤ x（ln(1+x) 的图像位于切线 y = x 下方）。

裂项求和：ln(n+1) = Σk=1n [ln(k+1) − ln k] = Σk=1n ln(1 + 1/k) ≤ Σk=1n 1/k ≤ n。ln 每涨一点，都用一整个单位来支付。

比值 ≤ 1 只说明有界，还不是 ≪。把同一工具用到 √n 上：ln √n ≤ √n − 1，于是 ln n = 2 ln √n ≤ 2(√n − 1)，故 ln n / n ≤ 2/√n → 0。

2–3第二、三级 · n ≪ nk ≪ an（a > 1）

第二级很直接：k > 1 时 n / nk = n1−k → 0。

第三级是“二项式击倒”：令 a = 1 + b，b > 0。则 (1+b)n = Σj=0n C(n, j) bj，每一项都为正，只保留一项便得 an ≥ C(n, k+1) · bk+1。

例：k = 2，a = 1.5（b = ½）。单独一项 C(n,3)·b³ 在 n = 51 处超过 n²，而完整的和 1.5ⁿ 早已冲出图外。

当 n ≥ 2k 时，C(n, k+1) = n(n−1)⋯(n−k)/(k+1)! 的每个因子都不小于 n/2，所以 an ≥ (nb/2)k+1/(k+1)! = c · nk+1，其中 c = (b/2)k+1/(k+1)! > 0。因此 an/nk ≥ c · n → ∞：一项就足以击倒整个幂，其余各项只是锦上添花。

4第四级 · an ≪ n!

把比值写成因子的乘积：an/n! = (a/1)(a/2)(a/3)⋯(a/n)。开头几个因子可能大于 1，乘积甚至会先增长一阵；但只要 n > 2a，每个新因子 a/n 都小于 ½。

正式地，取 N = ⌊2a⌋，当 n > N 时：an/n! = (aN/N!) · (a/(N+1)) ⋯ (a/n) ≤ (aN/N!) · (1/2)n−N → 0。单调的比值被等比数列夹住，这就是“减半接力”。

5第五级 · n! ≪ nn

n! = 1 · 2 · ⋯ · n，每个因子都不超过 n，所以 n!/nn = (1/n)(2/n)⋯(n/n) ≤ 1/n → 0。虽然平凡，却补全了阶梯。

悬而未决：n! 比 an 大多少？我们只知道 n!/an → ∞；定量的差距（Stirling 公式的领地）留待日后。

!小字条款：a > 1，k 固定

a = 1 时 an = 1 恒定不变；0 < a < 1 时 an → 0，毫无指数威力。若让 k 随 n 变，比如 k = n，nk 就变成了阶梯顶端的 nn。

数值演示：1.01n 终将胜过 n100。n = 104 时 n100 = 10400，而 1.01n ≈ 1043：幂领先 357 位数字。直到 n ≈ 1.17 × 105 才反超，那时两边都已有 507 位数字。

阶梯只说最终谁赢，不说交叉点在哪里。切勿不看条件 a > 1、k 固定，就机械套用“指数总是胜过幂”。

→阶梯的用武之地

级数的比较判别。若最终有 0 ≤ xn ≤ yn 且 Σ yn 收敛，则 Σ xn 收敛；各项缩小得“多快”正由阶梯来衡量。例如：由 n² ≪ 1.5n，当 n ≥ 13 时 n² ≤ 1.5n，于是 n²/2n ≤ (3/4)n，与等比级数比较可知 Σ n²/2n 收敛。反过来，由 ln n ≤ n 得 n ≥ 2 时 1/ln n ≥ 1/n，所以 Σ 1/ln n 与调和级数一样发散。

极限一眼可判。任意两级之比立刻可定：n50/1.01n → 0，因为 nk ≪ an；100n/n! → 0，因为 an ≪ n!；n!/nn → 0，因为 n! ≪ nn。

大 O 复杂度类。在计算机科学中，各级就是复杂度类 O(log n)、O(n)、O(n log n)、O(n²)、O(2n)、O(n!)——开头的例子在阶梯上一读即知。

展望：n! 到底胜多少？阶梯只说 n!/an → ∞。Stirling 公式 n! ≈ √(2πn) · (n/e)n 给出大小：n!/an ≈ √(2πn) · (n/(ea))n。阶梯回答“多快”，Stirling 回答“多少”——下一集见。

自测

  1. 下面哪条链是正确的增长阶梯（k ≥ 1 固定，a > 1）？
    A. n! ≪ aⁿ ≪ nᵏ ≪ nⁿB. ln n ≪ n ≪ nᵏ ≪ aⁿ ≪ n! ≪ nⁿC. ln n ≪ aⁿ ≪ nᵏ ≪ n! ≪ nⁿ
    答案 B.对数、幂、指数、阶乘、nⁿ 依次排列，相邻两项之比都趋于 0。
  2. 证明 ln n ≪ n 时，为 ln 的每次增量“付账”的是哪个不等式？
    A. ln(1 + x) ≤ xB. 二项式定理C. 均值不等式
    答案 A.ln(1 + 1/k) ≤ 1/k ≤ 1，所以 ln(n+1) = Σ ln(1 + 1/k) ≤ n；再把同一工具用到 √n 上得 ln n ≤ 2√n。
  3. 为什么二项展开中只留一项就能击倒 nᵏ？
    A. 因为 C(n, k+1) = 2ⁿB. 因为 (1+b)ⁿ 各项都为正，而 C(n, k+1)bᵏ⁺¹ 的增长是常数乘以 nᵏ⁺¹C. 因为必须有 b > 1
    答案 B.丢掉正项只会让和变小，而保留的那一项 ≥ c·nᵏ⁺¹，比 nᵏ 多出一个 n 的因子。
  4. 在 aⁿ/n! = (a/1)(a/2)⋯(a/n) 中，从哪里开始每个新因子都小于 ½？
    A. 从 n = 1 开始B. n > a 之后C. n > 2a 之后
    答案 C.a/n < ½ 当且仅当 n > 2a；此后乘积每步至少减半，趋于 0。
  5. 1.01ⁿ 与 n¹⁰⁰ 比较，哪种说法正确？
    A. 1.01 太接近 1，n¹⁰⁰ 永远更大B. 从 n = 100 起 1.01ⁿ 就更大C. 1.01ⁿ 终将胜出，但要到 n ≈ 10⁵ 之后
    答案 C.a = 1.01 > 1 且 k = 100 固定，所以指数最终获胜；交叉点约在 n ≈ 1.17×10⁵，那时两边都有 507 位数字。
  6. 下面哪种取法会破坏 nᵏ ≪ aⁿ 这一级？
    A. a = 1.0001B. k = 50C. a = 1
    答案 C.a = 1 时“指数”是常数 1；任何 a > 1，哪怕再接近 1，对固定的 k 都终将胜出。

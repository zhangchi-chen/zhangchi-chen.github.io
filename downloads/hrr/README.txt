Python verification for Nakano-positive determinants outside the Hodge-Riemann cone

verify_unrestricted.py: Section 3 seed case, n=4 and k=2.
verify_sd.py: Section 5 SD seed case, n=6 and k=2.
Both files also retain supplementary exact rank-extension checks.

Requires Python 3 and SymPy. Run python3 filename.py.
Alternatively paste a complete file into https://sagecell.sagemath.org/
and select Python. Each file ends with ALL CHECKS PASSED.
The general extension arguments are proved in the paper.

Analysis Proof & Manuscript Refinement

A public standalone Codex skill for auditing mathematical-analysis proofs and proof-centered manuscripts

Download ZIP Review source MIT License Markdown tutorial

What it does

It audits existing proofs for correctness, missing hypotheses, and dependencies; reorganizes theorem and section structure; aligns notation; and checks LaTeX structure and cross-references. It does not replace author verification or a formal proof assistant.

One-prompt installation in Codex desktop

Paste the following into a new Codex task:

Use $skill-installer to install the skill from this GitHub directory:
https://github.com/zhangchi-chen/zhangchi-chen.github.io/tree/analysis-proof-manuscript-refinement-v0.1.0/skills/analysis-proof-manuscript-refinement

Do not modify or overwrite any existing skill. If the destination already exists, stop and report it. After installation, confirm the skill name and actual install location, and tell me it should be available on the next turn. If it is still missing on the next turn, then suggest restarting Codex.

Codex may request permission to download from GitHub and write to the user skill directory. Verify the repository owner, version tag, and destination before approving. Invoke the skill explicitly in the next message after installation:

Use $analysis-proof-manuscript-refinement to audit the attached proof. Prioritize correctness issues and missing hypotheses, return findings in severity order, and do not edit files yet.

Manual installation

  1. Download and extract the ZIP.
  2. Place the complete folder in $HOME/.agents/skills/ on macOS/Linux, or $HOME\.agents\skills\ in Windows PowerShell.
  3. Restart Codex if it is not detected automatically.

Manual installation follows the current official user-level location. $skill-installer may use a managed location that varies by Codex version; rely on the actual path it reports.

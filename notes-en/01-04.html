Suprema & Infima

Episode 1.4 · from picture to proof

1 · Upper bounds and the least one

M is an upper bound of S if s ≤ M for every s ∈ S. The upper bounds form a set of their own; its least element is the supremum, sup S. Picture a lid lowered over the points: it stops at first contact. The supremum may lie inside the set or outside it — contact is all.

2 · The two-point template

β = sup S means:
(i) s ≤ β for every s ∈ S (β is an upper bound)
(ii) for every ε > 0 there exists s ∈ S with s > β − ε (no smaller number is an upper bound)

Read (ii) as a probe: however thin an ε-window you slide under β, some point of S lands inside it.

Model proof: sup{1 − 1/n : n ∈ ℕ} = 1

Let S = {1 − 1/n : n ∈ ℕ}, where ℕ = {1, 2, 3, …}. Claim. sup S = 1.

(i) 1 is an upper bound. For any n ∈ ℕ we have 1/n > 0, so 1 − 1/n < 1; hence s ≤ 1 for every s ∈ S.

(ii) 1 is optimal. Let ε > 0 be given. By the Archimedean property, choose n ∈ ℕ with n > 1/ε. Then 1/n < ε, so 1 − 1/n > 1 − ε: an element of S exceeds 1 − ε.

Both conditions hold, so sup S = 1. ∎

These two sentences — upper bound, then optimality — are exactly what graders look for.

3 · Infimum by mirror

A floor rises to first contact. m = inf S means (i) s ≥ m for every s ∈ S, and (ii) for every ε > 0 there is s ∈ S with s < m + ε.

sup S = Minf S = m
(i)s ≤ M for all s ∈ Ss ≥ m for all s ∈ S
(ii)∀ε > 0 ∃s ∈ S: s > M − ε∀ε > 0 ∃s ∈ S: s < m + ε

4 · The function version

For f defined on D: sup f = sup{f(x) : x ∈ D}. Same template, now probing the heights of the graph. The supremum may be attained (a maximum) or only approached.

5 · Subadditivity

sup(f + g) ≤ sup f + sup g,    inf(f + g) ≥ inf f + inf gwhenever the right-hand sides make sense.

One line of algebra. For every x ∈ D, f(x) ≤ sup f and g(x) ≤ sup g, so (f + g)(x) ≤ sup f + sup g. Thus sup f + sup g is an upper bound of f + g, and the least upper bound can only be lower.

Strictness. If f peaks on the left and g on the right, the sum never sees both maxima at once.

Recap

  • Two sentences make a supremum proof: (i) upper bound, (ii) optimal.
  • The ε-probe checks optimality.
  • Sums obey a one-way bound: sup(f + g) ≤ sup f + sup g.

Self-check

1. A proof that M = sup S must contain which two points?

  1. A. M ∈ S, and M is an upper bound.
  2. B. M is an upper bound, and for every ε > 0 some s ∈ S has s > M − ε.
  3. C. M is the largest element of S, and s < M for all s ∈ S.
B — Sentence (i) shows M is an upper bound and sentence (ii) shows nothing smaller is one; M need not belong to S.

2. For S = {1 − 1/n : n ∈ ℕ} and a given ε > 0, which n beats the probe 1 − ε?

  1. A. Any n ∈ ℕ with n > 1/ε.
  2. B. Any n ∈ ℕ with n < 1/ε.
  3. C. Only n = 1.
A — If n > 1/ε then 1/n < ε, so 1 − 1/n > 1 − ε.

3. Which statement about S = {1 − 1/n : n ≥ 1} is true?

  1. A. sup S = 1 and 1 ∈ S.
  2. B. sup S = 1 and 1 ∉ S.
  3. C. S has no supremum because it never reaches 1.
B — The lid stops at 1 although no point equals 1: the supremum exists but is not a member.

4. For f(x) = 1 − 1/x on [1, ∞), which is correct?

  1. A. sup f = 1 and f attains it.
  2. B. sup f = 1 but f has no maximum.
  3. C. sup f does not exist.
B — The graph climbs toward 1 without ever reaching it, so 1 is the supremum of the values but not a value.

5. When can sup(f + g) ≤ sup f + sup g be strict?

  1. A. Never: it is always an equality.
  2. B. When f and g peak at different points, so the sum never sees both maxima at once.
  3. C. Only when f or g takes negative values.
B — For f = e−(x+1)² and g = e−(x−1)², sup(f + g) ≈ 1.02 while sup f + sup g = 2.

6. What is the infimum version of subadditivity?

  1. A. inf(f + g) ≤ inf f + inf g
  2. B. inf(f + g) ≥ inf f + inf g
  3. C. inf(f + g) = inf f + inf g always
B — It is the mirror image: f(x) ≥ inf f and g(x) ≥ inf g give a lower bound for f + g, so the inequality reverses.

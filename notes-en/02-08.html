02-08 · order of infinity: the six-rung ladder

ln n ≪ n ≪ nk ≪ an ≪ n! ≪ nn

k ≥ 1 fixed · a > 1

The ladder

xn ≪ yn means xn/yn → 0: yn is an infinity of higher order. Read the ladder from the bottom: logarithms crawl, powers walk, exponentials run, factorials sprint, and nn leaves even them behind.

Fine print on every rung: k ≥ 1 is fixed and a > 1. The picture shows the six sequences on a logarithmic wall (k = 2, a = 3): their heights at n = 12 already form a staircase.

1Rung 1 · ln n ≪ n

The tool: ln(1 + x) ≤ x for x > −1 (the graph of ln(1+x) lies below its tangent line y = x).

Telescope: ln(n+1) = Σk=1n [ln(k+1) − ln k] = Σk=1n ln(1 + 1/k) ≤ Σk=1n 1/k ≤ n. Every increment of ln is paid for by a full unit.

A ratio ≤ 1 is only bounded, not yet ≪. Aim the same tool at √n: ln √n ≤ √n − 1, so ln n = 2 ln √n ≤ 2(√n − 1), hence ln n / n ≤ 2/√n → 0.

2–3Rungs 2–3 · n ≪ nk ≪ an (a > 1)

Rung 2 is immediate: n / nk = n1−k → 0 for k > 1.

Rung 3, the binomial knockout: write a = 1 + b with b > 0. Then (1+b)n = Σj=0n C(n, j) bj and every term is positive, so keeping a single term gives an ≥ C(n, k+1) · bk+1.

Example k = 2, a = 1.5 (b = ½): the single term C(n,3)·b³ overtakes n² at n = 51, while the full sum 1.5ⁿ runs off the chart long before.

For n ≥ 2k each factor of C(n, k+1) = n(n−1)⋯(n−k)/(k+1)! is at least n/2, so an ≥ (nb/2)k+1/(k+1)! = c · nk+1 with c = (b/2)k+1/(k+1)! > 0. Therefore an/nk ≥ c · n → ∞: one highlighted term knocks out the whole power; the rest of the sum is a bonus.

4Rung 4 · an ≪ n!

Write the ratio as a product of factors: an/n! = (a/1)(a/2)(a/3)⋯(a/n). The first few factors may exceed 1, so the product can grow for a while — but once n > 2a every new factor a/n is below ½.

Formally, with N = ⌊2a⌋ and n > N: an/n! = (aN/N!) · (a/(N+1)) ⋯ (a/n) ≤ (aN/N!) · (1/2)n−N → 0. A monotone ratio squeezed by a geometric sequence: the halving relay.

5Rung 5 · n! ≪ nn

n! = 1 · 2 · ⋯ · n and each factor is at most n, so n!/nn = (1/n)(2/n)⋯(n/n) ≤ 1/n → 0. Trivial, yet it completes the ladder.

Left open: how much does n! beat an? We only know n!/an → ∞; the quantitative gap (Stirling’s territory) is for another day.

!Fine print: a > 1 and k fixed

With a = 1, an = 1 forever; with 0 < a < 1 it tends to 0 — no exponential power at all. Let k move with n, say k = n, and nk becomes nn, the top of the ladder.

Numeric demo: 1.01n does beat n100, eventually. At n = 104, n100 = 10400 while 1.01n ≈ 1043: the power leads by 357 digits. The lead flips only near n ≈ 1.17 × 105, where both numbers already have 507 digits.

The ladder says who wins in the end; it says nothing about where the crossover happens. Never pattern-match “exponentials always beat powers” without checking a > 1 and that k is fixed.

Self-check

  1. Which chain is the growth ladder (k ≥ 1 fixed, a > 1)?
    A. n! ≪ aⁿ ≪ nᵏ ≪ nⁿB. ln n ≪ n ≪ nᵏ ≪ aⁿ ≪ n! ≪ nⁿC. ln n ≪ aⁿ ≪ nᵏ ≪ n! ≪ nⁿ
    Answer B.Logarithms, powers, exponentials, factorials, nⁿ — each adjacent ratio tends to 0.
  2. In the proof of ln n ≪ n, which inequality pays for each increment of ln?
    A. ln(1 + x) ≤ xB. the binomial theoremC. the AM–GM inequality
    Answer A.ln(1 + 1/k) ≤ 1/k ≤ 1, so ln(n+1) = Σ ln(1 + 1/k) ≤ n; aiming the same tool at √n gives ln n ≤ 2√n.
  3. Why does a single binomial term suffice to beat nᵏ?
    A. because C(n, k+1) = 2ⁿB. because all terms of (1+b)ⁿ are positive and C(n, k+1)bᵏ⁺¹ grows like a constant times nᵏ⁺¹C. because b must be larger than 1
    Answer B.Dropping positive terms only makes the sum smaller, and the kept term is ≥ c·nᵏ⁺¹, one power of n more than nᵏ.
  4. In aⁿ/n! = (a/1)(a/2)⋯(a/n), from which index on is every new factor below ½?
    A. from n = 1B. once n > aC. once n > 2a
    Answer C.a/n < ½ exactly when n > 2a; after that the product at least halves at every step and tends to 0.
  5. 1.01ⁿ versus n¹⁰⁰: which statement is right?
    A. n¹⁰⁰ wins forever because 1.01 is so close to 1B. 1.01ⁿ wins from n = 100 onwardC. 1.01ⁿ wins eventually, but only past n ≈ 10⁵
    Answer C.a = 1.01 > 1 and k = 100 is fixed, so the exponential wins in the end; the crossover is near n ≈ 1.17×10⁵, where both have 507 digits.
  6. Which choice breaks the rung nᵏ ≪ aⁿ?
    A. a = 1.0001B. k = 50C. a = 1
    Answer C.With a = 1 the “exponential” is the constant 1; any a > 1, however close to 1, still wins for every fixed k.

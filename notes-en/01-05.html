Proving the Supremum Principle

Hunting sup S digit by digit — and seeing exactly where completeness enters.

The supremum principle (least-upper-bound property)
If S ⊆ ℝ is nonempty and bounded above, then S has a least upper bound sup S in ℝ.
Two construction facts, at every stage n
✗ aₙ is not an upper bound of S
✓ aₙ + 10⁻ⁿ is an upper bound of S

1What must be built

One number α with two jobs: (i) α is an upper bound of S; (ii) no number b < α is an upper bound. Strategy: find its address digit by digit — street (integer part), block (tenths), door (hundredths), …

2–3The construction

Integer part. S ≠ ∅, so some integer is not an upper bound; S is bounded above, so some integer is. Let m be the greatest integer that is not an upper bound; then m + 1 is an upper bound, and the target lives in [m, m + 1].

Refinement. Split the current window into ten steps and let aₙ be the largest n-digit step that is not an upper bound. Then aₙ + 10⁻ⁿ is an upper bound, and the target lives in the nested window [aₙ, aₙ + 10⁻ⁿ] of length 10⁻ⁿ.

The address. Reading off the digits of a₁, a₂, a₃, … gives one infinite decimal α = m + 0.d₁d₂d₃…, whose n-digit truncation is aₙ.

Worked example: S = {q ∈ ℚ : q² < 2}

For c > 0: if c² < 2 some element of S beats c; if c² ≥ 2, c is an upper bound.   m = 1.

Each digit is a promise: the target is inside this smaller window.

4Verify the two points

For every n: aₙ ≤ α ≤ aₙ + 10⁻ⁿ (α and aₙ share their first n digits; the rest adds between 0 and 10⁻ⁿ).

(i) α is an upper bound.

Suppose some s ∈ S had s > α. Choose n so large that 10⁻ⁿ < s − α. Then aₙ + 10⁻ⁿ ≤ α + 10⁻ⁿ < s, so aₙ + 10⁻ⁿ is not an upper bound of S, contradicting the construction. Hence s ≤ α for every s ∈ S.

(ii) Nothing smaller is an upper bound.

Let b < α. Choose n so large that 10⁻ⁿ < α − b. Then aₙ ≥ α − 10⁻ⁿ > b. But aₙ is not an upper bound of S, so some s ∈ S has s > aₙ > b. Hence b is not an upper bound.

Therefore α = sup S. ∎

5The convention quietly saves the proof

Take S = [0, 0.42), so sup S = 0.42. Since 0.42 is an upper bound, the hunt never picks it: a₁ = 0.4, a₂ = 0.41, a₃ = 0.419, a₄ = 0.4199, … The digits spell α = 0.41999…, and the recurring-9s convention declares 0.41999… = 0.42. Without it, the address system would glitch at every terminating decimal.

0.41999… = 0.42

6The moral

Completeness enters at exactly one place: the hunt produces an infinite decimal, and ℝ accepts every infinite decimal as a number. Inside ℚ alone the same hunt for S = {q ∈ ℚ : q² < 2} closes in on 1.41421…, which is not rational. The nested-interval move returns later as a named theorem about nested closed intervals — here it already did real work.

✓Self-check

1. S = {q ∈ ℚ : q² < 3} has m = 1. Run stage 1: what is a₁?
A1.7B1.8C1.73
Correct: A. 1.7² = 2.89 < 3, so 1.7 is not an upper bound, while 1.8² = 3.24 ≥ 3 makes 1.8 an upper bound; hence a₁ = 1.7 and the target lives in [1.7, 1.8].
2. For S = [−2.5, −0.3), what is m, the greatest integer that is not an upper bound?
A−1B0C−3
Correct: A. −1 is beaten by −0.5 ∈ S, while 0 is an upper bound, so m = −1 and the target lives in [−1, 0].
3. For S = [0, 0.42), why does the recurring-9s convention matter?
AThe hunt spells 0.42000…, so it does not matterBThe hunt spells 0.41999…, which equals sup S = 0.42 only by the conventionCThe hunt never ends, so α does not exist
Correct: B. 0.42 is always an upper bound and is never picked, so the digits are 0.41999…, and the convention identifies this decimal with 0.42.
4. In point (i), which construction fact is contradicted?
Aaₙ is not an upper boundBaₙ + 10⁻ⁿ is an upper boundCα ∈ S
Correct: B. From s > α we get s > aₙ + 10⁻ⁿ for large n, so aₙ + 10⁻ⁿ would not be an upper bound.
5. Which inequality holds for every n?
Aaₙ < α < aₙ + 10⁻ⁿBaₙ ≤ α ≤ aₙ + 10⁻ⁿCα ≤ aₙ
Correct: B. aₙ is the n-digit truncation of α, and the remaining digits add between 0 and 10⁻ⁿ (equality is possible, as with 0.41999… = 0.42).
6. Where exactly did completeness enter the proof?
AIn choosing the integer mBIn accepting the infinite decimal α as a real numberCIn the contradiction of point (i)
Correct: B. Every other step is finite bookkeeping; only the claim that the infinite decimal α is a number in ℝ uses completeness.

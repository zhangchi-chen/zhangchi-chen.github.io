§2.2 · Mathematical Analysis I

Basic Properties of Convergent Sequences

Uniqueness · Boundedness · Sign preservation

A convergent sequence has infinitely many terms, but its limit is a single number — and that one number pins down almost every term.

Recall the definition

an→A ⇔ ∀ε>0, ∃N, ∀n>N: |an−A|<ε

For any ε>0, past some N every term lies in the band (A−ε, A+ε); only finitely many terms stay outside.

Analogy. The limit is a headquarters; almost all branch offices are locked inside a band around it.

Theorem 2.2 (Uniqueness)

Theorem 2.2 (Uniqueness)
If the sequence {an} converges, then its limit is unique.
  1. Suppose an→a and an→b with a≠b. Take ε0=|b−a|2.
  2. n>N1⇒an∈(a−ε0, a+ε0);   n>N2⇒an∈(b−ε0, b+ε0).
  3. For n>max{N1,N2}, an would lie in both bands — but they are disjoint. Contradiction, so a=b.

★ Only one headquarters address.

Theorem 2.3 (Boundedness)

Theorem 2.3 (Boundedness)
If {an} converges, then {an} is bounded; i.e., there exists M>0 such that |an|≤M for all positive integers n.
  1. Take ε=1: there is N with an∈(a−1, a+1) for all n>N, so |an|<|a|+1 on the tail.
  2. Only finitely many terms a1,…,aN remain; a finite list has a maximum.
  3. Let M=max{|a1|,…,|aN|, |a|+1}. Then |an|≤M for all n. ∎

Worked example

an=nn+1→1. With ε=1: |an−1|=1n+1<1 for every n, so 0<an<2 and M=2 works.

Necessary, not sufficient
Convergent ⇒ bounded, but not conversely: an=(−1)n satisfies |an|≤1, yet it jumps between −1 and 1 forever, so it diverges.

Theorem 2.4 (Sign preservation)

Theorem 2.4 (Sign preservation)
If liman=a>0 (or <0), then for any a′∈(0,a) (or a′∈(a,0)) there exists N such that an>a′ (or an<a′) whenever n>N. In practice one often takes a′=a/2.
  1. Take ε=a−a′>0. For n>N: an>a−ε=a′.
  2. With a′=a/2: an>a2>0 for all large n.
Geometric meaning. A positive limit makes the whole tail positive: if headquarters is on the positive side, almost all members are too.
Corollary
If liman=a, limbn=b, and a<b, then an<bn for all sufficiently large n.
Idea: take ε=b−a2; eventually an<a+b2<bn.

One pattern behind all three proofs

Uniquenessε0=|b−a|2
Boundednessε=1
Sign preservationε=a−a′, often a′=a2
Pick one concrete ε, and let the definition do the work.

Remark · Theorem 2.5 (Order preservation)

Theorem 2.5 (Order preservation)
If an≤bn for all large n and both converge, then liman≤limbn.
Warning: strict inequality may degenerate to equality in the limit: 1n>0 for every n, but lim1n=0.

Self-check · Test yourself

1. If aₙ → a and aₙ → b, then necessarily (　)

A. a = b　　B. a ≠ b　　C. a and b may differ

A. Take ε₀ = |b−a|/2: the two ε₀-bands around a and b are disjoint, yet for large n the term aₙ would have to lie in both — contradiction.

2. Which sequence is bounded but NOT convergent? (　)

A. aₙ = n　　B. aₙ = (−1)ⁿ　　C. aₙ = 1/n

B. |(−1)ⁿ| ≤ 1 is bounded, but it jumps between −1 and 1, so by uniqueness it cannot converge. A is unbounded; C converges to 0 — boundedness is only a necessary condition.

3. If lim aₙ = 2 and a′ = 1, then there is N such that n > N implies (　)

A. aₙ > 2　　B. aₙ > 1　　C. aₙ > 0 but not necessarily > 1

B. Sign preservation guarantees: for any a′ ∈ (0, 2), eventually aₙ > a′ — any number between 0 and 2, but never 2 itself.

4. The classical choice of ε in the proof of boundedness is (　)

A. ε = 1　　B. ε₀ = |b−a|/2　　C. ε = a − a′

A. Each proof has its key: boundedness takes ε = 1 (the tail lands in (a−1, a+1)); uniqueness takes ε₀ = |b−a|/2; sign preservation takes ε = a − a′ (often a′ = a/2).

5. If aₙ ≤ bₙ for all large n and both sequences converge, then (　)

A. lim aₙ < lim bₙ　　B. lim aₙ ≤ lim bₙ　　C. lim aₙ = lim bₙ

B. A strict inequality may degenerate to equality in the limit: 1/n > 0 for every n, yet lim 1/n = 0.

6. With ε = (b−a)/2 in the corollary, the middle cut point is (　)

A. (b−a)/2　　B. (a+b)/2　　C. b − a

B. For large n: aₙ < a + ε = (a+b)/2 = b − ε < bₙ — the two bands meet exactly at the midpoint.

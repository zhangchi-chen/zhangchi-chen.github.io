16-03 Iterated limits: across first, or down first

Iterated limits: across first, or down first

1 · Motivation

Iterated limits: do we go across first, or down first? A homework question: where does this fraction head at the origin? Lin sends x to zero first and lands on minus one. Zhou does it the other way round and lands on plus one. Same function, same point, and two different answers. We recheck both lines, and neither has a slip. So which one is the limit, or is it neither? Each of them answered a different question, in a different order. Today we find out what each order computes, and when to trust it.

2 · Statements

Picture f as a huge class grade sheet. Columns run along one variable, rows along the other. Our target is the far corner of the sheet. The double limit lets both labels move at once, by any route at all. That is the whole fan of paths from episode sixteen oh two. An iterated limit reads the same sheet in two separate steps.

Step one: freeze a row, and run across it to the very end. Whatever that row settles to, we call it phi of y. Do this for every row, and a new column of results appears. Step two: run down that new column toward the corner. That is the iterated limit: across first, then down. Or run down every column first, then across the bottom. Two readings of the same sheet, and nothing promises they agree.

The course text's Definition 3 says exactly this. First clause: every single row must finish its run. Those results form an ordinary function of one variable. And L is simply that function's ordinary limit. Read the notation from the inside out; the inner limit goes first. Swap the two limit signs, and the two jobs swap too. Careful: an iterated limit is a limit of limits, not a single path.

3 · Method

Exhibit one is Example 7 in the course text: our friends' function. Across first: each row settles to its label minus one. Then the column slides to minus one. That is Lin's minus one: she read the sheet across first. Down first: each column settles to one plus its label. Then the bottom row slides to plus one. Two complete readings, and two different destinations. Corollary 2 turns this clash into a firm conclusion. So the double limit does not exist, and we never hunted a single path. Lin and Zhou were both right; they just answered different questions.

Exhibit two, Example 6, is an old friend from episode sixteen oh two. Each line reports its own value, so no double limit exists. Across first: every row settles at zero. Down first: every column settles at zero too. Both iterated limits exist, and both are zero. Yet the diagonal of the sheet reads one half, all the way in. Each row passes its diagonal cell just once, then runs on to zero. The margins never notice the diagonal, but the double limit must. First row of our table: equal iterated limits prove nothing. That is the classic exam trap, and this function is the counterexample.

Exhibit three is Example 8, a function built from two wobbling sines. Freeze one row, at a quarter, and run toward zero. The second term keeps swinging, all the way in. Like that classmate whose weekly quiz scores never settle down. So no row ever finishes; the inner limit simply does not exist. By the same reasoning, no column finishes either. Neither iterated limit exists. Now skip both steps and ask the double limit itself. Each sine stays within one, so the coordinates keep the function small. And that bound depends on distance only, never on direction. The radial squeeze from sixteen oh two finishes it: the limit is zero. Second row: a double limit can exist while the iterated ones fail.

The course text sums up all three exhibits like this. No implication either way; each one must be checked on its own. Still, one bridge survives, and it runs in only one direction. Theorem 16.6: when both limits exist, they must agree. The idea of the proof fits in three frames. Frame one: close to the point, the function stays within epsilon of its limit. Frame two: hold x fixed and slide; the point never leaves the disk. In the limit the inequality survives, softened only to allow equality. Frame three: every nearby column obeys it, so the inner results close in. The double limit is stronger; it drags any existing order to its value. Mind the fine print: the iterated limit has to exist in the first place. Corollary 2 follows: one value cannot equal two different numbers.

4 · Outlook

So the theorem has two valid ways to be used. Use one: know the double limit, and any existing order comes for free. Better still, an iterated limit can guess the value for us. Down first, then across, and the candidate value is 2. A radial bound confirms it, with one ruler for every direction. So the double limit is 2: one order guessed it, the bound proved it. Use two: unequal iterated limits rule out the double limit at once. Two one-variable limits are often cheaper than a hunt for paths. But equal iterated limits prove nothing; remember exhibit two.

This is the third time we have met the order of limits. In thirteen oh one, swapping two limits for a sequence of functions failed. In thirteen oh four, uniform convergence let a limit pass through an integral. Today, the double limit forces any existing iterated limit to match it. One principle: two limits commute only when something stronger coordinates them. In sixteen oh four, double limits become the very definition of continuity.

Later, in multiple integrals, swapping two integrations needs a theorem too. Its counterexamples are today's table, dressed in integral signs. Same umbrella, heavier rain. Two orders, two questions, and the double limit asks the hardest one.

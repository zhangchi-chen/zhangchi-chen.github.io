The Extreme Value Theorem

Hello, everyone.Today: two guarantees on a closed interval.Your weather app says today's high came at 14:00.Say the high was 23 °C.But why must a highest temperature exist at all?Temperature changes continuously through the day.Yet a curve could climb forever toward a level.

Here x/(1+x) creeps toward 1 and stays below it.Its supremum is 1, yet no point reaches it.Two hypotheses block both escape routes.Continuity, and a closed bounded interval [a, b].The boundedness lemma comes first.If f is continuous on [a, b], then f is bounded on [a, b].The maximum-minimum theorem goes further.

If f is continuous on [a, b], it attains a max and a min.There exist points ξ and η in [a, b].For every x in [a, b]: f(η) ≤ f(x) ≤ f(ξ).Boundedness is the lemma; attainment is the theorem.Bounded: a ceiling exists. Attained: the curve touches it.

Now read the hypotheses one clause at a time.Closed: the endpoints a and b belong to the interval.Picture two walls that lock the exits.Bounded interval: the walls stand at finite places.Continuous: the graph is drawn without lifting the pen.No teleporting from one height to another.The lemma's picture: a net below the curve, a lid above.

The curve can neither fall through nor fly off.The theorem says more: the curve touches both lid and net.Is every hypothesis needed? Let's remove each one.

First, open the walls: f(x) = x on (0, 1).Its values lie between 0 and 1, so it is bounded.But sup = 1 and inf = 0, and neither is touched.The values escape through the open ends.

Second, keep the walls but break continuity.Inside (0, 1), let f(x) = x.Patch the endpoints wildly: f(0) = f(1) = 1/2.The interval is closed, yet sup = 1 is never reached.The minimum is missing too: inf = 0, never reached.The jump at each endpoint is the teleport.

Third, let the interval run forever: f(x) = x on [0, ∞).Continuous, closed at 0, yet it drifts to infinity.No upper bound, so no maximum.Every hypothesis is doing work.Closedness stops escapes through the endpoints.Continuity stops teleporting.A bounded interval stops drifting to infinity.

Now the proof, in two honest steps.Step one: suppose f is unbounded.Say f has no upper bound; below is the same.Then each n has a point xₙ with f(xₙ) > n.These runaway points all live inside [a, b].Bolzano–Weierstrass gives a convergent subsequence yₖ → c.Each yₖ is some xₙ with n ≥ k, so f(yₖ) > k.

Where is c? The walls drag it back: a ≤ c ≤ b.That is exactly where closedness is used.By continuity at c, f(yₖ) → f(c).But f(c) is just a finite number.Yet f(yₖ) > k marches off to infinity.Collision! So f is bounded above; likewise below.Step two: attainment.

By step one and the supremum principle, M = sup f exists.Suppose M is never reached: f(x) < M for every x.Here comes the signature move: build a helper.Let g(x) = 1/(M − f(x)).The denominator is always positive, so g is continuous and positive.By step one, g is bounded: g(x) ≤ K for some K > 0.Flip it: M − f(x) ≥ 1/K.

So f(x) ≤ M − 1/K for every x.Then M − 1/K is a smaller upper bound.That contradicts M being the least upper bound.So some ξ in [a, b] has f(ξ) = M.For the minimum, apply the same to −f.Test the engine on f(x) = x over [0, 1).Here M = 1, so g(x) = 1/(1 − x).

At x = 0.9, g(x) = 10.At x = 0.99, g(x) = 100.At x = 0.999, g(x) = 1000.g is unbounded, exactly as the logic demands.No contradiction: [0, 1) is not closed, so the lemma is silent.On [a, b], the lemma forbids that blow-up.Never reached ⇒ helper unbounded ⇒ contradiction.

Step one: a runaway sequence, dragged back by a subsequence.Step two: never reached becomes an unbounded helper.Where does this go next?A later exam episode asks: does a function on the whole line attain its maximum?Today's attainment theorem is the key tool there.These theorems also join the chapter-7 equivalence ring.There they sit beside the supremum principle and Bolzano–Weierstrass.

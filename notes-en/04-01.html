Continuity and Discontinuities

Continuity is a local, pointwise contract: at one point x₀, three numbers must agree — the left limit, the right limit, and the value f(x₀).

1 · The three-way handshake

f is continuous at x₀ when

limx→x₀ f(x) = f(x₀)

Three promises: f(x₀) is defined, the limit exists, and the two agree. Equivalently:

limx→x₀⁻ f(x) = f(x₀) = limx→x₀⁺ f(x)

2 · Three dialects, one statement

IncrementΔy = f(x₀ + Δx) − f(x₀) → 0 as Δx → 0
Limitlimx→x₀ f(x) = f(x₀)
ε–δfor every ε > 0 there is δ > 0 such that |x − x₀| < δ ⇒ |f(x) − f(x₀)| < ε

Why they agree: put x = x₀ + Δx, so Δx → 0 exactly when x → x₀ and Δy → 0 says f(x) → f(x₀). Writing that limit in ε–δ form gives 0 < |Δx| < δ ⇒ |Δy| < ε; at Δx = 0 we have Δy = 0 < ε anyway, so the condition 0 < |Δx| can be dropped. Compared with last chapter's limit inspector, the target is now f(x₀) itself and the point x₀ is on duty.

Worked check: f(x) = 3x + 1 at x₀ = 2 gives |f(x) − f(2)| = 3|x − 2|, so δ = ε/3 works; for ε = 0.3, δ = 0.1.

3 · One-sided continuity

Right-continuous at x₀: limx→x₀⁺ f(x) = f(x₀); left-continuous is the mirror image. f is continuous at x₀ if and only if it is both. On an interval, continuity at an endpoint means the matching one-sided kind — e.g. √x is right-continuous at 0, hence continuous on [0, +∞).

4 · The classifier: two questions

Q1 · Do both one-sided limits exist (as finite numbers)?
No → second kind
Q2 · Are they equal?
No → jump
Equal, but f(x₀) is missing or different → removable

Removable + jump = discontinuities of the first kind.

5 · Why classify first

  • Patch removable points: sin x / x is undefined at 0, its limit is 1; define the value 1 and it is continuous.
  • Read step functions: a parcel tariff of 8 for 0 < w ≤ 1 kg and 12 for 1 < w ≤ 2 kg jumps at 1 kg and is left-continuous there — the filled dot sets the boundary price.
  • Diagnose data: a lone outlier is removable (replace it by the neighbours' limit), a level shift is a jump (investigate, do not smooth), endless wobbling hints at a sampling problem.

Self-test

1. Continuity of f at x₀ requires which values to be equal?

A.left limit, right limit and f(x₀)B.left limit and right limit onlyC.f(x₀) and f(x₀ + 1)
Answer: A. Continuity is the three-way handshake: both one-sided limits must exist and equal f(x₀).

2. f(x) = x + 1 for x < 1 and 4 − x for x ≥ 1. At x = 1 the point is …

A.removableB.a jump, and f is right-continuousC.of the second kind
Answer: B. f(1⁻) = 2 and f(1⁺) = 3 both exist but differ; f(1) = 3 matches the right limit.

3. x·sin(1/x), undefined at 0, has at 0 a discontinuity that is …

A.removableB.a jumpC.of the second kind
Answer: A. |x·sin(1/x)| ≤ |x| → 0, so the limit 0 exists; defining the value 0 repairs it.

4. f(x) = 3x + 1, x₀ = 2, ε = 0.3. Which δ works?

A.δ = 0.1B.δ = 0.2C.δ = 0.3
Answer: A. |f(x) − 7| = 3|x − 2| < 3δ, so we need 3δ ≤ 0.3; with δ = 0.2, x = 2.15 gives 0.45 > 0.3.

5. Which of these is a discontinuity of the first kind?

A.sin(1/x) at 0B.1/x² at 0C.sgn x at 0
Answer: C. sgn x has one-sided limits −1 and 1: both exist and differ, a jump, hence first kind.

6. g equals f on (x₀ − 0.01, x₀ + 0.01) and f is continuous at x₀. Then g at x₀ is …

A.continuousB.possibly discontinuousC.always discontinuous
Answer: A. Continuity is local: only values near x₀ (including x₀) matter, and there g and f coincide.

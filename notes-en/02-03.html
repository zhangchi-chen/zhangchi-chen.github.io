Arithmetic of Limits

Sequences · sum, difference, product, quotient
TheoremIf an→a and bn→b, then an±bn→a±b, anbn→ab, and when b≠0, anbn→ab.

① One mechanism, four rules

Write an=a+αn, bn=b+βn with αn,βn→0. Everything is constant + infinitesimal.

  • an±bn=(a±b)+(αn±βn) — offsets just add.
  • anbn=ab+(aβn+bαn+αnβn) — αnβn is noise × noise: second-order small.
  • Quotient: first control 1bn.

② Why b ≠ 0 is a real wall

Moat (from sign preservation): since b≠0, eventually |bn|≥|b|2. Then 1bn−1b=b−bnbnb, with |bnb|≥|b|22.

With denominator limit 0, anything can happen (the 0/0 pattern):

1/n1/n2=n→∞1/n21/n=1n→0(−1)n/n1/n=(−1)n diverges

③ The rules point one way only

Convergent + convergent ⇒ convergent. The converse fails: (−1)n and (−1)n+1 both diverge, yet their sum is 0.

Rules are certificates for computing — not tests for convergence.

④ Read the proof as an error budget

|anbn−ab|≤|a||βn|+|b||αn|+|αn||βn|

Give each source a share ε/3; each demand holds after its own Ni; take N=max(N1,N2,N3). Constants like |b|+1 only tidy the bookkeeping: ε2(|b|+1) is accounting, not magic.

⑤ Finitely many operations only

For any polynomial P: P(an)→P(a). Infinitely many operations is a different world: 1n+1n+⋯+1n=1 (n terms), not 0, although each term →0.

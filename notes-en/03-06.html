Orders of Infinitesimals

O(f), o(f) as classes of functions — computing — equivalent replacement

1The race for smallness

As x → x₀, compare two infinitesimals u, v through the ratio limit — the finishing board:

ratio limitverdict
lim u/v = 0u is a higher-order infinitesimal than v: u = o(v)
lim u/v = c ≠ 0infinitesimals of the same order
c = 1equivalent infinitesimals: u ~ v
lim u/v = ∞u is of lower order
lim u/vk = c ≠ 0u is a k-th order infinitesimal

Mirror image of the growth ladder for infinities: there, who grows faster; here, who vanishes faster.

2Why classes at all

With u = x·sin(1/x), v = x (x → 0) the ratio sin(1/x) oscillates: no ratio limit, no label. Yet |u| ≤ |v| — a perfectly good comparison. So we state bounds and tendencies instead: the classes O(f) and o(f).

3The function-class language

Classes are cabinets for functions living near the process point x₀:

g ∈ O(f) ⟺ |g| ≤ C|f| on some punctured neighborhood of x₀
g ∈ o(f) ⟺ g/f → 0

Named classes: o(1) = the infinitesimals (this chapter sorts this class); O(1) = the locally bounded functions.

The confession (once): we write o(f) + o(f) = o(f), but the equals sign means ⊆: any member of the left lands inside the right. Read left to right only. The abuse is licensed — from here on, the equals sign counts.

4Compute with the table

Sort each factor into its class first, then compute with the table.

#identitypicture
1O(f) + O(f) = O(f)bounded by f + bounded by f
2O(f)·O(g) = O(fg)the constants multiply
3o(f) + o(f) = o(f)negligible + negligible
4o(f)·O(g) = o(fg)small × bounded = small
5c·o(f) = o(f)c constant
6x·o(f(x)) = o(x·f(x))x → 0; a variable multiplier rescales the class
7o(1)·O(f(x)) = o(f(x))the workhorse: tends-to-zero × controlled-by-f is beaten by f
8f ~ g ⟺ f − g = o(g)equivalence is a statement about the difference

A worked example (x → 0): x³·o(1)·(2 + sin(1/x))/x. Class: (2 + sin(1/x))/x ∈ O(1/x). Entry 7: o(1)·O(1/x) = o(1/x). Entry 6: x³·o(1/x) = o(x²). Verdict: o(x²).

5Replacement: free in products and quotients

f ~ g means f = g·(1 + o(1)). The correction factor tends to 1, merges freely (o(1)·o(1) = o(1)) and never changes a limit, so equivalent replacement is valid inside products and quotients.

limx→0 sin 3x·(e2x − 1) / (x·tan 5x) = lim 3x·2x / (x·5x) = 6/5

6The trap: sums and differences

Naive: tan x ~ x, sin x ~ x, so (tan x − sin x)/x³ → (x − x)/x³ = 0. Wrong — the true value is 1/2.

Class-level diagnosis: tan x = x + o(x), sin x = x + o(x), so tan x − sin x = o(x): the main parts cancelled, the remainders are in charge, and o(x)/x³ is undetermined. Like cancelling the leading digits of two numbers and expecting the remainder to be zero. Replacement inside sums and differences is invalid in general.

Cure — factor first, then replace in the factors:

tan x − sin x = tan x·(1 − cos x),   1 − cos x = 2sin²(x/2) ~ x²/2
(tan x − sin x)/x³ = (sin x/x)·(1/cos x)·((1 − cos x)/x²) → 1·1·(1/2) = 1/2

The deep cure — finer scales, higher-order expansions — is the Taylor expansion chapter ahead (preview).

7Family tree and the bridge

The equivalence table is grown, not memorized. Three mothers: sin x/x → 1 (children tan x ~ x, arcsin x ~ x, 1 − cos x ~ x²/2); the e family with its substitutions (ex − 1 ~ x); ln(1 + x)/x → 1, still carrying its IOU (ln(1 + x) ~ x).

The language of limits is complete. Next: if x → x₀, must f(x) → f(x₀)? That is continuity — the next chapter — and it pays off the IOU.

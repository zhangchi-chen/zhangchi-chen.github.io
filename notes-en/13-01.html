13-01 Pointwise convergence: passing the bar one point at a time

Pointwise convergence: passing the bar one point at a time

1 · Motivation

Pointwise convergence: a whole family passing the bar, one point at a time. Each curve is smooth, and every one of them runs through the same corner. Push the power up, and the curve slumps toward the floor. So where is this whole family heading? It looks like the floor, except one stubborn point refuses to move. And near the right end, the order of two limits quietly matters.

Picture a quiz coming back, desk by desk, across the room. Everyone passes sooner or later, each at a different minute. But no one ever announces a common deadline, and that will matter. Each desk is a point; each minute, one step of the index.

2 · Statements

Freeze one point x₀, and read off each curve's height there.
Those heights form an ordinary number sequence, as in chapter 2.
A sequence of functions is a family of number sequences, one per x.
Warm-up: fₙ(x) = sin(nx)/n, faster wiggles but smaller waves.
At any fixed x, |fₙ(x)| ≤ 1/n, so the heights are squeezed to 0.
Limit function 0; convergence domain, the whole real line.
If for x₀ ∈ E the numerical sequence f₁(x₀), f₂(x₀), … converges,
the sequence of functions {fₙ} is said to converge at x₀;
if it converges at every point of D ⊂ E,
the function f defined by lim fₙ(x) = f(x), x ∈ D, is called the limit function;
the set of all convergence points is the convergence domain.
Each point is settled on its own; that is what pointwise means.
For each fixed x ∈ D and each ε > 0 there exists N;
in general N depends on both ε and x — written N(ε, x).
Each desk's passing minute is set by N(ε, x).

Pin down a single point, and read each curve's height right there. Those heights are just an ordinary number sequence, the kind from chapter two. A sequence of functions is really a family of number sequences, one for every point.

Warm up with a wave that wiggles faster and faster while it shrinks. Wherever you stand, the height is pinned below one over n and crushed to zero. So the limit function is zero, and every real point converges.

Freeze a point: if the numbers stacked above it settle down, we say the sequence of functions converges at that point. if that happens at every point of a set D, and the function that collects all those limits is called the limit function. and all the points that converge, together, form the convergence domain. Every point settles its own business; that is all pointwise means.

For every point and every tolerance, some threshold N does the job. and in general that threshold depends on the tolerance and on the point. So each desk's own passing minute is set by that threshold.

3 · Method

Now meet the star of this chapter: the powers of x. At zero, the heights are zero from the very first step. At one half, the heights halve each step and vanish fast. At three quarters it still sinks to zero, only more patiently. Right next to one, it crawls: a hundred steps in, still above a third. At one itself, the heights never move, and the limit is one. At minus one it flips forever: the seesaw from the start of chapter twelve. Between minus one and zero the sign keeps flipping, yet the size still dies out. Beyond one in size, the powers blow up: no limit.

Gather the settling points: that's the convergence domain. and the limit function is zero inside, but one at the right end. Every member of the family is an unbroken curve. Yet their limit snaps, leaping from zero to one at a single point. Continuity didn't survive the trip; why, we'll see later.

At the right end, two limits meet head on. First hold n still and slide the point in; the height reaches one. Then let the index run: ones forever, so the answer is one. Now swap: hold the point below one, let n run; it sinks to zero. Then slide the point in: zeros all the way, so the answer is zero. Two honest computations, and two different answers. So the order of limits is not ours to shuffle. The repair condition comes in episode thirteen oh four, with Theorem 13.8.

Now set the bar at one hundredth, and ask each point when it passes. For points strictly inside, the course text hands us an exact threshold. It's exact: passing begins right after that step. Now walk toward the back row, and watch the wait. Each extra nine near the end makes the wait about ten times longer. Close to the back row, the wait grows without bound. So no one threshold can cover the whole interval. Everyone passes, but no minute ever sees the whole room passed. One threshold for everyone at once? That demand is the next episode's story.

4 · Outlook

A series of functions plays by the same rule, one point at a time. Freeze the point, and it's just a number series from chapter twelve. A series converges pointwise exactly when its running totals do. Take the geometric series; its running total has a closed form. Inside, the powers die out, and the sum function appears. Both ends fail, so the convergence domain is open, exactly as in chapter twelve. And last episode's sine series was pointwise convergence all along.

Here's the trap: continuous members, so a continuous limit? No. Pointwise convergence carries nothing across; the powers already broke continuity. And later on, integrals and derivatives misbehave as well.

A glimpse ahead: machine learning trains one model after another. Following one input as its prediction settles is pointwise thinking. Whether the entire model settles together comes back in later probability courses.

The powers in one breath: a domain, a broken limit, and a threshold with no ceiling. The recipe: pin a point, solve a plain sequence, then collect the answers. Each point passes in its own time; that, in one line, is pointwise convergence.

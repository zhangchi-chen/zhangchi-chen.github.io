Properties of Function Limits

A moving-in checklist: same furniture (mechanisms), new address (punctured neighborhoods instead of tails).

1 · The moving-in checklist

Nothing is re-proven: each mechanism is inherited from the sequence chapter. Only the address changes, from the tail n > N to a punctured neighborhood 0 < |x − x₀| < δ.

2 · The word “local”

Local means the guarantee covers the street, not the house itself. The punctured neighborhood leaves out x₀, so local sign preservation says nothing about f(x₀).

Example: f(x) = cos x for x ≠ 0, f(0) = −1. Then A = 1 > 0 and f(x) > 1/2 on 0 < |x| < π/3, yet f(0) = −1 — and far away cos x < 0. The global reading “A > 0 ⇒ f > 0 everywhere” is false.

f(x) > A/2

Half-strength sign, full-strength usability: it also gives 1/f(x) < 2/A, a safe denominator.

3 · The arithmetic gate

If f → A, g → B and B ≠ 0, then f/g → A/B.

B ≠ 0 is the same gate as in the sequence chapter. When the denominator's limit is 0, the rule does not apply: as x → 0, x²/x → 0, x/x → 1, and x/x² has no finite limit. Same 0 below, three fates.

4 · Squeezing — armed and shelved

If f(x) ≤ g(x) ≤ h(x) near x₀ and f, h → A, then g → A. Only “near x₀” is needed.

Picture: 1 − x² ≤ 1 + x² sin(1/x) ≤ 1 + x² pins g to 1 at 0. Shelved for now — it fires in the next episodes on the important limits.

Self-check

1. If lim(x→0) f(x) = 2, what can you conclude about f(0)?

  1. f(0) > 1
  2. f(0) > 0
  3. Nothing — f(0) may have any value, or not exist

Answer: C. Sign preservation is local: it covers a punctured neighborhood, never the point x₀ itself.

2. If lim(x→x₀) f(x) = A > 0, the usable form guarantees, on some punctured neighborhood:

  1. f(x) > A
  2. f(x) > A/2
  3. f(x) = A

Answer: B. f(x) > A/2 near x₀ — half-strength sign, but with a margin you can use.

3. For lim f/g = A/B with f → A, g → B, the rule needs:

  1. A ≠ 0
  2. B ≠ 0
  3. A ≠ 0 and B ≠ 0

Answer: B. Only the denominator's limit must be nonzero; A = 0 is fine.

4. As x → 0, f → 0 and g → 0. Then lim f/g:

  1. equals 1
  2. equals 0
  3. cannot be decided by the quotient rule

Answer: C. The gate is closed: x²/x → 0, x/x → 1, x/x² has no finite limit.

5. Why is boundedness of a function only local?

  1. Because limits need not be unique
  2. There are no “finitely many early terms” to absorb; f may blow up away from x₀
  3. Because f must be continuous

Answer: B. E.g. 1/x has limit 1 at x₀ = 1 but is unbounded near 0.

6. The sequence tail n > N translates to:

  1. the whole domain of f
  2. a punctured neighborhood 0 < |x − x₀| < δ
  3. the single point x₀

Answer: B. Mechanism unchanged, address changed: tails become punctured neighborhoods.

Cauchy Convergence Criterion for Sequences

Convergence without naming the limit: inspect the ranks, not the scoreboard.

Theorem (Cauchy convergence criterion)

{aₙ} converges ⇔ for every ε > 0 there exists N such that |aₙ − aₘ| < ε for all m, n > N.

A sequence satisfying the right-hand side is called a Cauchy sequence. The two sides are equivalent in ℝ, so the criterion is both a test for convergence and a test for divergence.

1 · Internal self-audit

ε–N definition

∀ε > 0 ∃N : n > N ⇒ |aₙ − A| < ε

needs a candidate limit A — the scoreboard value — before anything can be checked.

Cauchy criterion

∀ε > 0 ∃N : m, n > N ⇒ |aₙ − aₘ| < ε

needs no target: open a tail window after N and measure every pairwise distance inside it. If all gaps fall below ε, the sequence is Cauchy.

Inspect the ranks, not the scoreboard: the audit is internal, terms are checked against each other.

2 · Writing a Cauchy proof

Claim: the partial sums sₙ = 1 + 1/2 + 1/4 + … + 1/2ⁿ form a Cauchy sequence.

Split the tail. n > m:   sₙ − sₘ = nΣk = m+112ᵏ = 12ᵐ⁺¹ + … + 12ⁿ

Each piece is half of what was left, so the pieces telescope:

12ᵏ = 12ᵏ⁻¹ − 12ᵏ,   (12ᵐ − 12ᵐ⁺¹) + (12ᵐ⁺¹ − 12ᵐ⁺²) + … + (12ⁿ⁻¹ − 12ⁿ) = 12ᵐ − 12ⁿ < 12ᵐ

Proof

Given ε > 0, choose N with 1/2ᴺ < ε.

For n > m > N: |sₙ − sₘ| = 1/2ᵐ − 1/2ⁿ < 1/2ᵐ < 1/2ᴺ < ε.

No limit was named, yet convergence is certified. ∎

Telescoping tail (m = 3, n = 7)

Reading strategy

A Cauchy verification always has the same shape: write |aₙ − aₘ| as a tail, bound the tail by something that depends only on m (here 1/2ᵐ), then choose N so that this bound is below ε.

3 · The adjacent-term trap

Does |aₙ₊₁ − aₙ| → 0 imply that {aₙ} is Cauchy? No.

Harmonic partial sums sₙ = 1 + 1/2 + … + 1/n

|s₂ₙ − sₙ| = 1n+1 + … + 12n ≥ n · 12n = 12

Each step sₙ₊₁ − sₙ = 1/(n+1) → 0, but compare sₙ with s₂ₙ: there are n terms, each at least 1/(2n), so |s₂ₙ − sₙ| ≥ n · 1/(2n) = 1/2 forever. The far pairs never shrink.

Second example: aₙ = √n

Adjacent gaps √(n+1) − √n = 1/(√(n+1) + √n) → 0, yet √n → ∞: the sequence diverges.

Lesson: control ALL pairs in the tail, not just neighbors.

4 · Non-Cauchy as a divergence certificate

The negation of the criterion is a quantifier ladder:

∃ ε₀ > 0
⇓
∀ N
⇓
∃ m, n > N : |aₙ − aₘ| ≥ ε₀

Read: there is an ε₀ such that arbitrarily far pairs still differ by at least ε₀. The checker from the running-race analogy now measures pairs inside the tail window — and only needs to find one bad pair for each N.

Certificate for the harmonic partial sums

ε₀ = 12,   m = N + 1,   n = 2m  ⇒  |sₙ − sₘ| ≥ 12

Take ε₀ = 1/2. For any N let m = N + 1 and n = 2m. Then |sₙ − sₘ| ≥ 1/2, so {sₙ} is not Cauchy and therefore diverges — no limit value was ever discussed.

5 · Consistency with subsequences

Every subsequence of a Cauchy sequence is Cauchy.

Its pairs are already pairs from the tail window, so the same N works.

If one subsequence of a Cauchy sequence converges to L, the whole sequence converges to L.

For n > N pick a subsequence index nₖ > N: |aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε.

Bridge to the previous episode: a Cauchy sequence is bounded, every bounded sequence has a convergent subsequence, and by the fact above the whole sequence then converges — this is exactly why the criterion holds.

Cauchy⇒bounded⇒convergent subsequence⇒converges

Self-check

1. What does the Cauchy criterion compare?

A. each term aₙ with a candidate limit AB. pairs of terms aₙ, aₘ inside the tail (m, n > N)C. each term aₙ with 0
Correct answer: B. pairs of terms aₙ, aₘ inside the tail (m, n > N) — The criterion is an internal audit: it needs no target value, only pairwise distances in the tail.

2. For sₙ = 1 + 1/2 + … + 1/2ⁿ and n > m, the tail |sₙ − sₘ| equals

A. 1/2ᵐ − 1/2ⁿB. 1/2ⁿ − 1/2ᵐC. 1/2ᵐ⁺¹
Correct answer: A. 1/2ᵐ − 1/2ⁿ — The pieces 1/2ᵏ = 1/2ᵏ⁻¹ − 1/2ᵏ telescope from k = m+1 to n, leaving 1/2ᵐ − 1/2ⁿ.

3. Suppose |aₙ₊₁ − aₙ| → 0. Which statement is true?

A. {aₙ} must be CauchyB. {aₙ} must convergeC. neither follows — e.g. the harmonic partial sums
Correct answer: C. neither follows — e.g. the harmonic partial sums — Steps 1/n → 0 yet |s₂ₙ − sₙ| ≥ 1/2, so only neighbors are controlled, not all tail pairs.

4. Which formula says "{aₙ} is NOT Cauchy"?

A. ∀ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀C. ∃ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀
Correct answer: B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀ — Negation swaps every quantifier: one bad ε₀, and for every N some far pair still differs by at least ε₀.

5. A Cauchy sequence has a subsequence converging to L. Then

A. the whole sequence may still divergeB. the whole sequence converges to LC. only that subsequence converges
Correct answer: B. the whole sequence converges to L — Triangle inequality: |aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε for large n.

6. Which pair certifies the divergence of the harmonic partial sums with ε₀ = 1/2?

A. sₙ and sₙ₊₁B. sₙ and s₂ₙC. s₁ and sₙ
Correct answer: B. sₙ and s₂ₙ — Between sₙ and s₂ₙ there are n terms each ≥ 1/(2n), so the gap is at least 1/2 for every n.

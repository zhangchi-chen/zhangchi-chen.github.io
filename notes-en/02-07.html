Episode 2.7 · Sequences · first-year analysis

Cauchy Convergence Criterion for Sequences

Convergence without naming the limit: inspect the ranks, not the scoreboard.

Act 1 · Motivation

When may you stop?

Press cos on a calculator, then press it again and again. The display wanders — 1, 0.5403, 0.8576, 0.6543, … — and then settles: 0.7390, 0.7391, 0.7391, … Your worksheet asks for this number to three decimals.

cos ▸ 0.7391

Nobody handed you the limit, and it has no closed formula. So: when may you stop, and certify that you are close enough, using only the terms you have already computed?

First instinct: stop when the third decimal stops changing. Is that a proof? Hold that thought — Act 3 shows a sequence that fools exactly this test.

What is missing is a convergence test that never mentions the limit. That is the Cauchy convergence criterion.

Act 2 · What the theorem says

Theorem (Cauchy convergence criterion)

{aₙ} converges ⇔ for every ε > 0 there exists N such that |aₙ − aₘ| < ε for all m, n > N.

A sequence satisfying the right-hand side is called a Cauchy sequence. The two sides are equivalent in ℝ, so the criterion is both a test for convergence and a test for divergence.

One picture per clause

① for every ε > 0 — name any tolerance, as small as you like.

② there exists N — beyond some index, the early mess no longer matters.

③ |aₙ − aₘ| < ε for all m, n > N — ALL terms beyond N sit together in one cluster of width ε: every pair, not just neighbors. The cluster is drawn around the terms themselves; no limit is named.

Internal self-audit

ε–N definition

∀ε > 0 ∃N : n > N ⇒ |aₙ − A| < ε

needs a candidate limit A — the scoreboard value — before anything can be checked.

Cauchy criterion

∀ε > 0 ∃N : m, n > N ⇒ |aₙ − aₘ| < ε

needs no target: open a tail window after N and measure every pairwise distance inside it. If all gaps fall below ε, the sequence is Cauchy.

Inspect the ranks, not the scoreboard: the audit is internal, terms are checked against each other.

Why ℝ makes it enough

A cluster need not have a center, so clustering looks weaker than converging — and in ℚ it really is weaker: the truncations 1, 1.4, 1.41, 1.414, … of √2 form a Cauchy sequence (beyond the k-th term all gaps are below 10⁻ᵏ), but in ℚ there is nothing for them to converge to: the rational line has a hole at √2. The real numbers have no holes — every Cauchy sequence has a limit. That is completeness, and it is the true content of the theorem.

Act 3 · Proof

Direction 1: convergent ⇒ Cauchy

|aₙ − aₘ| ≤ |aₙ − A| + |A − aₘ| < ε/2 + ε/2 = ε

If aₙ → A, then beyond some N every term is within ε/2 of A. Go through A: two legs of less than ε/2 each, so |aₙ − aₘ| ≤ |aₙ − A| + |A − aₘ| < ε/2 + ε/2 = ε. This direction uses the limit; the other direction is the deep one.

Direction 2: Cauchy ⇒ convergent

  1. Step 1 — bounded. Take ε = 1: the whole tail stays within 1 of its first term, and the finitely many earlier terms cannot escape either.
  2. Step 2 — a convergent subsequence exists (last episode: every bounded sequence has one, Bolzano–Weierstrass). Call its limit L.
  3. Step 3 — the whole sequence follows. For n > N pick a subsequence index nₖ > N: |aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε.
Cauchy⇒bounded⇒convergent subsequence⇒converges

Completeness did the heavy lifting in Step 2. Consistency check: every subsequence of a Cauchy sequence is Cauchy, since its pairs are already tail pairs.

Warm-up · writing a Cauchy verification

Claim: the partial sums sₙ = 1 + 1/2 + 1/4 + … + 1/2ⁿ form a Cauchy sequence.

Split the tail. n > m:   sₙ − sₘ = nΣk = m+112ᵏ = 12ᵐ⁺¹ + … + 12ⁿ

Each piece is half of what was left, so the pieces telescope:

12ᵏ = 12ᵏ⁻¹ − 12ᵏ,   (12ᵐ − 12ᵐ⁺¹) + (12ᵐ⁺¹ − 12ᵐ⁺²) + … + (12ⁿ⁻¹ − 12ⁿ) = 12ᵐ − 12ⁿ < 12ᵐ

Proof

Given ε > 0, choose N with 1/2ᴺ < ε.

For n > m > N: |sₙ − sₘ| = 1/2ᵐ − 1/2ⁿ < 1/2ᵐ < 1/2ᴺ < ε.

No limit was named, yet convergence is certified. ∎

Telescoping tail (m = 3, n = 7)

Reading strategy

A Cauchy verification always has the same shape: write |aₙ − aₘ| as a tail, bound the tail by something that depends only on m (here 1/2ᵐ), then choose N so that this bound is below ε.

The adjacent-term trap

Does |aₙ₊₁ − aₙ| → 0 imply that {aₙ} is Cauchy? No.

Harmonic partial sums sₙ = 1 + 1/2 + … + 1/n

|s₂ₙ − sₙ| = 1n+1 + … + 12n ≥ n · 12n = 12

Each step sₙ₊₁ − sₙ = 1/(n+1) → 0, but compare sₙ with s₂ₙ: there are n terms, each at least 1/(2n), so |s₂ₙ − sₙ| ≥ n · 1/(2n) = 1/2 forever. The far pairs never shrink.

Second example: aₙ = √n

Adjacent gaps √(n+1) − √n = 1/(√(n+1) + √n) → 0, yet √n → ∞: the sequence diverges.

Lesson: control ALL pairs in the tail, not just neighbors.

Non-Cauchy as a divergence certificate

The negation of the criterion is a quantifier ladder:

∃ ε₀ > 0
⇓
∀ N
⇓
∃ m, n > N : |aₙ − aₘ| ≥ ε₀

Read: there is an ε₀ such that arbitrarily far pairs still differ by at least ε₀. The checker from the running-race analogy now measures pairs inside the tail window — and only needs to find one bad pair for each N.

Certificate for the harmonic partial sums

ε₀ = 12,   m = N + 1,   n = 2m  ⇒  |sₙ − sₘ| ≥ 12

Take ε₀ = 1/2. For any N let m = N + 1 and n = 2m. Then |sₙ − sₘ| ≥ 1/2, so {sₙ} is not Cauchy and therefore diverges — no limit value was ever discussed.

Act 4 · Applications and outlook

Application 1 · partial sums of a series

For a series Σaₖ the sequence is sₙ = a₁ + … + aₙ, so sₙ − sₘ = aₘ₊₁ + … + aₙ is a block of consecutive terms. The criterion becomes:

Σaₖ converges ⇔ for every ε > 0 there is N such that |aₘ₊₁ + … + aₙ| < ε for all n > m > N.

With n = m + 1: a convergent series has aₙ → 0 — but not conversely (harmonic series). The whole block must be controlled, not one term.

The harmonic witness

Hₙ = 1 + 1/2 + … + 1/n. Its steps shrink to zero: Hₙ₊₁ − Hₙ = 1/(n+1) → 0. Yet H₂ₙ − Hₙ = 1/(n+1) + … + 1/(2n) is a sum of n terms, each at least 1/(2n), so H₂ₙ − Hₙ ≥ 1/2 for every n. The Cauchy condition fails with ε = 1/2, and Hₙ diverges. Steps shrinking to zero is not convergence: ever-shorter steps can still never arrive.

H₂ₙ − Hₙ = 1n+1 + … + 12n ≥ n · 12n = 12

Earlier in the series we proved that 1 + 1/2ᵅ + … + 1/nᵅ converges for every α > 1, and the roof argument broke down at α = 1. Here is the answer: at α = 1 the sum diverges.

Now a convergent example: Σ 1/k². For k ≥ 2, 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k, so a block telescopes: for n > m, |sₙ − sₘ| = Σₖ₌ₘ₊₁ⁿ 1/k² < 1/m − 1/n < 1/m. After m terms the running total is certified within 1/m of the sum — whatever the sum is. Machine-usable: to be within 0.0005, take m = 2000: s₂₀₀₀ = 1.64443…

This sum does have a celebrated exact value, π²/6 — yet the guarantee above never used it: even when a closed form exists, the criterion certifies the error without it.

Application 2 · a stopping rule for an algorithm

Back to the calculator: xₙ₊₁ = cos xₙ, with steps dₙ = |xₙ − xₙ₋₁|. Small steps alone prove nothing — remember Hₙ. But here each step is at most q = sin 1 ≈ 0.84 times the previous one, because |cos u − cos v| ≤ sin 1 · |u − v| on [cos 1, 1] (mean value theorem).

So the tail is a geometric sum: |xₘ − xₙ| ≤ dₙ(q + q² + …) = dₙ · q/(1−q). That is the Cauchy condition, so the iteration converges to some x*, and letting m → ∞ gives |x* − xₙ| ≤ q/(1−q) · dₙ < 5.31 dₙ (q/(1−q) = 5.3079…).

Outlook

The criterion is not a trick about sequences — it says that ℝ has no holes. In chapter 7 it joins the equivalence ring: supremum property, monotone convergence, nested intervals, Bolzano–Weierstrass, Cauchy criterion. Any one of them can serve as the completeness axiom; the others follow.

And the statement travels. In the plane |aₙ − aₘ| becomes a distance between points; in ℝⁿ and in any metric space the same clustering condition makes sense: d(aₙ, aₘ) < ε. There is often no order and no supremum there, so Cauchy is the only convergence notion available. Spaces where every Cauchy sequence converges are called complete — ℝ is the first one you meet.

Self-check

1. What does the Cauchy criterion compare?

A. each term aₙ with a candidate limit AB. pairs of terms aₙ, aₘ inside the tail (m, n > N)C. each term aₙ with 0
Correct answer: B. pairs of terms aₙ, aₘ inside the tail (m, n > N) — The criterion is an internal audit: it needs no target value, only pairwise distances in the tail.

2. For sₙ = 1 + 1/4 + … + 1/n² and n > m ≥ 1, which tail bound follows from 1/k² < 1/(k−1) − 1/k (k ≥ 2)?

A. |sₙ − sₘ| < 1/mB. |sₙ − sₘ| < 1/m²C. |sₙ − sₘ| < 1/n
Correct answer: A. |sₙ − sₘ| < 1/m — Summing from k = m+1 to n telescopes to 1/m − 1/n, which is less than 1/m; the other two bounds fail for large n.

3. Suppose |aₙ₊₁ − aₙ| → 0. Which statement is true?

A. {aₙ} must be CauchyB. {aₙ} must convergeC. neither follows — e.g. the harmonic partial sums
Correct answer: C. neither follows — e.g. the harmonic partial sums — Steps 1/n → 0 yet |s₂ₙ − sₙ| ≥ 1/2, so only neighbors are controlled, not all tail pairs.

4. Which formula says "{aₙ} is NOT Cauchy"?

A. ∀ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀C. ∃ε₀ > 0 ∃N ∀m, n > N : |aₙ − aₘ| ≥ ε₀
Correct answer: B. ∃ε₀ > 0 ∀N ∃m, n > N : |aₙ − aₘ| ≥ ε₀ — Negation swaps every quantifier: one bad ε₀, and for every N some far pair still differs by at least ε₀.

5. A Cauchy sequence has a subsequence converging to L. Then

A. the whole sequence may still divergeB. the whole sequence converges to LC. only that subsequence converges
Correct answer: B. the whole sequence converges to L — Triangle inequality: |aₙ − L| ≤ |aₙ − aₙₖ| + |aₙₖ − L| < 2ε for large n.

6. For Hₙ = 1 + 1/2 + … + 1/n, which bound holds for every n ≥ 1?

A. H₂ₙ − Hₙ ≥ 1B. H₂ₙ − Hₙ ≥ 1/2C. H₂ₙ − Hₙ ≤ 1/(2n)
Correct answer: B. H₂ₙ − Hₙ ≥ 1/2 — H₂ₙ − Hₙ is a sum of n terms, each at least 1/(2n), so it is at least 1/2 (with equality at n = 1, which rules out ≥ 1).

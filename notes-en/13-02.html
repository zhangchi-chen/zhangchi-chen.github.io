13-02 Uniform convergence: the worst point must also pass

Uniform convergence: the worst point must also pass

1 · Motivation

Uniform convergence, where even the worst point has to pass. Last time, the powers of x sank to zero at every point between zero and one. Fix epsilon at one hundredth, and ask each point how long it must wait. The waits explode as the point creeps toward one. No single waiting time works for the whole interval.

Picture the class group chat the night before a deadline. Pointwise convergence sends each student a private message, with a different time for each. Uniform convergence posts one announcement, with one time for everyone. And the whole class passes only when its weakest score clears the bar. That single worst number is the hero of this episode. What we want is convergence where the whole picture settles at once.

3 · Method

Back to the permanent exhibit, the powers of x below one. Whatever the power, the nose still climbs to one at the right end. So the worst error is exactly one, every single time. The worst error never budges, so this is not uniform. The course text picks a concrete point, creeping toward one as n grows. There the error falls just short of one, and never below one half. So with epsilon set at one half, every moment meets a failing point.

Now shrink the set and stay away from one, stopping at some b. There the worst error is capped by the value at the edge. And that edge value dies out, so on this smaller set it is uniform. The course text sums it up: one sequence, two sets, two answers. Uniformity is a property of the pair, the sequence and the set together.

Now a sneakier sequence, living on the whole positive half line. Freeze any point: the exponential wins, and the values sink to zero. But look at the whole curve: there is a spike. The peak sits closer and closer to zero as n grows. And its height grows without bound. It is like a student who changes seats every single round. Wherever the teacher looks, he has already moved on. The spike breaks out of every band, so this is not uniform.

A shortcut from Theorem thirteen point two: test along points that move. Take the points one over n: the values climb to one, not zero. The course text records both routes, the peak and the moving points.

Series work the same way: a series is uniform when its partial sums are. Our exhibit is the geometric series, whose sum function we already know. After n terms, the leftover piece is the remainder. Pick a point that slides toward one, and the remainder there blows up. So it is not uniform on the open interval; near one, the leftover explodes. Plant one term for later: uniform convergence on closed pieces inside. The next two episodes will put that term to work.

A trap: if every function here is continuous, surely it is uniform? The counterexample: lines that keep getting flatter. At each fixed point the values sink to zero, so the limit is zero. But walk far to the right, and every line climbs forever. Every round has an infinite worst error, so it is never uniform. Yet on a bounded piece, the worst error dies out: uniform there. Uniformity has to be earned; continuity alone never hands it to you.

4 · Outlook

First use: a plotting app must be right to within a pixel, everywhere. That is a promise about the supremum: the worst pixel decides. Second use: the sine routine inside a calculator, a short polynomial. On that whole window, its worst error stays tiny, for every input.

Owed to the next episode: proving uniformity without knowing the limit. Theorem thirteen point one, the Cauchy criterion, is the black box behind it. And owed to episode thirteen four: what uniformity buys us.

Further out, the worst gap between two functions is a genuine distance. Later courses use it to measure entire spaces of functions. Fill in the gaps of such spaces, and integration theory is built anew. So remember: everyone passes only when the worst point passes too.

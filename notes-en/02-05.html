Monotone + Bounded ⇒ Convergent

Why some sequences must arrive — the proof, and where it pays off · Mathematical Analysis 2.5

IAct I · Motivation: the calculator puzzle

Type √2 into a calculator and keep pressing “add 2, take √”: 1.41421, 1.84776, 1.96157, 1.99037, 1.99759, … The digits lock onto 2. But a screenful of digits is evidence, not proof: no finite list of terms can show what happens forever after.

Algebra helps only conditionally: if a limit L exists, then L = √(2 + L), so L = 2. Algebra locates a limit; it cannot certify that one exists. Existence is a separate question — and that is the gap this theorem fills.

IIAct II · What the theorem says

Theorem (monotone convergence). A monotone bounded sequence converges: if (aₙ) is increasing and bounded above, or decreasing and bounded below, then (aₙ) converges.
Monotone — every step goes the same way. Alone it is not enough: aₙ = n climbs forever.
Bounded — a roof exists. Alone it is not enough: (−1)ⁿ stays under its roof but zigzags forever.
Conclusion: arrival. Climbing under a roof, you must arrive — possibly below the roof, at sup aₙ. The theorem certifies existence; it does not name the value.

IIIAct III · Proof and method

Why it is true: the proof

The hinge — the rationals. 1, 1.4, 1.414, 1.4142, … is increasing and bounded above by 2, yet it has no limit among the rationals (the only candidate is √2 ∉ ℚ). Worse, in ℚ its terms have no least upper bound at all: every rational upper bound exceeds √2, and a smaller rational fits in between. The proof needs exactly that object, so it cannot even start in ℚ. In ℝ the supremum principle (proved in episode 1.5) supplies it.

Let (aₙ) be increasing and bounded above, and set s = sup aₙ (it exists by the supremum principle). Claim: aₙ → s.

Take any ε > 0. Since s − ε < s and s is the least upper bound, s − ε is not an upper bound: some term aₘ > s − ε.

Monotonicity lifts every later term: for all n ≥ m, s − ε < aₘ ≤ aₙ ≤ s, that is |aₙ − s| < ε. This is the ε–N definition of episode 2.1 with N = m; as ε was arbitrary, aₙ → s.

Decreasing case, by symmetry: if (aₙ) decreases and is bounded below, (−aₙ) increases and is bounded above, so −aₙ → sup(−aₙ) = −inf aₙ, i.e. aₙ → inf aₙ.

The three-step recipe for aₙ₊₁ = f(aₙ)

  1. Estimate. If a limit L exists, it satisfies L = f(L). This is only a guess.
  2. Prove monotone + bounded, typically by induction. Now the theorem guarantees the limit exists.
  3. Pass to the limit in aₙ₊₁ = f(aₙ) and solve for L.

Worked example: a₁ = √2, aₙ₊₁ = √(2 + aₙ)

① L = √(2 + L) ⇒ L² = 2 + L ⇒ (L − 2)(L + 1) = 0, and L ≥ 0, so the guess is L = 2.

② Bounded: a₁ = √2 < 2; if aₙ < 2 then aₙ₊₁ = √(2 + aₙ) < √4 = 2. Increasing: a₂ = √(2 + √2) > √2 = a₁; since √(2 + x) is increasing, aₙ > aₙ₋₁ gives aₙ₊₁ > aₙ.

③ Let n → ∞: L = √(2 + L), so L = 2 — now earned, not assumed.

The shaded band between aₙ and 2 shrinks at every step.

The circular-logic trap

✗ Circular

Take a₁ = 1, aₙ₊₁ = 2aₙ.

Solve L = 2L ⇒ L = 0.

“So the limit is 0.”

In fact aₙ = 2ⁿ⁻¹ → ∞: there is no limit.

✓ Correct order

① Estimate: solve L = f(L) (a guess)

② Monotone + bounded ⇒ the limit exists

③ Pass to the limit and solve for L

L = f(L) only says where a limit could be, not whether one exists. The estimate is a guide; the theorem is the license.

IVAct IV · Applications and outlook

Application 1 · Compound interest and e

Deposit 1 at 100% interest per year, paid n times a year: you end with (1 + 1/n)ⁿ.

paidn(1 + 1/n)ⁿ
yearly12
half-yearly22.25
quarterly42.4414
monthly122.6130
daily3652.7146
continuously∞e ≈ 2.71828

Binomial picture: (1 + 1/n)ⁿ = Σₖ₌₀ⁿ (1/k!)·(1 − 1/n)(1 − 2/n)⋯(1 − (k−1)/n). Each factor is below 1 and grows with n, and more terms appear as n grows ⇒ increasing. Also (1 + 1/n)ⁿ ≤ Σₖ₌₀ⁿ 1/k! < 1 + 1 + 1/2 + 1/4 + ⋯ = 3 ⇒ bounded above. Monotone + bounded, so the limit exists: e = lim (1 + 1/n)ⁿ ≈ 2.71828.

Base versus exponent. The base 1 + 1/n → 1 while the exponent n → ∞, yet the limit is not 1: the sequence starts at 2 and only climbs, so its limit is at least 2 — it is e.

Application 2 · Fixed-point iteration (a preview of numerical methods)

Computers find √2 by iterating xₙ₊₁ = (xₙ + 2/xₙ)/2, x₁ = 2 — Newton's method for x² − 2 = 0. Iterates: 2, 1.5, 1.41666667, 1.41421569, 1.41421356237 (correct digits 1 → 3 → 6 → 12).

All xₙ > 0; by AM–GM xₙ₊₁ ≥ √(xₙ · 2/xₙ) = √2 — bounded below.

xₙ₊₁ − xₙ = (2 − xₙ²)/(2xₙ) ≤ 0 since xₙ ≥ √2 — decreasing.

So it converges, and L = (L + 2/L)/2 gives L² = 2, L = √2.

aₙ₊₁ = aₙ²: L = L² gives the fixed points 0 and 1. Start inside (0, 1): the sequence decreases to 0 (0.9 → 0.81 → 0.66 → 0.43 → …). Start above 1: it increases without bound (1.1 → 1.21 → 1.46 → 2.14 → …). Same rule, two fates — the starting point decides.

Application 3 · A running sum

A different species of object: fix α > 1 and let Sₙ = 1 + 1/2ᵅ + 1/3ᵅ + ⋯ + 1/nᵅ. It obviously increases; the question is a roof. The trick is self-similarity — split S₂ₙ into even- and odd-indexed terms:

Even part: Σₖ₌₁ⁿ 1/(2k)ᵅ = Sₙ/2ᵅ, a shrunken copy of the whole.

Odd part: 1 + Σₖ₌₁ⁿ⁻¹ 1/(2k+1)ᵅ < 1 + Σₖ₌₁ⁿ⁻¹ 1/(2k)ᵅ ≤ 1 + Sₙ/2ᵅ, since each odd term after the first is smaller than the even term before it.

Add: S₂ₙ < 1 + 2·Sₙ/2ᵅ = 1 + Sₙ/2ᵅ⁻¹. The sums increase, so Sₙ < S₂ₙ < 1 + Sₙ/2ᵅ⁻¹.

Since 1 − 2¹⁻ᵅ > 0: Sₙ < 1/(1 − 2¹⁻ᵅ). Increasing and bounded, so for every α > 1 the sums converge — existence proved wholesale, no closed form needed. (For α = 2 the roof is 2.)

As α → 1, 2¹⁻ᵅ → 1 and the roof collapses; whether the sum converges at α = 1 is settled two episodes ahead, by the Cauchy criterion.

Application 4 · Square-root cascades and continued fractions

√(2 + √(2 + √(2 + ⋯))) only means lim aₙ for the calculator sequence, and the theorem already pinned that limit at 2.

The continued fraction 1 + 1/(1 + 1/(1 + ⋯)) is lim bₙ with b₁ = 1, bₙ₊₁ = 1 + 1/bₙ: 1, 2, 1.5, 1.667, 1.6, 1.625, … — not monotone. But odd terms climb and even terms descend, each bounded in [1, 2], so each half converges; both limits satisfy L = 1 + L/(1 + L), i.e. L² − L − 1 = 0, so both equal the golden ratio φ = (1 + √5)/2 ≈ 1.618.

Outlook

No debts: the theorem is proved here, from the supremum principle.

Next episode: the odd/even split just used on the continued fraction is exactly the idea of subsequences and the Bolzano–Weierstrass theorem.

Self-check

1. In the proof (increasing, s = sup aₙ), why is there a term aₘ > s − ε?

A. s − ε is below the least upper bound, so it is not an upper boundB. Because aₙ → s is already knownC. Because the sequence is bounded below

Answer: A. s is the least upper bound and s − ε < s, so s − ε fails to bound some term; that term is aₘ.

2. Why can the proof not even start in ℚ for 1, 1.4, 1.414, 1.4142, …?

A. In ℚ its terms have no least upper boundB. In ℚ the sequence has no upper bound at allC. Its terms are not rational numbers

Answer: A. 2 is a rational upper bound, but every rational upper bound exceeds √2 and a smaller one fits in between, so there is no least one — and s = sup aₙ is the object the proof needs.

3. What makes (1 + 1/n)ⁿ converge, so that e is well defined?

A. It is increasing (binomial picture) and bounded above by 3B. Its base tends to 1C. It is decreasing and bounded below by 2

Answer: A. Monotone + bounded: each binomial term grows with n and more terms appear, while the sum stays below 1 + 1 + 1/2 + 1/4 + ⋯ = 3.

4. In the recipe for aₙ₊₁ = f(aₙ), when may you trust the root of L = f(L) as the limit?

A. As soon as you solve L = f(L)B. After proving the sequence is monotone and boundedC. After computing the first three terms

Answer: B. Only monotone + bounded guarantees a limit exists; then passing to the limit shows it solves L = f(L).

5. a₁ = 1, aₙ₊₁ = 2aₙ. Solving L = 2L gives L = 0. What is true?

A. aₙ → 0B. aₙ → ∞, so L = 0 is not a limitC. aₙ → 1

Answer: B. aₙ = 2ⁿ⁻¹ → ∞; L = f(L) says nothing about existence, so using it first is circular.

6. For aₙ₊₁ = aₙ² with a₁ = 0.5, the sequence…

A. decreases to 0B. converges to 1C. increases to ∞

Answer: A. Starting inside (0, 1), squaring makes each term smaller, and the decreasing sequence is bounded below by 0, so it tends to 0.

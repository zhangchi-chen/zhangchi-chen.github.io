arcsin · arccos · arctan

Inverse trigonometric functions: arcsin, arccos, arctan

Mathematical Analysis · Episode 01-06 · three siblings, one recipe

1 · Why no global inverse

All three are periodic, so a horizontal line meets each graph infinitely often: sin x = 1/2 has one solution per period. An inverse function must return one answer — the horizontal-line test fails for sin, cos and tan.

2 · The recipe (stated once)

Restrict the function to an agreed interval (principal interval) on which it is one-to-one (monotone) and still covers its whole range. This is a convention: chosen once, used forever.

The inverse returns, for each output value, the unique solution inside that interval:

arcsin : [−1, 1] → [−π/2, π/2], arcsin y = the unique x ∈ [−π/2, π/2] with sin x = y
arccos : [−1, 1] → [0, π], arccos y = the unique x ∈ [0, π] with cos x = y
arctan : ℝ → (−π/2, π/2), arctan y = the unique x ∈ (−π/2, π/2) with tan x = y

Graph: reflect each restricted branch across the line y = x (dotted: the branch, solid: the inverse).

3 · One table, three siblings

functionagreed intervalinverse function : domain → range
tan(−π/2, π/2)arctan : ℝ → (−π/2, π/2)
sin[−π/2, π/2]arcsin : [−1, 1] → [−π/2, π/2]
cos[0, π]arccos : [−1, 1] → [0, π]

The one asymmetry: arctan's interval is open — tan is not defined at ±π/2, so those endpoints are never values of arctan. The other two are closed — sin and cos attain ±1 at the endpoints. Open or closed is decided by the original function, not by taste. Cos gets [0, π] because on [−π/2, π/2] it rises then falls; its monotone branch lives on [0, π].

4 · The easy direction: outer undoes inner

tan(arctan x) = x for every x ∈ ℝ

sin(arcsin x) = x for every x ∈ [−1, 1]

arctan's output sits inside the branch, and tan undoes it. For x ∉ [−1, 1], sin(arcsin x) does not fail to simplify — it does not exist (arcsin stops at ±1): a diagonal segment with a wall at each end.

5 · The dangerous direction: one fold, two waves

Inner first: the inner function forgets which period x lived in; the outer inverse returns the representative of x inside its agreed interval.

arctan(tan x) = x if and only if x ∈ (−π/2, π/2)

Sawtooth: jumps of height π at x = π/2 + kπ (where tan x is undefined).

arcsin(sin x) = x if and only if x ∈ [−π/2, π/2]

Triangular wave: period 2π, corners at x = π/2 + kπ.

6 · The trap and two sanity checks

The trap: writing f⁻¹(f(x)) = x without asking where x lives.

arctan(tan π) = arctan 0 = 0 ≠ π
arcsin(sin 2π/3) = π/3, not 2π/3 (π/3 is the representative of 2π/3 inside [−π/2, π/2])
Reading rule for every composition: ask where the inner output lands relative to the outer function's agreed interval.

7 · Bonus identity

arcsin x + arccos x = π/2 for every x ∈ [−1, 1]

Picture (0 < x < 1): a right triangle with hypotenuse 1 has acute angles θ and π/2 − θ.

Proof in one line: let θ = arcsin x ∈ [−π/2, π/2]. Then cos(π/2 − θ) = sin θ = x and π/2 − θ ∈ [0, π], so arccos x = π/2 − θ.

Recap

Pick the agreed interval, solve there, reflect for the graph, fold for the compositions — and always ask where the input lands.

Self-check

C — sin 2π/3 = √3/2, and the unique x ∈ [−π/2, π/2] with sin x = √3/2 is π/3.

B — cos 7π/6 = −√3/2, and the unique x ∈ [0, π] with cos x = −√3/2 is 5π/6.

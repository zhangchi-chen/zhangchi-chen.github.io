The Squeeze Theorem

Limits of sequences · first-year mathematical analysis

Two neighbors are already certified by the checkers: both converge to A. Trap a third sequence between them and the gate closes from both sides, so the middle one is certified for free.

Theorem. If aₙ ≤ cₙ ≤ bₙ for all sufficiently large n, and aₙ → A, bₙ → A, then cₙ → A.

1 · The direction game of estimates

Squeeze works ✓

1 − 1/n² ≤ cₙ ≤ 1 + 3/n. The upper bound is crude (a constant × 1/n), but both bounds → 1.

Wrong-valued bound ✗

0 ≤ cₙ ≤ 1 + 3/n. True, but the bounds tend to 0 and 1: the gap never closes, nothing is concluded.

Precision may be asymmetric; the limits of the two bounds may not. Always ask: do both bounds reach the same A?

2 · Oscillating factors

cₙ = (−1)ⁿ · nn² + 1. The product rule fails because (−1)ⁿ has no limit. Squeeze the size instead:

|cₙ| = nn² + 1 ≤ 1n ⇒ −1n ≤ cₙ ≤ 1n ⇒ cₙ → 0

The sign flips forever, but the size is squeezed to 0.

3 · Classic 1: a sum of many small terms

xₙ = Σᵢ₌₁ⁿ 1/√(n²+i). Each term → 0, but there are n of them, so limits cannot be added term by term. Every term lies between the shortest and the tallest bar:

n = 12 terms, vertical axis zoomed: tallest 1/√(n²+1), shortest 1/√(n²+n).

n√(n²+n) ≤ xₙ ≤ n√(n²+1) , both → 1 ⇒ xₙ → 1

4 · Classic 2: the floor function

[x] = greatest integer ≤ x. From nα − 1 < [nα] ≤ nα, divide by n:

α = √2: the jumps of the floor never matter.

α − 1n ≤ [nα]n ≤ α + 1n ⇒ [nα]n → α

5 · Division of labor

Arithmetic rules sufficeSqueeze Theorem required
  • every piece has a limit, e.g. 2n+1n+3 → 2
  • denominator limit ≠ 0
  • oscillating factor: (−1)ⁿuₙ, sin n / n
  • sum of n terms: Σᵢ₌₁ⁿ 1/√(n²+i)
  • no usable limit rule, but two-sided bounds: [nα]/n

Arithmetic first; squeeze when arithmetic stalls.

Self-test

1. Bounds 0 ≤ cₙ ≤ 1 + 3/n are true. What do they prove about cₙ?

A. cₙ → 1B. Nothing about the limitC. cₙ → 0
B — The bounds tend to 0 and 1, different numbers, so the squeeze concludes nothing.

2. Is the upper bound 1 + 3/n good enough next to 1 − 1/n² ≤ cₙ?

A. Yes: both bounds tend to 1B. No: it is much cruder than the lower boundC. Only if we replace 3/n by 3/n²
A — Bounds may differ in precision; only their limits must agree.

3. Why can't the product rule give (−1)ⁿ · n/(n²+1) → 0?

A. n/(n²+1) has no limitB. The product is unboundedC. (−1)ⁿ has no limit
C — The product rule needs both factors to converge; (−1)ⁿ oscillates, so we squeeze |cₙ| ≤ 1/n instead.

4. Which bounds squeeze xₙ = Σᵢ₌₁ⁿ 1/√(n²+i)?

A. n/√(n²+n) and n/√(n²+1)B. 1/√(n²+n) and 1/√(n²+1)C. 0 and 1
A — Replace all n terms by the smallest, then by the largest; both bounds tend to 1.

5. Which inequality drives [nα]/n → α?

A. [nα] ≥ nαB. nα − 1 < [nα] ≤ nαC. [nα] ≤ nα − 1
B — Dividing nα − 1 < [nα] ≤ nα by n gives bounds that both tend to α.

6. Which limit really needs the Squeeze Theorem?

A. (2n+1)/(n+3)B. (n+1)/nC. sin n / n
C — sin n has no limit, so arithmetic stalls; |sin n / n| ≤ 1/n squeezes it to 0.

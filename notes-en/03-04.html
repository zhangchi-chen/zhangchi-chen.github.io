The Heine Principle

Episode 03-04 · Sequences as witnesses for function limits

The statement

Heine principle (sequential criterion for limits)
limx→x₀ f(x) = A
⟺  if and only if
for EVERY sequence {xn} in the domain of f with
xn ∈ D(f),   xn ≠ x₀,   xn → x₀,
one has  f(xn) → A

1 · The picture: sequences are probes

A function limit is the common endpoint of all approach paths to x₀.

A sequence x₁, x₂, x₃, … is a discrete probe sent along one path: it samples the approach at those instants.

The principle: every probe, without exception, must report the same destination A.

2 · One bad witness convicts

To refute limx→x₀ f(x) = A (or any limit at all), exhibit one sequence xn → x₀, xn ≠ x₀, with f(xn) divergent, or two such sequences whose values have different limits.

Exhibit A: f(x) = sin(1/x) at 0

Witness 1 · peak hunter
xn = 1/(2nπ + π/2)
sin(1/xn) = 1 → 1
≠
Witness 2 · zero hunter
xn = 1/(2nπ)
sin(1/xn) = 0 → 0
Verdict: limx→0 sin(1/x) does not exist.

Exhibit B: the Dirichlet function

D(x) = 1 if x ∈ ℚ,   D(x) = 0 if x ∉ ℚ

Rational probe
xn ∈ ℚ:  D(xn) = 1 → 1
≠
Irrational probe
xn ∉ ℚ:  D(xn) = 0 → 0
Verdict: D has no limit at any point x₀ (rationals and irrationals are dense near every point).

3 · Why “EVERY” cannot be dropped

Questioning only irrational sequences, the Dirichlet function passes: thousands of witnesses all report 0, yet the limit does not exist.

Checking finitely many sequences, or all the “natural” ones, proves nothing. The quantifier does the work, not the effort.

To prove a limit

∀ sequences must report A

To refute it

∃ one bad witness

4 · Dimension-reduction toolbox

Function questions become sequence questions.

  • Divergence. Build one bad sequence (or two that disagree), as for sin(1/x) and D(x).
  • Blow-up. ex → +∞ as x → +∞: the probe xn = n gives en → +∞, which already rules out every finite limit. The full claim needs every probe: since ex is increasing, xn → +∞ eventually gives xn > ln M, so exn > M.
  • Contradiction skeleton. Assume f(x) ↛ A: some ε₀ > 0 fails for every δ. With δ = 1/n pick xn, 0 < |xn − x₀| < 1/n, |f(xn) − A| ≥ ε₀. This sequence witnesses the failure; sequence facts finish the job.

5 · The ladder of discretization

Probes on their second tour of duty: subsequences probed sequence limits; now sequences probe function limits.  sequence ← subsequence;  function ← sequence.

Self-check

1. To show limx→0 sin(1/x) does not exist, which pair of probes works?
  1. Axn = 1/(2nπ + π/2) and xn = 1/(2nπ)
  2. Bxn = 1/n and xn = 2/n
  3. Cxn = 1/(2nπ) and xn = 1/(4nπ)
Correct: A. The first gives sin(1/xn) = 1 → 1, the second gives 0 → 0: two reports disagree, so no limit.
2. For the Dirichlet function at any x₀, which witnesses convict the limit claim?
  1. ATwo irrational sequences approaching x₀
  2. BA rational sequence and an irrational sequence approaching x₀
  3. CThe constant sequence xn = x₀
Correct: B. Rational probes report 1 and irrational probes report 0; the constant sequence is not allowed since xn ≠ x₀ is required.
3. f(x) = 1 for x > 0 and f(x) = −1 for x < 0. Which single witness pair shows there is no limit at 0?
  1. Axn = 1/n and xn = 1/n²
  2. Bxn = −1/n and xn = −1/n²
  3. Cxn = 1/n and xn = −1/n
Correct: C. From the right the values report 1, from the left they report −1; different limits mean no limit.
4. You checked one sequence xn → x₀ and found f(xn) → A. What can you conclude?
  1. Alimx→x₀ f(x) = A
  2. BNothing yet about the limit equalling A: another sequence may disagree
  3. CThe limit exists but may differ from A
Correct: B. Proving a limit needs EVERY sequence; the Dirichlet function passes all irrational probes yet has no limit.
5. Why does the probe xn = n with en → +∞ help with limx→+∞ ex?
  1. AIt rules out every finite limit; the full claim needs all probes (monotonicity supplies them)
  2. BIt proves the full claim by itself
  3. CIt shows the limit is 0
Correct: A. One unbounded report kills every finite candidate, but confirming +∞ still requires every sequence tending to +∞.

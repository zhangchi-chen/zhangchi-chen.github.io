Stolz–Cesàro Theorem

A tool for limits of averages: the ratio of increments decides the ratio of totals.

Act 1The question

A thermometer logs one reading a minute; its screen shows the running average. The first reading was a glitch (80°); afterwards the readings settle toward 20°. Does the average settle at 20° too, or does the glitch haunt the screen forever?

With Sn = a1 + … + an and an → a, we want lim Snn.

lim Snn ≟ lim Snlim n = +∞+∞  ✗

The quotient rule needs finite limits (and lim bn ≠ 0); here Sn → +∞ and n → +∞: on ∞/∞ it says nothing.

By hand: Snn = a1 + … + amn + am+1 + … + ann, then two ε-estimates. It works, but must be re-invented for every new average.

Sn+1 − Sn(n + 1) − n = an+1 → 20   ⟹ ?   Snn → 20

The insight: each minute the total grows by Sn+1 − Sn = an+1 and the count by 1, so the ratio of increments is the new reading itself, which tends to 20. Can the increments decide the limit of the totals?

Act 2What the theorem says

1. Differences replace values

Join the points (bn, an). The slope from the origin is the ratio of totals anbn; the slope of the newest segment is the ratio of increments ΔanΔbn, where Δan = an+1 − an.

Sequences (discrete)Functions (continuous)
Δan⟷f′(x)increment ↔ derivative
Σk≤n Δak⟷∫ f′sum ↔ integral
anbn⟷f(x)g(x)ratio of totals ↔ ratio of functions
ΔanΔbn⟷f′(x)g′(x)ratio of increments ↔ ratio of derivatives
L'Hôpitallim f′(x)g′(x) = L ⟹ lim f(x)g(x) = L
Stolz–Cesàrolim ΔanΔbn = L ⟹ lim anbn = L

2. The denominator marches strictly to +∞

Strictly increasing means every Δbn = bn+1 − bn > 0: each step opens a new window; bn → +∞ means the windows never stop opening.

With bn = 2 − 1/n, an = 3 − 1/n: every increment ratio equals 1, yet anbn → 3/2. The denominator is bounded, so the windows stop opening and the head is never washed out.

Checklist — run it first (marks: the example above)

  • 1. Is {bn} strictly increasing? ✓
  • 2. Does bn → +∞? ✗
  • 3. Does the increment ratio have a limit? ✓

3. Two types, one conclusion

∗/∞ type (often written ∞/∞)

{bn} strictly increasing, bn → +∞

If limn→∞ an+1 − anbn+1 − bn = L (finite, or ±∞), then limn→∞ anbn = L.

The star: an may do anything; only the denominator is checked. Use it for growing totals: sums, averages, powers.

0/0 type

an → 0, bn → 0, {bn} strictly decreasing (from some index, bn > 0)

If limn→∞ an+1 − anbn+1 − bn = L, then limn→∞ anbn = L.

Use it when both sequences shrink to 0, e.g. tails of a convergent series.

Act 3Proof: clamping with upper and lower limits

Fix ε > 0 and pick m so that every increment ratio beyond m lies in (L − ε, L + ε). The red head is the founding stock am, bm; every tail vote is priced inside the gold band.

Telescopean = am + Σk=mn−1 Δak,   bn = bm + Σk=mn−1 Δbk
Squeeze each tail term(L − ε) Δbk < Δak < (L + ε) Δbk,   k ≥ m
Divide by bnam + (L − ε)(bn − bm)bn ≤ anbn ≤ am + (L + ε)(bn − bm)bn

Let n → ∞: the head is divided by bn → +∞ and vanishes; both bounds tend to L ± ε.

upper limitlimsup anbn ≤ L + ε    lower limitliminf anbn ≥ L − ε
ε is arbitrary, so the limit exists and equals L. The tail outvotes the head.

Act 4Payoffs and outlook

Payoff 1 — Cesàro means, in one line

If an → a, take Sn = a1 + … + an, bn = n (strictly increasing, → +∞). Then

limn→∞ a1 + … + ann = limn→∞ Sn+1 − Sn(n + 1) − n = limn→∞ an+1 = a

Back to the thermometer: the screen settles at 20°; the glitch's extra share is only 60/n. The tail outvotes the head.

Payoff 2 — callback: polynomial vs exponential

limn→∞ nkaⁿ = 0   (a > 1)

Comparison route (earlier episode)

Write a = 1 + h, h > 0; for n ≥ k + 1, aⁿ ≥ C(n, k+1) hk+1, so

0 ≤ nkaⁿ ≤ (k+1)! nkn(n−1)⋯(n−k) hk+1

degree k over degree k + 1 → 0, then squeeze.

Stolz route

bn = aⁿ is strictly increasing to +∞, and

Δ(nk)Δ(aⁿ) = (n+1)k − nk(a − 1)aⁿ

(n+1)k − nk has degree k − 1: each Δ drops the degree by one, like differentiating. Induct down to 1/aⁿ → 0.

Payoff 3 — a staircase

The increments are n + 1 and 2n + 1, and n² is strictly increasing to +∞: the staircase fills half the square.

n + 12n + 1 → 12   ⟹   1 + 2 + … + nn² → 12

Outlook — a one-way street

✓ Legal use✗ Violation
Direction✓ ΔanΔbn → L ⟹ anbn → L✗ an = (−1)n, bn = n: anbn → 0, but ΔanΔbn = 2(−1)n+1 oscillates
∗/∞ type✓ {bn} strictly increasing, bn → +∞✗ bn = 2 − 1/n bounded: increment ratio 1, but anbn → 3/2
0/0 type✓ an → 0, bn → 0, {bn} strictly decreasing✗ an = 1 + 1/n ↛ 0, bn = 1/n: increment ratio 1, but anbn = n + 1 → +∞

Outlook — summability methods

The series 1 − 1 + 1 − 1 + … has partial sums Sn = 1, 0, 1, 0, …; their average tends to 1/2, so it is Cesàro summable to 1/2. Stolz guarantees consistency: if Sn → S then S1 + … + Snn → S.

Outlook — the smooth twin: L'Hôpital

For continuous f with f(x) → L:

limx→+∞ ∫0x f(t) dtx = limx→+∞ f(x)1 = L

Σ ↔ ∫, Δ ↔ d/dx: the same idea in the smooth world.

?Self-check

Pick an answer, then reveal.

1. In the dictionary, the increment Δan = an+1 − an plays the role of …
Answer: B. A single step is the discrete derivative; summing steps is the discrete integral.
2. For bn = 2 − 1/n, an = 3 − 1/n, which checklist item fails?
Answer: B. bn increases but stays below 2, so the head is never washed out and anbn → 3/2, not 1.
3. In the proof, why does the founding stock aₘ, bₘ stop mattering?
Answer: A. The head enters as (am − (L ± ε)bm)/bn, which tends to 0 because bn → +∞.
4. What does the clamping step give directly, for each fixed ε?
Answer: B. Upper and lower limits are trapped within ε of L; since ε is arbitrary they coincide at L.
5. What is lim (1 + 2 + … + n)/n²?
Answer: B. The increments are n + 1 and 2n + 1, whose ratio tends to 1/2, and n² is strictly increasing to +∞.
6. an = (−1)n, bn = n shows that …
Answer: A. anbn → 0, yet the increment ratio 2(−1)n+1 has no limit: the theorem runs one way only.

Stolz–Cesàro Theorem

The discrete twin of L'Hôpital's rule: the ratio of increments decides the ratio of totals.

1The dictionary

Join the points (bn, an). The slope from the origin is the ratio of totals anbn; the slope of the newest segment is the ratio of increments ΔanΔbn, where Δan = an+1 − an.

Sequences (discrete)Functions (continuous)
Δan⟷f′(x)increment ↔ derivative
Σk≤n Δak⟷∫ f′sum ↔ integral
anbn⟷f(x)g(x)ratio of totals ↔ ratio of functions
ΔanΔbn⟷f′(x)g′(x)ratio of increments ↔ ratio of derivatives
L'Hôpitallim f′(x)g′(x) = L ⟹ lim f(x)g(x) = L
Stolz–Cesàrolim ΔanΔbn = L ⟹ lim anbn = L

2The statement

∞/∞ type

{bn} strictly increasing, bn → +∞

If limn→∞ an+1 − anbn+1 − bn = L (finite, or ±∞), then limn→∞ anbn = L.

0/0 type

an → 0, bn → 0, {bn} strictly decreasing (from some index, bn > 0)

If limn→∞ an+1 − anbn+1 − bn = L, then limn→∞ anbn = L.

3The conditions are load-bearing

With bn = 2 − 1/n, an = 3 − 1/n: every increment ratio equals 1, yet anbn → 3/2. The denominator is bounded, so the windows stop opening and the head is never washed out.

Checklist — run it first (marks: the example above)

  • 1. Is {bn} strictly increasing? ✓
  • 2. Does bn → +∞? ✗
  • 3. Does the increment ratio have a limit? ✓

4Proof skeleton: clamping

Fix ε > 0 and pick m so that every increment ratio beyond m lies in (L − ε, L + ε). The red head is the founding stock am, bm; every tail vote is priced inside the gold band.

Telescopean = am + Σk=mn−1 Δak,   bn = bm + Σk=mn−1 Δbk
Squeeze each tail term(L − ε) Δbk < Δak < (L + ε) Δbk,   k ≥ m
Divide by bnam + (L − ε)(bn − bm)bn ≤ anbn ≤ am + (L + ε)(bn − bm)bn

Let n → ∞: the head is divided by bn → +∞ and vanishes; both bounds tend to L ± ε.

upper limitlimsup anbn ≤ L + ε    lower limitliminf anbn ≥ L − ε
ε is arbitrary, so the limit exists and equals L. The tail outvotes the head.

5Worked examples

(i) Cesàro means

If an → a, take An = a1 + … + an, bn = n (strictly increasing, → +∞). Then

An+1 − Anbn+1 − bn = an+11 → a
⟹ a1 + … + ann → a

(ii) A sum over a square

Numerator grows by n + 1, denominator n² grows by 2n + 1 (strictly increasing, → +∞). Then

n + 12n + 1 → 12
⟹ 1 + 2 + … + nn² → 12

?Self-check

Pick an answer, then reveal.

1. In the dictionary, the increment Δan = an+1 − an plays the role of …
Answer: B. A single step is the discrete derivative; summing steps is the discrete integral.
2. For bn = 2 − 1/n, an = 3 − 1/n, which checklist item fails?
Answer: B. bn increases but stays below 2, so the head is never washed out and anbn → 3/2, not 1.
3. In the proof, why does the founding stock aₘ, bₘ stop mattering?
Answer: A. The head enters as (am − (L ± ε)bm)/bn, which tends to 0 because bn → +∞.
4. What does the clamping step give directly, for each fixed ε?
Answer: B. Upper and lower limits are trapped within ε of L; since ε is arbitrary they coincide at L.
5. What is lim (1 + 2 + … + n)/n²?
Answer: B. The increments are n + 1 and 2n + 1, whose ratio tends to 1/2, and n² is strictly increasing to +∞.
6. an = (−1)n, bn = n shows that …
Answer: A. anbn → 0, yet the increment ratio 2(−1)n+1 has no limit: the theorem runs one way only.

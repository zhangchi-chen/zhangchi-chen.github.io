Episode 3.1 · Mathematical analysis

The limit of a function: the ε–δ definition

Same inspector, new post: why the neighborhood of x₀ is punctured.

1The inspector changes posts

A sequence marches on integer steps, so “approaching” meant n > N. A function lives on a continuum: x can creep toward any point x₀ from either side. The inspector moves from “beyond N” to “near x₀”.

2The translation table

for every ε > 0for every ε > 0

n > N (a tail)0 < |x − x₀| < δ (a punctured neighborhood)

The picture upgrades from a horizontal ε-band around A to a window: x₀ ± δ wide, A ± ε tall. Near x₀, the graph must stay inside.

Definition. limx→x₀ f(x) = A means: for every ε > 0 there exists δ > 0 such that 0 < |x − x₀| < δ implies |f(x) − A| < ε.

3Why punctured?

A limit describes the approach, never the arrival. The point itself may be a hole (sin x / x at 0), may carry a value different from A, or may lie outside the domain.

Remark. The value f(x₀) — defined or not — plays no role in the definition.

Two consequences

  1. f may be undefined at x₀ and still have a limit there.
  2. Changing f at x₀ alone never changes the limit.

Why did ε–N never need such a clause? Because ∞ is not an index: no term ever sits at the destination, so a tail is punctured for free. Here x can land exactly on x₀, so the exclusion must be written by hand — that is the job of 0 <.

4δ is a choice, not a function

If some δ works for a given ε, every smaller δ works too: a narrower window only lets in fewer points. So δ need not be optimal. It depends on ε — and, silently, on the point x₀.

5Model verification

Claim: limx→1 (2x + 1) = 3.

Scratch: |(2x + 1) − 3| = 2|x − 1|, and 2|x − 1| < ε ⟺ |x − 1| < ε/2. Try δ = ε/2.

Verification. Let ε > 0 be given, and choose δ = ε/2 > 0. Then for every x with 0 < |x − 1| < δ we have |(2x + 1) − 3| = 2|x − 1| < 2δ = ε, so limx→1 (2x + 1) = 3. ∎

0 < |x − 1| < δ  ⟹  |(2x + 1) − 3| = 2|x − 1| < ε

6Recap

  • Same inspector, new post: ε sets the tolerance around A, δ marks the neighborhood of x₀.
  • The door — the point x₀ itself — stays shut.
  • The neighborhood speaks; the point stays silent.

?Self-check

1. In the ε–δ definition of lim(x→x₀) f(x) = A, what role does the value f(x₀) play?
  1. A. It must equal A.
  2. B. It must at least be defined.
  3. C. None at all.
Answer: C. The condition 0 < |x − x₀| < δ excludes x = x₀, so f(x₀) is never checked.
2. Why did the ε–N definition never need a “0 <” clause?
  1. A. Because sequences are always monotone.
  2. B. Because ∞ is not an index, so no term ever sits at the destination.
  3. C. Because N is an integer.
Answer: B. A tail n > N never contains “n = ∞”, so it is punctured for free; x, by contrast, can equal x₀.
3. Suppose lim(x→2) f(x) = 5 and we change only the value f(2) from 5 to 9. The limit…
  1. A. becomes 9.
  2. B. stays 5.
  3. C. no longer exists.
Answer: B. Changing f at x₀ alone never changes the limit: the punctured neighborhood never looks at x₀.
4. Which line of the ε–δ definition is the counterpart of “n > N”?
  1. A. for every ε > 0
  2. B. 0 < |x − x₀| < δ
  3. C. |f(x) − A| < ε
Answer: B. Both describe where the inspector checks: a tail for sequences, a punctured neighborhood for functions.
5. For lim(x→1) (2x + 1) = 3 and ε = 0.1, which δ is guaranteed to work?
  1. A. δ = 0.05
  2. B. δ = 0.1
  3. C. δ = 0.2
Answer: A. We need 2|x − 1| < 0.1, i.e. |x − 1| < 0.05; δ = ε/2 = 0.05 works (and so does any smaller δ), while δ = 0.1 fails, e.g. at x = 1.08.
6. If δ = 0.3 works for a given ε, then δ = 0.1…
  1. A. also works.
  2. B. may fail.
  3. C. works only if 0.3 was the largest possible δ.
Answer: A. A narrower window only admits fewer points, all of which already satisfied |f(x) − A| < ε.

04-08-composition-bugs · Composition: one bad point, two patches

Motivation

  1. Today's question: when can a limit pass through g(f(x))?
  2. One bad point of the outer function can spread into many bad x's.
  3. A homework limit: this expression as x → 0.
  4. Set u = x sin(1/x).
  5. Then the expression is just sin u / u.
  6. Since sin u / u → 1 as u → 0, the answer is 1?
  7. Lin's phone app says 1.
  8. Zhou's phone, on the newer version, refuses: undefined arbitrarily close to 0.
  9. Same app, two versions, two answers. Which one has the bug?
  10. Here is the graph of u = x sin(1/x) near 0.
  11. Since |u| ≤ |x|, the graph is squeezed to 0.
  12. But u is exactly 0 at every x = 1/(nπ).
  13. These zeros pile up at 0: every interval around 0 holds infinitely many.
  14. At each of them, sin u / u becomes 0/0: undefined.
  15. One bad point of sin u / u became a whole patch of bad x's.
  16. Think of a call chain: x goes into f, then into g.
  17. g crashes on exactly one input: u = 0.
  18. And f keeps sending exactly that input, again and again.
  19. Lin's version quietly patched g: it sets g(0) = 1.
  20. A limit at 0 needs values at every point near 0, except 0 itself.
  21. Here that fails, so strictly the limit is not even defined.
  22. Not both right: Lin computed the patched function.
  23. The smallest version: inner function f(x) ≡ 0, a constant.
  24. Outer function: g(u) = 1 whenever u ≠ 0.
  25. But at the single point 0, g(0) = 2.
  26. f → 0 and g(u) → 1 as u → 0, so substituting predicts 1.
  27. But g(f(x)) = g(0) = 2 for every x: the limit is 2.
  28. Moral: when the inner function keeps landing on u₀,
  29. the composite sees g's value at u₀, not its limit.

What the statement says

  1. The textbook offers two patches for this bug.
  2. Patch A is Theorem 3.8, on composite limits.
  3. Its first two clauses: f tends to u₀, and g tends to A.
  4. The limit of g looks only near u₀, never at u₀ itself.
  5. A hollow (punctured) neighbourhood: an interval around x₀, with x₀ removed.
  6. Third clause: on some hollow neighbourhood of x₀, f(x) ≠ u₀.
  7. That is Patch A, block the input: f never sends u₀ there.
  8. Conclusion: lim g(f(x)) = A; g(u₀) plays no role, may not even exist.
  9. Patch B starts from Theorem 4.5: continuity survives composition.
  10. Here the limit walks straight inside g.
  11. The note after §4.2 Example 1 stretches this further.
  12. The inner function only needs a limit a at x₀.
  13. f(x₀) may differ from a, or not exist: a removable discontinuity.
  14. What matters is the outer g: continuous at u = a.
  15. Then lim g(f(x)) = g(lim f(x)) = g(a).
  16. Patch B makes g robust: f may hit a as often as it likes.
  17. Safety table. Rows: does the inner avoid u₀? That is Patch A.
  18. Columns: is the outer continuous at u₀? That is Patch B.
  19. Both patches: safe, and the answer is A = g(u₀).
  20. Patch A alone: safe, the answer is A, the limit of g.
  21. Patch B alone: safe, the answer is g(u₀).
  22. Neither patch: the bug cell, where substitution breaks.
  23. Three safe cells out of four: either patch alone is enough.
  24. Both bugs from the start live in the fourth cell.

Method / proof core

  1. Patch A's proof is left as Exercise 3.2 No. 10; here is its skeleton.
  2. Start with any ε > 0 for the output.
  3. Link 1, from lim g: 0 < |u − u₀| < δ₁ gives |g(u) − A| < ε.
  4. Link 2, from lim f: some δ₂ ≤ δ forces |f(x) − u₀| < δ₁.
  5. But link 1 needs 0 < |f(x) − u₀|, that is, f(x) ≠ u₀.
  6. Link 3, the third hypothesis, supplies exactly f(x) ≠ u₀.
  7. Chain closed: 0 < |x − x₀| < δ₂ gives |g(f(x)) − A| < ε.
  8. Without link 3, f ≡ 0 slips through the gap and breaks the chain.
  9. Only A: take the inner f(x) = x near 0.
  10. Outer: the same jumpy g, with g(0) = 2.
  11. f avoids 0 off x = 0, so A holds; g jumps, so B fails.
  12. The composite is 1 off 0: limit 1, the limit of g, not g(0).
  13. Only B: the inner is our friend x sin(1/x),
  14. outer g(u) = u², continuous: A fails, B holds.
  15. The composite x² sin²(1/x) ≤ x², so it tends to 0 = g(0).
  16. Neither: keep the inner x sin(1/x),
  17. and take g(u) = 1 for u ≠ 0, but g(0) = 0.
  18. g has limit 1 at 0, so 0 is a removable bad point.
  19. The composite is 0 at every x = 1/(nπ), and 1 everywhere else.
  20. Two sequences tending to 0 give values 0 and 1: no limit.
  21. So A and B are independent: neither implies the other.
  22. How do you detect an inner function that keeps hitting u₀?
  23. Recycle the sequence tool of episode 03-04 as a bug detector.
  24. Hunt a sequence xₙ → x₀, xₙ ≠ x₀, with f(xₙ) = u₀.
  25. Here xₙ = 1/(nπ) → 0, and f(xₙ) = sin(nπ)/(nπ) = 0.
  26. One such sequence kills Patch A; only Patch B can save you.
  27. If no such sequence exists, Patch A holds.
  28. Before any substitution in a limit, ask two questions out loud.
  29. One: can the inner function keep attaining its limit value?
  30. Two: is the outer function continuous at that value?
  31. On the opening example, question one gets a yes.
  32. Question two: sin u / u is undefined at 0. Bug cell.
  33. Patch it with g(0) = 1, as Lin's phone did: B holds, limit 1.
  34. Second test: √(2 − sin x / x) as x → 0.
  35. Inner 2 − sin x / x → 1; outer √ is continuous at 1.
  36. Patch B applies, so the limit is √1 = 1.

Applications and outlook

  1. Use one: ln(1 + x)/x as x → 0.
  2. Rewrite it as ln of (1 + x) to the power 1/x.
  3. Inner → e, undefined at 0; ln is continuous at e: Patch B, limit 1.
  4. Use two: (eˣ − 1)/x as x → 0.
  5. Substitute u = eˣ − 1, so x = ln(1 + u).
  6. The fraction becomes u / ln(1 + u), whose limit at 0 is 1.
  7. Here g is undefined at 0, but eˣ − 1 ≠ 0 for x ≠ 0: Patch A.
  8. A preview we owe to episode 09-02: the same question for integrability.
  9. There, inner integrable plus outer continuous makes g(f(x)) integrable.
  10. Its proof runs on uniform continuity, from episode 04-05.
  11. On a closed interval, Cantor's theorem guarantees it, as episode 04-06 showed.
  12. Outer: that same g; inner: Riemann's function R. Both are integrable.
  13. On (0, 1), R is positive at rationals and 0 at irrationals.
  14. So g(R(x)) is 1 at every rational and 0 at every irrational.
  15. Dirichlet's function is not integrable: the bad point spread everywhere.
  16. Slogan: outer continuity is the universal patch.
  17. Programmers know this anatomy as a call-chain bug.
  18. One level up the stack, a caller passes exactly the input that crashes yours.
  19. Patch A, a local fix: never pass the bad input.
  20. Patch B, a robust wrapper: make the callee tolerate it.
  21. Same two strategies, in limits and in code.
